# 题目

给你八副已经装好的鲁班锁。请根据零件的精确结构和初始位置，将每副锁完整拆成独立零件，并尽量减少移动步数。

这些锁按难度从易到难编号，分为三个档次：简单档 2 题，中档 4 题，困难档 2 题。拆解路线要靠自己推理找出：观察给定结构，推演零件的移动与相互阻挡，写出拆解路线。可以用题目提供的路线检查器检查自己写出的路线是否合法，用位置记账工具记录零件位置（见第三节）；除此之外，不得编写或运行程序来搜索路线、模拟移动、计算碰撞或自动更新状态，也不得使用任何求解器。可以写文字笔记、手工列举分支和记录坐标。

最终评判路线能否完整拆开，以及用了多少步。不要求制作网页、动画或求解程序。

## 一、题目数据

| 档次 | 题号 | 零件数 | 分值 |
|---|---|---:|---:|
| 简单档 | 01、02 | 4、4 | 共 16 分，每题 8 分 |
| 中档 | 03、04、05、06 | 4、3、6、4 | 共 48 分，每题 12 分 |
| 困难档 | 07、08 | 5、4 | 共 36 分，每题 18 分 |

每题提供两种结构资料：

- [第01题](鲁班锁拆解/01.md)、[第02题](鲁班锁拆解/02.md)、[第03题](鲁班锁拆解/03.md)、[第04题](鲁班锁拆解/04.md)、[第05题](鲁班锁拆解/05.md)、[第06题](鲁班锁拆解/06.md)、[第07题](鲁班锁拆解/07.md)、[第08题](鲁班锁拆解/08.md)：初始装配和各零件的精确分层图。
- `鲁班锁拆解/01.json` 至 `鲁班锁拆解/08.json`：与分层图相同的精确体素数据。每个零件有固定编号、局部坐标 `voxels` 和初始位置 `position`。

分层图的每个字符代表一个单位格，字母表示对应零件，`.` 表示空位；单件分层图用 `#` 表示实心格。每行沿 x 正方向读取，行号沿 y 正方向递增，层号沿 z 正方向递增。

一个体素 `[x,y,z]` 表示单位立方体 `[x,x+1]×[y,y+1]×[z,z+1]`。将局部坐标加上该零件的 `position`，就是它在装配初态中的位置。坐标均为整数，所有零件的初始朝向已经体现在体素数据中。零件之间允许表面接触，内部不能重叠。

框架也属于零件，需要与其余零件完全分开；同形零件仍按各自编号区分。文件中的单位不影响解题规则。

## 二、怎样移动和拆开

零件始终保持初始朝向，只能沿 x、y、z 三个轴平移，不能旋转、变形或穿过其他零件。

每一步可以选择当前组件中的一个零件，也可以选择若干零件，让它们沿同一轴、同一方向一起移动整数距离。这些零件在该步中保持相对位置，不要求彼此接触。不能选择当前组件的全部零件来整体搬动。

检查的是移动经过的整个区间，不能跳过中间的碰撞位置。

如果一组零件能够沿某个轴向一直移到无限远，途中始终不会与其余零件相撞，就可以将两组分离。这一步用 `out` 表示。分离后，两组分别作为独立组件继续拆解，互不干涉；它们可以移到不同工作台上操作，搬运工作台上的组件不计步。仅仅移出画面或拉开一点距离，不算完成分离。

一组分成两组后，分别拆开这两组，直到每组只剩一个零件，才算完整解答。可以分离多个零件组成的子组件，不必每次都只取出一个零件。

同一组零件沿同一轴、同一方向连续移动，计一步，距离长短不另计。把一段直线移动分成多个指令不会增加步数；接着沿同方向移出到无限远，也合并计一步。换组、换轴或反向，开始下一步。两个已经分开的组件分别计步。

## 三、提交答案

在开始作答时所在的工作目录下，自行创建 `答案/` 文件夹，并按题号提交 `答案/第01题.json` 至 `答案/第08题.json`。答案文件使用 UTF-8 编码的 JSON。某题没有解出，可以不创建对应文件，不影响其他题。

每份答案包含题号 `puzzle` 和拆解树 `plan`。`puzzle` 使用与题号一致的两位数字字符串，即 `"01"` 至 `"08"`。一个非单件组件的拆解计划包含：

- `moves`：本组件分离前的移动，最后一个指令必须是 `out`。
- `removed`：`out` 选中的那组零件接下来的拆解计划。
- `remaining`：其余零件接下来的拆解计划。

分支只有一个零件时写 `null`。下面只是格式示例，不是八题中任何一题的答案：

```json
{
  "puzzle": "示例",
  "plan": {
    "moves": [
      {"pieces": ["A", "B"], "delta": [0, 2, 0]},
      {"pieces": ["A", "B"], "out": [1, 0, 0]}
    ],
    "removed": {
      "moves": [
        {"pieces": ["A"], "out": [0, 0, -1]}
      ],
      "removed": null,
      "remaining": null
    },
    "remaining": null
  }
}
```

这里先让 A、B 一起沿 y 正向移动 2 个单位，再沿 x 正向移出；随后将 A 从 B 中沿 z 负向取出。示例假定原来只有 A、B、C 三个零件，因此根节点的 `remaining` 是单件 C，写 `null`。

`delta` 恰有一个非零整数分量。`out` 恰有一个非零分量，且只能为 `1` 或 `-1`。每条指令的 `pieces` 都列出本次一起移动的零件编号。

提交结束后，由出题端使用原始结构自动验证完整路线并计步。

`鲁班锁拆解/工具/` 里有两个工具，作答时可以随时运行：

- 路线检查器：`python 鲁班锁拆解/工具/check.py 答案/第01题.json`。检查答案里写出的整条拆解路线是否合法、是否完整拆开，出错时指出在哪一步碰撞或没拆完；合法时按第二节的规则给出总步数和每次分离用的步数。路线写到一半也可以运行，用来核对已经推演出的步骤。它只检查你写出的路线，不会替你找路线；不要用脚本批量调用它来试探移动。
- 位置记账工具：`python 鲁班锁拆解/工具/positions.py 01 记录.json`。`记录.json` 是移动指令数组，格式同 `moves`；工具把指令逐条累加，输出各零件当前的 `position`，加 `--piece A` 另列出零件 A 当前占据的单位格，一次只能查一个零件。它不检查碰撞。

## 四、评价

总分 100 分。题号按难度从易到难排列，分为三档：简单档 01、02 共 16 分，每题 8 分；中档 03—06 共 48 分，每题 12 分；困难档 07、08 共 36 分，每题 18 分。

每题先检查整条路线是否合法、是否把全部零件完整拆开，完整合法的路线再比较总步数：步数越少，得分越高。路线不需要与参考答案相同。只找到首次分离、没有完成后续拆解的，不算完整解答。

观察方式和解释文字不计分。

1. 全程离线，不得搜索、下载、安装软件包或调用其他 AI 模型与服务。

3. 所有题目读取、推理笔记和答案输出都在开始作答时所在的工作目录内完成。工具本身必需的安装文件除外，不得访问其他题目的目录、历史答案、求解缓存或出题端资料。

6. 不得切换账户或使用需要其他账户密码的命令。需要结束进程时，只按 PID 结束自己启动的进程，不得按进程名批量结束。
