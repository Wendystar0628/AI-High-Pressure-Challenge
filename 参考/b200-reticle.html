One coherent device.

Each die is built at the lithographic reticle limit. NV-HBI joins them at 10 TB/s so both halves address one memory space and present as a single CUDA GPU — no split, no host-visible seam.

两颗裸片各自达到光刻极限面积。NV-HBI 以 10 TB/s 将两者连接为一个统一的地址空间和单一 CUDA 设备。滚动使两侧计算单元逐步激活，数据跨越中缝流动。

Transformer Engine, second generation

Fewer bits, more operations.

A 64-bit lane carries one FP64 value or sixteen FP4 values. Micro-tensor scaling keeps FP4 usable, so the same silicon moves more values per cycle.

一条 64 位通道可承载 1 个 FP64 值或 16 个 FP4 值。第二代 Transformer Engine 的微张量缩放使 FP4 保持可用精度，同一片硅每周期处理更多数值。

Memory is stacked, not spread.

Eight HBM3e stacks surround the die pair on the interposer. 180 GB at 7.7 TB/s in HGX B200; 186 GB at 8 TB/s in the GB200 NVL72 configuration.

八颗 HBM3e 堆栈环绕两颗裸片，直接键合在中介层上。滚动将一颗堆栈逐层展开，露出贯穿各层的硅通孔。

One NVLink domain of 72.

Fifth-generation NVLink gives each GPU 1.8 TB/s. NVSwitch makes eight GPUs fully connected on an HGX baseboard at 14.4 TB/s; in GB200 NVL72, 72 GPUs share a 130 TB/s domain.

第五代 NVLink 为每颗 GPU 提供 1.8 TB/s。NVSwitch 使 HGX B200 上的 8 颗 GPU 全互联（14.4 TB/s）；GB200 NVL72 将 72 颗 GPU 置于同一个 130 TB/s 的 NVLink 域。悬停节点查看其链路。

Five names,five scales.

B200 是一颗 GPU；HGX 是一块 8 GPU 基板；DGX 是一台整机；GB200 是 CPU + 2 GPU 的超级芯片；NVL72 是一整机柜。以下数据来自 NVIDIA 数据手册与产品页。
