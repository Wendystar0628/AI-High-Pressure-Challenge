# 题目

给你25套机械零件和装配体的工程图纸。请读懂每套图纸，推断三维形状，用规定的JSON建模描述写出每个零件；装配体还需写出各零件装好后的位置与朝向。总分100分，建议按题号由易到难作答，没做完的部分也可提交。

形状须靠读图和手工推理：对照视图、剖视、尺寸链与局部放大图，推导特征的大小和位置。允许文字笔记和手工计算，允许运行提供的轴测预览，可以一次预览多题。JSON尺寸目录可按第五节显示、列出和整理；尺寸与几何推算须手工完成。不得使用CAD软件、几何内核或其他建模工具，不得改动题目工具。

- 零件图采用各零件自身坐标系，装配图采用总坐标系。装配题按明细栏序号建模，再根据配合、同轴、相切与定位关系推导placement。

## 二、作答

在开始作答时的工作目录中创建 `答案/`，提交 `答案/第01题.json` 至 `答案/第25题.json`。格式见 [建模描述](机械结构重建/建模描述.md)。用一串拉伸、旋转、加料、除料、孔、倒圆、倒角、阵列、镜像特征描述每个零件，装配题用placement表示位置和朝向。

没做完的题提交已写出的零件与特征；某题没写可以不交，不影响其他题。不要求网页、动画或建模程序。

## 三、自查工具

```powershell
python 机械结构重建/工具/preview.py 答案/第01题.json
```

只输出作答实体的两张轴测着色图 `轴测-1.png`、`轴测-2.png`，默认保存在 `预览/第01题/`。报告特征错误、体积与外形尺寸。它不读取题图、尺寸目录或评分材料，不输出正投影、剖视、原图布局或任何对照与差异信息。可用 `--out 目录` 指定输出位置。

## 四、评价

01—08题各3.5分，09—15题各4分，16—25题各4.4分；三档合计28、28、44分，总分100。

每题分别在0.2毫米和2毫米容差下比较作答与参考表面。每档都先计算 `F = 2PR/(P+R)`：P按作答表面积，R对参考每个相连同曲面合并后的几何面单独按面积采样，再按面等权。孔壁、肋面、圆角面和倒角面与大平面同样计入R。

先用0.2毫米档求整题一次整体平移；2毫米档沿用同一平移，不重新对齐，两档均不允许旋转。`F综合 = 0.8 × F(0.2mm) + 0.2 × F(2mm)`，每题得分为 `分值 × min(1, F综合/0.99)`。宽容差只占20%，不是两档平均。

装配按序号比较，共用上述平移；每档分别汇总全部作答表面积与全部参考面，缺件的参考面记0，由该档汇总P、R计算F，再合成两档F；不平均零件F。特征失败的零件按失败前一步实体计，其他零件照常。

## 五、规定

1. 全程离线，不得搜索、下载、安装软件包或调用其他 AI 模型与服务。
2. 可使用文件读取、看图和文本编辑工具读图推理与作答。命令行可列出本题文件、直接显示内容、保存人工写出的文本、运行 `机械结构重建/工具/preview.py`（可以用命令一次预览多题）。可以用命令或脚本显示、列出、整理JSON尺寸目录的现有内容，包括提取字段、按编号/视图/类型排序或分组，等同于看图读数；不得用程序计算尺寸（如累加尺寸链、求坐标、换算角度或法向）、推导几何、重建或比对形状、生成或筛选候选模型。不得修改 `机械结构重建/工具/` 下任何文件。不得使用CAD软件、几何内核或其他建模、重建工具。
3. 所有题目读取、推理笔记和答案输出都在开始作答时所在的工作目录内完成。工具本身必需的安装文件除外，不得访问其他题目的目录、历史答案或出题端资料。
4. 全程独立作答，不得开启子代理（subagent），也不得使用任何多代理或并行协作功能。
5. 不得切换账户或使用需要其他账户密码的命令。

需要结束进程时，只按 PID 结束你在本会话中启动的进程；不得结束其他进程，不按进程名批量结束。
