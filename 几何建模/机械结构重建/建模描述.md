# 建模描述格式

每题提交一份 `答案/第NN题.json`（UTF-8），用特征列表描述每个零件的三维形状。评分程序按本文规则把它生成为实体，再与参考零件比对表面。单位一律为毫米，角度为度。

## 一、整体结构

```json
{
  "problem": "01",
  "parts": [
    {"name": "1", "title": "底座", "placement": {...}, "features": [ ... ]}
  ]
}
```

- `problem`：两位题号字符串。
- `parts`：零件数组。单件题只写一个零件，`name` 写 `"1"`。装配题按明细栏序号写 `name`（`"1"`、`"2"` …），每个序号一个零件。
- `title`：可选，零件名称。
- `features`：特征数组，按顺序执行。第一个特征必须加料。
- `placement`：可选，见第五节；单件题不写。

## 二、坐标

零件在图纸标出的坐标系中建模：原点 O 和坐标轴 X、Y、Z 画在各基本视图上，箭头指向正向。主视图沿 +Y 方向投射（X 向右、Z 向上），俯视图沿 −Z，左视图沿 +X，第一角画法。装配题的装配图给总坐标系，零件图给各零件自身坐标系。

## 三、草图平面与轮廓

拉伸、旋转、孔都在一个草图平面上定义。特征里写 `plane` 和 `origin`：

| `plane` | 草图 x 轴 | 草图 y 轴 | 法向 n |
|---|---|---|---|
| `"XY"` | +X | +Y | +Z |
| `"YZ"` | +Y | +Z | +X |
| `"ZX"` | +Z | +X | +Y |
| `"XZ"` | +X | +Z | −Y |
| `"YX"` | +Y | +X | −Z |
| `"ZY"` | +Z | +Y | −X |

`origin` 是草图坐标 (0, 0) 所在的三维点，默认 `[0, 0, 0]`。草图点 (x, y) 对应三维点 `origin + x·(草图 x 轴) + y·(草图 y 轴)`。

也可以自定义平面：`"plane": {"origin": [x, y, z], "normal": [nx, ny, nz], "x_dir": [dx, dy, dz]}`，草图 y 轴 = normal × x_dir（x_dir 中平行于 normal 的分量会被去掉）。

`loops` 是封闭轮廓数组，每个轮廓是下面一种：

| 写法 | 含义 |
|---|---|
| `{"rect": [x0, y0, x1, y1]}` | 矩形，两个对角点；可加 `"r": 5` 把四角倒成圆弧 |
| `{"circle": [cx, cy], "d": 20}` | 圆，`d` 直径（或 `r` 半径） |
| `{"slot": [[x1, y1], [x2, y2]], "width": 10}` | 长圆（腰形），两端半圆圆心和宽度 |
| `{"path": [项, 项, ...]}` | 任意直线、圆弧围成的轮廓，最后自动用直线回到起点 |

`path` 的项：

- `[x, y]`：从上一点画直线到这一点。第一项是起点。
- `{"p": [x, y], "r": 3}`：画直线到这一点，并在这个顶点倒圆角 R3（两侧都必须是直线）。
- `{"arc": [x, y], "center": [cx, cy]}`：从上一点画圆弧到 (x, y)，圆心 (cx, cy)，默认逆时针，加 `"cw": true` 为顺时针。起点、终点到圆心的距离必须相等。
- `{"arc": [x, y], "through": [mx, my]}`：从上一点经过 (mx, my) 画圆弧到 (x, y)。
- 最后一项若与起点重合，就以这一项的线段闭合（可用于以圆弧收尾）。

轮廓的走向（顺时针、逆时针）不影响结果。一个特征里的多个轮廓按嵌套关系组合：被奇数个轮廓包住的是孔，例如外框里再写一个圆就是带孔的板。轮廓不能自相交。

## 四、特征

每个特征有 `type`；`op` 为 `"add"`（加料，默认）、`"cut"`（除料）或 `"intersect"`（与已有实体求交）。可加 `"name"` 写备注，不影响形状。

### 拉伸 extrude

```json
{"type": "extrude", "op": "add", "plane": "XY", "origin": [0, 0, 0],
 "loops": [{"rect": [-60, 0, 60, 80], "r": 10}], "depth": 15}
```

- `depth`：数字 d 表示沿法向 n 从草图平面拉到 d（负数则沿 −n）；数组 `[a, b]` 表示从 a 拉到 b（沿 n 计），例如 `[-5, 5]` 为对称拉伸 10，`[-12, 0]` 为反向拉伸 12。
- 除料可以用 `"through": true`（向两侧切穿全部材料）、`"through": "+"`（只沿 +n 切穿）或 `"through": "-"`，此时不写 `depth`。

### 旋转 revolve

```json
{"type": "revolve", "plane": "XZ", "axis": "x",
 "loops": [{"path": [[0, 16], [0, 60], [12, 60], [12, 30], [40, 30], [40, 16]]}]}
```

- `axis`：旋转轴，在草图坐标中给出。`"x"` 为草图 x 轴，`"y"` 为草图 y 轴（都过草图原点），或 `{"point": [x, y], "dir": [dx, dy]}`。轮廓必须全部在轴的一侧（可以贴在轴上）。
- `angle`：默认 360；数字为从草图平面起转过的角度，`[a0, a1]` 为从 a0 转到 a1。正向按右手定则绕轴的方向。

### 孔 hole

```json
{"type": "hole", "plane": "XY", "origin": [0, 0, 15], "at": [[-50, 40], [50, 40]],
 "d": 11, "through": true, "cbore": {"d": 18, "depth": 6}}
```

- 孔从草图平面起沿 **−n** 方向钻入（`"reverse": true` 改为沿 +n）。`at` 为孔心的草图坐标，可以是一个点或点数组。
- `d` 孔径；`depth` 孔深（平底），或 `"through": true` 钻穿。
- `cbore`：沉孔 `{"d": 直径, "depth": 深度}`；`spotface`：锪平，写法同 `cbore`；`csink`：锥形沉孔 `{"d": 大端直径, "angle": 锥角，默认 90}`。三者至多写一个。
- `tip_angle`：盲孔底部钻尖锥角（如 118），不写为平底。
- 孔只能除料。

### 线性阵列 pattern_linear

```json
{"type": "pattern_linear", "features": [3, 4], "dir": [1, 0, 0], "spacing": 30, "count": 4,
 "dir2": [0, 1, 0], "spacing2": 25, "count2": 2}
```

把第 3、4 个特征（序号从 1 开始，只能引用前面的特征）沿 `dir` 每隔 `spacing` 复制，`count` 含原特征。`dir2`、`spacing2`、`count2` 可选，构成二维阵列。复制件沿用原特征的加料或除料。

### 环形阵列 pattern_circular

```json
{"type": "pattern_circular", "features": [2], "axis": {"point": [0, 0, 0], "dir": "Z"}, "count": 6}
```

绕轴复制 `count` 个（含原特征），相邻间隔 `step` 度，默认 360/count。`dir` 可写 `"X"`、`"-Y"` 这类轴名或三维向量。

### 镜像 mirror

```json
{"type": "mirror", "features": [2, 3], "plane": "YZ", "origin": [0, 0, 0]}
```

把所列特征关于镜像平面复制一份；`plane` 用第三节的平面名（取其法向所在平面，过 `origin`），或 `{"point": [x, y, z], "normal": [nx, ny, nz]}`。`"features": "all"` 表示把当前整个实体镜像后合并。

阵列、镜像引用阵列或镜像特征时，连同其全部复制件一起复制。

## 五、装配位置

装配题每个零件按自己零件图的坐标系写特征，再用 `placement` 放到装配坐标系：

```json
"placement": {"rotate": [{"axis": "Y", "angle": 90}, {"axis": "Z", "angle": 30}], "translate": [-35, 30, 45]}
```

先依次绕装配坐标系的轴（过原点，右手定则）旋转，再平移：装配坐标 = 平移 + 旋转 × 零件坐标。`axis` 可写 `"X"`、`"Y"`、`"Z"` 或三维向量。零件图与装配图坐标系相同时不写 `placement`。

## 六、生成与计分

- 特征按顺序生成。某个特征出错（格式不对、轮廓不封闭、布尔运算失败、实体被切空等）时，这个零件停在出错前一步，后面的特征不再生成，评分按停下时的实体计。
- 标注的三维倒圆、倒角须建模；未注棱保持理论交线，不自行补充拔模。
- 螺纹孔按技术要求的写法建模（通常为公称直径的光孔）。

## 七、示例

一块 80×50×10 的板，中间一个 Φ20 通孔，左右各一个带 R5 圆角的凸耳由镜像得到（只是格式示例，不是任何一题的答案）：

```json
{
  "problem": "示例",
  "parts": [
    {"name": "1", "features": [
      {"type": "extrude", "plane": "XY", "loops": [{"rect": [-40, -25, 40, 25]}], "depth": 10},
      {"type": "hole", "plane": "XY", "origin": [0, 0, 10], "at": [0, 0], "d": 20, "through": true},
      {"type": "extrude", "plane": "XY", "loops": [{"path": [[40, -10], {"p": [55, -10], "r": 5}, {"p": [55, 10], "r": 5}, [40, 10]]}], "depth": 6},
      {"type": "mirror", "features": [3], "plane": "YZ"}
    ]}
  ]
}
```

## 八、三维棱修饰

```json
{"type":"fillet","radius":3,"edges":[[0,0,10]],"name":"左前竖棱R3"}
{"type":"chamfer","distance":2,"edges":[[20,0,0]],"name":"前下棱C2"}
```

`fillet`将所选棱做定半径三维圆角，包含凸棱与凹棱根部过渡；`chamfer`做45°等距倒角，两邻面上的退让距离均为distance。一次可选多条棱，按当前实体同时处理。

`edges`为零件自身坐标系中的棱上见证点数组，每点只选一条棱。点须落在当前棱中部，避开顶点及圆柱缝线，不能用拓扑序号。默认选择容差0.05mm，可设`tolerance`，上限0.2mm；0条或多条命中、重复选棱、半径过大等均报告错误并保留上一步实体。见证点可选圆周上任意非端点位置，不必与参考答案使用同一点。先做改变该棱的加减料，再选当前实际棱；也可先修饰再做后续特征，以最终形状为准。棱修饰不能作为独立切削工具阵列；可阵列基础几何后再做倒圆/倒角。

斜面用第三节的任意草图平面，或用斜边轮廓拉伸/旋转得到；斜孔用自定义plane的normal与x_dir确定。孔默认沿草图法向反向钻入，`reverse:true`可改为正向。角度须自己从图纸换算成法向数值。

## 九、自查工具

`机械结构重建/工具/`只提供`preview.py`及离线依赖drawkit。人工逐题运行：

```powershell
python 机械结构重建/工具/preview.py 答案/第01题.json
```

只出两张轴测着色图，不读取题图或JSON目录，不出正投影、剖视、参考轮廓或差异提示。打印体积、外形尺寸和特征错误；输出在`预览/第01题/`，可用`--out`指定目录。不得改动工具或脚本批量调用。
