# 首页

路径 `/`，展示页。读 `models.json`、`tasks.json`、`scores.json`：模型只放已排名的前 5 名，另写模型总数。动效名见 [motion.md](motion.md)。

## 全页

从上到下：页顶 → 首屏（左栏前五名，右栏八项星盘）→ 题目滚动条 → 总分怎么合成 → 一道题怎么测 → 去往各页 → 页脚。段与段之间用 `decor/constellation/constellation-strip` 分隔条（墨 2），段间距按 visual.md 的段落留白，段标题用眉标加四角星细线标题。颜色和装饰按 [visual.md](visual.md)；页面背景两角是 `starfield-corner-tr` 和 `starfield-corner-bl`。

首屏只有一个焦点：星盘。字标、前五名都比它轻一级，阅读顺序按 Z 形：左上字标 → 右上星盘 → 左下前五名 → 右下按钮。

本页有一个状态「本页模型」，默认是榜首。点前五名的一行或总分合成里的模型名，就换成那个模型，星盘随之变化；不写进地址。

## 2. 首屏

高度 = 视口高 − 命令栏 − 滚动条，窗口矮时保留一个最小高度，不压扁星盘。两栏，右栏（星盘）宽于左栏，宽 1024 时也不换行。

**左栏**

- 字段：`2026.11.04 更新 / 7 个模型 / 12 道题 / 8 个类别 / 每题 60–100 分钟`。日期取 `scores.updated`；模型数含评测中的。动效：数字落定。
- 字标：实心 `AI OCTATHLON`，空心 `TIMED CHALLENGE`，较长的空心行占满左栏；字明显小于星盘，不和星盘抢焦点。动效：字标推入。
- 马克笔（全页唯一）：`AI八项全能·定时挑战赛`，和上面两行英文同等分量：字号约为英文行的 0.8 倍（见 visual.md「字号」），荧光绿块和 1px 墨边随之放大，间隔号用中文字体。窄屏下同样排在一行、不出左栏。动效：马克笔划过。
- 简介一句（次要墨）：`AI 编程智能体每题独立作答 60–100 分钟，无人答疑，到时中止。`
- 前五名：眉标 `// TOP 5`，四角星细线标题 `前五名`。每行：编号标签 `01`、厂商图标、模型全名、总分（宽体数字）、一根 0–100 的分数条（紫 300）。第 1 名的分数用荧光绿高光，编号左侧放 `decor/rays/rays-burst-light.svg` 小徽记（深色用 `-dark`）。
  - 模型名是链接，到模型得分页 `/models/<id>/`（名字接力）；行的其余部分是按钮（`aria-pressed`）：点了设为本页模型；当前行淡紫底、左边紫条、名字加粗。
  - 末行：字段 `共 7 个模型`，主要按钮 `查看排行总榜` → `/leaderboard/`（全页唯一的主要按钮）。
  - 动效：逐行亮起、图表绘制（分数条）、紫条落下、当前标记滑动、荧光绿擦入。

**右栏：八项星盘**（D3 画 SVG，正方形，边长取右栏宽与首屏可用高的较小者）

- 从里到外四圈：紫盘 → 星区（紫盘外沿是 0 分，往外到 100 分）→ 类别板 → 外沿刻度。星区占半径的大部分，圈与圈之间留窄缝。
- 星盘后面衬 `decor/orbit/orbit-corner-br`，单色当遮罩（紫 300，不透明度 0.2），从首屏右下角伸出，不压类别板上的字。
- 类别板：8 段，从 12 点顺时针：数学推理、算法竞赛、空间推理、复杂交互应用、游戏设计与开发、物理模拟、视觉设计与渲染、系统架构与实现；圆心角 = 权重 × 3.6°（54 / 54 / 36 / 36 / 45 / 36 / 54 / 45）。前三段（标准评判题）底色荧光绿 100，后五段（主动设计题）紫 100，两组之间一道墨线；类名墨字。板上沿弧排类名（粗体）和权重（字段），下半圈反向排，保持正读。每段是链接 → `/categories/#<类别>`。
- 外沿刻度：每 1% 权重一格，类别分界处加长，线型照 `decor/dial/dial-ring.svg`。
- 板内侧一道细括弧把前三类和后五类分开，弧上眉标字：`标准评判 40%`、`主动设计 60%`。
- 星区：25 / 50 / 75 / 100 分四道虚线圈（细线色），刻度数字放在 12 点方向的缝里。12 道题各一颗四角星，落在本类扇区内（同类几题平分扇区角）。星到中心的距离 = 本页模型这道题的得分；星的面积和题目权重成正比。星是墨色（深色里浅墨）；本页模型在这道题上是全场第一的，星是荧光绿（浅色加 1px 墨边）。
- 星座：12 颗星按扇区顺序连成闭合的 1px 紫线，线在每颗星前断开。
- 紫盘（全页唯一的整块紫色）：荧光绿标签（墨字：厂商图标 + 模型全名）、白色大号总分 `74.7`、白色粗体 `第 1 名`。白字按 1024 宽下的星盘尺寸算也要 ≥ 18.66px 粗体；小字只写在荧光绿标签里。
- 指向或聚焦：
  - 类别板：板填深一档（标准评判题荧光绿 500，主动设计题紫 300）、墨字，外沿紫色括弧，紫色光束连到紫盘；其余扇区的星和连线退淡；紫盘换成该类：标签 = 类名，大字 = 本页模型的类别分，下行 = 该类名次。
  - 星：星填荧光绿；紫盘换成这道题：标签 = 题目短名，大字 = 得分，下行 = 该题名次。点星 → 题目页。
  - 离开后紫盘回到本页模型。紫盘标签上的模型名链到该模型的模型得分页（名字接力）。
- 星盘下方三行小字图例：星到中心的距离 = 本页模型这道题的得分；星的面积 = 题目权重；中心紫盘 = 本页模型和总分。
- 读屏：每段、每颗星的 `aria-label` 写全名、权重、得分、名次。
- 动效：星盘组装、星位就位、星座连线、锁定、读数切换、联动高亮、数字落定、名字接力（点扇区或星换页）。

## 4. 总分怎么合成

眉标 `// SCORING`，标题 `总分怎么合成`。

- 一行一个模型，每行一条 0–100 的长条，按类别权重分成 8 格（格间一道纸色缝）；格里填满的比例 = 该类得分，整行填满的总长就是总分。
- 填满部分用该类的颜色，和总榜的得分构成一致：每类用 visual.md 的类别固定颜色（标准评判题三类荧光绿族加墨边，主动设计题五类紫族）；空的部分浅填充。本页模型那一行左边紫条、行名加粗。
- 表头：类别图标（`website/icons/categories/<类别>.svg`，单色，当遮罩跟随墨色）、类名、权重。表头和格子都链到 `/categories/#<类别>`。
- 底下两道括弧：两类题的题数、权重合计、谁评分。
- 指向格子或表头：这一列以外退淡，这一列五个模型里最高的那格挂一颗荧光绿四角星，被指的格上方出浮签 `81.2 分 │ 计入总分 12.2`。指向模型名：其余行退淡；点模型名去模型得分页，点名字格的其余部分 = 设为本页模型。
- 动效：图表绘制（进入视口时每行从左揭开）、联动高亮、浮签、名字接力。

## 5. 一道题怎么测

眉标 `// HOW IT RUNS`，标题 `一道题怎么测`，标题线右端放次要按钮 `完整规则` → `/about/`。

- 四步横排：节点是四角星，步间 1px 细线；每步一个宽体编号、粗体步名、一行字段。不可点，直角。
  - 01 拿到题面：只有题面和材料
  - 02 独立作答：无人答疑，看不到限时
  - 03 到时中止：不延长，成果靠 git 提交
  - 04 评分合成：每题 0–100，按权重合成
- 四步下面是限时尺。
- 限时尺：横轴 0–100 分钟，占左边大部分，右边留给各档的题；三条计时条（紫 300）走到 60 / 90 / 100，末端一道墨色止线；止线后一条细点线连到右侧这一档的题：60 分钟 7 题（形式化证明、数学竞赛、单位正方形、Transformer、电路仿真、鲁班锁、果冻水槽），90 分钟 3 题（塔防、NVIDIA_B200、操作系统嵌套），100 分钟 2 题（AE 编辑器、渔港）。每题一颗四角星，面积按权重，和星盘同一套大小；标准评判题的星荧光绿加墨边，主动设计题的星紫色。
- 星是链接 → 题目页；指向时填荧光绿，出浮签 `动态路由塔防 │ 游戏设计与开发 │ 12.5%`。指向一条计时条：其余两档退淡。
- 动效：计时条走满（进入视口时）、浮签、联动高亮、名字接力。

## 6. 去往各页

眉标 `// INDEX`，标题 `去往各页`。四个入口一排（窗口窄时排成 2 × 2），之间 1px 细线，不做卡片。

- 空心大编号都是真实计数：`07` 模型数、`08` 类别数、`12` 题数、`04` 测法步数；模型数随数据变。
- 每个入口是一个链接：眉标英文、粗体中文、一行字段（排行总榜 `总分、8 类得分、勾选对比`；题目类别榜 `每类排名、各题分`；题目拆解 `题面、考点、各模型得分`；挑战赛说明 `测法、两类题、权重`）、小按钮 `进入`。
- 动效：紫色灌满、数字落定（指向）、荧光绿擦入、换页快门。

## 入场顺序

骨架 → 焦点星盘 → 字标 → 数据 → 前五名 → 连线和马克笔收尾。各片段前后重叠，整段在技能的 `sequenceMax` 内结束；星和扇区都顺时针。

1. 一开始同时起步：光谱条扫过（本次访问的第一页才有）、紫盘组装；题目滚动条硬切出现，随即开始走。
2. 类别板 8 段紧跟紫盘，顺时针按段错开组装。
3. 字标实心行比星盘稍晚推入，空心行再晚一拍；同时字段、紫盘总分、前五名总分开始数字落定，这组的错开压在技能的读数范围内。
4. 12 颗星在类别板组装途中起飞，顺时针依次就位。
5. 前五名逐行亮起；紫盘标签擦入；前五名分数条随后一起长出。
6. 收尾：马克笔划过，星座连线跟在星后面从 12 点顺时针画出，最后结束。
