# 题目详情 `/tasks/` 与题目页 `/tasks/<类别>/<题目>/`

阅读页。`/tasks/` 是 10 个类别的题目入口；题目页是 13 道题共用的一套模板，现在只搭好区块、数据和空状态，讲解内容以后再填；题干由导出脚本从题面原件摘录。

## 一、首页 `/tasks/`

**页头**
- 眉标 `// TASKS`，页名「题目详情」，计数「13 题」在右（`.st-sheet-head`）。
- 字段：`10 个类别 │ 标准评判题 7 │ 主动设计题 6`。
- 导语一句：每道题一页，讲题面要点、考点、各模型得分和评分要点。

**权重条**
- 复用说明页的「权重条」图示。点某一段滚到下面对应的类别分组。

**类别分组**（8 组，顺序同 `tasks.json`）
- 分组头（`.st-group-head`）：类别图标 + 中文名 + 英文眉标（`en`）；右端字段 `N 题 │ 权重 X%`，再加小链接「题目类别榜」→ `/categories/#<类别>`。
- 每题一条记录行（`.st-record`），整行链到题目页。五列：
  - 编号 `No.01`–`No.10`，按题目总览的顺序
  - 题名（阅读字体）
  - 类型：标准评判题 / 主动设计题（字段样式，不加框）
  - 限时：一段细条，长度按分钟（100 分钟为满长），标准评判题荧光绿 500 加墨边、主动设计题紫 300，后跟「90 分钟」
  - 权重：`6.25%`，右对齐
- 分组锚点用类别路径名 `#reason` 等。

**左栏**
- 目录：10 个类别（图标 + 名），当前分组紫条。
- 统计：标准评判题 7 题 50%、主动设计题 6 题 50%、受测模型 N 个（`models.json` 条数）、更新日期（`scores.json` 的 `updated`）。

**数据**：全部来自 `tasks.json`，本页没有手写内容。

## 二、题目页模板 `/tasks/<类别>/<题目>/`

### 页头（全部来自数据）
- 上一级：`题目详情 / <类别>`，分别链到 `/tasks/` 和 `/tasks/#<类别>`。
- 编号行：编号标签 `No.XX`（当前样式）+ 键值「类别 │ 数学推理」（链到 `/categories/#<类别>`）+ 类型字。
- 字段：`限时 N 分钟 │ 权重 X% │ 交付物 │ 评分方式`；交付物取 `deliverable`（代码字体）；评分方式按 `kind`：标准评判题写「程序校验生成分数」，主动设计题写「两位评分员取平均」。
- 标题：题名，下有光谱条。
- 导语：`brief` 的一句定位。

### 五个区块
网站轻量，不展示作品的截图、录像和解答摘录，作品由视频展示。顺序固定。每块是中英成对的段落标题（眉标在上），块与块之间一条细线。“手填”的块写在各题自己的页面文件里，一块一个槽（`data-slot`）；槽为空时显示这块的空状态。

**1. 题面要点** `// BRIEF`（手填）
- 正文 + 要点列表，可插图。题面原件的链接在第 5 块「题干」。
- 空：「这道题的题面要点还在整理，整理好后写在这里。」

**2. 考点** `// KEY POINTS`（手填）
- 编号列表，每条：宽体编号 `01` + 粗体引词 + 一两句。
- 空：「这道题的考点还在整理，整理好后按重要程度列在这里。」

**3. 各模型得分** `// SCORES`（自动）
- 数据：`scores.json` 的 `scores.<模型id>.tasks.<题目>`；模型名、厂商图标取 `models.json`。
- 块头右端字段：`已评 N 个模型 │ 更新 <updated>`（日期写成 `2026.11.03` 的格式）。
- 一行一个模型，行高固定：名次（宽体 `01`）│ 厂商图标 + 模型全名 │ 0–100 横条 │ 分数（一位小数，右对齐）。条上方一条刻度 0 / 25 / 50 / 75 / 100。
- 按本题分数降序，同分同名次。条按本题类型上色：标准评判题荧光绿 500 加墨边，主动设计题紫 300；最高分那一行条尾挂荧光绿四角星，分数荧光绿高光；指向某行，条加深一档。
- 分数为 `null` 的模型排在最后：名次空，条的位置铺斜线纹，分数处写「评测中」。
- 默认显示前 10 行，多于 10 个时下面「展开全部 N 个」。
- 模型名链到模型得分页，点行的其余部分打开模型侧面板（与两个榜单页同一部件）。
- 空（没有任何模型有分数）：「这道题还没有评分结果，评完后各模型的分数从高到低排在这里。」

**4. 评分要点** `// SCORING`（上半自动，下半手填）
- 上：复用说明页里这道题的图示。主动设计题是它的分值条；标准评判题是所在类别的判法图或计分曲线。
- 下：手填要点列表。
- 块尾链接「完整评分方向」→ `/about/#<类别>`。
- 空（手填部分）：图示照常显示，下面一句「这道题的评分要点还在整理，整理好后写在这里。」

**5. 题干** `// STATEMENT`（自动，导出时从题面原件摘录）
- 块头：一句说明「从题面原件摘录题干；作答格式、运行环境、规定和评分标准等章节不在其中，见完整题面。」；链接「完整题面 GitHub」（仓库 main 分支上这道题的 `.md`），有题目材料文件夹的再加「题目材料 GitHub」（文件夹页）；一行「未收录的章节」列出被排除的章节标题；有折叠小节时右端一个「全部展开 / 全部收起」。
- 正文：题面开头的导语，然后每个保留的章节一个小标题（题面原样的标题，如「第 1 题」「二、游戏内容」），章节里的下级小节折成一列折叠条（同说明页的折叠，展开时逐行亮起）。章节锚点 `#stem-1`、`#stem-2`…，左栏目录在「题干」下列出这些章节。
- 版式：段落、列表、表格、代码块（Lean、C++、JSON，左上小标签写语言）、公式都用阅读页现有样式；公式走站内的 TeX 转 MathML（`site/src/reading/tex.js`），题干里的公式用带 MATH 表的数学字体（Cambria Math 等），矩阵、根号、大运算符才排得对。题面里指向同仓库文件的相对链接改成 GitHub 链接。
- 英文页不翻译题干：块标题、说明和链接是英文，说明开头写明下面是模型拿到的中文原文；正文、章节标题和未收录章节名照中文原文显示（`lang="zh-CN"`）。
- 空（数据没载入）：「这道题的题干没能载入，可以在 GitHub 上看完整题面。」完整题面链接照常显示。

**题干的摘录规则**（唯一的规则写在 `website/tools/export_data.py` 的 `STEM_RULE` 注释和 `NOT_STEM` 词表，这里照录）：
- 题面按标题分节。标题含下列任一词的章节，连同它的全部下级小节，不算题干：作答、提交、交付（作答与交付）；规定、规则、注意事项（规定）；评分、评价、评测（评分、计时、评测程序和评测机器）；运行环境、本机环境、技术要求（环境与技术）；视频导出、录制（录制作品用的接口）。例外：「游戏规则」是玩法本身，算题干。其余章节都算题干，第一个章节之前的导语也算；最上面的一级标题（「题目」或题名）不收，页面已有标题。
- 定这条规则的理由：10 份题面都把作答格式、运行环境、规定、评分写成单独的章节，标题用词固定，按标题排除最稳，题面以后改动也能自动跟上；章节里的内容不做逐句删改，免得改动题面原意。词表只用完整的词（如「运行环境」而不是「环境」），避免误伤「水下环境」这类题目内容。
- 题目放在单独文件里的：题面旁同名材料文件夹（`orchestrator/tasks.py` 的 `MATERIALS`）顶层名为 `第NN题.md` 的文件，按题号接在题干后面，每个文件一个章节，同样按上面的规则摘录。数学竞赛原创试题的 24 道题就这样收进来；鲁班锁的 8 副锁分层图和体素数据不叫这个名字，只链接（题面「一、题目数据」里的链接和块头的「题目材料」），分层图太长，放进页面反而难读；光线追踪、电路的材料是评测程序、头文件和核对工具，同样只链接。

### 题干在手机宽度
- 阅读页在 759px 以下左栏移到正文之后、不再吸顶，正文占满一栏；题干里的代码块、表格和展示公式在自己框内横向滚动，整页不出现横向滚动。题目页的得分行在手机宽度按题目类别榜的窄列排法。

### 页尾
- 上一题 / 下一题：两条记录行（编号 + 题名），按 `No.` 顺序，第一题没有上一题，最后一题没有下一题。

### 左栏
- 本页目录：五个区块 + 上一题 / 下一题，当前块紫条；「题干」下列出题干的章节。区块为空时目录里照常列出。
- 本题统计：类别、类型、限时、权重、本题最高分（数据高光）和得分模型、已评模型数。
- 同类别的题：本类别其他题的题名链接；只有一题的类别不显示这一组。

### 空状态的样子
- 细线框，底铺斜线纹，句子压在纸色底上（`.st-empty`）。区块标题照常显示，空状态里不放按钮。

## 三、动效（参数见 motion.md）

- 换页快门、命令栏当前块滑动（全站）
- 题目页标题下光谱条扫过
- 目录当前节滑动
- 记录行指向（套件自带）；权重条指向高亮（与说明页同一图示）
- 得分条进入视口时从 0 伸到分数（只播一次），分数乱码后落定
- 展开全部 N 个：新行逐行亮起
- 评分图示进入视口时绘制（与说明页同一图示）
- 题干的折叠小节展开时逐行亮起（与说明页的折叠同一部件）
- 模型侧面板推入、推回（同榜单）
