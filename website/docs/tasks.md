# 题目拆解 `/tasks/` 与题目页 `/tasks/<类别>/<题目>/`

阅读页。`/tasks/` 是 8 个类别的题目入口；题目页是 12 道题共用的一套模板，现在只搭好区块、数据和空状态，讲解内容以后再填。

## 一、首页 `/tasks/`

```text
┌──────────────────────── 深色命令栏（当前项：题目拆解）────────────────────────┐
├────────────┬──────────────────────────────────────────────────────────────┤
│ 左栏        │ // TASKS                                                      │
│ 本页目录     │ 题目拆解                                          12 题        │
│ ┃ 数学推理   │ ───────────────────────────────────────────────────────────  │
│   算法竞赛   │ 字段 / 导语                                                    │
│   …         │ ▤▤▤▤▤▤▤▤▤ 权重条（与说明页同一张图示）▤▤▤▤▤▤▤▤▤                │
│ ──────     │ [图标] 数学推理  <EN>                 2 题 │ 15% │ 类别榜 ──── │
│ 统计         │  No.01  形式化证明题          标准评判题  ▬▬▬    60 分钟   7.5% │
│             │  No.02  数学竞赛原创试题      标准评判题  ▬▬▬    60 分钟   7.5% │
│             │ [图标] 算法竞赛 …                                              │
└────────────┴──────────────────────────────────────────────────────────────┘
```

**页头**
- 眉标 `// TASKS`，页名「题目拆解」，计数「12 题」在右（`.st-sheet-head`）。
- 字段：`8 个类别 │ 标准评判题 6 │ 主动设计题 6`。
- 导语一句：每道题一页，讲题面要点、考点、各模型得分、代表作和评分要点。

**权重条**
- 复用说明页的「权重条」图示。点某一段滚到下面对应的类别分组。

**类别分组**（8 组，顺序同 `tasks.json`）
- 分组头（`.st-group-head`）：类别图标 + 中文名 + 英文眉标（`en`）；右端字段 `N 题 │ 权重 X%`，再加小链接「类别榜」→ `/categories/#<类别>`。
- 每题一条记录行（`.st-record`），整行链到题目页。五列：
  - 编号 `No.01`–`No.12`，按题目总览的顺序
  - 题名（阅读字体）
  - 类型：标准评判题 / 主动设计题（字段样式，不加框）
  - 限时：一段细条，长度按分钟（100 分钟为满长），标准评判题荧光绿 500 加墨边、主动设计题紫 300，后跟「90 分钟」
  - 权重：`7.5%`，右对齐
- 分组锚点用类别路径名 `#reason` 等。

**左栏**
- 目录：8 个类别（图标 + 名），当前分组紫条。
- 统计：标准评判题 6 题 40%、主动设计题 6 题 60%、受测模型 N 个（`models.json` 条数）、更新日期（`scores.json` 的 `updated`）。

**数据**：全部来自 `tasks.json`，本页没有手写内容。

## 二、题目页模板 `/tasks/<类别>/<题目>/`

```text
┌────────────┬──────────────────────────────────────────────────────────────┐
│ 本页目录     │ 题目拆解 / 数学推理                                             │
│ ┃ 题面要点   │ [No.01] [类别│数学推理]  标准评判题                              │
│   考点      │ 限时 60 分钟 │ 权重 7.5% │ 程序校验生成分数                       │
│   各模型得分 │ 形式化证明题（标题）                                             │
│   代表作     │ ━━━━ 光谱条 ━━━━                                              │
│   评分要点   │ 导语（手填，一句定位）                                           │
│   上一题/下一题│ // BRIEF 题面要点 ……                                          │
│ ──────     │ // KEY POINTS 考点 ……                                         │
│ 本题统计     │ // SCORES 各模型得分   ▬▬▬▬▬▬▬▬▬▬▬ 86.0                       │
│ 同类别的题   │ // WORKS 代表作  ┌──── 16:9 ────┐ ▫▫▫▫                         │
│             │ // SCORING 评分要点  分值条 / 判法图 + 要点                       │
│             │ 上一题 / 下一题（记录行）                                        │
└────────────┴──────────────────────────────────────────────────────────────┘
```

### 页头（全部来自数据）
- 上一级：`题目拆解 / <类别>`，分别链到 `/tasks/` 和 `/tasks/#<类别>`。
- 编号行：编号标签 `No.XX`（当前样式）+ 键值「类别 │ 数学推理」（链到 `/categories/#<类别>`）+ 类型字。
- 字段：`限时 N 分钟 │ 权重 X% │ 交付物 │ 评分方式`；交付物取 `deliverable`（代码字体）；评分方式按 `kind`：标准评判题写「程序校验生成分数」，主动设计题写「两位评分员取平均」。
- 标题：题名，下有光谱条。
- 导语：`brief` 的一句定位。

### 五个区块
顺序固定。每块是中英成对的段落标题（眉标在上），块与块之间一条细线。“手填”的块写在各题自己的页面文件里，一块一个槽（`data-slot`）；槽为空时显示这块的空状态。

**1. 题面要点** `// BRIEF`（手填）
- 正文 + 要点列表，可插图。块尾一个链接「题面原文」，链到 GitHub 仓库里这道题的 `.md`。
- 空：「这道题的题面要点还在整理，整理好后写在这里。」题面原文链接照常显示。

**2. 考点** `// KEY POINTS`（手填）
- 编号列表，每条：宽体编号 `01` + 粗体引词 + 一两句。
- 空：「这道题的考点还在整理，整理好后按重要程度列在这里。」

**3. 各模型得分** `// SCORES`（自动）
- 数据：`scores.json` 的 `scores.<模型id>.tasks.<题目>`；模型名、厂商图标取 `models.json`。
- 块头右端字段：`已评 N 个模型 │ 更新 <updated>`（日期写成 `2026.11.03` 的格式）。
- 一行一个模型，行高固定：名次（宽体 `01`）│ 厂商图标 + 模型全名 │ 0–100 横条 │ 分数（一位小数，右对齐）。条上方一条刻度 0 / 25 / 50 / 75 / 100。
- 按本题分数降序，同分同名次。条按本题类型上色：标准评判题荧光绿 500 加墨边，主动设计题紫 300；最高分那一行条尾挂荧光绿四角星，分数荧光绿高光；指向某行，条加深一档。
- 分数为 `null` 的模型排在最后：名次空，条的位置铺斜线纹，分数处写「评测中」。
- 默认显示前 10 行，多于 10 个时下面「展开全部 N 个」。
- 模型名打开模型侧面板（与两个榜单页同一部件）。
- 空（没有任何模型有分数）：「这道题还没有评分结果，评完后各模型的分数从高到低排在这里。」

**4. 代表作** `// WORKS`（手填）
- 主动设计题：上面一个 16:9 大框（直角，1px 细线），放截图或录像；下面一排缩略图，可点（右下小切角），当前一张是淡紫底加底边紫条。大框下一行字段：`模型名 │ 本题分数 │ 一句说明`。录像用带控制条的播放器，不自动播放，有封面图。
- 标准评判题：同一个大框换成解答摘录：代码或证明片段（等宽字，细边框纸色底），或截图；下一行同样是 `模型名 │ 本题分数 │ 一句说明`。
- 多件作品按得分从高到低排。
- 空：大框铺斜线纹，中间纸色底一句。设计题：「代表作的截图和录像还没放上来，放上来后按得分从高到低排在这里。」标准评判题：「代表性解答还没放上来，放上来后按得分从高到低排在这里。」

**5. 评分要点** `// SCORING`（上半自动，下半手填）
- 上：复用说明页里这道题的图示。主动设计题是它的分值条；标准评判题是所在类别的判法图或计分曲线。
- 下：手填要点列表。
- 块尾链接「完整评分方向」→ `/about/#<类别>`。
- 空（手填部分）：图示照常显示，下面一句「这道题的评分要点还在整理，整理好后写在这里。」

### 页尾
- 上一题 / 下一题：两条记录行（编号 + 题名），按 `No.` 顺序，第一题没有上一题，最后一题没有下一题。

### 左栏
- 本页目录：五个区块 + 上一题 / 下一题，当前块紫条。区块为空时目录里照常列出。
- 本题统计：类别、类型、限时、权重、本题最高分（数据高光）和得分模型、已评模型数。
- 同类别的题：本类别其他题的题名链接；只有一题的类别不显示这一组。

### 空状态的样子
- 细线框，底铺斜线纹，句子压在纸色底上（`.st-empty`）。区块标题照常显示，空状态里不放按钮。

## 三、动效（参数见 motion.md）

- 换页快门、命令栏当前块滑动（全站）
- 题目页标题下光谱条扫过
- 目录当前节滑动
- 记录行指向（套件自带）；权重条指向高亮（与说明页同一图示）
- 得分条进入视口时从 0 伸到分数（只播一次），分数乱码后落定
- 展开全部 N 个：新行逐行亮起
- 代表作切换：大框快门换图
- 评分图示进入视口时绘制（与说明页同一图示）
- 模型侧面板推入、推回（同榜单）
