## 段落（README 各节 → 页面）

### 01 项目简介 `#intro`
- 六条要点（是什么、测谁、怎么测、两类题、谁来评、总分）排成定义行：左列粗体短标签，右列一句话，行间细线。
- 图示「一道题怎么测」。

### 02 题目总览 `#overview`
- 导语一句：README 原句，“点题名可看题面原文”改成“点题名进入题目页”。
- 图示「权重条」，下接总览表（`.st-table`）：类别（图标 + 名）│ 题目 │ 限时 │ 交付物（代码字体）│ 权重（右对齐）；末行「合计 12 题 100%」。
- 表下两句：网页题双击 `index.html` 运行、操作系统嵌套的承载环境；权重先分到类别、类别内平分。
- 联动：指向权重条某段，表里对应的行落紫条；指向表行，权重条对应的格变实紫。

### 03 题目与考点 `#tasks`
- 8 个类别各一小节。小节头：类别图标 + 中英成对标题（英文取 `tasks.json` 的 `en`），右端字段 `N 题 │ 权重 X%` 和小链接「类别榜」→ `/categories/#<类别>`。
- 类别说明一句（README 原文），接这一类的图示。
- 每道题一条，题与题之间一条细线，不用卡片：
  - 题名（四级标题，链到题目页）
  - 引用行：一句定位
  - 字段：`限时 │ 交付物 │ 权重 │ 计分`
  - 考点列表：粗体引词 + 一句
  - 折叠块「评分方向」或「分项与计分」：README 折叠块里的列表和分项表（评分方向 │ 分值 │ 分项，分值右对齐）

### 04 测试形式 `#format`
- 8 个小节照 README：谁在运转测评、一场作答怎样进行、提醒与立即续做、故障与续做、隔离的作答环境、两个测试批次、工具与联网规定、评分员怎么评。
- README 的表一律用 `.st-table`，首列粗体；提醒的原文用引用样式（左边墨线）。
- 「提醒的去重与补发」放折叠块；角色表里的“见下文”链到 `#format-8`。
- 四张图示（时间线、谁能看到什么、测试赛程、各类题能用什么）各放在对应小节的表格前。

### 05 打分机制 `#scoring`
- 总分怎样合成：图示「分数进入总分」→ 两栏对照表（标准评判题 / 主动设计题）→ 总分公式块 → 两条说明 → 折叠块「评分失败与精度」。
- 各题型的计分方式：图示「六种题型怎样计分」→ 三个折叠块：极值构造锚点表、性能题加速比与锚点（含公式和两张锚点表）、鲁班锁步数计分（含公式和分档表）。锚点表横排。
- 设计题计分：图示「分项打分示意」+ README 那段说明。
- 公式块用 MathML 写进页面，不引公式库；居中于阅读栏，上下留白，字用界面字体。

### 06 设计原则 `#principles`
- 三组：出题、作答、评分，每组中英成对小标题（`Setting` / `Answering` / `Grading`）。
- 条目是“粗体引词 + 一句”，三组连续编号 01–11（宽体编号在左）。

### 仓库结构：删掉
- 目录树、`Grading/` 文件表和调研记录表只对开发者有用，网页不放。
- 页尾留一行：题面原文、评分指南和评测脚本在 GitHub 仓库（链接）。各题题面原文从题目页链出。

## 图示

通用：
- 内联 SVG，由 D3 画；颜色只用 `--st-*` 变量，切深浅自动跟着变；字用 Saira + 黑体，数字等宽。
- 直角、1px 细线，不分类别色；类别靠图标（`website/icons/categories/`）和名字区分。
- 上色按 [visual.md](visual.md)：标准评判题的数据用荧光绿族，主动设计题用紫族，参考和基准（锚点表的参考值、鲁班锁的 B、及格线）用青；指向和选中加深一档；“通过、得分”墨色实心，“0 分”空框，“规定禁止”斜线纹；README 里的示例数字用次要墨，图名后加「示意」。
- 每张图上面眉标 `// FIG.01` 起编号加中文图名；下面一行读数（字段样式），指向图中元素时换成该元素的数值。可指的元素都能 Tab 聚焦，读数同步。
- 类别、题、权重、限时、类型从 `tasks.json` 取；评分方向分值、锚点、示例这些取 README 原文写在页面里。
- 等比缩放用满白纸宽；最窄时图里字不小于 12px。

## 动效（参数见 motion.md）

- 换页快门、命令栏当前块滑动（全站）
- 标题下光谱条扫过
- 目录当前节滑动；目录子项展开
- 图示进入视口时绘制（每张图只播一次：线描出，格按顺序亮起）
- 图示指向高亮；读数乱码后落定
- 权重条与总览表联动高亮
- 折叠块展开时内容逐行亮起
- 链接、表行、按钮的指向效果用套件自带的
