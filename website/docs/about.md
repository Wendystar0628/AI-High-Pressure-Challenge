# 挑战赛说明 `/about/`

阅读页，是项目 README 的网页详细版。文字以 README 为准，不新编事实。README 的配图只用来确定每张图要讲的内容，网页图示按星辰风格新画成内联 SVG，跟随深浅主题；不用 README 的旧配图、旧图标和旧配色。

## 版式

- 左栏贴顶，上面本页目录，下面一张统计（`.st-ledger`）：题目 13 题、类别 10 个、标准评判题 7 题 50%、主动设计题 6 题 50%、单题限时 60–100 分钟。
- 右边一张白纸紧贴左栏、左对齐，页头和正文都在白纸上。白纸有最大宽度，比正文宽。正文和列表限一行阅读宽度（技能的 `measure`）；图示、表格、公式块用满白纸宽。没有右侧页边。

## 页头

- 眉标 `// ABOUT`，标题「挑战赛说明」，标题下光谱条。
- 导语：README 顶部那句（13 道题、10 个类别、60–100 分钟独立作答、到时直接中止）。
- 字段：`13 题 │ 10 个类别 │ 标准评判题 7 │ 主动设计题 6`。
- 开篇图「十类十三题」（见图示表）。

## 左栏目录

- 六节，编号 01–06：项目简介、题目总览、题目与考点、测试形式、打分机制、设计原则。
- 只展开当前节的子项：题目与考点下是 10 个类别（类别图标 + 名）；测试形式下 8 个小节；打分机制下 3 个小节。
- 当前节和当前子项用目录的紫条标出，`aria-current` 同步。
- 锚点：`#intro` `#overview` `#tasks` `#format` `#scoring` `#principles`；类别用路径名 `#reason` `#algo` …；小节用 `#format-<n>`、`#scoring-<n>`。点目录跳到锚点，地址栏同步，可直接分享到某一节。

## 段落（README 各节 → 页面）

### 01 项目简介 `#intro`
- 五条要点（是什么、测谁、怎么测、两类题、总分）排成定义行：左列粗体短标签，右列一句话，行间细线；细节不在这里展开，链到 04、05。
- 图示「一道题怎么测」。

### 02 题目总览 `#overview`
- 导语一句：README 原句，“点题名可看题面原文”改成“点题名进入题目页”。
- 图示「权重条」，下接总览表（`.st-table`）：类别（图标 + 名）│ 题目 │ 限时 │ 交付物（代码字体）│ 权重（右对齐）；末行「合计 13 题 100%」。
- 表下两句：网页题双击 `index.html` 运行、操作系统嵌套的承载环境；权重先分到类别、类别内平分。
- 联动：指向权重条某段，表里对应的行落紫条；指向表行，权重条对应的格变实紫。

### 03 题目与考点 `#tasks`
- 10 个类别各一小节。小节头：类别图标 + 中英成对标题（英文取 `tasks.json` 的 `en`），右端字段 `N 题 │ 权重 X%` 和小链接「题目类别榜」→ `/categories/#<类别>`。
- 类别说明一句（README 原文），接这一类的图示。
- 每道题一条，题与题之间一条细线，不用卡片：
  - 题名（四级标题，链到题目页）
  - 引用行：一句定位
  - 字段：`限时 │ 交付物 │ 权重 │ 计分`
  - 考点列表：粗体引词 + 一句，与题目页的考点是同一份文字
  - 主动设计题有折叠块「分项与计分」：分项表（评分方向 │ 分值 │ 分项，分值右对齐）；标准评判题不设折叠块，计分规则由本类图示和 05 节交代

### 04 测试形式 `#format`
- 8 个小节照 README：谁在运转测评、一场作答怎样进行、提醒与立即续做、故障与续做、隔离的作答环境、两个测试批次、工具与联网规定、评分员怎么评。
- README 的表一律用 `.st-table`，首列粗体；提醒的原文用引用样式（左边墨线）。
- 「提醒的去重与补发」放折叠块；角色表里的“见下文”链到 `#format-8`。
- 四张图示（时间线、谁能看到什么、测试赛程、各类题能用什么）各放在对应小节的表格前。

### 05 打分机制 `#scoring`
- 总分怎样合成：图示「分数进入总分」→ 总分公式块 → 两条说明 → 折叠块「评分失败与精度」。
- 各题型的计分方式：图示「六种题型怎样计分」→ 三个折叠块：性能题加速比与锚点（含公式和两张锚点表）、鲁班锁步数计分（含公式）、图纸建模吻合度计分（含公式）。锚点表横排。
- 设计题计分：图示「分项打分示意」+ README 那段说明。
- 公式块用 MathML 写进页面，不引公式库；居中于阅读栏，上下留白，字用界面字体。

### 06 设计原则 `#principles`
- 三组：出题、作答、评分，每组中英成对小标题（`Setting` / `Answering` / `Grading`）。
- 条目是“粗体引词 + 一句”，三组连续编号 01–13（宽体编号在左）。

### 仓库结构：删掉
- 目录树、`Grading/` 文件表和调研记录表只对开发者有用，网页不放。
- 页尾留一行：题面原文、评分指南和评测脚本在 GitHub 仓库（链接）。各题题面原文从题目页链出。

## 动效（参数见 motion.md）

- 换页快门、命令栏当前块滑动（全站）
- 标题下光谱条扫过
- 目录当前节滑动；目录子项展开

- 图示指向高亮；读数乱码后落定
- 权重条与总览表联动高亮
- 折叠块展开时内容逐行亮起
- 链接、表行、按钮的指向效果用套件自带的
