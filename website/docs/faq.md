# 猜你想问 `/faq/`

阅读页：观众最常问的问题和回答，按板块排。内容只在内容文件里，加问答、加板块不改代码；同一份内容在页上导出成 1920×1080 的图片（视频和转发用）。

## 内容

- 中文 `site/content/zh/faq.json`：板块的顺序、问答、标签、附加块都以它为准。英文 `site/content/en/faq.json` 只写译文，板块和问答按 `id` 对上中文，没译的显示中文。
- 格式写在 `site/src/pages/faq/model.js` 顶上，要点：
  - 板块 `{ id, title, wide?, items }`；`wide: true` 只影响导出图片（整宽、三张一行），不写时半宽、两个板块左右并排。
  - 问答 `{ id, tag?, q, a }`，编号 Q1、Q2… 按出现顺序自动生成；`a` 是一段字，或段落和附加块的数组。
  - 没有 `q` 的一条是说明块 `{ id, lead, a, side }`：大号的一句，不编号。
  - 标签：类别路径名（如 `"reason"`），字和颜色取网站的类别名、类别色；或 `{ "kind": "design", "text": "其他主动设计类题目" }` 按题型上色。
  - 附加块：来源网址 `{ "source": { label, url } }`、倍数小块 `{ "ratios": [{ label, pre, value, unit }] }`、权重条 `{ "weights": "说明一句" }`（两类题的百分数读 `data/tasks.json` 的类别权重之和）。
  - 行内：`**重点**` 高亮，`~` 是不断行的空格（`Opus~5.5`、`60~分钟`，连着的一串不拆行），链接同说明页（`lb:`、`about:#x`、网址）。
- 界面文字（页头、目录、导出面板、图片上的页眉页脚）在 `site/src/i18n/<zh|en>/faq.json`。

## 版式

- 同说明页：左栏贴顶，上面本页目录（板块 01–，只展开当前板块的问答 Q1–），下面统计（问答数、板块数、数据更新）；右边白纸。
- 页头：眉标 `// FAQ`，标题「猜你想问」，光谱条，导语，字段 `9 问 │ 4 个板块`，页头横幅 `star/star-cluster`（紫 300）。下接「导出图片」面板。
- 每个板块：轨道分隔线 + 中英成对标题（中文页眉标是 `01 / 英文板块名`）。
- 每条问答一行条目，条目之间细线，不用卡片：左列编号小块 `Q1`（`.st-tag`，链到本条锚点），右列类别标签（色块 + 类别图标 + 类别名，链到题目类别榜）、问题（四级标题）、回答（次要墨色，重点墨色加粗、荧光绿高光笔）。
- 倍数用 `.st-figs` 大数字三格；来源网址完整写出、新窗口打开；权重条荧光绿（墨边）/ 紫 300 两段，下面小按钮「去调权重」到排行总榜的权重沙盘。
- 手机宽度：左栏移到正文之后，编号小块移到问题上面，整页不横向滚动。

## 导出图片

- 面板里「生成图片」：在屏幕外按导出版式排好（`sheet.js`、`sheet.css`），转成 SVG（`sheet-svg.js`，Saira 内嵌、中文用系统字体），再由 `charts/export.js` 的 `svgToPNG` 画成 1920×1080 PNG。生成后列出每一张的缩略图，可以单张保存或「全部保存」，文件名 `ai-decathlon-faq-<zh|en>-<n>.png`。
- 版式照 `videos/faq/faq.html`（用户确认的浅色版）：纸色底、白板、墨字，荧光绿和紫为主体色；直角，线宽至少 2px，不发光；彩色字只用在大号粗字上；荧光绿填充加墨边。深色主题下导出的也是浅色版。
- 页眉：荧光绿 `FAQ` 块 + `FREQUENTLY ASKED`，题名「猜你想问」（「想问」荧光绿笔），右上紫色四角星和页码 `01 / 02`；页脚站名和 `FAQ 1/2`。
- 板块头是墨色整块标签加 3px 墨线；问答是白板卡片，编号荧光绿块；标签用类别色加墨边；来源网址下面青色虚线；倍数墨底荧光绿大字；说明块左边大号一句、右边附加块。
- 自动分页：半宽的板块在两栏里依次往下流（整块放得下就整块放，放不下才按问答拆开，续上的一栏重写板块头加「（续）」）；整宽的板块排在下面，一行三张、同行等高，说明块独占一行；一行放不下就换页。任何一块的下沿不越过 1000px（页脚在下面）。段落最后一行只剩一个字时把它和前面几个字一起换行。
