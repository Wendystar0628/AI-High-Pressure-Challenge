# 配色与版式

全站和 README 配图共用这一套。技能 `website/stellar-ui-skill` 的固定规则照旧（四角星、切角表示可点、直角细线、红色只给删除），这里定本站的配色比例、色阶、语义、版式和装饰用法。

依据：60-30-10 配色比例；伊顿的色彩对比（互补、明度、冷暖、纯度、面积）；歌德的互补色面积比（亮色面积小于暗色）；ColorBrewer 的顺序、发散、分类配色；WCAG 对比度；格式塔原则；对比、重复、对齐、亲密四原则；网格系统；Tufte 的数据墨水比；Cleveland 与 McGill 的视觉编码排序。

## 一、配色比例 6:3:1

- 版面先分两层：中性底（纸、板、墨、灰）承载文字和留白，占画面大头；有色部分按 **紫 6、荧光绿 3、星光青 1** 分配。
- **紫 `#9859FF`，主色**：品牌、结构、当前位置、主动设计题的数据、单一指标图表的默认系列。
- **荧光绿 `#D1FF57`，次色**：紫的互补色。主要操作、标准评判题的数据、星光、最佳成绩的标记、深色带上的线和字。
- **星光青 `#62D4F5`，点缀**：参考和基准：及格线、参考步数、平均值、全场最高刻线，以及光谱条。每屏一两处。
- 紫和荧光绿是互补对比，明度差大（L* 约 53 对 95）。按歌德的面积比，亮色面积要小于暗色，6:3 正好让两色平衡。青是技能光谱条里的第三色，给冷色添一层；暖意只来自荧光绿，保持星空的冷调。

## 二、色阶

大面积只用浅色阶，饱和的 500 只用在小面积和焦点（纯度对比、面积对比）。

| 色阶 | 紫 | 荧光绿 | 星光青 |
|---|---|---|---|
| 100 底色 | `#F1E8FF` 当前项底、分组底 | `#F6FFDB` 分组色带 | `#E2F7FD` 参考区间底 |
| 300 浅 | `#C9AEFF` 普通柱、浅分段 | `#E6FFA3` 浅分段 | — |
| 400 | `#B083FF` 分段 | — | — |
| 500 主值 | `#9859FF` | `#D1FF57` | `#62D4F5` |
| 600 深一档 | `#7A3CF0` 强调柱、选中 | `#A9D932` 深分段 | — |
| 700 | — | `#7FA318` 只给算法对抗的类别色 | — |
| 800 写字 | `#4A22B8` 浅色底上的紫色小字 | `#4F6A00` 浅色底上的绿色小字；识图建模的类别色 | `#0B7FA3` 浅色底上的青色线和字 |

- 深色主题：紫色字用紫 300；荧光绿 500 可以直接做线和字；青用 500。
- 对比度：正文 ≥ 4.5:1，图形 ≥ 3:1。浅色底上，荧光绿 500 和青 500 只做填充，并加 1px 墨边或贴着墨色元素；要写这两种颜色的字或细线时用 800。

## 三、颜色的意思（全站和 README 一致）

| 意思 | 用色 |
|---|---|
| 品牌、结构、当前位置 | 紫 500；当前项是紫 100 底加 3px 紫条 |
| 主动设计题 | 紫族，各类别的颜色见下表，分段间 1px 纸色缝 |
| 标准评判题 | 荧光绿族，各类别的颜色见下表，带墨边 |
| 主要操作 | 荧光绿 500 填充，墨字 |
| 最佳、第一名 | 数字用荧光绿高光（荧光绿底墨字，技能的 `.st-hi`），在深色底或图表标签里用墨底荧光绿字；旁边一颗荧光绿四角星。柱子本身不换色 |
| 参考、基准（及格线、参考步数、平均、全场最高） | 星光青：线用青 800（深色用 500），区间底用青 100 |
| 低于及格线、未出分、评测中 | 中性灰填充或斜线纹，不用彩色 |
| 对比视图的 2–4 个模型 | 按勾选顺序：紫 500、荧光绿 500、星光青 500、墨，后三种加墨边 |
| 删除 | 红，只此一处 |

- 类别的固定颜色（全站和 README 一致；按类别顺序深浅交替，相邻两类明度差大；最浅用到 300，不用 100，免得看着像空条；荧光绿各档加墨边）：

  | 标准评判题 | 颜色 | 主动设计题 | 颜色 |
  |---|---|---|---|
  | 数学推理 | 绿 600 | 复杂交互应用 | 紫 800 |
  | 性能优化 | 绿 300 | 游戏设计与开发 | 紫 400 |
  | 算法对抗 | 绿 700 | 物理模拟 | 紫 600 |
  | 空间推理 | 绿 500 | 视觉设计与渲染 | 紫 300 |
  | 识图建模 | 绿 800 | 系统架构与实现 | 紫 500 |

- 同一张图里一种颜色只表示一件事。
- 厂商图标：`website/logos/mark/` 里有彩色版 `<名>-color.svg` 的用彩色版，深色主题也不反色；没有的（OpenAI 等）用单色版，跟随文字颜色。都不染紫、不染荧光绿。
- 两类题同时出现时，除颜色外再用形状区分：标准评判题用方块，主动设计题用四角星。

## 四、配色禁忌

- 紫和荧光绿等面积并排、细线相贴都不行：同时对比会让边缘发闪。两色相邻时隔一道纸色缝或墨线。
- 不做紫到绿的渐变，也不把两色混成中间色。
- 一屏至多一整块紫 500（技能规则不变）；另外可以有一条整宽的绿 100 色带，用来标出一组内容。
- 紫、荧光绿两色的明度相差大，常见的三种色弱都分得清；青和紫在部分色弱下相近，所以青只做参考线，不做数据系列。（对比视图的第三个模型是例外，柱前另写勾选序号。）

## 五、版式

- **网格**：12 栏，内容最宽 88rem；栏间、页边、内边距都取 8px 基准上的值，宽窗口时页边放宽。
- **字号**：用技能的字号阶。一屏最多四级字号，标题和正文至少差 1.6 倍。
  - 中文标题和英文同等分量：中文和并排的英文同处一处时，中文字号约为英文的 0.8 倍（思源黑体字身约占 0.88em，Saira 大写约 0.70em），让汉字和英文大写一样高。
  - 卡片标题（看板、面板，眉标下的中文）用 22px（`--st-t-h2`），区块标题（一页里分段的标题）用 30px（`--st-t-title`），侧栏小标题用 17px；页面大标题不变。
- **焦点**：每屏只有一个视觉焦点，尺寸最大、颜色最强的那个；其余降一级。首页首屏的焦点是星盘，字标让位。
- **阅读路径**：展示页按 Z 形排：左上字标 → 右上星盘 → 左下内容 → 右下按钮。榜单按 F 形排：名次和名字左对齐成一条竖线，数字右对齐。
- **格式塔**：
  - 同一组靠近，组与组之间用留白隔开，不加框（亲密）。
  - 同类元素同形同色（相似）。
  - 一组数据用共同底色或细线圈出（共同区域）。
- **对齐**：文字左对齐到栏线；数字列右对齐，用等宽数字；同一页各看板的刻度列对齐。
- **留白**：段与段之间的留白明显大于段内各组之间，组内最紧；切角旁的留白按技能规则。
- **图表**：
  - 去掉不承载数据的框、底色和重复图例，能直接标注就不放图例（数据墨水比）。
  - 优先用位置和长度编码，面积和颜色次之（视觉编码排序）。矩阵格里必须写数字。
  - 同一页里同一个量用同一把刻度。

## 六、装饰素材（`website/decor`）

| 位置 | 素材 | 浓度 |
|---|---|---|
| 每页背景两角 | `starfield/starfield-corner-tr` + `starfield-corner-bl`（代替技能自带的星图底纹） | 0.2 |
| 首页首屏 | `orbit/orbit-corner-br` 从右下伸出，衬在星盘后面；星盘外圈刻度照 `dial/dial-ring` 的画法 | 0.2 |
| 第一名徽记 | `rays/rays-burst-light`（深色用 `-dark`），首页前五名和模型得分页的第一名 | 1 |
| 段落分隔 | `constellation/constellation-strip`（首页）、`orbit/orbit-divider`（说明页）、`rays/rays-divider`（榜单页的两组之间）；同一页只用一种 | 1 |
| 页头横幅 | 排行总榜 `dial/dial-quarter-tr`；题目类别榜 `dial/dial-arc-wide`；说明页 `trails/trails-wide`；题目详情 `constellation/constellation-pair`；模型得分 `rays/rays-fan-up`；猜你想问 `star/star-cluster`（紫 300） | 0.5 |
| 看板角 | `starfield/starfield-panel`，每页只给最重要的一块看板 | 0.5 |
| 空状态 | 没有数据 `orbit/orbit-nested`；未出分 `star/star-outline`；评测中 `trails/trails-center` | 1 |
| 页脚 | `sphere/sphere-horizon` 从页脚下沿升起 | 0.5 |

- 一屏里的装饰最多两处，背景两角不算；双色版每页最多一处，其余用单色版，单色版的颜色用墨 2 或紫 300。
- 装饰不压数据和正文，永远在内容下面，也不动。
