# 全站动效

依据：迪士尼动画原则在界面上的用法（时间、缓入缓出、预备、跟随与重叠、舞台调度）；Material 动效（按距离和面积定时长、进入减速退出加速、共享元素过渡）；IBM Carbon 的效率型和表现型动效；Heer 与 Robertson 的统计图动画过渡（分阶段、对象恒常）；Doherty 阈值（回应要及时）；格式塔的共同命运。曲线、时长和错开沿用技能（`stellar-ui-skill/references/motion.md`、`assets/tokens.json`、`fx.js`），变体 `动效 full`。本文写每个动效的用途、触发、曲线、档位和先后，具体时长以 `tokens.json` 为准。

## 一、原则

1. **每个动效只做四件事之一**：
   - 定位：东西从哪来、到哪去，比如换页、名字接力、锚点落位、侧面板。
   - 反馈：按下、擦入、完成。
   - 关系：联动高亮、视图形变、星位就位。
   - 引导注意：入场时焦点先动，最佳成绩亮起星光。
   说不出属于哪一件的，不做。
2. **效率型和表现型**：
   - 回应操作的是效率型，以短、中档为主，用户在等它。
   - 打开页面、图第一次出现是表现型，单件可用长档，整段不超过技能的 `sequenceMax`，每页每张图只播一次。
   - 同一个元素再出现时只用效率型。
3. **舞台调度**：一次只让一个主角动。焦点先动，配角稍晚跟上，和焦点的尾段重叠（跟随与重叠）。
4. **共同命运**：一起变化的东西用同一曲线、同一档位、同一方向；不同组靠错开拉开层次。
5. **对象恒常**：同一个模型、类别或题目，在动画前后是同一个元素，只变位置和形状，不消失再出现。
6. **可打断**：动画进行中来了新操作，从当前位置直接转向新目标，不排队，也不先回起点。
7. **静止的底**：背景星图和装饰不动。唯一持续的动画是首页题目滚动条，指向即停。
8. **减少动态效果**：系统打开这个设置时全部关闭，一切直接到终态。

## 二、档位与曲线

时长分三档，各档对应技能 `tokens.json` 里 `motion.duration` 的令牌：

| 档 | 技能令牌 | 用在 |
|---|---|---|
| 短 | `press`、`row`、`figFill` | 按下、颜色变化、浮签、联动高亮、紫条落下 |
| 中 | `wipe`、`edge`、`lock`、`come`、`scramble`、`shutter`、`assemble`、`tab`、`drawerIn` | 擦入、当前标记滑动、侧面板、换页、行重排、数据形变的每一段 |
| 长 | `stroke`、`fill`、`power`、`sweep`、`scrambleLoad`、`drive` | 打开页面、图第一次绘制 |

- 档位按距离和面积定：小位移、小面积用短档，跨大半屏或整页用中档。
- 退出比进入快，比例照技能，一律 mech。
- 曲线：
  - 进入用 snap，减速到位。
  - 屏内的移动、变形、擦入和所有退出用 mech，慢起硬停。
  - 颜色和光谱条用 ease；数字落定和进度用 linear。
- 错开只用技能的三档：行 `stagger.row`、段 `stagger.segment`、块 `stagger.block`。一组多时压缩间隔，不拉长总时长。错开顺序跟阅读路径：展示页按 Z 形，榜单从上到下，星盘顺时针。
- 拖动这类直接操作：跟手，不加缓动。

## 三、数据图的过渡

- 分三段：刻度 → 图形 → 数字。每段中档，后一段在前一段中途起步（重叠）；整段仍是一次回应，不拖成入场。
- 刻度不变时跳过第一段。位置、长度、颜色不在同一段里一起变。
- 排序：所有行一起滑到新位置，按新名次依次稍晚起步，总错开压短，减少交叉遮挡。
- 筛选：被筛掉的行先收起，留下的行补位，新出现的行逐行亮起。
- 数字：值变了才落定，和所属图形的最后一段同时结束。
- 屏外的图形直接到终态，只动视口里的。

## 四、各处的动效设计

### 首页（入场顺序见 [home.md](home.md#入场顺序)）

- **入场**：按骨架 → 焦点 → 字标 → 数据 → 列表 → 连线的顺序。
  - 星盘先组装，是焦点；字标稍晚推入。
  - 12 颗星从紫盘外沿沿半径飞到得分位置，顺时针依次错开，和扇区组装同一方向。
  - 星座连线跟在星后面，从 12 点顺时针画出。马克笔最后划过。
- **换本页模型**（点前五名）：分三段，前后重叠。
  1. 星沿半径移到新分数，同时动。
  2. 星座连线补间成新形状，稍晚起步。
  3. 紫盘标签擦入、总分落定，再晚一拍。新模型拿第一的星最后变成荧光绿。
- **指向扇区**：括弧和光束画出（锁定）；其余扇区退淡；紫盘读数切换。离开后恢复。
- **滚到“总分怎么合成”**：每行 8 格按类别顺序从左揭开，格间、行间依次错开，整段在入场时长内。
- **滚到“一道题怎么测”**：
  - 三条计时条同时起步，时长和限时分钟数成正比，让时间差本身被看见；最长一条也在长档内。
  - 走到头时止线落下，这一档的星逐颗亮起。
- **去往各页**：指向时空心大编号紫色灌满，同时字段数字落定。

### 排行总榜

- **入场**：看板通电 → 刻度条 → 柱子从 0 长出（从上到下逐行错开）→ 分数落定。
- **换视图**：分段控件的当前块滑过去，同时开始下表的三段。反向切换按原路倒着走。

| 从总分到 | 刻度 | 图形 | 数字 |
|---|---|---|---|
| 及格线 | 刻度标签换成 −60…+40，60 处基准线变青 | 柱子改以 60 为原点：高于 60 的左端滑到 60；低于 60 的翻到左侧 | 柱端差值落定 |
| 得分构成 | 图例擦入 | 每根柱沿长度切成 8 段，段缝张开，颜色从紫 300 变成类别色（段按类别顺序错开） | — |
| 两类题 | — | 柱子收成两个标记：左端滑到标准评判题分，右端滑到主动设计题分，中间留连线 | 两个分数落定 |
| 类别矩阵 | 表头擦入 | 柱子淡出，8 格按列从左到右灌满（逐列错开） | 格内数字落定 |
| 对比 | 行收起 | 新的项目行逐行亮起 | — |

- **换排序**：行重排（第三节），名次列数字落定。
- **权重沙盘**：
  - 拖滑块时柱长跟手实时变，行不重排，免得在手下跳动。
  - 松手稍停后行重排，名次差 `▲2` 擦入。
- **勾选**：勾选框填色；被勾的模型在各图里加深一档；对比栏的槽擦入。
- **指向一行**：紫条落下，其余数据图形退淡，浮签出现。
- **侧面板**：
  - 推入；推到大半时内容开始逐行亮起；推入结束后面板里的柱子长出。
  - 换模型不收面板：标题擦入，柱子形变。

### 类别榜

- **入场**：只动首屏里的看板（通电，按块错开）和它们的柱子，屏外的直接在。
- **到锚点**：平滑滚动到位后，目标看板的页签伸开，停留片刻后收回。
- **展开各题得分**：
  - 开关箭头转 90°。
  - 子行区域从上往下揭开，下面的内容同时下移。
  - 揭开后子柱从 0 长出，逐行错开。
  - 收起时倒序，比展开快。
- **展开全部 N 个**：视口里的新行逐行亮起；按钮字擦入换成「收起到前 10」。

### 模型详情

- **入场**：页头通电 → 星盘组装、星位就位（同首页，星从中心出发）→ 两张柱图长出。
- **上一个 / 下一个**：
  - 名字和图标向点击方向滑出，新名字从另一侧滑入，方向表示前后。
  - 星和柱子按首页换模型的三段走。

### 挑战赛说明、题目拆解

- 标题下的光谱条扫过；正文和段落不做入场。
- 图示第一次进入视口时绘制一次：线按阅读方向描出，格按顺序逐格亮起，整段在入场时长内。
- 目录：当前节的紫条随滚动滑到新位置。点目录时平滑滚动，目标标题左边紫条擦入，停留片刻后收回。
- 折叠块：内容逐行亮起，下方内容下移。
- 题目页代表作：切换时新图斜切盖过旧图（换图快门），画框不动。

### 全站

- **换页**：快门。点类别名、题名或星换页时，被点的名字作为共享元素滑到新页标题位置（名字接力），其余部分照常快门。
- **命令栏**：指向时荧光绿细条沿底边擦过；换页时当前块滑动。
- **搜索**：
  - 对话框通电打开、从下往上关上（技能的对话框进出）。
  - 每次输入后结果区硬切，新结果逐行亮起，很快到齐。
  - ↑ ↓ 选中块滑动，短档。
- **深浅切换**：从按钮处圆形揭开，速度和时长范围照技能的 `themeReveal`。
- **按钮**：
  - 指向时擦入（普通按钮擦入荧光绿，主要按钮擦入墨色）。
  - 按下；完成时荧光绿穿过一次（技能的 `done`）。
  - 存为图片、下载数据用这个完成反馈。
- **提示条**：擦入、停留、擦掉，照技能提示条的进、停、出。

## 五、名称速查

各页文档用这些名字，括号里是同义叫法。档位见第二节；写了令牌名的照技能取值，没有令牌的按同档定。

| 名称 | 档位 | 曲线 | 动什么 |
|---|---|---|---|
| 光谱条扫过 | 长 `sweep` | ease | scaleX 0→1 |
| 字标推入 | 长 `drive`，空心行稍晚 | mech | clip-path 揭开、横移 |
| 马克笔划过 | 长 `stroke` | mech | background-size |
| 数字落定（读数落定） | 打开长 `scrambleLoad`；换值、指向中 `scramble` | linear | 数字逐位乱码后从左锁定 |
| 通电 | 长 `power`，按块错开 | mech | clip-path 从上往下、opacity |
| 逐行亮起 | 中 `come`，按行错开 | snap | clip-path、横移、opacity |
| 星盘组装 | 中 `assemble`，按段错开 | snap | opacity、微缩放到位 |
| 星位就位 | 中；打开时依次错开 | 打开 snap；换模型 mech | 星沿半径移动 |
| 星座连线 | 打开长；换模型中 | mech | stroke-dashoffset；补间 `d` |
| 图表绘制（柱子绘制、得分条伸出、图示绘制） | 柱、条、线长；点中 | mech；点 snap | 从基线长出；描线；点显出 |
| 计时条走满 | 和限时分钟数成正比 | mech | scaleX；星逐颗亮起 |
| 柱形变形 | 中 | mech | D3 补间长度和位置 |
| 行重排 | 中，按新名次错开 | mech | FLIP translateY |
| 视图形变（视图切换重排） | 三段，各中档，相互重叠 | mech | 见排行总榜换视图表 |
| 视图换片 | 收起短 + 逐行亮起 | mech；snap | 进出对比视图 |
| 联动高亮（指向高亮） | 短 | ease | 同一对象加深一档，其余退淡（全站统一用一个退淡不透明度，定在 `site/src/motion.js` 的令牌里） |
| 勾选点亮（勾选变色） | 颜色短；槽中 | ease；mech | 颜色；clip-path |
| 浮签 | 短 | 进 snap；出 mech | 略上移并显出 |
| 读数切换 | 标签中；数字中 `scramble` | mech；linear | clip-path、文字 |
| 锁定 | 中 `lock` | mech | 括弧和光束 stroke-dashoffset |
| 荧光绿擦入、亮边扫过 | 中 `wipe`；`edge` | mech | transform |
| 按下 | 短 `press` | — | 技能的下沉微缩 |
| 紫条落下 | 短 `row` | snap | transform |
| 页签伸开 | 中 `tab` | mech | transform |
| 紫色灌满、荧光绿垫底 | 长 `fill`；短 `figFill` | mech | background-size |
| 当前标记滑动（当前块滑动、目录当前节滑动） | 中；换页 `shutter` | mech | transform |
| 命令栏擦过 | 短 | mech | transform |
| 侧面板推入 / 推出 | `drawerIn` / `drawerOut`，遮罩 `scrimIn` / `scrimOut` | mech | transform；opacity |
| 面板换内容 | 中 | mech | 标题 clip-path；柱 D3 补间 |
| 展开 / 收起（子行展开、折叠块展开） | 中；收起更快 | mech | clip-path、FLIP 下移上移 |
| 展开箭头 | 短 | mech | rotate 0↔90° |
| 换页快门 | 中 `shutter` | mech | clip-path 斜切 |
| 名字接力 | 中 `shutter` | mech | `view-transition-name` 共享元素 |
| 锚点落位 | 平滑滚动；页签伸开或紫条擦入，停留片刻后收回 | mech | transform、clip-path |
| 换图快门 | 中 `shutter` | mech | clip-path 斜切 |
| 深浅揭幕 | `themeReveal` | mech | 圆形 clip-path |
| 滚动条 | `ticker` 一圈 | linear | transform |
| 未知进度 | 完成即停 | linear | 紫格移动 |

## 六、实现

- 档位、曲线和错开集中在 `site/src/motion.js` 顶部，从 `tokens.json` 读；技能没有的（计时条、星位就位等）在同一处按档位定。
- HTML 元素只动 transform、opacity、clip-path、background-size、stroke-dashoffset。SVG 的几何属性（`d`、`x`、`width`、`r`、`transform`）由 D3 补间。
- 数据元素按 id 绑定（D3 的 key），保证对象恒常；D3 新过渡直接接管旧过渡，实现可打断。
- CSS 动效写在 `@media (prefers-reduced-motion: no-preference)` 里；JS 先查 `matchMedia('(prefers-reduced-motion: reduce)')`，为真时补间时长设 0、FLIP 跳过、浮签直接显隐。
