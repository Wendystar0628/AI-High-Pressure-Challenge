# 星辰风味 UI（stellar-ui）

这个 skill 教你做出"像一本观测笔记、一张星图那样"的桌面网页界面：纸面安静，线条细，数字排得整齐，只有一对互补色在说话。**只做桌面网页**（宽 1024 以上的浏览器窗口）。

## 先抓住气质：六条法则

> 读起来像一本编了号的观测笔记；首屏和控制台像天文台里的一张星图和一台仪器。

这句话是给你的设计方向，不是界面文案，不要把它写进产品里。

不是"深色背景 + 霓虹 + 满屏星空粒子"的科幻页面，也不是把天文照片铺满背景。从星图取的是**秩序**：星等分大小、坐标成网格、每颗星有编号。归成六条法则：

1. **一对互补的主题色**：紫 `#9859FF` 是**品牌和结构色**（字标、大标题和大数字的强调、`//` 分节标记、轨道线和星图线、图表主色、链接下划线、当前位置）；荧光绿 `#D1FF57` 是**能量和高光色**（主要操作、最佳成绩和新纪录这类数据高光、提示和标记、星星的光点）。中性色占大头；有色部分按 6:3:1 分配：紫 6、荧光绿 3、星光青 `#62D4F5` 1（只做参考和基准）。两色可以在同一张图里各表示一组数据，但不等面积并排，不细线相贴，不混成渐变。
2. **切角 = 可点击**：切掉一个小角的块可以按；正文、图片、展示用的栏目都是直角。看形状就分得出按钮和展示栏目。
3. **拉宽字母，加粗汉字**：英文小字大写、拉宽、在上，中文粗体在下（`// RECORDS` / `记录`）。
4. **使用数字装饰**：编号、日期、计数、进度这些真实统计数字（`No.024`、`2026.10.17`、`24 篇`、`第 214 夜`）用宽体等宽数字排出来，就是界面的装饰。数字必须是真的，不编造。
5. **简约细线分割空间**：用 1px 细线分区，引线的端点是一颗四角星；不用滥用的阴影、发光、渐变和带边框的卡片。背景只有两角极淡的一小片星图。**星星一律画成四角星。**
6. **干脆利落的动画**：短、硬、机械，每个动效对应一次操作；不弹跳、不缩放弹出，星空永远不动。

## 第一步：选页面类型

每个页面先判断属于哪一种。三种页面类型共用同一套颜色和部件，差别在"敢不敢大"。

| 页面类型 | 用在 | 样子 |
| --- | --- | --- |
| **阅读**（安静） | 文章、详情、列表、归档、设置、帮助 | 左侧竖排导航；一栏正文（约 38 个汉字宽），黑体常规字重、行高宽；右边页边放目录和真实统计；紫色只在分节标记、链接下划线和当前项上，荧光绿只在马克笔和要看一眼的小块上 |
| **展示**（大胆） | 首页、落地页 | 超大宽体字标（实心墨字加紫色空心字）、切角画框和斜线纹影子、空心大编号、深色滚动条、入场动效；全页可以有一整块紫色（通常是画框），上面一颗荧光绿四角星 |
| **控制台**（大胆但要好用） | 仪表盘、管理后台 | 深色命令栏；中间一个分段星盘，看板围着它排（不排成规整的卡片网格）；下面是干活用的列表、图表和表单；详情用右侧侧面板 |

拿不准时：**内容是给人读的，就用阅读页**。

## 第二步：定变体

这套风格会被很多产品用，不定变体，做出来就都一样。开工前读 `references/variation.md`，然后：

1. 从四组预设里挑一组（`zenith` 天顶、`observatory` 观测站、`nebula` 星云、`midnight` 子夜），或者把五个维度逐项定值：纸色、切角、底纹、密度、动效。两种主题色是固定的，不在变体里。
2. 想好**主视觉**：首屏和控制台中间放什么，从产品自己的内容里来，不用模板里的 LYRA 字标、行星仪线稿和星盘占位数据。
3. 把结果写成三行"变体卡"放在交付说明最前面，只在一个地方设置（`<html>` 上的 `data-st-*`）。

不能变的是固定规则：两种主题色的分工和用量、红色只给删除、切角表示可点击、星星一律四角星、宽体英文配粗体中文、编号日期计数都是真数据、细线、底纹只在两角、机械动效。

## 第三步：照着做

1. 读 `assets/tokens.json`：全部颜色、字号、间距、切角、动效曲线，单位是 CSS px。
2. 读 `references/web.md`：怎么把 `assets/` 接进项目、字体自托管、在 React / Vue / Tailwind / 组件库里用。
3. 模板和界面范式（`references/patterns.md`）用来看部件怎么写、怎么组合，**版式由自己的内容决定**，不照搬模板的结构和占位内容。部件优先用套件里现成的（`references/components.md`）；套件里没有的，按 `references/variation.md` 最后一节从固定规则里推出来。
4. 做完按文末清单逐项检查，并截图对照 `examples/web/`。

模板要用静态服务器打开（浏览器不允许从 `file://` 加载 ES 模块）：在本目录运行 `python3 -m http.server 8766`，打开 `http://localhost:8766/templates/showcase.html`。

## 字体（最容易做错）

一半的秩序感在字上：**宽、几何、大写的拉丁字** + **干净的中文黑体**。没有楷体、宋体、手写体，正文也是黑体。

| 角色 | 推荐 | 用在 |
| --- | --- | --- |
| 界面 | **Saira**（可变字体，宽度轴 50–125、字重 100–900，SIL OFL）+ 中文黑体 | 导航、按钮、标签、编号、数字、标题、字标 |
| 阅读 | 中文黑体常规字重（Noto Sans SC / 思源黑体） | 正文、详情、列表里的标题 |
| 代码 | 系统等宽 | 只给代码 |

- 宽度是关键：字段 112%，小标签和字标 125%，用 `font-stretch` 设。
- Saira 要自托管（`assets/fonts/` 里有一份，带许可证），写法见 `references/tokens.md`。别的宽体几何字体也能替代（如 Exo 2、Chakra Petch；Michroma 只做标题）。
- 数字用等宽数字（tabular figures）。英文标签全大写、字距 0.14em；中文不加字距。
- 没有中文的产品：上行仍是宽体大写眉标，下行标题用同一宽体的粗字，宽度回到 100%，不要全大写。

## 规则（做之前读一遍）

**颜色**（数值和对比度见 `references/tokens.md`）
- 浅色为主：纸 `#F2F1F6`、板 `#FFFFFF`、墨 `#1A1726`。深色（纸 `#121019`、板 `#1B1824`、墨 `#ECEAF3`）是另一套完整主题，不是反色。
- **紫 `#9859FF` 是品牌和结构色**：字标（空心那行）、大标题和大数字的强调、`//` 分节标记、看板页签、轨道线和星图线、图表主色、链接下划线，以及当前位置（当前页面、当前一节、选中的筛选、打开的开关、进度、指针停在哪一行）。当前项的块仍是淡紫底 `--st-wash` + 3px 紫条 + 墨色粗体字。展示页可以有**一整块紫色**（一页至多一处），上面只放白色或荧光绿的大号粗字和一颗荧光绿四角星。
- **荧光绿 `#D1FF57` 是能量和高光色**：主要操作（静止就是荧光绿）、按钮被指向时的擦入、最佳成绩和新纪录这类数据高光、需要处理的数字和状态、提示小旗、马克笔、星星的光点。浅色里**只做填充**，上面写墨字（15.20:1）；深色里也可以做线和字（纸上 16.30:1）。
- **用量**：中性色（纸、板、墨、灰）占大头，有色部分紫 6、荧光绿 3、星光青 1：荧光绿除主要操作和高光外，也做第二组数据的颜色（浅色里只做填充、加墨边），青只做参考线和基准。两色同框时（紫色块上一颗荧光绿四角星、紫页签的看板里一个荧光绿高光数字）；不等面积并排，不让紫线和荧光绿线贴在一起（会闪），不混成渐变。
- **对比度是硬限制**（实算见 `references/tokens.md`）：浅色底上荧光绿不做线和字（白上 1.16:1）；紫色写字只写大字（≥ 24px，或 ≥ 18.66px 粗体；白上 4.03:1，纸上 3.59:1）；白字压紫 4.03:1、荧光绿字压紫 3.49:1，都只给大号粗字。
- **红色只给删除**。告警、待审、失败、快满了，一律用荧光绿块和墨线。图表不用红绿：淡紫柱，当前的那根实紫，最佳的荧光绿，超阈值的挂荧光绿小方块。
- 不用柔和投影、发光、装饰性渐变、圆角（radius 一律 0；星盘、行星这些本来就是圆的东西除外）。允许硬边的斜线纹"影子"。

**星星**
- **凡是星星一律画成四角星**：四个尖角、四边内凹，底纹、引线末端、主视觉、图标和装饰都一样；最暗最小的一档也是四角星，不用圆点、五角星或十字光芒代替。网页里用 `--st-star`（CSS 遮罩），脚本里用 `assets/stars/draw-stars.mjs` 的 `star()`。

**形状**
- 切掉一个小角 = 可以按。正文、图片、铭牌、不可点的容器都是直角。画框的两个大切角、看板朝星盘的大切角是构图，不表示能点。
- 切角里不压字：文字离切角至少留出和切角一样宽的空白，切角变大（`wide` 变体）时留白跟着变大。
- 用细线分区，不用一堆带边框和投影的卡片。

**底纹**
- 星图底纹只在页面两角（右上大、左下小），极淡，向边缘渐隐，永远在内容下面。不铺满全屏，不加星云色块、照片、粒子，不画坐标数字、十字准星、假文字。
- 想换一片星空：改 `assets/stars/draw-stars.mjs` 底部的种子和数量，运行 `node draw-stars.mjs`，同一个种子永远画出同一张图。

**文字与内容**
- 标题前缀 `//`；中英成对；字段用竖线 `│` 或斜线 `/` 分隔，不用中间点 `·`。
- 用数字装饰界面：编号、日期、计数、进度多排一些，但每个都是真实数据，不编造。不放假技术文字、二进制串、条形码、坐标、十字标记。
- 空状态写成一句完整的话，说明这里将来会出现什么。

**术语与界面文案**（术语表见 `references/glossary.md`）
- 本 skill 里的叫法（页面类型、固定规则、眉标、字标、字段、看板、轨道紫、星火绿、通电、快门、灌满……）只是给你理解设计用的内部术语，**不得出现在产品界面、用户文档和宣传文字里**。只有产品本身就在介绍这套设计时才能提到，那时也要换成术语表里"对人怎么说"那一列。
- 界面上的字来自产品自己的业务词汇：按钮写动作（"保存""删除这条记录"），标题写内容（"本月观测"），不写风格词，不写比喻。
- 英文眉标是中文标题的直译（`// NOTES` / `笔记`），不用 STELLAR、COSMOS、SIGNAL 这类风格词。想不出贴切的英文，就用编号（`// 01`）或只写中文。
- 每句只说一件事，让没读过这个 skill 的人一看就懂。

**动效**（详见 `references/motion.md`）
- 短、硬、机械：出现用 snap `cubic-bezier(0.16,1,0.3,1)`，快门、擦入、灌满和所有退出用 mech `cubic-bezier(0.7,0,0.2,1)`。回应操作 100–400ms，单个入场 ≤ 650ms，一个入场序列整体不超过 1 秒；错开间隔只用 38 / 45 / 100ms 三档。
- 每个入场都有退出（约为进入的 2/3）；出错用荧光绿小旗擦入，不抖动；处理中铺斜线纹，完成时荧光绿穿过按钮一次。
- 每个动效对应一次操作或状态变化。不做持续循环的装饰动画（星空不闪、不转、不跟着滚动）、不做弹簧和果冻。
- 系统"减少动态效果"打开时全部关闭。

**交互**
- 指向时出现的信息，键盘聚焦时也要出现；焦点框看得见（套件里是 2px、跟随文字颜色）。
- 可点区域至少 32px 高；当前项除了颜色，还要靠加粗、紫条和 `aria-current` 区分，色盲和读屏都分得出。

| 文件 | 内容 |
| --- | --- |

| `templates/motion.html` | 动效样张：每个动效一格带重放、三条曲线、入场时间轴 |
| `templates/specimen.html` | 全部部件的样张，含两种主题色的分工和对比度 |
| `templates/antipatterns.html` | 做与不做的对照页 |
| `references/tokens.md` | 色值和对比度、两种主题色的分工、深色主题、字体、字号 |
| `references/components.md` | 每个部件的写法（类名）、含义和禁忌 |

| `references/variation.md` | 变体：不能变的固定规则、五个可变维度、四组预设、变体卡、不照抄模板、新部件怎么推 |
