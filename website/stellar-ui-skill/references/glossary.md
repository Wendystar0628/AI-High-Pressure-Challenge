# 术语表

这个 skill 里有很多为了说清设计而起的简称。它们**只给你（agent）理解用**，不是界面文案。

- 产品界面、用户文档、宣传文字里**不出现这些词**。界面上的字用产品自己的业务词汇。
- 只有当产品本身就在介绍这套设计（比如这个 skill 的演示页、说明视频）时，才需要讲这些概念，那时用"对人怎么说"这一列。
- 英文眉标是中文标题的直译，不用这里的英文 token 名（orbit、flare、wash、chip……）当标签。

## 总体概念

| 内部叫法 | 意思 | 对人怎么说 |
| --- | --- | --- |
| 页面类型（阅读 / 展示 / 控制台） | 按用途分的三种页面，决定排版敢不敢大 | 阅读页 / 展示页 / 控制台 |
| 固定规则 | 每个产品都不能改的几条：两种主题色各管一件事、红色只给删除、切角表示可点击、宽体英文配粗体中文、真实数据、细线、机械动效 | 基本规则 |
| 外观 / 变体 | 每个产品可以换的五项：纸色、切角、底纹、密度、动效 | 外观设置 |
| 预设（zenith / observatory / nebula / midnight） | 四组现成的外观搭配 | 天顶 / 观测站 / 星云 / 子夜，或"四种现成搭配" |
| 主题 | 只指浅色 / 深色 | 浅色 / 深色 |
| 变体卡 | 交付说明开头的三行设置记录 | 不对外说 |
| 主视觉 | 首屏或控制台中间放的主图 | 首页大图、主图 |
| 气质 | 整体给人的感觉 | 风格 |

## 颜色

| 内部叫法 | 意思 | 对人怎么说 |
| --- | --- | --- |
| orbit、轨道紫、紫 | `#9859FF`，只表示当前位置：线、色条、括弧、大字 | 紫色 |
| flare、星火绿、荧光绿 | `#D1FF57`，只表示可以按 / 要看一眼，只做填充 | 荧光绿 |
| 当前位置 / 可以按 / 要看一眼 | 两种主题色各自的含义 | 原样说 |
| wash、淡紫底 | 当前项底下那块很淡的紫，配 3px 紫条和墨色粗体字 | 浅紫底 |
| 紫条 | 标出当前项的 3px 紫色色条 | 紫色标记线 |
| 纸、paper | 页面底色 | 底色、背景色 |
| 板、panel | 白纸、看板、输入框的底色 | 卡片底色 |
| 墨、ink | 正文和线条的夜空色近黑 | 黑色、文字颜色 |
| chip | 浅灰色的安静填充 | 浅灰底 |
| 光谱条 | 紫 / 星光青 / 荧光绿三等分的 3px 细条 | 三色细条 |
| 星光青 | 只在光谱条中间出现的青色 | 不单独说 |

## 部件

| 内部叫法 | 意思 | 对人怎么说 |
| --- | --- | --- |
| 眉标、eyebrow | 标题上方那行拉宽的英文小字，常带 `//` 前缀 | 英文小标题 |
| 中英成对 | 英文小字在上、中文粗体在下的标题 | 中英双行标题 |
| 字标、wordmark | 用文字做的标志，或展示页的超大标题字 | 大标题、标志字 |
| 字段、真实字段 | 编号、日期、字数、计数这类元数据，必须是真数据 | 编号、日期、数量（直接说是什么） |
| 编号标签 | 墨底白字、切一个角的 `No.024` | 编号 |
| 记录行 | 列表里一整行：编号 / 日期 / 名称 / 计数 | 列表项、一行 |
| 看板 | 控制台上显示一组数据的面板 | 数据块、面板 |
| 页签 | 看板顶边那段粗线 | 不对外说 |
| 星盘 | 控制台中间分成几段的圆形导航 | 圆形导航 |
| 星点 | 引线、标题细线末端的小圆点 | 不对外说 |
| 引线 | 从看板连到星盘、末端带星点的细线 | 连接线 |
| 命令栏 | 控制台顶部的深色横条 | 顶栏 |
| 侧面板 | 从窗口右边推入的详情 / 操作面板 | 侧边面板 |
| 画框 | 展示页里切角的大边框 | 图片边框 |
| 斜线纹、hatch | 45° 细斜线填充 | 斜线底纹 |
| 星点底纹、stars | 两角很淡的星图：星点、星座连线、几段弧 | 背景纹理 |
| 星图底纹、chart | 右上角很淡的一组同心弧 | 背景纹理 |
| 切角 | 切掉一个角，表示能点 | 切角 |
| 马克笔 | 标题下用荧光绿涂的一句话 | 荧光笔高亮 |
| 小旗 | 提示前面那块荧光绿小色块 | 提示标记 |

## 交互和动效

| 内部叫法 | 意思 | 对人怎么说 |
| --- | --- | --- |
| 指向 | 鼠标放在上面，或键盘焦点停在上面 | 鼠标移上去 |
| 可点击 | 能点的东西 | 能点 |
| 擦入 | 颜色从左往右扫进来 | 颜色扫过 |
| 通电 | 面板从上往下展开出现 | 面板展开 |
| 快门 | 换页时新页面从一侧斜切推入 | 换页动画 |
| 灌满 | 颜色从一边填满 | 填色 |
| 乱码后落定 | 文字先乱跳再定格 | 文字跳动后定格 |
| 逐行亮起 | 列表一行接一行出现 | 列表逐行出现 |
| 星盘组装 | 圆形导航的几段依次拼上 | 圆盘拼合 |
| 页签伸开 | 面板顶边的粗线伸长 | 面板标记伸长 |
| 锁定 | 指向星盘某段时画出紫色括弧和光束 | 选中 |
| 揭幕 | 深浅主题切换时扩散一个圆 | 深浅色切换 |
| snap / mech / ease | 三条动画曲线 | 不对外说，必要时说"出现 / 机械式 / 普通过渡" |
