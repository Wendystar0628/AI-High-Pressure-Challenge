# 变量：颜色、字体、字号

数值的唯一来源是 `assets/tokens.json`（单位 CSS px）；网页版定义在 `assets/stellar.css` 开头（`--st-*` 变量）。下面是含义、理由和对比度。所有对比度都按 WCAG 2.x 的相对亮度公式算出，保留两位小数。

判读标准：正文和小字至少 4.5:1；大字（≥ 24px 常规，或 ≥ 18.66px 粗体）至少 3:1；线、色条、图形和控件的边界（非文字）至少 3:1。

## 颜色

### 两种主题色：一对互补色，各有地盘

紫 `#9859FF` 和荧光绿 `#D1FF57` 在色环上几乎相对，是一对互补色。两种都要用足，但分工明确。两种主题色对每个产品都一样，变体不改它们。

| 变量 | 色值 | 角色 | 用在 |
| --- | --- | --- | --- |
| `--st-orbit` 轨道紫 | `#9859FF` | **品牌和结构** | 字标（空心那行）、大标题和大数字的强调、`//` 分节标记、看板页签、侧面板顶边、轨道线和星图线、图表主色（柱、仪表弧）、链接下划线、命令栏徽记；以及**当前位置**：当前页面、当前一节、当前编号、选中的筛选、打开的开关、进度走到哪、指针停在哪一行。展示页可以有一整块紫色（一页至多一处） |
| `--st-flare` 星火绿 | `#D1FF57` | **能量和高光** | 主要操作（静止就是荧光绿）、按钮被指向时的擦入、可点入口被指向时、最佳成绩和新纪录这类数据高光、需要处理的数字和状态、提示小旗、马克笔、选中文字、星星的光点（深色底纹、引线末端、紫色块上的那颗星） |

一句话记住：**紫色搭起骨架、标出你在哪；荧光绿点亮要按、要看的那一处。**

**用量**：中性色（纸、板、墨、次要墨、细线）占大头；有色部分按紫 6、荧光绿 3、星光青 1 分配。展示页那一整块紫色一页至多一处。

**色阶**（大面积只用浅色阶，饱和的 500 只用在小面积和焦点）：

| 色阶 | 紫 | 荧光绿 | 星光青 |
| --- | --- | --- | --- |
| 100 | `#F1E8FF` 当前项底 | `#F6FFDB` 分组色带 | `#E2F7FD` 参考区间底 |
| 300 | `#C9AEFF` 普通柱 | `#E6FFA3` 浅分段 | — |
| 400 | `#B083FF` 分段 | — | — |
| 500 | `#9859FF` | `#D1FF57` | `#62D4F5` |
| 600 | `#7A3CF0` 强调、选中 | `#A9D932` 深分段 | — |
| 800 | `#4A22B8` 浅色底上的紫色小字 | `#4F6A00` 浅色底上的绿色小字 | `#0B7FA3` 浅色底上的青色线和字 |

**两色同框**：分工明确，比如两组数据各用一族颜色，或紫色块上一颗荧光绿四角星、紫色页签的看板里一个荧光绿高光数字、紫色空心大编号旁的荧光绿"最新"小旗。不要：等面积并排的紫块和绿块；紫线和荧光绿线贴在一起（3.49:1 又是互补色，边缘会闪）；紫绿渐变。

对比度（WCAG 2.x，实算）：

| 组合 | 对比度 | 结论 |
| --- | --- | --- |
| 紫在板 `#FFFFFF` 上 | 4.03:1 | 线、色条、括弧、图形可以（≥ 3）；大字可以；小字不行（< 4.5） |
| 紫在纸 `#F2F1F6` 上 | 3.59:1 | 线和大字可以；小字不行 |
| 紫在浅填充 `#E7E5EE` 上 | 3.23:1 | 线可以，勉强；不写字 |
| 紫在淡紫底 `#F1E8FF` 上 | 3.40:1 | 当前项左边的紫条可以 |
| 白字在紫底上 | 4.03:1 | **只放 ≥ 24px 常规或 ≥ 18.66px 粗体的字**（紫色块上的标题、徽记字母、色值大字）；标签、按钮、导航这类小字不放在紫底上 |
| 荧光绿字在紫底上 | 3.49:1 | 同上，只给大号粗字；荧光绿的图形（四角星）可以 |
| 墨字在紫底上 | 4.36:1 | 不够小字，不用 |
| 墨字在荧光绿上 | 15.20:1 | 任何字号都可以 |
| 荧光绿在板上 | 1.16:1 | **浅色里几乎看不见**：不做线、不写字，只做靠色相分辨的填充块 |
| 荧光绿在纸上 | 1.03:1 | 同上 |
| 紫在深色纸 `#121019` 上 | 4.68:1 | 线和大字可以；正文大小的字也刚好够，但仍只用于大字，和浅色一致 |
| 紫在深色板 `#1B1824` 上 | 4.33:1 | 线和大字可以 |
| 荧光绿在深色纸上 | 16.30:1 | 深色里可以做线和字 |
| 荧光绿在深色板上 | 15.09:1 | 同上 |

所以：

- **当前项的块**（当前导航、当前编号、选中的筛选、分段选择的当前段、星盘的当前段）= 淡紫底 `--st-wash` + 一条 3px 紫条（左边或底边）+ 墨色粗体字。墨字在淡紫底上 14.84:1。
- **紫色的线**（页签、分节标记、链接下划线、柱、仪表弧、星图线、当前项的色条、进度亮起的格）两套主题都一样。
- **紫色的字**只写大字：空心字标、空心大编号、紫色块上的白字。小字永远是墨或次要墨。
- 荧光绿的块上写字，一律用 `--st-on-flare`（墨色，两套主题相同）。
- **荧光绿的线和字**只在深色底上（深色主题、命令栏、滚动条）：引线末端的星、底纹的星、深色条上的细条。浅色里它只做填充。

### 用色规则

- 中性色占大头，有色部分紫 6、荧光绿 3、星光青 1。整块紫色只在展示页、一页至多一处。
- 阅读区正文只用墨、次要墨和纸；紫色只在分节标记和链接下划线上，荧光绿只在链接被指向时、马克笔和数据高光上。
- 光谱条只出现两处：页顶全宽、文章标题下方。
- 不要紫底配小白字，不要紫绿渐变，不要两色等面积并排或细线相贴，不要发光的荧光绿字。
- 告警、待审、失败、磁盘快满：荧光绿块加墨字。**不用红**。图表不用红绿：淡紫柱（紫 45% 混入板色），当前的柱实紫，最佳的柱荧光绿加墨色细边，超阈值的挂荧光绿小方块。

## 字体

### 三个角色

| 变量 | 字体 | 用在 |
| --- | --- | --- |
| `--st-font-ui` | Saira（可变，宽度 50–125、字重 100–900）+ 思源黑体 Noto Sans SC | 一切界面文字：导航、按钮、标签、编号、数字、标题、字标 |
| `--st-font-text` | 思源黑体 Noto Sans SC 常规字重 | 供人阅读的内容：正文、详情、列表里的标题、摘要 |
| `--st-font-mono` | 系统等宽 | 只给代码 |

宽度靠 `font-stretch`：

| 变量 | 值 | 用在 |
| --- | --- | --- |
| `--st-wide` | 112% | 字段：编号、日期、计数 |
| `--st-wider` | 125% | 大写英文小标签、眉标、字标 |

为什么是 Saira：宽、几何、全大写的英文标签和数字，是这套界面秩序感的一半。Saira 是开源（SIL OFL 1.1）的可变字体，一个文件就包含从窄到超宽的全部宽度和字重。也可以换成别的宽体几何字体（Exo 2、Chakra Petch；Michroma 只做标题）。

- 字重：正文 400，标签 600，按钮和标题 700，字标和大数字 800。
- 数字用等宽数字（`font-variant-numeric: tabular-nums`）。
- 英文小标签全大写、字距 0.14em；中文不加字距。
- 没有中文的产品：上行仍是宽体大写眉标，下行标题用同一宽体的粗字，宽度回到 100%，不要全大写。

### 自托管

模板为了能直接打开，从 Google Fonts 加载（`family=Saira:wdth,wght@50..125,100..900`），上线前换成自托管。两种做法：

**fontsource**（中文按 unicode-range 切片，一页只下载用到的字）：

```sh
npm i @fontsource-variable/saira @fontsource-variable/noto-sans-sc
```

```css
@import '@fontsource-variable/saira/standard.css'; /* 含宽度轴 */
@import '@fontsource-variable/noto-sans-sc/wght.css';
```

**用包里的 Saira**（`assets/fonts/Saira.ttf`，许可证 `assets/fonts/Saira-OFL.txt` 随附）：

```css
@font-face {
  font-family: 'Saira';
  src: url('./fonts/Saira.ttf') format('truetype');
  font-weight: 100 900;
  font-stretch: 50% 125%;
  font-display: swap;
}
```

两者都是 SIL OFL 1.1，可以商用和自托管；把许可证文本放进仓库。

## 字号

比例约 1.33。

| 变量 | 大小 | 行高 | 字体 |
| --- | --- | --- | --- |
| （大字标） | `clamp(3rem, 10vw, 11rem)`，可用 `--st-wordmark` 覆盖 | 0.84 | 界面 800，宽度 125%，大写，字距 -0.02em |
| （空心大编号） | `clamp(5rem, 14vw, 14rem)` | 0.8 | 界面 800，宽度 112%，2px 描边 |
| `--st-t-h1` | 40px | 1.25 | 界面 700 |
| `--st-t-title` | 30px | 1.35 | |
| `--st-t-h2` | 22px | 1.45 | |
| `--st-t-body` | 17px | 1.85 | 黑体正文 400 |
| `--st-t-ui` | 15px | 1.6 | 界面 |
| `--st-t-field` | 13px | 1.5 | 字段，宽度 112% |
| （眉标） | 11px | — | 界面 600，宽度 125%，大写，字距 0.14em |

- 阅读栏宽 `--st-measure: 40rem`，约 38 个汉字一行，左对齐，不两端对齐。
- 页边距 `--st-pad: clamp(1.5rem, 3vw, 2.5rem)`。
- 小切角 `--st-cut: 7px`；按钮切角 0.5rem；画框切角 3.25rem；看板朝星盘的大切角 1.6rem。都乘 `--st-cut-k`（变体）。
- 当前项的紫条 `--st-bar-w: 3px`。

## 缓动

| 变量 | 曲线 | 用在 |
| --- | --- | --- |
| `--st-ease` | `cubic-bezier(0.2, 0.7, 0.1, 1)` | 普通过渡：光谱条扫过、颜色变化 |
| `--st-snap` | `cubic-bezier(0.16, 1, 0.3, 1)` | 出现、到位后稳住：列表行右移、逐行入场 |
| `--st-mech` | `cubic-bezier(0.7, 0, 0.2, 1)` | 慢起硬停，像机械：快门、擦入、页签伸开、颜色灌满、侧面板 |
