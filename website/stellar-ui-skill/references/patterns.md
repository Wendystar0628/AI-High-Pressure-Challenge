# 版式与界面范式

这套 UI 只做桌面网页。下面是三种页面类型怎么搭，以及对话框、侧面板、提示、空状态、加载这些常见状态怎么放。尺寸单位是 CSS px。

验收宽度：1024、1280、1440、1920，浅色和深色两套，都不能出现横向滚动。页边距 `--st-pad` 在 24–40 之间随窗口变化。

---

## A. 阅读页（安静）

模板 `templates/reading.html`，截图 `examples/web/reading-light.jpg`、`reading-dark.jpg`。

```
┌──────────┬─────────────────────────────┬──────────────────────┐
│ 侧栏     │ 白纸（约 640 宽）             │ 页边                  │
│ 192 宽   │  // NOTES / OBSERVING        │  目录                 │
│          │  全部笔记 / 目视观测          │  ┃ 一、暗适应  ← 紫条  │
│ ▌笔记    │  ▌No.024 分类｜目视观测 草稿   │    二、找参照星         │
│   分类   │  2026.10.16 │ 6,380 字 │ …   │  ─────                │
│   …      │  标题（界面字体 700，40）      │  按分类  9 篇         │
│          │  ━━━━━ 光谱条 ━━━━━          │  字数合计 48,210 字   │
│          │  导语 / 正文 / 记录行 …        │                       │
└──────────┴─────────────────────────────┴──────────────────────┘
```

- **侧栏**（窗口 ≥ 1100）：竖排导航，当前项是淡紫底、左边 3px 紫条、粗体，右下切角。更窄时变成顶部横栏。
- **白纸**：一个阅读栏宽加两侧边距，紧贴侧栏，**左对齐，不居中**。
- **页边**：目录、统计、日历这类旁注，内容都是真实数字。正在读的那一节在目录里换成紫条。窄于 960 时移到白纸下面。
- 页头顺序：上一级 → 编号和分类 → 字段 → 标题 → 光谱条（只在详情页）→ 导语 → 标签。
- 列表页：页名加"共 N 篇" → 筛选块（选中的是淡紫底加紫条）→ 按年份或分类分组 → 记录行。**不用卡片网格**。
- 阅读区里只有墨、次要墨和纸；紫色只在 `//` 分节标记、链接下划线和当前项的标记上，荧光绿只在链接被指向时、马克笔和需要看一眼的小块上。

- 首屏左栏：一行字段统计（数字乱码后落定）、大字标、马克笔一句、简介、2–3 个按钮（只有一个主要操作）。
- 首屏右栏（约 42%）：切角画框加斜线纹影子加铭牌。图要产品自己的：线稿、照片、示意图。模板里的行星仪是占位。画框可以是这一页唯一的紫色块（`.st-frame.orbit`）：白色线稿，一颗荧光绿四角星。
- 首屏底：滚动条贯穿全宽，两套主题都是深色。
- 段落标题后面是一条以四角星结尾的细线。
- 窗口窄于 900 时，画框移到文字下面。

## C. 控制台（大胆但要好用）

模板 `templates/console.html`，截图 `examples/web/console-light.jpg`、`console-dark.jpg`。

```
┌──────────────────────────────────────────────────────────────┐
│ [L] CONSOLE │▒概览▒ 笔记 评论² 统计 备份 │   查看网站  深浅    │ ← 深色命令栏
├──────────────────────────────────────────────────────────────┤
│ ┌─────────◣              ╭┄┄┄┄┄┄╮              ◢─────────┐   │
│ │ 笔记 16 0 7│          ╱  概览   ╲          │ 访问 3 58 242│ │ ← 上：向星盘靠，切朝圆的角
│ └──────────┘        │读者  ◎   笔记│        └──────────┘   │
│ ┌────────┐───✦     │   中心读数    │     ✦───┌────────┐   │ ← 中：退开，引线末端四角星接到圆
│ │ 互动 …   │        │备份       评论│        │ 观测 …    │   │
│ └────────┘          ╲  统计       ╱          └────────┘   │
│ ┌─────────◤             ╰┄┄┄┄┄┄╯             ◥─────────┐   │ ← 下：向星盘靠，切朝圆的角
│ │ 网站 …    │                                 │ 机器 …    │   │
│ └──────────┘                                 └──────────┘   │
├──────────────────────────────────────────────────────────────┤
│ ┌─▀▀▀── 访问柱图 / 草稿 ──────┐ ┌─▀▀▀── 设置 ─────────────┐     │ ← 普通工作看板
└──────────────────────────────────────────────────────────────┘
```

- **没有左侧列表**。命令栏是唯一的导航，两套主题都是深色；当前分区是淡紫底加底部紫条。
- 中心是星盘（`dial.js`），每段一个入口；当前分区的那段有一道常显的紫色括弧。
- 左右各三块看板，左右对称、同一行等高，但**不排成规整的表格**：上下两块向星盘靠拢并切掉朝星盘的角；中间一块退开，用末端带四角星的引线连到星盘边上。看板顶边是紫色页签。
- 看板区宽于 992 时才把看板排到星盘两侧，否则星盘在上、看板依次往下排，引线隐藏。
- 下方是普通工作看板：两栏（3:2），窗口窄于 1024 时变一栏。
- 控制台的子页面（列表、表单、编辑器）：命令栏加页名（`.st-head`：粗体中文、小号英文、四角星细线），下面筛选条（主操作放最右），内容放在看板里。

## D. 套在已有应用外面

如果里面是一个做好的交互应用（编辑器、可视化、地图），**只换外框**：导航、标题、编号、筛选、字体、底纹。应用内部的交互和配色保持原样，只要它不和两种主题色的含义冲突（例如它自己的选中色不要再用紫色以外的强调色表示"当前"）。

## 常见状态

### 对话框

- 只用来确认会造成后果的操作（删除、覆盖、离开时丢失修改）。
- 一块看板：顶边粗墨页签、右下切角。眉标 `// CONFIRM` 加中文问题，一句说明后果的话，右下两个小按钮，确认在右。删除确认的按钮是红色。
- 遮罩是墨色半透明，不加模糊。

### 侧面板

- 在列表或看板里看一条记录的详情、对它做操作，而不离开当前页时用。
- 贴窗口右边、满高，宽约 28rem；顶部 5px 墨线，标题区中英成对加"关闭"按钮。
- 每个操作一行（`.st-act`），删除那行字是红色；底部一排按钮，主要操作一个。
- 不要用它装一整页内容；那就开新页面。

### 提示条与提示

- 提示条（`toast()`）：操作完成后一句话，深色条、左边荧光绿条，出现在窗口左下角，2 秒后擦掉。
- 提示（`.st-notice`）：出错、警告、需要读的说明，留在页面上，前面一面荧光绿小旗。错误也不用红色。

### 空状态

- 写成一句完整的话，说明这里将来会出现什么，下面最多一个主要按钮。
- 可以放在细线框里，底下铺斜线纹，句子压在纸色底上。

### 加载

- 知道进度：24 格分段条，走到的格是紫色，读数补零 `063%`。
- 不知道进度：一段紫格从左往右走，完成即停。不用转圈。
- 骨架屏：浅灰块，不闪光；内容到了硬切成内容，看得见的行逐行亮起。
