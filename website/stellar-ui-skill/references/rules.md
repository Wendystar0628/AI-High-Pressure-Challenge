# 做与不做

每条都写了理由。对照效果见 `templates/antipatterns.html`（截图 `examples/web/antipatterns.jpg`）。

## 做

- 先选页面类型：阅读（安静）/ 展示（大胆）/ 控制台（大胆但要好用）。
- 浅色为默认，深色是完整的第二套主题，不是反色。
- 两种主题色是一对互补色，各有地盘：
  - **紫 `#9859FF` = 品牌和结构**：字标、大标题和大数字的强调、`//` 分节标记、看板页签、轨道线和星图线、图表主色、链接下划线，以及当前位置（当前页面、当前一节、选中的筛选、打开的开关、进度、指针停在哪一行）。做线、色条、括弧和大字（≥ 24px，或 ≥ 18.66px 粗体）。当前项的块写成淡紫底加 3px 紫条、墨色粗体字。展示页可以有一整块紫色，一页至多一处。
  - **荧光绿 `#D1FF57` = 能量和高光**：主要操作、按钮被指向时的擦入、最佳成绩和新纪录这类数据高光、需要处理的数字和状态、提示小旗、马克笔、星星的光点。浅色里只做填充，上面写墨字；深色里也可以做线和字。
  - 用量：中性色为主，有色部分紫 6、荧光绿 3、星光青 1。两色同框时分工明确，例如紫色块上一颗荧光绿四角星，或两组数据各用一族颜色。
- 星星一律画成四角星：底纹、引线末端、主视觉、图标、装饰都一样，最小最暗的一档也是。
- 切掉一个角 = 可以点。文字和切角之间留出至少一个切角宽的空白，切角放大时留白跟着放大。
- 用细线分区；列表用整行的记录，每一列都是真实字段。
- 用真实的统计数字装饰界面：篇数、字数、夜数、进度，比空白的装饰更有秩序感。数字、日期、编号用宽体等宽数字；日期写成 `2026.10.16`；编号补零写成 `No.024`；`当前 / 总数`。
- 界面用宽体几何英文（如 Saira）配中文黑体，可以很粗；英文标签大写、拉宽，前缀 `//`，中英成对。正文用黑体常规字重。
- 展示页大胆：超大实心字标加空心字标、空心大编号、切角画框和斜线纹影子、深色滚动条。
- 控制台：深色命令栏，中间星盘，看板对称但不成方格，引线末端是四角星。
- 质感只用一点：两角极淡的星图底纹、少量斜线纹。
- 动效短、硬、机械，每个对应一次操作，减少动效时全部关掉。按下和指向用擦入，不用涟漪。
- 空状态写成完整的一句话。

## 不做

| 不做 | 为什么 |
| --- | --- |
| 发光的荧光绿字、霓虹字，整段荧光绿文字 | 像终端特效和霓虹招牌，刺眼；荧光绿铺成一大片字，就不再是点缀 |
| 用红色表示告警、失败、待审 | 红色一出现就显得出事了。告警用荧光绿块和墨线；红色只留给删除 |
| 图表用红绿 | 同上；而且红绿色盲看不出区别。用淡紫柱，当前或指向的那根实紫，最佳的荧光绿，超阈值挂荧光绿小方块 |
| 一页里好几块整块的紫、大面积铺荧光绿、彩色横幅 | 紫超过一成、荧光绿超过点缀，颜色就只剩装饰；整块紫色一页至多一处 |
| 紫块和荧光绿块等面积并排；紫线和荧光绿线贴在一起 | 互补色等量并置会互相抢，细线相贴边缘会闪。两色只在一个焦点上同框，一主一次 |
| 浅色主题里用荧光绿画线或写字 | 白底上只有 1.16:1，纸色上 1.03:1，看不见 |
| 紫底配小号白字或荧光绿字（标签、按钮、导航项） | 白字压紫 4.03:1、荧光绿字压紫 3.49:1，正文大小的字不够清楚。紫底上只放大号粗字；当前项用淡紫底加紫条、墨字 |
| 用紫色写正文大小的字 | 白底上 4.03:1、纸色上 3.59:1，小字不够清楚；紫色字只用在大字上，链接是墨字加紫色下划线 |
| 紫绿渐变、柔和投影、发光、霓虹、扫描线 | 那是另一种科幻（赛博朋克、游戏界面），不是这种克制的星图感 |
| 星星画成圆点、五角星、十字光芒或带光晕的亮斑 | 这套界面里星星只有一种画法：四角星 |
| 圆角、胶囊按钮、圆形浮动按钮 | 和切角语言冲突。圆形只留给星盘、仪表弧和行星 |
| 卡片网格（阅读页的文章列表、控制台的方格仪表盘） | 像后台模板。阅读页用记录行；控制台用围着星盘的不规则看板 |
| 点阵、方格纸、铺满全屏的星空、星云照片背景 | 太满、太"设计感"，抢正文。星点只在两角，极淡，向边缘渐隐 |
| 会动的星星：闪烁、漂移、流星、随滚动视差 | 一直在动的东西让人分心；背景永远静止 |
| 假技术文字、坐标数字、赤经赤纬读数、十字准星、装饰小方点 | 只有质感，没有信息；每个数字都要是真的 |
| 满屏全大写英文 | 只在展示页和控制台的小标签上用 |
| 楷体、宋体、手写体、圆体，或等宽字体当正文 | 界面和正文都是干净的黑体；书卷气、可爱、"程序员"风的字会把气质带偏 |
| 英文用普通窄字（Arial、Roboto 默认宽度）当标签 | 宽、几何、大写的英文是辨识度最高的一点 |
| 不打包英文宽体，指望系统字体 | 系统里没有宽体几何字，标签会退回普通字体 |
| 持续循环的装饰动画、弹跳、文字逐个缩放弹出、滚动触发的逐段淡入 | 动效要对应操作 |
| 用中间点 `·` 串字段 | 用竖线或斜线 |
| 把切角放在不能点的东西上 | 切角的意思就是"可以按"；只有看板朝星盘的大切角是排版用的 |

## 反例对照

`templates/antipatterns.html` 把最常见的九种错误和正确做法并排放在一起：

1. 发光的霓虹字
2. 用红色表示告警
3. 圆角卡片网格
4. 胶囊、紫绿渐变、发光按钮
5. 点阵、方格纸、铺满全屏的星空
6. 假技术文字、坐标、十字准星
7. 方格仪表盘
8. 浅色里用荧光绿画线写字；紫底配小白字
9. 紫绿等面积并排、两色细线相贴

动手前看一眼。
