# 设计来源说明

这套 UI 有两个来源：**结构**借鉴自一个已有的界面 skill，**意象**来自星辰和星图。这一篇说明各借了什么、改了什么、哪些故意不借，方便以后改动时知道一条规则从哪里来。

## 1. 结构：借鉴 hhikr 的 endfield-ui-skill

结构来自 hhikr 的 endfield-ui-skill（https://github.com/hhikr/endfield-ui-skill）。那个 skill 把一种工业科技感的界面整理成了可复用的规则、token、网页套件和模板。这里沿用了它的骨架，配色和意象全部重做。

**借来的：**

| 借来的 | 在这里的样子 |
| --- | --- |
| 三种页面类型：阅读 / 展示 / 控制台 | 原样保留，判断方法也一样："内容是给人读的，就用阅读页" |
| 切角 = 可以点 | 右下切一个小角；不能点的东西是直角 |
| 宽体英文在上、粗体中文在下 | Saira 拉宽到 112% / 125%，中文黑体 |
| `//` 眉标 | 原样保留 |
| 真实数字做装饰 | 编号、日期、计数、进度用宽体等宽数字排开，不编造 |
| 1px 细线分区，不堆卡片 | 原样保留 |
| 短、硬、机械的动效 | 三条曲线、三档错开间隔、每个入场有退出、减少动效时全关 |
| 变体机制 | 每个产品定一次外观，写成变体卡，只在 `<html>` 上设置 |
| 模板和文档的组织方式 | 入口 `SKILL.md`、按需读的 `references/`、可直接拷贝的 `assets/`、模板和截图 |

**改掉的：**

| 改了什么 | 为什么 |
| --- | --- |
| 配色：纸色偏冷的淡紫灰，墨是夜空色近黑 | 从星辰主题推出来，不用原版的颜色 |
| 一种强调色 → 一对互补的主题色 | 紫 `#9859FF` 是品牌和结构色（含当前位置），荧光绿 `#D1FF57` 是能量和高光色。两种颜色的对比度条件不同：紫能做线和大字，荧光绿在浅色里只能做填充，所以按"形式"和"角色"一起分工，并规定用量：中性色为主，紫约一成，荧光绿点缀 |
| 当前项的写法 | 淡紫底加 3px 紫条、墨色粗体字，而不是整块亮色加小字（紫底白字只有 4.03:1） |
| 三色条 → 光谱条 | 紫 / 星光青 / 荧光绿，像一段星光的光谱 |
| 等高线 → 星图底纹 | 按星等分大小的四角星、星座连线、赤纬圈和时圈的弧，由脚本按种子生成；线是紫，星是墨（深色里是荧光绿） |
| 分段圆盘 → 星盘 | 外圈虚线环；当前段有常显的紫色括弧；引线末端是四角星 |
| 标题后的斜线纹带 → 四角星细线 | 一条细线末端一颗四角星，像星图上的连线 |
| 底部面板 → 侧面板 | 只做桌面网页，详情和操作从窗口右边推入 |
| 只做桌面网页 | 移动端的模板、平台指南和相关规则都不收 |
| 模板内容 | 换成一个业余观测者的观测笔记（全部是示例数据） |

## 2. 意象：星辰和星图

| 来源 | 取了什么 | 用在 |
| --- | --- | --- |
| 印刷星图的星等符号 | 星越亮越大，分几档，不画光晕；形状统一成四角星 | 星图底纹 |
| 星座连线 | 稀疏、不闭合的折线，线在星前停住 | 星图底纹 |
| 赤纬圈与时圈 | 围着画面外一个天极的同心弧和几段放射线，只露出一角 | 星图底纹、`chart` 底纹 |
| 行星仪 | 倾斜的轨道椭圆、轨道上的小圆、中心一颗四角星 | 展示页画框里的占位线稿 |
| 星盘、活动星图 | 一圈分段、中心读数 | 控制台的星盘 |
| 观测笔记 | 按顺序编号、点分日期、夜数、天体数这类真实记录 | 字段、编号、模板文案 |
| 夜空 | 带一点紫的近黑 | 墨色、深色主题、命令栏 |

**紫色和荧光绿的来由**：紫是夜空和星云的颜色，适合做"轨道"——搭起页面的骨架、标出你走到哪；荧光绿像一颗亮起的星火，适合做"这里要按、这里最亮"的那一点。两者几乎是互补色，放在一起很响，所以按 6:3:1 分配：紫 6、荧光绿 3、星光青 1。按歌德的互补色面积比，亮的荧光绿面积要小于紫；两色相邻时隔开，不细线相贴。

**四角星的来由**：肉眼和照片里的亮星常带四道衍射尖芒，四角星是它最简的符号；它有方向感、和切角的几何语言相配，比圆点更像"星"，又比五角星克制。

## 3. 不借的

| 不借 | 为什么 |
| --- | --- |
| 真实星图的坐标、星名、赤经赤纬读数 | 对产品没有信息，只是质感；读者会以为那是真数据 |
| 十字准星、瞄准框、雷达扫描 | 像游戏和监控界面，和"克制的星图"相反 |
| 假技术文字、二进制串、条形码 | 同上 |
| 铺满全屏的星空、星云照片、渐变夜空背景 | 太满，压正文，也太像壁纸 |
| 闪烁的星星、流星、粒子 | 一直在动的东西让人分心 |
| 发光、霓虹、紫绿渐变 | 那是另一种科幻 |
| 圆角卡片 | 和切角语言冲突；圆形只留给星盘和行星 |
| 圆点星、五角星、带光晕的亮斑 | 星星只用四角星一种画法 |
