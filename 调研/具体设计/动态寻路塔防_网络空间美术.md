## 〇、结论

1. **推荐风格：“协议空间”。** 把网络空间画成一张立体的网络图：
   - 整张地图是悬浮在空间里的一块网格，下方一层层半透明的协议层隐入深处，远处是别的网络聚成的星团，星团之间有流量往来；
   - 链路里流着一颗颗封装好的包，旧链路里的包摊开成可读的字符，加密与明文一眼可见；
   - 线条精确如图解，材质是磨砂玻璃、哑光的实体和光；只有信息才带颜色；
   - 三张图三种光场：明场（纸白）、暮场（暖到冷的渐变）、暗场（近乎墨黑），避免整局都是“黑底发光”。
   - 备选：暗场数据雕塑（全粒子、全暗）；纸面图解（等距平涂的网络图）。
2. **地图与背景。** 三张图改名并去掉现实地景，网格逐格不变：
   - **分段内网**（明场）：外网 → DMZ → 两个分段 → 核心数据库；
   - **骨干流域**（暮场）：原来的江变成一条向东奔流的“公网流”，只有专线隧道和旧专线能跨过，南侧是两团晶格球般的双活数据中心；
   - **气隙深层**（暗场）：网络最深的一层，中央的气隙是一块什么都没有的空洞，能看见下面的深渊。
3. **塔与敌人以本征功能造型。** 守方是透光、规整的几何体，敌方是吸光、破碎的暗色实体加品红紫字符：
   - 防火墙是一道带细缝的过滤膜，被挡的敌人压在膜上；
   - 蜜罐是一团诱饵漩涡；探针是一只扫描的光眼；沙箱是套着小立方的透明立方；光端机是一颗射出准直光束的光源；
   - 蠕虫是一串一模一样的链节；洪泛团是一大团挤在一起的包；木马是一颗大了一圈的正常封装包；勒索者是一团密文锁链；零日是一块说不出形状的空洞；
   - Boss：万傀是被细线吊着的万千傀儡方格；蜃楼是伪造路由线织成的幻影；蛰影是一节节战术板连成的长蛇。
4. **体系调整。** 规则一条不改，只换设定：
   - 汐城和水电换成网络空间里的自治域“汐域”，玩家从“值守员”改为汐域的“守护进程”；
   - 设备平台画成悬浮在链路上方的旁路平台，用细光线连向链路，直接画出“旁路”；
   - 飞行的伪热点在链路上方的“无线层”飘行，应急隔离器用一根细光线连到无线层，所以会被它劫持；
   - 时段（晨、黄昏、夜）换成光场（明、暮、暗）；
   - 调度站的“水务、电网调度室”换成“过程控制核心”和“安全联锁核心”。
5. **拍板点：** 风格选哪个、世界观是否完全去掉城市、三张图的新名字、三种光场、“守护进程”的身份、题面篇幅，见第八部分。

## 一、网络空间的视觉语言

### 1.1 难点

“虚拟网络空间”有三重难处：
1. **好看又不落套。** 一提网络空间，最容易做成黑底蓝光的霓虹网格，几十年来已经用滥了。
2. **抽象但要可读。** 塔防要求一眼看清路线、封锁、拥塞、感染、状态。越抽象，越容易糊成一片光。
3. **形态要从功能来。** 塔和敌人不画成炮台和怪物，要让人看到形状就猜得出它做什么。

### 1.3 要避开的套路

| 套路 | 为什么不要 | 用什么代替 |
|---|---|---|
| 霓虹网格地面（无尽的发光方格平面） | 用滥了，而且会和真正的游戏网格抢视线 | 地块是有厚度的磨砂玻璃砖，网格线是极细的发丝线；背景的协议层是稀疏的点阵，不是线格 |
| 绿色字符雨 | 用滥了，而且满屏动的字符会盖住信息 | 字符只出现在有意义的地方：旧链路里摊开的包、明文的敌人、勒索者的密文 |
| 骷髅头、兜帽黑客 | 廉价、和机制无关 | 敌人的形态都来自它的功能 |
| 满屏蓝光、光晕泛滥 | 一片蓝，信息被光晕淹没 | 三种光场；发光只给信息；所有信息元素带暗色细边 |
| 攻击地图式的“光弧乱飞”（例如 [Kaspersky Cybermap](https://cybermap.kaspersky.com/)） | 好看但读不出局势 | 弧线只用于背景的远方流量；战场上的流动都沿链路 |
| 电子回路板地面 | 和“网络空间”不是一个尺度，说不清楚 | 不用 |

### 1.4 推荐方向：“协议空间”

**一句话：** 一张会动的、立体的网络图。

**六条原则：**
1. **空间就是网络图。** 层、段、链路、节点、包，全部来自网络图的画法；地块侧面露出层层薄片，暗示协议栈。
2. **守方是光与秩序，敌方是暗与噪声。** 守方透光、规整、对称、动作干脆；敌方吸光、破碎、不对称、带故障抖动。
3. **只有信息才带颜色。** 空间和地块是中性的；颜色只给路线、守方、敌方、危险和旧链路。
4. **加密与明文看得见。** 正常链路里的包是封装好的小胶囊；旧链路里的包摊开成一串串可读的字符；明文的敌人外壳变透明、露出字符。
5. **线条精确如图解。** 细线、刻度、编号、定位标记做细节；光晕只用在需要强调的地方。
6. **三张图三种光场。** 明场、暮场、暗场，各图的明暗、背景和主色调不同，但同一套造型和配色角色。

**配色角色：**

| 角色 | 用在哪里 | 明场上 | 暗场上 |
|---|---|---|---|
| 中性 | 空间、地块、障碍、设备平台 | 纸白、浅灰、淡淡的冷灰阴影 | 墨蓝黑、深灰 |
| 守方 | 塔、正常流量的包 | 白色透光体，靠暗色细边和阴影立住 | 白光 |
| 敌方 | 敌人、加密、感染 | 吸光的暗色实体，品红紫的字符纹 | 暗色实体，靠品红紫辉光和边缘高光浮出来 |
| 危险 | 只用于危险：危急、会封死、Boss 的锁定和预警、中枢受损 | 红 | 红 |
| 旧链路 | 旧链路、降级区域 | 铜色 | 暗铜色光 |
| 入口 A、B、C | 路线、入口标识、来袭预报 | 与以上都不撞，例如翠绿、天蓝、明黄 | 同左 |

**可读性的统一手段：** 所有信息元素（路线、状态框、生命条、标识）都带一圈暗色细边。明场里靠暗边看清，暗场里靠发光看清，同一套元素在三种光场里都成立。

### 1.5 备选

| | 推荐：协议空间（明暗三场） | 备选 A：暗场数据雕塑 | 备选 B：纸面图解 |
|---|---|---|---|
| 样子 | 立体网络图，磨砂玻璃加光，三种光场 | 全暗，一切由粒子和点阵构成，像池田亮司和 Refik Anadol 的作品 | 等距视角的平涂网络图，像 Mini Metro 的三维版 |
| 好看、现代 | 高 | 很高，震撼 | 高，清新 |
| 一眼看清局势 | 高 | 中：粒子多了容易糊 | 很高 |
| 与玩法贴合 | 高：层、旁路平台、明文与加密都有形 | 中：形体靠粒子，阻挡、受击不直观 | 中：缺少纵深，旁路平台、无线层不好表现 |

## 二、背景与地图

### 2.1 背景的通用结构

- **尺度感。** 整张地图是一块悬浮在空间里的网格，边缘干净地截断，露出地块的厚度。它下面是一层层半透明的“协议层”平面，越往下越淡，隐入深处；远处是别的网络聚成的星团，有大有小，缓缓转动。
- **三个层次：**
  - 近：地图本身，清楚、锐利；
  - 中：协议层平面上稀疏的点阵在呼吸，几条大的流从远方连进各个入口；
  - 远：网络星团和星团之间成串往来的流量，被空间的雾气冲淡，对比度明显低于地图。
- **不抢视线。** 背景不穿过地图所在的平面，亮度和对比度都低于地图；最亮的东西永远在地图上。

### 2.2 格子在网络空间里的样子

| 格子 | 样子 | 网络意象 | 一眼怎么读 |
|---|---|---|---|
| 地块 | 有厚度的磨砂玻璃砖，侧面露出层层薄片；格子之间是极细的发丝缝 | 协议栈的分层 | 每一格边界清楚 |
| 链路 | 地块顶面一道透明的流道，略低于顶面，里面流着一颗颗白色的封装包 | 链路和正常流量（加密的） | 有流动的就是能走的路 |
| 路线 | 流道里的包染上入口色，带朝向出口的箭头；几条路线重叠时并排流动 | 路由 | 颜色即入口，流向即方向 |
| 设备平台 | 明显高出链路、悬浮的平整平台，几根细光线从它垂向旁边的链路 | 旁路：接镜像口，看流量但不在路径上 | 悬浮的、带细线的就是放远程塔的地方 |
| 障碍 | 一簇簇高低不齐、不透光的数据柱，像立体柱状图 | 不可路由的地址空间、静止的存储 | 高、不平、没有流动 |
| 交换节点 | 链路交汇处一圈端口灯环绕的圆形节点，端口灯缓缓转 | 可网管的交换节点 | 圆环即关键点位 |
| 旧链路 | 铜色的流道，里面的包摊开成一串串可读的字符，走得慢、挤在一起 | 带宽低、不加密的老链路 | 铜色、慢、拥挤 |
| 暗光纤 | 只有一圈虚线轮廓的空流道 | 铺好了但没点亮的链路 | 虚线即“计划中的路” |
| 新开链路 | 点亮后的流道，边缘留一圈虚线 | 新开通的链路 | 虚线边即“这是开出来的” |
| 封存旧通道 | 一段铜色的旧流道，被一块红色斜纹的拒绝板和锁符封住 | 被访问控制封禁、却没拆掉的旧连接 | 红色斜纹即“被封着” |
| 气隙（地图三） | 一块什么都没有的空洞：地块在这里断开，能直接看见下方的深渊，断口的边缘散成细小的颗粒 | 物理隔离 | 空的就是断开的 |
| 公网流（地图二） | 一条宽阔的流，成千上万的小包高速向东奔流，延伸到地图两侧的天边 | 运营商的公网骨干，内部流量不能踏进去 | 奔流着的宽带子，不能走 |
| 入口 | 地图边缘一个光口，一道长长的流从远方的某个星团连进来，旁边立一根入口色的标识 | 外部接入点 | 流从哪里进来 |
| 出口 | 中枢的核心：一团缓缓呼吸的晶体，各图的形状不同 | 中枢 | 流最终汇向哪里 |
| 黑洞 | 向内旋转的漩涡，周围的包被吸进去 | 黑洞路由 | 有倒计时环 |
| 锁死段 | 铺满紫色密文锁纹的格子 | 被勒索加密的链路 | 有倒计时环 |

**节点的状态：**
- 直通：端口灯白色，缓缓转，包流穿过；
- 被塔隔离：节点两侧竖起光板，包流止于光板前、在那里堆住；节点上方一道情报进度弧，走满时弹出一枚情报符号；
- 被隔离器隔离：节点上悬着一枚临时规则环，一根细光线连到上方的无线层，带时限环；
- 此刻隔离会封死：端口灯变红，浮出一个断开的链节符号；
- 抑制中：端口灯变灰，一圈倒计时弧；
- 被盯上：一条红色虚线从洪泛团或万傀连到节点，节点外圈出现收缩的红色锁定框；
- 被冲垮：节点上的塔解体，一道白色旁路光桥接通节点两侧，包流重新穿过。

### 2.3 三张地图

网格、节点位置、各节点单独隔离后的改道结果、互斥组合、光端机和封存旧通道的作用全部不变（见 `动态寻路塔防_网络安全.md` 第四部分）。下面只改名字和样子。

#### 地图一：分段内网（明场；14 波；原“市府园区”）

- **网络：** 典型企业网，外网 → DMZ → 内网两个分段 → 核心数据库。
- **光场：** 明亮柔和的纸白，阴影浅而清楚，像一张摊开的架构图。
- **背景：** 淡而明亮的空间，远处是浅灰的细线星团；地图下方的协议层像一叠半透明的描图纸。
- **主要样子：**
  - 北缘的 DMZ 是一条淡色的带，被一层透明的边界膜和外网隔开；入口 A“门户网站”是一个框形光口，B“邮件网关”是一个折叠信封般的光口，木马多从这里来。
  - 中央的暗光纤隔离带是一条下沉的空沟，沟里只有虚线轮廓；两个网段的地块各带一层很淡的底色，分段一目了然。
  - 中段的旧互通和西侧外缘的旧系统网段是铜色的流道，里面的包摊开成字符；东侧外缘的灾备环是一道干净的白色流道。
  - 障碍是一簇簇白色的数据柱。
  - 出口“核心数据库”是一座层层叠起的晶体，像一摞发光的数据页。
- **视觉主题：** 秩序与分段。整张图最“干净”，敌人的暗色在这里最显眼，适合第一张图教会玩家读图。

#### 地图二：骨干流域（暮场；15 波；原“双子江岸”）

- **网络：** 跨网专线与双活数据中心。北侧是三种外部接入，南侧是互为备份的两座数据中心。
- **光场：** 由北向南、由冷到暖的暮色渐变；两座数据中心在南面发出暖光，像两轮低垂的太阳。
- **背景：** 北面天空里是巨大的互联网星团；公网流向东西两侧延伸到天边。
- **主要样子：**
  - 原来的江变成一条宽阔的“公网流”：成千上万的小包高速向东奔流，流面有反光。内部流量不能踏进去，只能走专线跨过。
  - 西侧的专线隧道是一条封闭的透明管，从公网流上方拱过去，管里是封装好的包；中段的旧专线是一串铜色的踏板，包在上面摊开成字符，慢慢挪过去。
  - 两条预留隧道只有虚线轮廓，点亮后成为新的跨越点。
  - 入口 A“互联网”是一个连着北方星团的大光口，C“分支专线”是一根细长的专线，B“云端互联”是一个向上连到高空的光口。
  - 出口 X、Y 是两团亮着暖光的晶格球，里面能看见成排的叶脊结构；两球之间有一道同步光线，表示双活。
  - 障碍是中灰色的数据柱。
- **视觉主题：** 流动与调度。公网流是整张图的视觉主轴，玩家隔离节点、把攻击整批调度到另一座数据中心时，路线在两团暖光之间换向。

#### 地图三：气隙深层（暗场；16 波；原“深井调度站”）

- **网络：** 工控网，网络最深的一层，控制着物理设备。
- **光场：** 近乎墨黑。主光来自塔的白光、链路里的包流、两个控制核心的波形光，以及头顶上面几层透下来的微光。
- **背景：** 抬头能看见上面几层协议层的底面，像几层半透明的天花板，透着稀疏的光点；脚下、气隙之外是深渊；空间里飘着几道缓慢起伏的控制波形，像示波器上的曲线。
- **主要样子：**
  - 中央的气隙是一块什么都没有的空洞，断口散成细小的颗粒，能直接看见下方的深渊；一圈“运维环”绕着它把南北连通，气隙其实被绕过去了。
  - 气隙边缘和东联络段的老工控总线是铜色的流道，里面的包摊开成一行行控制指令。
  - 三条封存旧通道被红色斜纹的拒绝板和锁符封着；被撬开时锁符碎开，流道亮起暗铜色的光。
  - 跨气隙的旧桥是一道悬在空洞上的虚线流道，点亮后变成一座细窄的光桥，两侧都是深渊。
  - 入口 A“运维跳板机”是一个孤零零的光口，B“办公网下行”是从上面一层垂下来的一道流，C“供应商远程维护”是一根从远处接进来的细长专线。
  - 出口是两个控制核心：X“过程控制核心”里是平稳起伏的波形，Y“安全联锁核心”里是一圈圈锁定的环。
  - 障碍是不透光的暗色数据柱。
- **视觉主题：** 深与隔。黑暗里只有信息在发光，敌人的品红紫在这里最刺眼。

### 2.4 网格可读性

1. 网格线是极细的发丝缝，在三种光场里都看得见，但不发光。
2. 每类格子靠高度和材质区分，不只靠颜色：链路是凹下去的流道，设备平台是悬浮的，障碍是高而不平的柱簇，气隙和公网流是空的或流动的。
3. 背景不穿过地图平面；地图边缘截断干净，露出地块的厚度。
4. 包流的密度有上限：正常流量是稀疏的小点，有路线经过时变成入口色的连续流，不让流量本身糊住格子。
5. 摄像机拉近、转动时，背景只做缓慢的视差，不做快速运动。

## 三、塔与敌人：以本征功能和意象造型

### 3.1 总原则

- **形态即功能。** 每种塔和敌人的剪影都从它“做什么”来。看到形状，就猜得出它的作用。
- **守方：** 透光、规整、对称的几何体，材质是磨砂玻璃、光膜和光束；每座塔立在统一的“端口座”上，端口座是一圈嵌在地块里的细方环，前缘一条状态光（平时白，受击闪，危急红）。
- **敌方：** 吸光的暗色实体，表面流着品红紫的字符纹，轮廓不规整，边缘有故障色散；受击时整块错位跳帧。体型分小、中、大、飞行四档，Boss 远大于这些。
- **升级与分支：** 2 级都是“再叠一层”：多一层膜、多一圈环、多一只眼；分支各加一个不同的部件，场上看得出来。
- **朝向：** 有朝向的塔，端口座前缘有一个指向光标；部署和选中时，地面投出作用范围（扇形或直线）。

**守方的通用状态：**

| 状态 | 样子 |
|---|---|
| 受击 | 受击处出现几个缺像素的小洞，洞边一圈品红紫，状态光闪一下 |
| 危急 | 轮廓边缘泛红并慢闪，几何体出现细小的裂缝 |
| 加密进度 | 生命条下方三枚小锁符，逐个点亮 |
| 加密 | 紫色的密文锁链一圈圈缠住塔身，正面浮出锁符和倒计时环；塔的光暗下来、动作停住 |
| 护盾 | 一层略大一圈的半透明“复影”套在外面，受击时泛起涟漪，被打穿时碎成玻璃片 |
| 失效（被零日穿过） | 阻挡用的膜或光幕被撕开一道紫色裂口，1.5 秒后重新合上 |
| 被摧毁 | 几何体解体成一段段白色线段，沉进地块；若在节点上，一道白色旁路光桥接通节点两侧 |

### 3.2 塔

| 塔 | 意象 | 造型与动态 | 2 级与分支 | 朝向与特殊 |
|---|---|---|---|---|
| 防火墙 | 有选择地放行的过滤栅 | 横跨链路的两根细柱之间绷着一层半透明的膜，膜上一道道细缝。正常的白色包从缝里穿过；被挡的敌人压在膜上，膜随之鼓起。柱顶一排名额刻度，被挡几个就亮几格。站在节点上时膜变得不透光，封住节点；阻断相邻格时向外推出一圈平面脉冲。技能“封禁”：细缝全部合上，膜上浮出拒绝斜纹 | 下一代防火墙：两层膜，一道扫描带在两层之间上下扫过；被它挡住的敌人外壳被扫透明（明文） | 无朝向，膜总是横跨链路 |
| 蜜罐 | 吸引流量的诱饵漩涡 | 链路上一团缓缓旋转的光之漩涡，中心是一颗光洁得过分的假核心，散着暖白的光。朝前方三格飘出一粒粒诱饵光点（伪造应答）；被它吸引的勒索者和洪泛团身上连着一根细细的诱饵线。技能“诱捕”：最长的一条旋臂甩出去，卷住最远的敌人拖回来，漩涡收拢成一只螺旋笼 | 高交互：漩涡加深成漏斗，漏斗底部是一套嵌套的假系统（几圈小环和小节点）；蜜网：分成三四团相连的小漩涡，彼此有细线 | 最长的那条旋臂就是朝向。被勒索者打中时密文锁链从它身上滑落：它不会被加密 |
| 网闸 | 物理隔开，只摆渡数据 | 两块厚重的不透光平板，中间一道空无一物的缝。偶尔有一个小方块从缝上跳过去，表示摆渡 | 单向网闸：方块只朝一个方向跳，拖着箭头形的轨迹；攻击它的敌人的碎片被“摆渡”到另一侧，摊开成字符（明文） | 无朝向；在节点上时两板封住节点。不会被加密 |
| 拦截器 | 定向截断 | 端口座上悬浮着一枚三棱镜，地面投着所朝方向 90° 的扇形扫描线，棱镜只在扇形里转动。攻击是一根细而直的光针，像刀一样从目标身上截过，留下一道白色切痕 | 穿透：棱镜拉长成一片刃，光针贯穿一条线上的几个敌人；压制：棱镜外套几圈同心细环，向外荡出干扰波纹，命中伪热点时波纹把它的电波震散 | 扇形扫描线就是朝向 |
| 探针 | 检测光束与特征匹配 | 一只悬浮的光眼：透明的球里一圈虹膜般的光环，平时投出一道缓缓扫过的锥形检测光束。攻击时光束聚成分叉的特征弧，在敌人之间跳跃。打到明文的敌人时，它和相邻的同种敌人头上亮起同一个特征符号，被细线连成一组 | 2 级：上下两只眼，弧多跳一个敌人 | 技能“特征更新”：虹膜张开，光束变亮，弧更粗更快 |
| 沙箱 | 透明的隔离盒 | 一只套着小立方的透明立方，内外两层反向缓转，里面是细网格。抛出小小的采样立方，落地展开成一只透明方格，罩住一片区域一闪而逝 | 2 级：再套一层，范围更大 | 技能“引爆舱”：落点留下一片带网格墙的玻璃区，持续发着微光 |
| 均衡器 | 分流 | 一枚缓缓旋转的光环，环面上的流分出一根根细线，流向范围内可用性最低的那座塔 | 双活：两枚扣在一起的光环，同时分出两股；热备：光环外绕着一枚半透明的复影环，复影定时脱离、飞去套住范围内的塔 | 技能“冗余切换”：范围内每座塔“啪”地套上复影，缠在上面的密文锁链随之碎落 |
| 光端机 | 光源点亮暗路 | 一个方框里亮着一颗光源，朝前射出一道准直光束。光束沿着暗光纤推进，虚线一格格变成发光的流道 | 2 级：双框，光束更亮更长 | 光束就是朝向。技能“降级”：光束变成铜色，这条线上的包摊开成字符，流道变成铜色 |

**剪影一览：** 栅、漩涡、双板、棱镜、光眼、套方、光环、光源，八种剪影各不相同。

### 3.3 敌人

| 敌人 | 意象 | 造型与动态 | 识别特征 | 特殊外观 |
|---|---|---|---|---|
| 蠕虫 | 一串会自我复制的链节 | 一串一模一样的六棱链节，每节里都是同一个紫色字符，像尺蠖一样一伸一缩地爬；头节有一道扫描缝 | 小、长、节节相同 | 复制：走过直通的节点时，链节一节节“复印”出另一串，从节点上分出去 |
| 洪泛团 | 一大团密集的流量 | 成千上万个小暗包挤成的一大团，边缘不停甩出、吸回碎包，中心透着紫光；体积是蠕虫的三四倍，走得沉 | 大、蓬松、不停翻涌 | 冲击节点时拉长成一道包的洪流，撞上去时碎包四溅 |
| 木马 | 外壳下包着别的东西 | 看上去就是一颗正常的白色封装包，只是大了一圈；一道细缝里，有暗色的东西在动 | 混在正常的包里几乎认不出，只有那道缝 | 明文或可疑时外壳像种荚一样裂开，露出暗色的内核和紫色触须；死时炸出一圈紫色碎片 |
| 勒索者 | 加密的锁链、密文 | 一团由密文字符串成的锁链，关节上挂着锁符，贴着链路缠绕着爬行 | 中等、链状、带锁符 | 投掷时甩出一段密文链，命中的塔被它缠上一圈 |
| 撬锁者 | 钥匙与凭据 | 一根由钥匙齿廓一节节叠成的细长身形，身边转着一圈凭据令牌 | 细高、齿状、带一圈令牌 | 撬锁时钥齿一节节转进锁符，令牌飞转；锁符碎开，拒绝板脱落 |
| 零日 | 没有特征、难以描述 | 一块说不出形状的空洞：纯黑、不反光，轮廓不停改写成别的形状，连影子也在变；边缘撕出紫色的裂口 | 唯一不反光、轮廓不定的东西 | 变成“已知”时轮廓定格，凝成一块刻着白色特征符号的多面体，开始有明暗和反光 |
| 伪热点 | 伪造的信号源 | 在链路上方一层“无线层”里飘行的一枚细环，向四周荡出一圈圈扭曲空气的波纹；地上有投影，投影中心一根虚线指向它 | 高、环形、带波纹 | 掉线时波纹塌缩，跌落到地块上躺几秒；劫持时波纹聚成一束，打向隔离器的细光线 |
| 加壳器 | 层层外壳 | 一颗暗核外面裹着好几层半透明的紫壳，各层以不同速度转动 | 中等、圆、多层 | 定时剥下最外层，甩向附近的同伴，壳在同伴身上合拢 |

**带状态时的样子：** 状态都画在身上，同时存在时叠加，生命条上方有对应的小符号。

| 状态 | 样子 |
|---|---|
| 明文 | 暗色的外壳变成半透明，里面一行行字符清晰可读 |
| 可疑 | 一个带暗边的白色取景框锁住它，身后拖着一串记录点：它走过的路被记下了 |
| 隔离 | 一只透明的玻璃方盒把它罩住，盒棱发白光，它在盒里迟缓地挪动 |
| 重置 | 一圈白色光环炸开，它僵住，身体沿扫描线错位 |
| 困住 | 蜜罐的螺旋笼罩住它 |
| 退避 | 身后拖出几道向后的残影，脚步一顿一顿 |
| 减速 | 身后拖出几道拉长的流线 |
| 掉线 | 伪热点的波纹塌缩，跌落在地块上冒着火花 |
| 壳 | 一层层半透明的紫壳，受击时一片片剥落 |
| 伪装 | 木马的白色封装包外形 |
| 潜伏 | 蛰影只剩热浪般的扭曲和缺像素的轮廓 |
| 未知、已知 | 零日的轮廓不停改写；已知后定格成刻着特征符号的多面体 |

**被遮挡时：** 敌人被数据柱或平台挡住时，显示一圈紫色描边的剪影和生命条。

### 3.4 Boss

| Boss | 意象 | 造型 | 阶段变化 |
|---|---|---|---|
| 万傀 | 被操纵的万千傀儡 | 成千上万个被劫持的小设备方格聚成的爬行巨团，方格形状各异（有的像镜头，有的像天线），每一格都有一根紫色细线向上连到悬在半空的主控核心，像一大群提线傀儡。主控核心发出的指令沿细线一波波传下去 | 生命降到三分之二和三分之一时，一束束细线断开，断线的方格掉下来，变成一群蠕虫；巨团变小，主控核心越压越低、越来越亮。“洪峰”时巨团前半身抬起，砸出一道包的洪流 |
| 蜃楼 | 伪造的路径 | 一团由纠缠的路由线织成的半透明巨影，像一张打了结的线路图立了起来；它不断折射背后的景物，轮廓旁跟着几个错位的幻影 | “伪路由”时投出一道紫色虚线落到目标路段，那一段卷成黑洞。生命过半后外层线团碎裂，露出水晶般的路由内核，扰动范围变大 |
| 蛰影 | 按攻击链推进的潜伏者 | 一条由一节节战术板连成的长蛇，每节刻着一个攻击阶段的符号，头冠是一圈撬针 | 潜伏：只剩热浪般的扭曲和缺像素的轮廓，头冠撬针闪着微光。提权：战术板一节节点亮，背上叠起一层层权限甲片，吐出一群零日。破坏：身体沿接缝裂开，露出密文锁纹，咆哮时把锁印打向前方一段运维环，那段铺满锁纹 |

**Boss 登场：** 画面边缘泛起暗红，Boss 的名牌像协议头一样横扫过屏幕（例如“蛰影 · 高级持续性威胁”），顶部出现生命条，条上标出换阶段的位置。

## 四、体系、玩法、美术的契合

### 4.1 世界观的调整

| 原来 | 改为 | 理由 |
|---|---|---|
| 海滨城市“汐城”，水、电、交通、医院由中枢调度 | 网络空间里的一片自治域“汐域”，它的“中枢”保存着整个域的数据和控制 | 去掉现实设定；“自治域”是真实的路由概念（一个独立管理路由的网络） |
| 中枢：市政的核心数据库、江边的两座数据中心、地下的调度站 | 中枢：核心数据库、两座双活数据中心、深层的工控核心 | 同上 |
| 玩家是安全运营中心的值守员 | 玩家是汐域的“守护进程” | 在网络空间里，玩家本身也是一段程序；“守护进程”是真实的计算机术语，字面也是“守护” |
| 游戏内文案用值班频道的口吻 | 用系统日志的口吻，例如“西边界节点宕机，已旁路直通”“B 收敛 → 出口 Y” | 与网络空间统一 |
| 正常业务也走这些链路 | 不变，而且看得见：链路里一直流着白色的正常包 | 美术直接讲出“为什么不能封死” |

### 4.2 对照表的更新

| 游戏概念 | 原来的样子 | 网络空间里的样子 | 规则是否变 |
|---|---|---|---|
| 地图 | 城市网络的白模沙盘 | 悬浮在网络空间里的一块网格 | 不变 |
| 道路 | 光纤槽 | 透明流道，流着封装包 | 不变 |
| 高台 | 设备平台 | 悬浮在链路上方的旁路平台，细光线垂向链路 | 不变，名字仍叫“设备平台” |
| 障碍 | 楼宇、机柜、岩壁、江水 | 数据柱（不可路由的地址空间）、公网流、气隙 | 不变 |
| 关键点位 | 交换节点 | 端口灯环绕的圆形节点 | 不变 |
| 特殊地形 | 铜缆槽 | 铜色流道，包摊开成字符 | 不变 |
| 改变地形 | 光端机点亮暗光纤 | 光源的准直光束点亮虚线流道 | 不变 |
| 不受地形约束 | 伪热点在空中飞 | 伪热点在链路上方的“无线层”飘行 | 不变 |
| 时段 | 晨、黄昏、夜 | 明场、暮场、暗场 | 不变（题面“与各图的时段相符”改为“与各图的光场相符”） |
| 基地 | 中枢的门户建筑 | 中枢的核心晶体 | 不变 |
| 塔 | 精密网络硬件 | 以功能为形的光几何体 | 不变 |
| 敌人 | 黑色实体 | 吸光的暗色实体加字符 | 不变 |

### 4.3 逐条自洽检查

| 规则或设定 | 换到网络空间后的问题 | 处理 |
|---|---|---|
| 远程塔只能放在设备平台 | 设备平台在网络空间里是什么 | 画成悬浮在链路上方、用细光线连着链路的旁路平台：它看得见流量，但不在路径上。比原来更直接 |
| 障碍不能走、不能放 | 网络空间里“楼宇”没有了 | 数据柱：不可路由的地址空间，静止、高、不平 |
| 地图二的江不能走 | 江是现实地景 | 改为“公网流”：运营商的公网骨干，内部流量不能踏进去，只能走专线；原来“江水向东流”的动态保留为包流向东奔流 |
| 地图三的气隙 | 原来是深沟 | 直接画成地块断开的空洞，意象更准 |
| 伪热点飞行、不受链路约束 | “空中”在网络空间里没有意义 | 无线层：链路上方的一层，无线信号走的是另一层介质，所以不受链路和气隙约束 |
| 应急隔离器会被伪热点劫持 | 原来靠“无线遥控” | 隔离器是一枚悬在节点上的临时规则环，一根细光线连到上方的无线层；伪热点在无线层里，所以能劫持它 |
| 只有拦截器和探针能打伪热点 | 原来靠“带天线” | 拦截器的扇形扫描和探针的光束都能扫到无线层；沙箱的采样立方只落在地块上 |
| 节点上的塔被摧毁，旁路直通 | 塔不再是硬件 | 规则照旧，画面上一道白色旁路光桥接通节点；“宕机”对程序和服务同样适用 |
| 光端机、网闸是硬件名 | 网络空间里的光几何体用硬件名，是否别扭 | 保留名字：用户已采纳真实的设备名，名字说明功能；造型从功能来（光源、双板） |
| 光照与时段 | 网络空间没有晨昏 | 改为三种光场；题面的“光照与各图的时段相符”改为“光场” |
| 实时阴影 | 网络空间里光从哪来 | 明场是柔和的顶光，暮场是两座数据中心的暖光加北面的冷光，暗场是头顶上层透下的微光加塔和包流的自发光；都能投出实时阴影 |
| 零日“说不出形状” | 题面要求敌人有明暗和实时阴影 | 未知时它不反光，但影子仍在，并随轮廓改写；已知后才有正常的明暗 |
| 地图以外的环境与动态 | 原来是城市、江、岩洞 | 协议层、网络星团、远方流量、公网流、控制波形 |
| 出口名“水务、电网调度室” | 现实设定 | 改为“过程控制核心”“安全联锁核心”，都是工控网里的真实概念 |
| 地图名“市府园区”“双子江岸”“深井调度站” | 现实地名 | 改为“分段内网”“骨干流域”“气隙深层”，名字说明网络类型和看点 |
| 两种资源 | 无 | 不变；图标改为：算力是一圈运转的刻度，情报是一枚折角的标签 |
| 状态链 | 无 | 不变；明文、可疑、隔离的样子本来就是网络意象，更贴合了 |

### 4.4 不变的部分

- 规模：3 张地图，8 种塔、8 种敌人、3 个 Boss、4 种道具，14、15、16 波，每局 8–15 分钟。
- 规则：改道、禁止封死、光端机恢复、阻挡、互相攻击、状态与配合、资源与代价，一条不改。
- 题面里的所有边界细节：入口和出口不能放阻挡塔、会困住场上敌人的操作要拒绝、塔失去阻挡能力的那一刻、几座塔同一时刻被摧毁、暂停期间的变化在恢复后生效、被拒绝时不扣资源、加速时的判定、切换标签页、重开不残留等，都在题面不改的段落里。
- 2.10 的操作要求，包括“按住鼠标拖动来平移镜头和旋转视角”，一字不改。

## 五、界面与战斗效果

### 5.1 界面风格：“协议面板”

- **整体：** 面板是半透明的磨砂玻璃，细线边框，角上有图纸式的定位标记；标题栏像协议头一样分成几格字段；数字等宽；图标是单线描。同一套面板在三种光场里通用：明场上底板偏白、文字深色，暗场上底板偏深、文字浅色，结构和样式不变。
- **主界面：** 标题《断链》，字形中间断开一节；背后是汐域的网络星团缓缓转动，镜头在协议层之间慢慢下沉。
- **关卡选择：** 三张地图是悬浮在空间里的三团网络，分别处在明、暮、暗三种光里；选中后镜头飞进去。每团旁边一张卡片：地图名、网络类型、波数、入口数和出口数，附一张小拓扑图。
- **常驻信息：** 顶部一行“协议头”：
  - 算力：数字和一圈运转的刻度，刻度走满就 +1；
  - 情报：数字和 9 个小格；
  - 中枢完整度：一条分段的条，左端是中枢核心的图标，扣减时那一段先闪红再消失；
  - 波次和下一波倒计时、“立即来袭”按钮；
  - 速度（暂停、1×、2×、3×）和菜单。
- **流量预报（来袭预报）：** 右侧一列，每个入口一行：入口色的色条和字母，后面是敌人的小剪影和数量。新种类的敌人第一次出现时，从右边滑出它的“威胁档案”卡；Boss 波整块面板边缘泛红。
- **待部署栏：** 底部一排功能模块卡，顺序固定：
  - 每张卡上是这种塔的单线剪影，悬停时剪影动起来（膜起伏、漩涡转、光眼扫）；
  - 卡上写名字、类型标签（串接、旁路、节点、支援、地形）和价格；
  - 卡角一枚端口灯：亮着表示能部署；灭了表示不能，下面写出原因（算力不足、整备 5 秒、修复 18 秒、没有可放的位置）；冷却时端口灯外圈走一圈进度。
  - 道具卡是更窄的“规则卡”，标着花情报还是算力。
- **选中塔时的面板：** 浮在画面上远离这座塔的一侧，不挡住塔和它的作用范围。字段：名字、等级、类型；可用性条和主要属性；状态标签（加密、护盾、封禁）；技能充能环和释放按钮；升级按钮，有分支时并排两张分支卡（小剪影、效果、情报价格）；撤下按钮要按住片刻，环形进度走满才生效。节点上的塔另有情报进度弧和“撤下会让哪些入口收敛”的提示。
- **选中敌人、查看地块：** 一张小卡，写着名字、战术标签、生命、护甲、能力、当前状态、攻击谁；地块写类型、能否通行、能部署什么、寻路代价。
- **路线预览与改道预览：**
  - 当前路线是流道里入口色的实线包流；
  - 拖到节点上、部署或升级光端机时，操作后的路线以虚线和半透明的“幽灵包”叠加显示，会改变的路段闪烁；每个入口标识旁出现一枚小标签，例如“A +10 格 → X”“B 不变”；
  - 会封死时，受影响的入口标识闪红，会被困住的敌人头顶出现红叉，节点浮出断开的链节符号，底部写出原因；松手不生效，不扣资源。
- **暂停：** 所有包停在半空，画面轻微降饱和；中央一块面板写“已暂停”，按钮是继续、重新开始、返回关卡选择、设备手册、威胁档案。
- **结算画面：** 一份“事件报告”，排版像一段抓包记录：抬头写“威胁已清除”或“中枢失陷”，下面是消灭、漏入、中枢完整度、收敛次数、隔离总时长、被摧毁的塔、情报收支、用时，旁边一条完整度随时间变化的折线；底部是重新开始本图、返回关卡选择。
- **性能读数：** 按一个键在角落打开一块等宽字的小面板。

### 5.3 动效语言

- **秩序与噪声。** 守方的动作精确、平滑、干脆，光的流动连续；敌方蠕动、翻涌、改写形状，带故障般的抖动和跳帧。两种节奏放在一起，就能分清谁是谁。
- **分量对应时长。** 轻的一闪即逝，中的停留片刻，重的有停顿、扩散的光环和足够的持续，能被注意到。
- **变化有过程。** 光束一格格推进，铜色漫开又退去，光板升起，路线从变化处画向出口；看得出从什么变成了什么。
- **放慢时的样子。** 拿起卡片、选择位置和朝向、选中场上的塔时，包流和敌人一起慢下来，画面轻微降饱和；结束时平滑恢复。
- **背景克制。** 星团、协议层、公网流的动态节奏缓慢，不抢战斗信息。

#### 2.1 题材与美术方向

1. **世界观。** 网络空间里有一片自治域“汐域”，它的“中枢”保存着整个域的数据和控制：核心数据库、两座双活数据中心和深层的工控核心。攻击组织“蛰影”带着蠕虫、木马、勒索软件和僵尸网络从外网涌入，恶意流量混在正常流量里，被网络按路由转发向中枢。玩家是汐域的“守护进程”：在链路上串接防火墙和蜜罐，在悬浮的设备平台上旁路部署检测和处置功能，隔离交换节点，逼敌人改道。正常流量也走这些链路，所以任何入口和网段都不能被切成孤岛；攻击者自己也要到达中枢，所以它也不会把路全封死。恶意程序进入出口，“中枢完整度”（基地生命值）下降。游戏内的文案用系统日志的口吻，例如“西边界节点宕机，已旁路直通”“B 收敛 → 出口 Y”。

3. **配色与光场。** 三张图三种光场：分段内网是明亮的纸白，骨干流域是由冷到暖的暮色渐变，气隙深层近乎墨黑。守方是白色的透光体，敌方是吸光的暗色实体加品红紫的字符纹，红色只用于危险，铜色只用于旧链路。入口 A、B、C 各有固定颜色，与上述颜色都不撞，路线、入口标识和来袭预报都用它。信息元素都带一圈暗色细边，在明场和暗场上都看得清。

#### 2.2 格子与地形

- **链路**（道路）：地块上一道透明的流道，流着白色的封装包。受地形约束的敌人可以通行。阻挡型的塔可以部署在链路上（入口和出口除外），这一格仍然可以通行，路线照常经过它，敌人走到这里时被塔阻挡。
- **设备平台**（高台）：悬浮在链路上方、明显更高的平整平台，有细光线垂向旁边的链路，可以部署远程、支援和改变地形的塔，敌人不能通行。
- **障碍**：一簇簇高低不齐、不透光的数据柱，以及公网流和气隙，不能通行，也不能部署。
- **交换节点**：链路交汇处一圈端口灯环绕的圆形节点。部署防火墙、网闸或插入隔离器都算隔离；隔离时节点两侧竖起光板，包流止于光板前，这一格不能通行。
- **入口与出口**：入口是连着远方星团的光口，立一根入口色的标识；出口是一团缓缓呼吸的中枢晶体。
- **旧链路**（特殊地形）：带宽低、不支持加密的铜色流道，包摊开成字符，又慢又挤。地面敌人可以通行但会减速，寻路时一格旧链路按比链路更长的行程计算；走在上面的敌人变成明文（见 2.8 第 3 条）。
- **暗光纤**：只有一圈虚线轮廓的空流道，不能通行；被光端机点亮后成为可以通行、不能部署的“新开链路”，边缘留一圈虚线。
- **封存旧通道**：被红色斜纹拒绝板封住的铜色旧流道，不能通行；被撬开后变成旧链路。
- **黑洞与锁死段**：Boss 造成的临时地形，不能通行。黑洞是向内旋转的漩涡，锁死段铺满紫色密文锁纹。

#### 2.3 地图

三张地图都能从关卡选择界面直接进入，不需要先通关其他地图。每张图对应一种有代表性的网络。

1. **分段内网**（明场，典型企业网；14 波）。外网 → DMZ → 内网两个分段 → 核心数据库。北缘是隔着一层透明边界膜的 DMZ；入口 A“门户网站”在西北，攻击者利用对外服务进来；B“邮件网关”在东北，钓鱼邮件在这里落地，木马多从这里来。南端是唯一的出口“核心数据库”，一座层层叠起的晶体。暗光纤隔离带纵贯中央，把内网分成西边的办公网段和东边的业务网段，只有北端的 DMZ 互联和中段一段分段前遗留的旧链路能跨过；西侧外缘全程是旧链路的旧系统网段和东侧外缘的灾备环也能绕到核心。5 个节点：两个网段各有边界节点和汇聚节点，核心前一个。隔离西边界节点，A 折向 DMZ 互联，跨过隔离带挤进业务网段与 B 同路；隔离核心节点，A 绕旧系统网段、B 绕灾备环。两个边界节点同时隔离会封死，除非在隔离带北端的平台上部署光端机并升到 2 级，点亮一段暗光纤，打通“分段直连”。挑战是两个网段的取舍，以及要不要为了封锁亲手打通分段。
2. **骨干流域**（暮场，跨网专线与双活数据中心；15 波）。入口 A“互联网”、C“分支专线”、B“云端互联”在北侧自西向东排开；南侧是互为备份的两座数据中心 X、Y，两团亮着暖光的晶格球。一条“公网流”横贯东西，无数包向东奔流，内部流量不能踏进去；跨过它只有西侧的专线隧道和中段的旧专线（旧链路），C、B 平时都走旧专线；另有两条只剩虚线轮廓的预留隧道，点亮暗光纤就多出一处跨越点，整张图的流向随之改变。6 个节点，有的让 A 改去另一座数据中心，有的让 C、B 同时改去另一座，把攻击调度给防守更强的一边。挑战是隔离节点整批调度出口、三个入口共用两处跨越点，以及开通隧道。
3. **气隙深层**（暗场，工控网；16 波）。这是网络最深的一层。入口 A“运维跳板机”在西、B“办公网下行”在北、C“供应商远程维护”在东，出口是南边的“过程控制核心”X 和“安全联锁核心”Y。中央是号称物理隔离的气隙，一块能望见深渊的空洞，运维环却绕它一圈连通南北，几条链路把运维环连到入口和控制核心；气隙边缘和东联络段有几段不加密的老工控总线（旧链路）。7 个节点，两个控制核心前的节点不能同时隔离。三条封存旧通道挡住几条联络段，撬开后会开出绕过节点的近路。气隙南沿的光端机升到 2 级能点亮一座跨气隙的旧桥，让 B 更快到达，却挤进两侧都是空洞的窄桥。挑战是封锁会被旧通道绕开、七个节点相互牵连、要不要亲手在气隙上开口子，以及暗场里的可读性。

#### 2.4 塔

八种塔都有生命值（可用性），归零时宕机，即被摧毁。阻挡型的塔串接在链路上，流量必须穿过它；其余的在设备平台上旁路工作，靠注入阻断包打击敌人。每种都能升到 2 级，外观随之改变；蜜罐、拦截器、均衡器升 2 级时在两个互斥分支中二选一，选后不能更改。技能充满后释放。塔被摧毁或撤下时，它正在持续的技能和区域效果立即结束，已经给出的护盾和状态保留到时间结束。

1. **防火墙**（阻挡；链路或节点）：横跨链路的过滤栅：两根细柱间绷着带细缝的半透明膜，正常的包从缝里穿过，被挡的敌人压在膜上，柱顶有名额刻度。护甲高，同时挡 3 个；站在节点上时膜变得不透光、隔离节点，不阻挡，改为阻断相邻格的敌人。技能“封禁”靠受到攻击充能：细缝合上，一段时间内大幅减伤，攻击它的敌人变得可疑。2 级“下一代防火墙”：双层膜，一道扫描带在两层间扫过；多挡 1 个，阻断打到所有相邻格的敌人，被它挡住的敌人变成明文。
2. **蜜罐**（阻挡；仅链路；有朝向）：一团缓缓旋转的诱饵漩涡，中心一颗光洁得过分的假核心，最长的旋臂指向前方。同时挡 2 个，朝正前方三格飘出诱饵光点（伪造应答），打到的敌人变得可疑；附近的勒索者和洪泛团优先攻击它；它不会被加密，但很脆。技能“诱捕”靠攻击充能：旋臂甩出，把正前方最远的地面敌人卷到面前，收拢成螺旋笼困住。分支“高交互”：漩涡加深成藏着假系统的漏斗，被它挡住的敌人不能发动能力、受伤增加；分支“蜜网”：分成几团相连的小漩涡，伪造应答改为让敌人变成明文。
3. **网闸**（仅节点）：两块厚重的不透光平板，中间一道空无一物的缝，偶尔有小方块从缝上跳过。最便宜的隔离手段，不攻击，护甲很高，不会被加密。2 级“单向网闸”：方块只朝一个方向跳，攻击它的敌人变成明文。
4. **拦截器**（远程；平台；有朝向）：悬浮的三棱镜，地上投着 90° 的扇形扫描线，棱镜只在扇形里转。在扇形内单体攻击，射出截断目标的细光针，射程远，地面、空中都打。分支“穿透”：棱镜拉长成刃，光针贯穿一条线上的多个敌人；分支“压制”：棱镜外套几圈同心环，命中伪热点使其掉线，命中地面敌人使其减速。
5. **探针**（远程；平台）：悬浮的光眼，球里一圈虹膜般的光环，平时投出缓缓扫过的检测光束，攻击时聚成分叉的特征弧，在相邻的敌人之间跳跃，地面、空中都打，跳不到伪装中的木马。技能“特征更新”随时间充能，打到明文的敌人时额外充能：一段时间内攻速大增、每击都使目标重置。2 级：双眼，多跳一个敌人。
6. **沙箱**（远程；平台）：套着小立方的透明立方，两层反向缓转。抛出采样立方，落地展开成一只透明方格，范围内的敌人变得可疑；对壳伤害加倍；只打地面。技能“引爆舱”靠消灭敌人充能：接下来几发在落点留下一片带网格墙的玻璃区，持续让经过的敌人可疑。2 级：再套一层，范围更大。
7. **均衡器**（支援；平台）：一枚缓缓旋转的光环，分出细线流向范围内可用性最低的另一座塔，为它分担负载（治疗）。技能“冗余切换”随时间充能：范围内的塔获得护盾并解除加密。分支“双活”：两枚扣在一起的光环，同时治疗两座塔；分支“热备”：外绕一枚复影环，不再治疗，复影定时飞去套住范围内的塔加护盾。
8. **光端机**（改变地形；平台；有朝向）：方框里的光源朝前射出一道准直光束，光束就是朝向。它把朝向上一段直线内的暗光纤一格格点亮成新开链路，遇到平台或障碍即止；2 级换成双框，直线更长。技能“降级”随时间充能：光束变成铜色，一段时间内这条直线上的链路和新开链路变成旧链路，结束后复原。

#### 2.5 敌人与 Boss

敌人不只沿链路前进，还各有办法对付玩家的布防。

1. **蠕虫**：一串节节相同的链节，一伸一缩地爬。沿路走，被挡就攻击挡住它的塔；第一次走过直通的节点时，链节一节节复印出另一串，复制出的不再复制。
2. **洪泛团**：无数小暗包挤成的翻涌大团，体积是蠕虫的三四倍。占 2 个阻挡名额，受到拦截器的伤害减半。直穿某个被隔离的节点比现在的路线近得多、这个节点又离它不远时，它拉成一道包的洪流冲到节点前，以数倍伤害冲击节点上的塔或隔离器；节点一直通就按新路线前进。
3. **木马**：一颗大了一圈的白色封装包，细缝里有暗色的东西在动。明文或可疑之前远程塔不能选它为目标，被阻挡时照常挨打、溅射照常命中；明文或可疑时外壳裂开，露出暗核。没有可疑或隔离时被消灭，它炸开载荷，伤到相邻格的塔。
4. **勒索者**（远程）：密文字符串成的锁链，挂着锁符。边走边朝射程内的塔甩出密文链段，打得到平台上的塔；同一座塔在短时间内被打中 3 次就被加密一段时间：不能攻击、治疗、技能充能、升级或撤下，但仍然阻挡、仍然隔离节点。
5. **撬锁者**：钥匙齿叠成的细长身形，身边转着凭据令牌。撬开路线附近的封存旧通道能让它少走一大段时，它走到通道前花几秒撬锁，锁符碎开，通道变成旧链路；被重置、困住或隔离则进度清零。
6. **零日**：说不出形状的纯黑空洞，不反光，轮廓不停改写。未知时不能被阻挡，穿过阻挡型的塔时撕开它，让它短暂失去阻挡能力，也不受特征扩散和清除；变得可疑后成为“已知”，定格成刻着特征符号的多面体，此后照常被阻挡。
7. **伪热点**（飞行）：在链路上方的“无线层”飘行的细环，荡出一圈圈波纹，地上有投影。沿直线从入口飞往固定的出口，只有拦截器和探针能打它；掉线时跌落几秒，这时或在频谱干扰区里，所有远程塔都能打它，蜜罐也能把它诱过来。航线经过的节点上插着隔离器时，它悬停片刻劫持隔离器，节点随之直通；悬停中被消灭、掉线或重置则作废。
8. **加壳器**：裹着几层转动紫壳的暗核。定时剥下外层甩给附近的同伴：壳吸收伤害；带壳时明文立即消失、也不会再明文；沙箱对壳伤害加倍。

**Boss** 占用多个阻挡名额，名额不够时把阻挡塔挤开；不受重置和困住，隔离对它的减速减半。它们改变地形的能力先预警 3 秒，并且不会造成封死：攻击者自己也要到达出口。Boss 登场时画面边缘泛红，名牌横扫过屏幕，顶部出现标着换阶段位置的生命条。

1. **万傀**（分段内网第 14 波；气隙深层第 11 波重临）：被劫持的小设备方格聚成的爬行巨团，每格由一根紫线吊在半空的主控核心上，像一群提线傀儡。“洪峰”：定时冲击附近一个被隔离的节点，重创上面的塔、冲毁隔离器。生命降到三分之二和三分之一时，细线成束断开，掉下的方格变成一群蠕虫，主控核心越来越亮。
2. **蜃楼**（骨干流域第 15 波）：伪造路由线织成的半透明巨影，折射着背后的景物，身旁跟着错位的幻影。“伪路由”：在前方路线经过的链路上造一段临时的路由黑洞，优先选能让最多入口改道的位置；会封死时改选别处，找不到就改为降级那一段。“路由风暴”：定时放出一圈扰动，清掉范围内塔的护盾、扣减技能充能、打伤隔离器；生命过半后外层线团碎裂，露出水晶内核，范围变大。
3. **蛰影**（气隙深层第 16 波）：攻击组织的本体，战术板连成的长蛇，头冠是一圈撬针，按攻击链分三段。“潜伏”：只剩热浪般的扭曲轮廓，远程塔只能在它明文或可疑时打它，头冠撬开附近的封存旧通道。“提权”：生命降到三分之二时现形，战术板依次点亮，背上叠起权限甲片、护甲升高，吐出一群零日。“破坏”：降到三分之一后身体裂开、露出密文锁纹，定时加密锁死前方一段运维环，暂时不能通行，会封死时改选另一段。

#### 2.6 道具

道具有冷却，使用流程与部署塔相同。改变路线的道具花情报，其余的花算力。

- **应急隔离器**（情报）：悬在节点上的临时规则环，有细光线连到无线层；插进直通的节点隔离它，有耐久和时限，不产情报。
- **协议降级**（情报）：小信标落地亮起，铜色从落点漫开，周围一片链路暂时变成旧链路。
- **频谱干扰**（算力）：在无线层张开一张干扰网，经过的伪热点减速，所有远程塔都能打它。
- **备份还原**（算力）：一道扫描光掠过塔身，恢复这座塔的部分生命，解除加密。

#### 2.11 美术

画面要达到可以正式发行的商业游戏的水准。图形素材由你自己制作。

1. **统一的视觉语言。** 整个游戏属于 2.1 所述的同一套视觉语言：战斗画面与各个界面（信息栏、待部署栏、操作面板、说明、关卡选择、结算画面）在风格、质感和细节程度上一致。
2. **3D 场景。** 战场是实时渲染的 3D 场景，有透视和纵深。光照统一，与各图的光场相符：分段内网是柔和的顶光，阴影浅而清楚；骨干流域北冷南暖，两座数据中心发出暖光，公网流反光；气隙深层很暗，靠塔的白光、包流、控制核心的波形光和头顶上层透下的微光照明。地形、塔和敌人有相应的明暗和实时阴影，不同材质看得出区别。各类格子不看文字也一眼可辨；地形的细节不妨碍分辨每一格能否通行、能部署哪一类塔。
3. **场景与氛围。** 地图以外的网络空间与战场连成一体，并有动态：地图下方的协议层一层层隐入深处，层面上稀疏的光点在呼吸；远处的网络星团缓缓转动，星团之间有成串的流量往来，各入口的流从远方连进地图；骨干流域的公网流延伸到两侧天边，气隙深层头顶透着上层的微光、脚下是空洞外的深渊。背景比地图暗淡，不抢视线。
4. **造型。** 每种塔、敌人和 Boss 在场上的尺寸下仅凭外观就能区分：八种塔的剪影各不相同（栅、漩涡、双板、棱镜、光眼、套方、光环、光源），守方的透光几何体与敌方的吸光暗色实体一眼分得开；塔的升级和分支在场上看得出来，有朝向的塔看得出朝向；Boss 在体量和细节上明显区别于普通敌人，换阶段时外形随之改变。伪热点在无线层飘行，离地有明显的高度。
5. **动画。** 塔和敌人都有连续的动画，包括敌人的行走、攻击、受击和倒下，塔的待机、攻击、受击、释放技能和被摧毁；朝向随行进或攻击的方向变化。塔的动作精确、干脆，光的流动平滑连续；敌人蠕动、翻涌、改写形状，带故障般的抖动。
6. **攻击与特效。** 各种塔和勒索者的攻击有各自的弹道或攻击表现：防火墙推出的平面脉冲、蜜罐飘出的诱饵光点、拦截器截过目标的细光针、探针跳跃的特征弧、沙箱落地展开成透明方格的采样立方、勒索者甩出的密文链段。命中、技能释放、治疗、护盾和状态施加都有相应的特效，强弱与事件的分量相称；特效有层次和质感。
   - 治疗是顺着细线流进塔身的光点，护盾是套上的复影，受击时泛起涟漪；
   - 配合效果有单独的表现：特征扩散时同种敌人头上亮起同一个特征符号并被细线连起，关联隔离时字符和取景框合成玻璃方盒扣下，清除时方盒连同敌人碎成像素；
   - 敌人被消灭时碎成暗包、从地块缝里漏下去，蠕虫复制时链节在节点上一节节复印；
   - 节点隔离时光板竖起、包流在光板前堆住，节点上的塔被摧毁时一道白色旁路光桥接通节点；改道时一圈收敛波扫过地图，旧路线的包流退去变灰，新路线从变化处一路亮向出口；
   - Boss 换阶段时停顿片刻，伴随冲击波和外形的变化；这类大事件持续到足以被注意到。
