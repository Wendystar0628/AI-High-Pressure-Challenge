## 〇、结论

1. **推荐主题：火与霜，游戏名《燎台》。** 雪山温泉镇靠一团“心火”过冬；冰雪和枯枝凝成的“霜魇”怕火、掉进深水就化，下山来扑灭心火。守火人在路口地火口上的“燎台”点火封路，逼霜魇改道。
2. **为什么不是换皮。** “霜魇怕火、遇深水就化，冷能冻水立冰，热能融雪化冰”这一条冷热规律，同时推出了：
   - 哪里能走、关键点位为什么能封路、塔被打掉为什么路会开；
   - 地形塔怎样开路、撤走后为什么回填、为什么有时暂不回填；
   - 减速地形为什么既减速又抬高寻路代价；
   - 两种资源为什么一个随时间来、一个“守住才产”；
   - 状态连锁，以及每个敌人的能力和破解办法。

   把“燎台”换成“木桩”、“霜魇”换成“机器人”，这些规则就全都失去来由，只能靠硬规定。
3. **明日方舟的代表机制。**
   - 干员方面：阻挡数、费用随时间回复、撤退返还与再部署、近战位与远程位、朝向、三种技能充能（时间、攻击、受击）、物理与法术两类伤害、治疗与护盾、减速、推与拉（推进深水即消灭，对应方舟的“推坑”）、嘲讽、反隐。
   - 敌人方面：飞行、远程、隐匿、高防与高法抗、多阻挡名额、条件无视阻挡、死亡爆炸、给同伴加成、复活、专打装置、Boss 多阶段。

   每个机制的触发条件都由冷热推出，名称、角色、美术全部原创。
4. **规模与负担。**
   - 地图、塔、敌人、Boss、道具、波次、时长都与现题面相同。
   - 没有加音效之类的新负担；新增的是机制，即伤害类型、推拉、隐匿、复活、死亡爆炸，它们替换掉了原来同位置的机制。
   - 地图拓扑沿用原设计中已经验算过的网格，只换地形。

## 一、主题候选

### 1.1 怎样算“不是换皮”

先看《盐闸》为什么被认为是换皮：
- **两种资源：** “闸印守住能产、落闸要花”只能靠规定；盐晶换成金币，玩法完全一样。
- **各管各的道理：** 盐垒卫上闸封路、拾荒鸥叼闸板、蚀盐蠕溶盐柱，各自有一点道理，但没有一条共同的规律把它们串起来。
- **画面：** 盐、卤水、锈铜做出来，难有好看的现代感。

据此定四条检验标准：
1. **由名推规则。** 只看名字，玩家能猜出它怎样起作用、怕什么。
2. **换名就失效。** 换成通用名字（木桩、金币、泥地），规则失去来由，只能靠硬规定。
3. **一条规律串起多个系统，并长出新规则。** 主题自己长出原来没有的机制，而不只是给旧规则贴名字。
4. **画面好看、统一、现代。** 关键信息能靠主题自己的视觉语言交代，例如能不能走，一眼看得出。

### 1.2 候选一：火与霜《燎台》（推荐）

**一句话：** 冰雪凝成的“霜魇”怕火、掉进深水就化。守火人在路口地火口上的“燎台”点起大火，把霜魇逼去别的路。

| 系统 | 在《燎台》里是什么 | 道理（换名就说不通的地方） |
|---|---|---|
| 动态寻路 | 霜魇循着冷路下山，找最近的暖门 | 雪和冰做的东西走不进火、掉进深水就化，能走的路天然由火和水划定 |
| 截断与改道 | 燎台：路口地火口上的石台，点燃后火柱封路 | 火挡住雪是常识。“只有地火口点得起封路的大火”，解释了为什么只有关键点位能封路 |
| 塔被打掉，路恢复 | 塔的生命就是火势；燎台上的火被压灭，燎台就熄 | 熄了就不再挡路，一句话说通 |
| 攻击关键点位的敌人 | 扑燎熊把背上的雪往火上扑；雪鸮扇雪扑灭火把 | 灭火的方式就是它们的能力，伤害倍率也有来由 |
| 改变地形的塔 | 热泉井：喷热泉融开雪墙和冰塞，开出新路 | 撤走后风雪回填；井被打灭时，被踩实的雪道暂不回填。这正是“禁止封死”时的滞留规则 |
| 特殊地形 | 温泉滩：霜魇踩进热水会化 | 绕着走（寻路代价高）、走得慢、身上湿，三件事同出一源 |
| 敌人改变通行 | 冻川龟冻住暗溪，开出近路；冰笙、寒螭竖起冰棱冰脊，暂时封路 | 寒冷冻水、立冰，正是霜魇的本事 |
| 不受地形约束 | 雪鸮沿直线飞向最亮的心火 | 夜鸟扑火光，所以航线固定 |
| 出入口 | 冰隙是入口，暖门是出口，基地值是心火 | 霜魇进镇，心火就弱 |
| 资源一：薪 | 镇上源源送来的柴；霜魇化掉后，身上的枯枝落地成柴 | 部署就是给炉灵添柴；撤下退还“没烧完的一半”；击杀掉柴 |
| 资源二：火种 | 点燎台只能用心火分出的火；燎台烧满 40 秒能再分出一粒（以火传火） | “点燎台要花、守住能产、熄了就断”，三条规则同出一个道理 |
| 不能互换 | 有柴没火点不着燎台，火也变不出柴 | — |
| 状态连锁 | 湿加灼化成雪泥；热风吹散雪泥 | 冷热物理 |
| 方舟机制 | 隐匿：雪幕里看不见，火光照到才显形。复活：被打散的雪团会重新聚起，被烧化的不会。死亡爆炸：冰甲碎裂，被烧化的不炸。推拉：风箱吹和吸，推进深水就化 | 每个机制的触发条件都由冷热推出 |
| 界面 | 能用的卡片亮着火，不能用的火熄了，冷却时火苗一点点长回来 | 界面状态的读法与世界观一致 |

**换名测试：** 把燎台换成木桩、霜魇换成机器人，就会出现一连串说不通的地方：
- 机器人为什么过不了木桩？
- 木桩被打坏，路为什么会开？
- 为什么有的敌人专门往木桩上扑雪？
- 温泉滩为什么让敌人既慢又能化成雪泥？
- 守住木桩为什么会产资源？

这些都要另立硬规定。

**画面：**
- **主轴是冷暖对比。** 雪白、透光的冰蓝，对上我方的琥珀火光。路面是扫开积雪的深色湿石，敌人的白雪身体和冷白光核在路面上很醒目。
- **三张图三套光。** 晴朗清晨的温泉雪坡，黄昏的冰河渡口，冰川下的夜间冰湖。
- **我方：** 白瓷加黑铁加暖光，是当代产品设计的语言，不是旧铜旧木。
- **动态：** 温泉蒸汽、浮冰、热浪、落雪，都是好看的现成动态。

**弱点：** 冰火对立是常见题材，要靠具体设定做出辨识度：白瓷炉灵、温泉雪镇、枯枝霜魇、以火传火。

### 1.3 候选二：灯与影《长夜灯》

**一句话：** 长夜里，影从暗处涌出，要吞掉城中央的长明灯。影只能在暗处移动，守灯人在老灯杆上点灯，照亮路口，把影逼去别的暗路。

| 系统 | 对应 | 评价 |
|---|---|---|
| 动态寻路 | 影只能走暗处，路线就是一条暗路 | 绑定极强；能不能走就是亮不亮，一眼可见 |
| 截断与恢复 | 灯杆上点灯照亮路口；灯被扑灭，黑暗回来 | 自然 |
| 特殊地形 | 半影（月光地）：影能走，但变慢、变弱 | 自然 |
| 改变地形的塔 | 遮光幕：把一片月光地遮暗，开出新暗路 | 勉强：守方主动给影造暗路，动机弱 |
| 敌人改变通行 | 开路：织暗蛛给天窗织网遮光 | 开路自然 |
| | 封路：影不会造光，Boss 造临时障碍缺少道理 | 封路缺道理 |
| 飞行 | 扑灯蛾飞向长明灯，顺路扑灭灯笼 | 自然 |
| 隐匿与复活 | 影在暗处看不见；在暗处被打散的会重聚，在光里打散的不会 | 自然 |
| 资源 | 灯油（随时间）、火种（以火传火） | 自然 |

**画面：** 夜里的灯火水城，暖光圈、墨色剪影、体积光，很好看。

**弱点：**
- 三张图都是夜，信息多时整体偏暗，混战可读性风险大。
- 每座塔都发光，哪些光挡路要另立规则。
- 地形塔和 Boss 封路缺少道理。

### 1.4 候选三：网络与路由《断链》

**一句话：** 恶意程序沿城市网络的路由涌向核心机房。管理员在交换节点上部署防火墙断开链路，路由随之重新收敛。

| 系统 | 对应 | 评价 |
|---|---|---|
| 动态寻路 | 就是“动态路由”：链路断开后，路由重新收敛 | 语义最贴 |
| 截断与恢复 | 防火墙断开链路；防火墙被流量洪泛打垮，链路恢复 | 自然 |
| 改变地形的塔与特殊地形 | 布线机拉一条新光纤；拥塞链路代价高、走得慢 | 自然 |
| 飞行 | 隧道包不走路由，直达目标 | 自然 |
| 方舟机制 | 加密流量（隐匿）、逻辑炸弹（自爆）、蠕虫自我复制（复活）、僵尸网络控制端（加成） | 自然 |
| 资源 | 算力（随时间）、授权证书 | 勉强：守住节点为什么产证书，说不太通 |

**画面：** 只能做成发光线路与机柜组成的数据城。容易落入霓虹网格的套路；阻挡、肉搏、治疗、受击在数据世界里没有直观形象，做出来正是用户担心的“莫名其妙”。

**弱点：** 画面风险最大。

### 1.5 比较与推荐

| | 火与霜《燎台》 | 灯与影《长夜灯》 | 网络与路由《断链》 |
|---|---|---|---|
| 寻路与截断的道理 | 强 | 很强 | 很强 |
| 地形塔（开路、回填、滞留） | 很强 | 弱 | 中 |
| 敌人开路和封路 | 都有道理 | 开路有、封路没有 | 有 |
| 两种资源 | 很强 | 很强 | 弱 |
| 方舟机制的落点 | 全部有冷热上的道理 | 多数有 | 抽象 |
| 画面好看、现代 | 晨、黄昏、夜三套光，冷暖对比 | 好看但偏暗 | 抽象，易落套路 |
| 混战可读性 | 暖色我方、冷色敌人、深色路面 | 吃力 | 单调 |

**推荐候选一。** 它是唯一一个“开路和封路两个方向都有物理道理”的题材，正好对上这道题最难的耦合：地形塔的回填与滞留，以及敌人封路时不能封死。它也把候选二最好的部分吸收了进来：火光让隐匿显形，以火传火做资源，扑火的飞鸟。

另外考虑过“蚁群与信息素”：信息素路径就是路线，粉笔线截断。没有列为候选，原因有两个：守方是谁说不顺；昆虫题材对部分人观感不佳。

## 二、明日方舟的代表机制

只借鉴机制类型。下表“方舟里”一栏是对机制的概括，不是原文。

### 2.1 干员方面

| 机制 | 方舟里 | 本设计 |
|---|---|---|
| 阻挡数 | 地面干员各有阻挡数，挡住的敌人停下交战；大型敌人一个顶几个名额（如“阻挡它相当于阻挡三名敌人”） | 采用。炉卫 3（2 级 4），鼓风手 2；扑燎熊占 2，Boss 占 3–4 |
| 部署费用与回复 | 费用随时间自然回复；先锋能额外回费 | 采用自然回复（薪）；不设回费单位，击杀掉柴已承担这个作用 |
| 撤退返还与再部署时间 | 撤退返还一半费用，要等再部署时间；被击倒同样进入冷却 | 采用。撤下退一半薪，短暂整备；熄灭不退，进入更长的“重燃”，可以花火种跳过 |
| 近战位与远程位 | 地面格放近战，高台放远程 | 采用：道路和高台 |
| 攻击范围有朝向 | 部署时选朝向，范围按朝向展开 | 采用：鼓风手、长弩、热泉井 |
| 技能充能 | 自动回复（随时间）、攻击回复、受击回复三种；有手动和自动释放 | 采用三种：炉卫受击，鼓风手攻击，汽笛、燃灯、热泉井随时间。另加击杀充能（熔渣炉） |
| 伤害类型 | 物理受防御减免，法术受法抗减免，另有真实伤害 | 采用：物理和焰，分别受护甲、抗焰减免；散泥无视护甲 |
| 治疗与护盾 | 医疗干员治疗，部分干员给护盾 | 采用：燃灯，分支长明（双目标）和照野 |
| 减速 | 辅助干员减速 | 采用：汽笛、缆叉、温泉滩 |
| 推与拉 | 特种干员把敌人推开或拉近，受敌人重量影响；推进坑里直接消灭 | 采用：鼓风手两个分支，烈风推、回风吸。深水就是坑；扑燎熊和 Boss 推不动 |
| 嘲讽 | 部分重装吸引敌人火力 | 采用：炉卫技能炽壁 |
| 反隐 | 少数干员或装置让隐匿敌人能被攻击 | 采用：燃灯灯光、汽笛热汽、照明弹、身上带灼 |
| 召唤、替身、天赋、潜能、精英化 | 养成和特殊职业 | 不采用：一局制，而且与改道无关 |

### 2.2 敌人方面

| 机制 | 方舟里 | 本设计 |
|---|---|---|
| 飞行 | 沿自己的航线飞，航线与地面路线用不同颜色显示；不能被阻挡，只有远程能打；被眩晕、冻结时失去低空悬浮 | 雪鸮。被缆叉命中或炫目时坠落 |
| 远程 | 在射程内攻击干员，被阻挡时先打阻挡者 | 冰棱手，打得到高台上的塔 |
| 隐匿 | 未被阻挡时不成为攻击目标 | 雪幕者及其身边的同伴；火光照到就显形 |
| 高防御、高法抗 | 重装敌人用法术打，术师敌人用物理打 | 冰甲卒护甲高，冰棱手抗焰高 |
| 多个阻挡名额 | 大型敌人占多个名额 | 扑燎熊占 2，Boss 占 3–4；名额不够时 Boss 把塔挤开 |
| 无视阻挡 | 部分敌人不能被阻挡 | 冰獭：带湿时打滑，不能被阻挡 |
| 自爆、死亡爆炸 | 部分敌人自爆，伤害干员 | 冰甲卒：不是被焰伤害击杀时，冰甲炸开，伤到相邻的塔 |
| 给同伴加成 | 部分敌人提升周围同伴 | 雪幕者：同伴隐匿，并且不会带湿 |
| 复活 | 部分敌人倒下后以另一形态复活，能力冷却重置 | 雪团的“复凝”；负雪卸雪换阶段 |
| 专打装置 | 部分敌人优先攻击特定目标 | 扑燎熊专扑燎台，雪鸮专扑火把 |
| Boss 多阶段 | 首领倒下或掉血后换阶段、换技能 | 负雪三段；冰笙过半血后冰管裂开；寒螭按血量唤獭 |
| 装载、潜地、能量护盾等 | — | 不采用，避免数量膨胀 |

### 2.3 选出的一组怎样互相克制

| 敌人 | 怕什么 | 别用什么 |
|---|---|---|
| 雪团 | 焰伤害、温泉滩（被烧化或在热水里死，不会复凝） | 只靠物理：会复凝 |
| 冰甲卒 | 焰；雪泥让护甲减半；散泥 | 物理：打不动，死时还会炸伤相邻的塔 |
| 冰棱手 | 长弩（物理）、炽壁嘲讽、汽幕（看不见目标） | 焰：抗焰高 |
| 扑燎熊 | 炉卫嘲讽；地火盆加熔渣炉，化成雪泥后扑火变慢；燃灯添火 | 火把：几下就灭。推拉：推不动 |
| 冰獭 | 鼓风手阻挡、远程集火；身边有雪幕者时它不会湿，反而挡得住 | 温泉滩、汽笛、熔冠炉卫：一湿就滑走 |
| 冻川龟 | 推拉、炫目（打断冻溪） | 放任它走到溪边 |
| 雪鸮 | 长弩、汽笛；缆叉或炫目让它坠落；照明弹 | 只打地面的塔；在它航线下插火把 |
| 雪幕者 | 燃灯、照明弹、汽笛、灼，让它显形 | 只靠远程：看不见 |

同一种手段常常“对这个有利，对那个有害”。例如：
- 汽笛的湿是雪泥连锁的起点，却让冰獭滑走；
- 物理伤害克冰棱手，却让雪团复凝、冰甲卒炸伤塔；
- 雪幕者让同伴不湿，破坏了连锁，却也让冰獭挡得住。

这就是“没有一招通吃”的来源。

### 2.4 原创的边界

- 不沿用方舟的职业名（重装、先锋、特种等）、干员名、敌人名、源石、感染等世界观元素。
- 方舟“雪境”一带有寒冷系敌人，例如冻结干员的寒冷状态，以及冰雪主题的首领。本设计的霜魇是冰雪枯枝凝成的东西，不是人；冷热规则作用在敌人身上，不冻结我方。名称和造型都与之无关。
- “阻挡在路上、远程在高台、技能按受击充能”这类通用机制，题面原来就有；本设计只把类型补全。

## 三、《燎台》完整设计

### 3.1 世界观

- **舞台：** 雪山半腰的温泉小镇。镇中央有一团从地火里引上来、千年不灭的“心火”，全镇靠它熬过极夜。
- **敌人：** 每到极夜，山顶冰川的裂隙里爬出“霜魇”，由雪、冰和林子里的枯枝凝成。
  - 它们怕火，掉进深水就化；
  - 能把浅水冻住、把冰竖起来；
  - 循着冷路下山，要去扑灭心火。
- **玩家：** 镇上的“守火人”，指挥“炉灵”。炉灵是白瓷炉身、胸中燃火的构装：
  - 生命就是火势；
  - 被压灭就熄了，靠添火恢复，熄灭后要重燃。
- **燎台：** 镇子四周的路口建有古老的燎台。燎台是地火口上的圆形石台，只有在这里点得起封路的大火。
- **出口与基地：** 出口是进镇的“暖门”，即透出炉火暖光的石拱门。霜魇走进暖门，心火就弱一分。
- **三张地图的故事：**
  1. 霜魇第一次冲下雪脊坡；
  2. 它们沿冰河涌到渡口；
  3. 它们从冰川底下的冰湖窟钻到镇子正下方。
- **游戏内文案：** 守火人的口吻，短句。例如关卡副标题“雪下来了”，燎台被扑灭时提示“西坡的火灭了！”

### 3.2 美术方向

**画风：** 现代风格化的雪景沙盘。
- 地块是有厚度的方块，侧面露出岩层和雪层。
- 形体简洁、边角圆润、大块干净的颜色。
- 雪面细腻、微微透光，有细碎闪点；冰通透，带内部的气泡和裂纹。
- 整体参照当代风格化游戏，不走写实，也不走复古。

**冷暖是画面的主轴：**
- **环境：** 雪和冰是冷蓝白的环境光。
- **我方：** 一切发暖光，火光把周围的雪染出一圈暖色。
- **敌人：** 由冷色组成。

**配色与材质：**

| 用途 | 颜色与材质 |
|---|---|
| 炉灵（塔） | 哑光白瓷配黑铁；炉窗和火口透出琥珀色火光 |
| 燎台 | 深色石台。未点燃时石缝里透暗红余烬；点燃时火柱腾起，热浪扭曲空气 |
| 霜魇（敌人） | 压实的白雪、深蓝透明的冰、黑色枯枝，体内有冷白的光核 |
| 路面 | 扫开积雪、露出深色湿石的石板路，和雪面、敌人都拉开明度 |
| 温泉滩 | 白色钙华台阶里的浅绿松石色热水，冒蒸汽 |
| 深水 | 墨蓝，漂着浮冰 |
| 危险 | 只用红色 |
| 入口 A、B、C | 各取一种与琥珀、冰蓝、警示红都不撞的颜色。路线、入口旗、来袭预报一律同色 |

**光照与各图时段：**
1. **雪脊坡（晴朗清晨）：** 低角度的暖阳，长影子，天空浅蓝。温泉梯田的蒸汽在逆光里发亮。
2. **冰河渡（黄昏）：** 橙紫的天空。河面起雾，镇上的灯随波次逐盏点亮。
3. **冰湖窟（夜，地下）：** 环境光很暗，靠燎台和塔的火光、温泉的微光、冰层的冷光照明。湖底一层层冰透出流动的冷光。

| 格子 | 外观 | 敌人能否通行 | 能部署什么 |
|---|---|---|---|
| 道路 | 深色湿石板路（冰湖窟里是岩廊） | 能 | 炉卫、鼓风手 |
| 高台 | 明显高出地面的平整石台、屋顶平台 | 不能 | 长弩、熔渣炉、汽笛、燃灯、热泉井 |
| 障碍 | 木石坡顶小屋、雪松、岩壁、冰壁，顶面不平 | 不能 | 无 |

**燎台的状态：**
- 未点燃；
- 被塔点燃，脚下有一圈“火种计时”环；
- 被火把点燃，带剩余时间环；
- 此刻点燃会封死：石台变红，叠一个熄火图标；
- 地火口回气中：余烬变灰，显示秒数；
- 被盯上：被扑燎熊或负雪盯上时，上方出现雪爪标记。

### 3.5 塔（炉灵）

**通用规则：**
- 八种塔都有火势（生命），归零即熄灭。
- 都能升到 2 级，外观随之改变。鼓风手、长弩、燃灯在 2 级时二选一分支。
- 伤害分物理和焰两类。

**1. 炉卫**（阻挡；道路或燎台；物理）
- **外观：** 矮壮的白瓷炉身，胸口一扇琥珀色炉窗，扛一面边缘烧红的黑铁圆盾。
- **能力：** 同时挡 3 个。
  - 站在燎台上时，把炉火接进地火口点燃燎台、封路；这时不阻挡，改为盾击相邻格的敌人。
- **技能“炽壁”（受击充能）：** 一段时间内大幅减伤；近战攻击它的敌人带灼；把附近的冰棱手和扑燎熊引来打自己。
- **2 级“熔冠”：** 盾缘熔成亮红，头顶炉口喷出火冠。多挡 1 个，盾击打到所有被挡的敌人。被它挡住的敌人贴着炉身带湿。代价是冰獭会从它身边滑走。
- **原型：** 方舟的重装：阻挡、受击回复、嘲讽。

**2. 鼓风手**（阻挡；仅道路；有朝向；焰）
- **外观：** 高瘦的白瓷身躯，怀抱一只黑铁风箱，箱口亮着火。
- **能力：** 同时挡 2 个，朝正前方三格鼓出热风。
  - 热风吹到雪泥，就把雪泥吹散。
- **技能“鼓风”（攻击充能）：** 把正前方三格内的地面敌人沿朝向推开一格。
  - 被推进深水的被冲散；
  - 扑燎熊和 Boss 推不动；
  - 推拉会打断冻溪。
- **分支：**
  - **烈风：** 风箱加一对铁翼。技能推开两格；热风把灼吹到身后的敌人身上。
  - **回风：** 箱口倒转成吸口。技能改为把正前方一条线上最远的地面敌人（包括坠落的雪鸮）吸到面前，并使其炫目。
- **原型：** 方舟特种干员的推与拉，加上重量与坑。

**3. 火盆**（仅燎台）
- **外观：** 黑铁三足盆，盆里一团明火。
- **能力：** 最便宜的封路手段。不攻击，攻击它的敌人被火星反烫。
- **2 级“地火盆”：** 盆底接通地火，火柱更高，挨打时盆底喷出热汽，让攻击者带湿。

**4. 长弩**（远程；高台；有朝向；物理）
- **外观：** 白瓷转台上架一张黑铁长弩，箭羽琥珀色。
- **能力：** 在所朝方向的 90° 扇形内单体攻击，地面、空中都打。
- **分支：**
  - **穿云：** 双层弩臂，弩矢贯穿一条线上的多个敌人。
  - **缆叉：** 发射拖着火绳的鱼叉。命中雪鸮使其坠落，命中地面敌人使其减速。

**5. 熔渣炉**（远程；高台；焰）
- **外观：** 矮胖的陶炉，炉顶一支长柄铁勺抛臂。
- **能力：** 抛出发光的熔渣，落点溅射并施加灼，只打地面。
- **技能“熔浆”（击杀充能）：** 接下来几发留下熔浆池。落在温泉滩上则成“沸泉”，同时施加湿和灼，当场化成雪泥。
- **2 级：** 双炉口，溅射更大。

**6. 汽笛**（远程；高台；焰，伤害很低）
- **外观：** 一束白瓷汽管，顶端的铜哨喷着白汽。
- **能力：** 朝周围一圈喷热汽，地面、空中都打。被喷到的敌人带湿并减速；热汽里的隐匿敌人显形。
- **技能“汽幕”：** 随时间充能，每喷到一个带灼的敌人额外充能。一段时间内白汽笼罩整个范围：敌人大幅减速，冰棱手看不见目标、不能投掷。
- **2 级：** 多一组汽管，范围更大。
- **原型：** 方舟辅助干员的减速，加反隐。

**7. 燃灯**（支援；高台）
- **外观：** 细长的白瓷灯柱，琉璃灯罩里一团暖火。
- **能力：** 给范围内的其他塔添火（治疗）；灯光范围内的隐匿敌人显形。
- **技能“灯华”（随时间充能）：** 范围内所有塔获得护盾。
- **分支：**
  - **长明：** 上下两盏灯，同时治疗两座塔。
  - **照野：** 灯罩换成大透镜，不再治疗。灯光范围变大，被照到的敌人受到的伤害增加。技能改为强光一闪，范围内敌人炫目。

**8. 热泉井**（改变地形；高台；有朝向）
- **外观：** 白瓷井台伸出一支铁喷管，冒着热汽。
- **能力：** 把朝向上一段直线内的雪墙和冰塞融成融雪道。直线 1 级 3 格、2 级 5 格，遇到高台或障碍即止。
- **技能“涌泉”（随时间充能）：** 一段时间内把这条直线上的道路和融雪道变成温泉滩，结束后复原。
- **离场：** 撤下或熄灭时，融雪道被风雪回填，回填前先进入“积雪中”，格上的敌人走出来。会封死时：
  - 撤下被拒绝；
  - 熄灭引起的回填则暂留为“踩实的雪道”，直到回填不再封死。

**塔与改道的关系：**
- 炉卫和火盆是点燃燎台的两种塔：炉卫能打，火盆便宜。
- 燃灯保住燎台上的塔，就保住了火种计时。
- 鼓风手的推拉会改变敌人在路线上的位置，被推回去的敌人从新位置重新寻路。
- 热泉井是唯一改变地形的塔，它的部署、升级、撤下、熄灭都要预览，都受禁止封死约束。

### 3.6 敌人（霜魇）与 Boss

**1. 雪团**（基础；复活）
- **外观：** 膝盖高的圆滚滚雪团，两根枯枝当手，冰蓝小眼。
- **能力：** 沿路走，被挡就攻击挡住它的塔。
- **复凝：** 被物理伤害打散时，留下一颗光核，几秒后在原地重新聚成，只聚一次。被焰伤害击杀、死时带灼或站在温泉滩上，就化掉，不再聚。

**2. 冰甲卒**（高防；死亡爆炸）
- **外观：** 裹着厚厚透明冰甲的雪兵，一面冰盾护在身前。
- **能力：** 护甲很高。
- **碎甲：** 不是被焰伤害击杀时，冰甲当场炸开，伤到相邻格的塔。被烧化的不炸。

**3. 冰棱手**（远程；高抗焰）
- **外观：** 深蓝冰凝成的细长身形，背一束冰棱。
- **能力：** 边走边朝射程内的塔投冰棱，打得到高台上的塔，让塔结霜、受伤增加。体内是致密的玄冰，抗焰很高。
- **目标：** 被阻挡时打阻挡者。画面上有它和目标之间的细线。

**4. 扑燎熊**（多阻挡名额；专打燎台）
- **外观：** 用枯枝兜着一座雪山的雪熊，步子沉重。
- **能力：** 占 2 个阻挡名额，推不动。
- **扑燎：** 直穿某个点燃的燎台比现在的路线近得多（参考原设计：近 6 格以上），这个燎台又离它不远（参考：8 格以内）时：
  - 它走到燎台前，把背上的雪一捧捧扑上去，对燎台上的塔或火把造成数倍伤害；
  - 火一灭，就按新路线前进。
- **画面：** 头顶亮起雪爪标记，一条红线连到目标燎台。
- **奖励：** 击杀得火种。

**5. 冰獭**（条件无视阻挡）
- **外观：** 半透明冰身、雪白肚皮的水獭，贴地滑行。
- **能力：** 在冰面上更快。身上带湿时浑身打滑，不能被阻挡，从阻挡塔身边滑过去；阻挡塔上方飘出“滑走”字样。

**6. 冻川龟**（改变通行：开路）
- **外观：** 背着一座蓝色冰川冰壳的大龟。
- **冻溪：** 冻住路线附近的暗溪能让它少走一大段（参考：至少 4 格）时：
  - 它爬到溪边伏进水里，花几秒把暗溪冻成冰面；
  - 被推拉或炫目，进度清零；
  - 冰面只增加可以通行的格子，不会封死。
- **画面：** 决定冻溪时，它与暗溪之间连一条线，暗溪上出现结冰的倒计时，并预示冻住后的新路线。
- **奖励：** 击杀得火种。

**7. 雪鸮**（飞行）
- **外观：** 霜羽和枯枝爪的猫头鹰，地面有投影。
- **航线：** 沿直线从入口飞往本图规定的暖门，不随燎台变化。
- **谁能打它：** 只有长弩和汽笛。被缆叉命中或炫目时坠落；坠落时，或在照明弹的光里，所有远程塔都能打。
- **扑火把：** 航线经过的燎台上插着火把时，它悬停片刻，扑扇雪羽把火把扑灭，燎台随之熄灭。悬停中被打死、坠落或炫目，这次作废。

**8. 雪幕者**（隐匿；给同伴加成）
- **外观：** 细高的蒙面身形，身周常年飘着一小片落雪。
- **雪幕：** 它自己和 1.5 格内的同伴处在雪幕里。
  - 隐匿：远程塔不能把它们选为目标。被阻挡时照常挨打，溅射照常命中。
  - 同伴身上的湿立即消失，也不会再带湿。
- **显形：** 燃灯的灯光、点燃的燎台近旁、照明弹、汽笛的热汽，以及身上带灼，都能让雪幕里的敌人显形。
- **画面：** 玩家始终看得见隐匿的敌人，是半透明的雪影；显形后变实。

**Boss 的通用规则：**
- 占用多个阻挡名额，名额不够时把阻挡塔挤开；
- 不受炫目和推拉，雪泥对它的减速减半；
- 改变地形的能力先预警 3 秒，并且不会造成封死。

**负雪**（雪脊坡第 14 波；冰湖窟第 11 波重临；占 3）
- **外观：** 房子大的雪鹿，枯枝巨角兜着背上的一座雪山。
- **覆燎：** 定时把一大片雪抖向附近一个点燃的燎台，重创上面的塔、直接扑灭火把。预警时燎台上出现收缩的雪爪圈。
- **多阶段：**
  - 生命降到三分之二、三分之一时，背上的雪滑落成一群雪团。
  - 最后一次卸完雪，它不再覆燎，改为狂奔。

**冰笙**（冰河渡第 15 波；占 3）
- **外观：** 一座会走的冰山，背上一排冰管，像一支笙。
- **立棱：** 在前方路线经过的道路上竖起一段临时的冰棱。
  - 优先选能让最多入口改道的位置；
  - 会封死时改选别处；
  - 找不到合格的位置，改为在原位置结一片冰面。
- **寒音：** 定时吹出一圈寒气：清掉范围内塔的护盾，扣减技能充能，打弱火把。
- **多阶段：** 生命过半后冰管裂开，寒音范围变大。

**寒螭**（冰湖窟第 16 波；占 4）
- **外观：** 巨大的冰蛇，头冠是一圈冰棱，腹下透出冷白光。
- **冻溪：** 冻住头部附近的暗溪。
- **封岸：** 让前方的一段湖岸隆起冰脊，暂时不能通行；会封死时改选另一段，都不行就不发动。
- **唤獭：** 生命降到一定比例时，从湖里唤出一群浑身湿透的冰獭。它们一上岸就能滑过阻挡。

### 3.7 道具

道具有冷却，使用流程与部署塔相同。

| 道具 | 花什么 | 外观与效果 | 方舟或原设计的对应 |
|---|---|---|---|
| 火把 | 火种 | 插进空闲的燎台点燃它，有火势和时限。会被雪鸮扑灭，被扑燎熊、负雪和寒音打弱 | 原闸板 |
| 沸水罐 | 薪 | 陶罐在落点碎开，周围一片道路暂时变成温泉滩，范围内的敌人带湿 | 原卤水桶 |
| 照明弹 | 火种 | 升空后挂着燃烧，照亮一片圆形区域。经过的雪鸮眩光：减速，所有远程塔都能打。区域里的隐匿敌人显形 | 原雾网，加反隐 |
| 添柴 | 薪 | 给一座塔添一捆柴，立即恢复部分火势，清除结霜 | 原急修铆 |

道具改为按道理分别花两种资源：用火的花火种，用柴和水的花薪。

### 3.8 两种资源

| | 薪 | 火种 |
|---|---|---|
| 是什么 | 镇上送来的柴，炉灵烧的就是它 | 从心火分出的火 |
| 怎样获得 | 随游戏时间自动增长，顶部有到下一次增长的进度；霜魇化掉后，枯枝落地成柴（击杀奖励） | 每波开始时心火分出 1 粒；燎台上的塔每连续燃烧 40 秒再分出 1 粒（以火传火），燎台熄灭则计时清零；击杀扑燎熊、冻川龟和 Boss，取回它们体内冻着的火种 |
| 用在哪里 | 部署塔；升到 2 级；沸水罐、添柴 | 每次点燃燎台 1 粒（塔或火把都算）；选升级分支；火把、照明弹；让熄灭的塔立即重燃 |
| 撤下与熄灭 | 撤下退还一半没烧完的薪，短暂整备 | 熄灭不退任何东西，卡片进入较长的重燃，已升的等级作废；花 1 粒火种可以立即重燃 |
| 不能互换 | 有柴没火点不着燎台 | 火也变不出柴 |

**改道的代价：**
- 点燃燎台要花火种；
- 燎台熄灭后地火口要回气几秒（复位冷却），期间不能再点；
- 迷途的对应物“惊火”有免疫期。

因此不能几乎零代价地反复开关同一处。

### 3.9 状态与配合效果

**敌人的状态：**

| 状态 | 来源 | 效果 |
|---|---|---|
| 湿 | 温泉滩（离开后短暂保留）、汽笛、地火盆、熔冠炉卫、沸水罐、涌泉、沸泉、从湖里爬出 | 本身无减益；是雪泥的一半；冰獭带湿时不能被阻挡 |
| 灼 | 熔渣、熔浆池、沸泉、炽壁、烈风吹过来的火 | 持续焰伤害；身上发光，隐匿的会显形 |
| 雪泥 | 湿与灼同时存在的一刻，两者都被消耗 | 大幅减速，攻击变慢，护甲减半；Boss 的减速减半 |
| 惊火 | 燎台点燃的一刻，正朝它走来、新路线要它掉头的敌人 | 减速，受到伤害增加；之后一段时间不再受惊 |
| 炫目 | 照野强光、回风吸扯 | 短暂定住；打断扑燎、冻溪、投冰棱、雪鸮扑火把；雪鸮炫目时坠落；之后一段时间不再炫目 |
| 坠落 | 缆叉、炫目（只对雪鸮） | 落到地面，所有远程塔都能打，回风能把它吸过来 |
| 眩光 | 照明弹（只对雪鸮） | 减速，所有远程塔都能打 |
| 隐匿 | 雪幕者 | 远程塔不能选为目标；显形条件见雪幕者 |

**塔的状态：**
- **结霜：** 来自冰棱手，受到伤害增加，添柴可以清除。
- **护盾：** 来自灯华。
- **嘲讽：** 来自炽壁。

**配合效果：**

| 配合效果 | 搭配 | 结果 | 类型 |
|---|---|---|---|
| 化泥 | 湿的来源（温泉滩、汽笛、地火盆、沸水罐、涌泉）+ 熔渣炉 | 化成雪泥 | 状态相互作用 |
| 散泥 | 雪泥 + 鼓风手 | 雪泥被吹散：无视护甲的伤害，溅伤邻格敌人 | 状态相互作用 |
| 风助火 | 灼 + 烈风 | 灼沿风向传给身后的敌人 | 塔与塔 |
| 惊火 | 燎台点燃时机 + 覆盖回头路的远程塔 | 掉头的敌人减速、易伤 | 关键点位与改道 |
| 推入深水 | 鼓风手 + 河岸、湖岸 | 非重型敌人被冲散 | 地形 |
| 叉落 | 缆叉或照野 + 回风、熔渣炉 | 雪鸮坠落后被吸到面前，或被炮击 | 塔与塔 |
| 汽封扑燎 | 地火盆 + 熔渣炉 | 扑燎熊带湿，再被灼，化成雪泥，扑火变慢 | 关键点位 |
| 沸泉 | 涌泉或沸水罐 + 熔浆 | 整段路上的敌人同时湿与灼，当场化泥 | 地形改变 |
| 破幕 | 燃灯、照明弹、汽笛、灼 + 远程塔 | 雪幕里的敌人显形，能被集火 | 反隐 |

**反向作用：**
- 湿会让冰獭滑走；
- 雪幕者清掉同伴的湿；
- 物理伤害让雪团复凝、冰甲卒碎甲。

### 3.10 改道相关的联动

1. **雪脊坡：点燃西坡上段。**
   - 扣 1 火种；A 的路线折向北垭口，旧路线淡出，新路线画过垭口和东坡。
   - 正在西坡上段往下走的冰棱手要掉头，受惊火。东坡长弩按新的剩余行程重排目标。
   - 40 秒后，燎台分出一粒火种。
2. **扑燎熊扑火，燎台熄灭。**
   - A 的扑燎熊算出：直穿西坡上段近 10 格。它走到燎台前开扑，红线连到燎台。
   - 结局一：火盆熄灭的一刻，燎台熄灭、火种计时清零、卡片进入重燃，A 改回西坡；北垭口上的敌人有的掉头，有的继续走东坡。
   - 结局二：放的是地火盆，扑燎熊每扑一下就带湿；熔渣炉一发让它化成雪泥，扑火变慢。炉卫用炽壁把它引走。
3. **封死被拒绝，热泉井让它可行。**
   - 西坡上段已点燃，再把炉卫拖到东坡上段：预览中 A、B 两条路线画不出来，两面入口旗闪红，提示“这样会封死入口 A、B”，不扣资源。
   - 在北端岩台部署热泉井并升到 2 级，雪墙融开，雪沟路打通，两个上段才能同时点燃。
   - 这时撤井被拒绝。井被冰棱手打灭时，雪沟路暂留为踩实的雪道。
   - 之后玩家撤下一个燎台上的塔，回填不再封死：雪沟进入“积雪中”，沟里的敌人走出来，最后一只离开后回填。
4. **冰河渡：点燃渡心燎台，C、B 改去西门。**
   - C、B 的路线折向西桥，出口由 Y 换成 X，入口旁弹出“C 改道 → 出口 X”。
   - B 的队伍沿北岸码头路西行。路边朝南的鼓风手（烈风）一次技能，把岸上的雪团和冰棱手推进冰河冲散；扑燎熊推不动，照常前进。
5. **冰河渡：融开东廊桥，全图流向改变。**
   - 在东仓台部署热泉井，东廊桥里的积雪化开，B 直接过东廊桥去 Y，不再经过中浅滩。
   - 原来的几组互斥燎台不再互斥。代价是 B 更快到达 Y。
6. **雪鸮扑火把。**
   - 雪脊坡的暖门前燎台插着火把，A 的雪鸮航线掠过它，悬停扑扇。
   - 保住：缆叉把它打得坠落，或照野一闪让它炫目。
   - 没保住：火把熄灭，A、B 同时改回暖门路。
7. **冰湖窟：冻川龟冻溪，绕开封锁。**
   - 点燃东廊燎台后，C 改走温泉岩廊、环湖去 X。C 的冻川龟发现冻住东廊暗溪能省 12 格，于是伏进溪里，暗溪上出现结冰倒计时和预示路线。
   - 结局一：回风把它吸走，或照野让它炫目，进度清零。
   - 结局二：冻成冰面，C 改走冰面去 Y，封锁被绕开。
8. **雪幕者加冰獭的混编。**
   - 雪幕者走在冰獭群中间：冰獭看不见、不会湿，反而能被炉卫挡住。可是远程塔打不到它们。
   - 一发熔渣让雪幕者带灼、显形，集火打掉它之后，冰獭又会在温泉滩上湿透滑走。
9. **推拉与改道。**
   - 回风把走过岔口的敌人吸回岔口这一侧，它从新位置重新寻路，可能走上另一条路。
   - 推拉不会把敌人推进障碍、推过燎台，也不会推到没有路通往出口的地方。

### 3.11 界面风格：霜玻璃与暖瓷

- **面板：** 半透明的磨砂冰玻璃，后面透出模糊的战场，边缘一圈细细的暖光。
- **卡片和按钮：** 哑光白瓷片，凹槽里亮着火。
  - 能用：火亮着；
  - 悬停：火变亮、瓷片微微抬起；
  - 不能用：火熄灭，只剩冷灰的瓷面，并写出原因；
  - 冷却（整备、重燃）：火苗从底部一点点长回来。
- **图标：** 单线的琥珀色火纹。
  - 薪是一束枯枝；
  - 火种是白瓷小盏里的一粒火；
  - 心火是炉膛里的火；
  - 燎台是石台上的火柱。
- **文字：** 标题用简洁的现代衬线风格，正文用清楚的无衬线风格，数字用等宽风格。
- **布局：** 沿用原设计 2.16 的布局：顶栏、右侧来袭预报、底部卡片栏、选中面板、性能读数。
- **关卡选择：** 三张地图的雪景微缩模型在暖光里缓慢旋转。
- **结算：** 胜利时暖门喷出一束火光，写“心火长明”；失败时心火熄灭，写“心火熄灭”。

### 一、任务

制作一款在浏览器中运行的三维塔防游戏《燎台》。战场是三维的网格地图，地图自带地形，敌人沿可通行的道路自动寻路前往出口。敌人是怕火的冰雪“霜魇”；地图上有若干“燎台”（关键点位），在燎台上部署塔或插上火把就点燃了它，截断这段道路，迫使敌人改道。塔有生命值，敌人会攻击塔；燎台上的塔熄灭后，道路重新打开，敌人的路线随之改变。玩家既要打赢每一场交战、保住自己的塔，又要经营路线：点燃哪个燎台、何时点、怎样守住，每次改道值不值得付出代价。

第二节描述游戏的设计，第三节说明这些内容要做到什么、哪些情形必须正确。不得照搬现有游戏。

本测试是 AI 模型能力竞赛。建议充分利用全部时间，把作品做到完成度尽量高、各方面都优秀。

### 二、游戏内容

凡是写明“由你设计”的地方，具体怎么做由你决定，但规则要前后一致，并与游戏内的说明相符。

#### 2.1 题材与美术方向

1. **世界观。** 雪山温泉小镇靠千年不灭的“心火”熬过极夜。极夜里，冰川裂隙中爬出雪、冰和枯枝凝成的“霜魇”，它们怕火，掉进深水就化，要下山扑灭心火。玩家是“守火人”，指挥白瓷炉身、胸中燃火的“炉灵”守住出口“暖门”，炉灵的生命就是火势。敌人走进暖门，心火（基地生命值）减弱。
2. **画风。** 现代风格化的雪景沙盘：地块是有厚度的方块，形体简洁、边角圆润；雪面细腻、微微透光，冰通透。
3. **配色与材质。** 冷暖对比是主轴：雪和冰冷蓝白，路面是扫开积雪的深色湿石板。我方一切发暖光：炉灵是哑光白瓷配黑铁，透出琥珀色火光。霜魇由白雪、深蓝透明的冰和黑色枯枝组成，体内有冷白光核。红色只用于危险。入口 A、B、C 各有固定颜色，路线、入口旗和来袭预报都用它。
4. **界面风格。** “霜玻璃与暖瓷”：面板是磨砂冰玻璃；卡片和按钮是哑光白瓷片，凹槽里的火能用时亮、不能用时熄、冷却时慢慢长回；图标是琥珀色火纹。

#### 2.2 格子与地形

- **道路**：受地形约束的敌人可以通行。阻挡型的塔可以部署在道路上（入口和出口除外），这一格仍然可以通行，路线照常经过它，敌人走到这里时被塔阻挡。
- **高台**：明显高出地面的平整石台，可以部署远程、支援和改变地形的塔，敌人不能通行。
- **障碍**：房屋、雪松、岩壁、冰壁等，不能通行，也不能部署。
- **燎台**：建在地火口上的圆形石台，是道路格。部署炉卫、火盆或插上火把都算点燃（占用）；点燃时火柱腾起，这一格不能通行。
- **入口与出口**：入口是冰川的冰隙，插一面入口色的旗；出口是透出炉火暖光的暖门。
- **温泉滩**（特殊地形）：浅温泉。地面敌人可以通行但会减速，寻路时一格温泉滩按比道路更长的行程计算；走在上面的敌人带湿（见 2.8 第 3 条）。
- **深水**：河、湖和暗溪，不能通行，霜魇被推进去会化掉；暗溪能被冻成可以通行、不能部署的冰面。
- **雪墙与冰塞**：高雪墙和堵路的大冰块，不能通行；被热泉井融开后成为可以通行、不能部署的融雪道。

#### 2.3 地图

三张地图都能从关卡选择界面直接进入，不需要先通关其他地图。

1. **雪脊坡**（晴朗清晨的温泉镇；14 波）。北缘是冰隙，入口 A 在西北、B 在东北；南缘是镇子，唯一的暖门嵌在镇脚。一道雪墙纵贯中央，把战场分成西坡和东坡，只有北端的垭口和中段被温泉化开的浅滩能跨过；西侧外缘的温泉梯田和东侧外缘的干路也能绕到暖门。5 个燎台：两条坡路的上段、下段各一个，暖门前一个。点燃西坡上段的燎台，A 折向北垭口，翻过雪墙挤上东坡与 B 同路；点燃暖门前的燎台，A 绕西侧温泉梯田、B 绕东侧干路。两个上段的燎台同时点燃会封死，除非在雪墙北端的岩台上部署热泉井并升到 2 级，融开一段雪墙，打通“雪沟路”。挑战是两条坡路的取舍。
2. **冰河渡**（黄昏的渡口镇；15 波）。入口 A、C、B 在北岸自西向东排开；两座暖门 X、Y 开在南城墙上。漂着浮冰的冰河横贯东西，过河只有西石桥和中段的温泉浅滩；另有两座塞满积雪的廊桥，用热泉井融开就成为新渡口，整张图的流向随之改变。6 个燎台，有的让 A 改去另一座暖门，有的让 C、B 同时改去另一座暖门。挑战是点燃燎台整批改换出口、三个入口共用两处过河点，以及用热泉井开廊桥。
3. **冰湖窟**（夜，冰川下的洞窟；16 波）。中央是湖底透出冷光的冰湖。入口 A 在西、B 在北、C 在东，出口 X、Y 是南边的两座升降井。环湖路绕湖一圈，几条岩廊把它连到入口和井口，湖岸和东侧岩廊有几段温泉滩。7 个燎台，两座井口前的燎台不能同时点燃。三道暗溪横穿几条联廊，冻成冰面后会开出绕过燎台的近路。湖南岸的热泉井升到 2 级能融开湖心旧堤上的冰塞，打通一条穿湖的窄堤。挑战是封锁会被冰面绕开、七个燎台相互牵连，以及夜景下的可读性。

#### 2.4 塔

八种塔都有生命值（火势），归零时熄灭。每种都能升到 2 级，外观随之改变；鼓风手、长弩、燃灯升 2 级时在两个互斥分支中二选一，选后不能更改。技能充满后释放。塔熄灭或撤下时，它正在持续的技能和区域效果立即结束，已经给出的护盾和状态保留到时间结束。

1. **炉卫**（阻挡；道路或燎台；物理）：矮壮的白瓷炉身，胸口亮着炉窗，扛一面烧红边的铁盾。同时挡 3 个；站在燎台上时点燃燎台、不阻挡，改为盾击相邻格的敌人。技能“炽壁”靠受到攻击充能：一段时间内大幅减伤，近战攻击它的敌人带灼，附近的冰棱手和扑燎熊改打它。2 级“熔冠”：头顶喷出火冠；多挡 1 个，盾击打到所有被挡的敌人，被它挡住的敌人带湿。
2. **鼓风手**（阻挡；仅道路；有朝向；焰）：抱着黑铁风箱的白瓷身躯。同时挡 2 个，朝正前方三格鼓热风。技能“鼓风”靠攻击充能：把正前方三格内的地面敌人沿朝向推开一格，扑燎熊和 Boss 推不动。分支“烈风”：风箱加铁翼，推开两格，热风把灼吹给身后的敌人；分支“回风”：箱口倒转成吸口，改为把前方最远的地面敌人吸到面前并炫目。
3. **火盆**（仅燎台）：黑铁三足盆里一团明火，最便宜的封路手段。不攻击，攻击它的敌人被火星反烫。2 级“地火盆”：盆底接通地火，挨打时喷出热汽，让攻击者带湿。
4. **长弩**（远程；高台；有朝向；物理）：白瓷转台上的黑铁长弩。在所朝方向的 90° 扇形内单体攻击，地面、空中都打。分支“穿云”：弩矢贯穿一线上的多个敌人；分支“缆叉”：发射拖着火绳的鱼叉，命中雪鸮使其坠落，命中地面敌人使其减速。
5. **熔渣炉**（远程；高台；焰）：顶上一支铁勺抛臂的陶炉。抛出发光的熔渣，落点溅射并施加灼，只打地面。技能“熔浆”靠击杀充能：接下来几发留下熔浆池，落在温泉滩上则成“沸泉”，同时施加湿和灼。
6. **汽笛**（远程；高台；焰）：喷着白汽的白瓷汽管。朝周围喷热汽，伤害很低，地面、空中都打，被喷到的敌人带湿、减速，隐匿的显形。技能“汽幕”随时间充能，喷到带灼的敌人额外充能：一段时间内白汽罩住整个范围，敌人大幅减速，冰棱手不能投掷。
7. **燃灯**（支援；高台）：琉璃罩里亮着暖火的白瓷灯柱。给范围内的其他塔添火（治疗），灯光里的隐匿敌人显形。技能“灯华”随时间充能：范围内的塔获得护盾。分支“长明”：上下两盏灯，同时治疗两座塔；分支“照野”：换成大透镜，不再治疗，灯光更远，被照到的敌人受伤增加，技能改为强光一闪，使范围内敌人炫目。
8. **热泉井**（改变地形；高台；有朝向）：伸出铁喷管、冒着热汽的白瓷井台。把朝向上一段直线内的雪墙和冰塞融成融雪道，2 级时直线更长。技能“涌泉”随时间充能：一段时间内把这条直线上的道路和融雪道变成温泉滩，结束后复原。

#### 2.5 敌人与 Boss

敌人不只沿道路前进，还各有办法对付玩家的布防。

1. **雪团**：两根枯枝当手的圆雪团。沿路走，被挡就攻击挡住它的塔。被物理伤害打散后几秒，在原地重新聚成一次；被焰伤害击杀、死时带灼或在温泉滩上则化掉。
2. **冰甲卒**：裹着透明冰甲的雪兵。护甲（减免物理伤害）很高；不是被焰伤害击杀时，冰甲炸开，伤到相邻格的塔。
3. **冰棱手**（远程）：深蓝冰凝成的细长身形。边走边朝射程内的塔投冰棱，打得到高台上的塔，让塔结霜、受伤增加。抗焰很高。
4. **扑燎熊**（扑火）：背驮雪堆的雪熊，占 2 个阻挡名额，推不动。直穿某个点燃的燎台比现在的路线近得多、这个燎台又离它不远时，它走到燎台前把雪扑上去，对燎台上的塔或火把造成数倍伤害；火一灭就按新路线前进。
5. **冰獭**：贴地滑行的冰水獭，在冰面上更快；带湿时打滑，不能被阻挡，从阻挡塔身边滑过去。
6. **冻川龟**：背着冰壳的大龟。冻住路线附近的暗溪能让它少走一大段时，它伏进溪水，花几秒把暗溪冻成冰面；被推拉或炫目则进度清零。
7. **雪鸮**（飞行）：霜羽猫头鹰。沿直线从入口飞往固定的暖门，只有长弩和汽笛能打它；被缆叉命中或炫目时坠落，坠落或在照明弹的光里时所有远程塔都能打。航线经过的燎台上插着火把时，它悬停片刻扇雪扑灭火把，燎台随之熄灭；悬停中被打死、坠落或炫目则作废。
8. **雪幕者**：身周飘雪的蒙面身形。它和身边的同伴处在雪幕里：远程塔不能选它们为目标，被阻挡时照常挨打；同伴的湿立即消失，也不会再湿。燃灯、汽笛、照明弹、点燃的燎台近旁和身上的灼都能让它们显形。

**Boss** 占用多个阻挡名额，名额不够时把阻挡塔挤开；不受炫目和推拉。它们改变地形的能力先预警 3 秒，并且不会造成封死。

1. **负雪**（雪脊坡第 14 波；冰湖窟第 11 波重临）：背驮雪山、长着枯枝巨角的巨鹿。“覆燎”：定时把一大片雪抖向附近一个点燃的燎台，重创上面的塔、扑灭火把。生命降到三分之二和三分之一时，背上的雪滑落成一群雪团；雪卸完后不再覆燎，改为狂奔。
2. **冰笙**（冰河渡第 15 波）：背上一排冰管、形如笙的冰山。“立棱”：在前方路线经过的道路上竖起一段临时冰棱，优先选能让最多入口改道的位置；会封死时改选别处，找不到就改结一片冰面。“寒音”：定时吹出一圈寒气，清掉范围内塔的护盾、扣减技能充能，打弱火把；生命过半后范围变大。
3. **寒螭**（冰湖窟第 16 波）：头冠一圈冰棱的巨大冰蛇。“冻溪”：冻住头部附近的暗溪。“封岸”：让前方一段湖岸隆起冰脊，暂时不能通行，会封死时改选另一段。生命降到一定比例时，从湖里唤出一群浑身湿透的冰獭。

#### 2.6 道具

道具有冷却，使用流程与部署塔相同。

- **火把**（火种）：插进空闲的燎台点燃它，有火势和时限。
- **沸水罐**（薪）：陶罐在落点碎开，周围一片道路暂时变成温泉滩。
- **照明弹**（火种）：升空燃烧，照亮一片区域：经过的雪鸮眩光、减速，所有远程塔都能打；区域里的隐匿敌人显形。
- **添柴**（薪）：立即恢复一座塔的部分火势、清除结霜。

#### 2.7 改道

1. **通行因什么改变。** 下面这些事会改变通行情况：燎台上的塔被部署、撤下或熄灭；火把插上、燃尽或被扑灭；热泉井被部署、升级、撤下或熄灭；暗溪被冻成冰面；冰棱和冰脊出现与消退。除点燃燎台和敌人的能力外，塔、道具和其他任何操作都不能让道路格变得不可通行；部署在普通道路上的阻挡型塔只阻挡敌人，不改变通行情况。沸水罐和涌泉只改变行程，同样按第 2 条重算路线。
2. **改道。** 通行情况无论因哪件事改变，都按同一套规则处理：每个入口出发的敌人路线都显示在画面上，并随通行情况同步更新；场上受地形约束的敌人从当前位置重新寻路，继续前进；之后出发的敌人按新路线行进。塔、道具、状态或能力中，凡是以路线或到出口的距离为依据的部分，都改以新路线为准。一个格子变得不可通行时，无论是燎台被点燃、被改变的地形恢复原状，还是敌人的能力生效，正在这一格上或正要进入这一格的敌人怎样处理，由你设计。例如雪脊坡点燃西坡上段的燎台，西坡路上的敌人掉头去北垭口，东坡的塔按新路线重排目标。
3. **预览与禁止封死。** 在燎台上部署塔或插火把、部署或升级热泉井时，玩家在确认之前就能预览操作后各入口的路线。游戏禁止封死道路（见 3.2 第 1 条）：此刻进行会造成封死的操作，包括会让场上某个敌人无路可走的，在预览时就能看出；这样的操作不能完成，并给出提示。
4. **热泉井的恢复。** 它被撤下或熄灭时，融开的格子被风雪回填，格上的敌人按第 2 条处理。回填不能造成封死：撤下会造成封死时不能完成，并给出提示；由它熄灭引起的回填同样不能造成封死，这些格子已被踩实，先保持可以通行，直到回填不再会封死。
5. **会改变通行情况的敌人。** 敌人的能力引起的变化同样按第 2 条处理，同样不能造成封死。能力影响到玩家的塔或道具时，占用状态和资源的变化与说明一致。
6. **雪鸮。** 雪鸮不受地形和道路约束：可以经过障碍、高台、深水和点燃的燎台，不能被任何塔阻挡；它同样前往出口，到达后同样减弱心火，航线同样显示在画面上。燎台的点燃与熄灭、热泉井和其他敌人的能力，都不改变它的航线；它所在的位置也不会让任何操作因封死而被拒绝。
7. **入口之间的取舍。** 每张地图上至少有一个燎台，点燃它会同时改变两个以上入口的路线。改道会在入口之间转移压力，点燃方案需要在不同入口之间取舍，而不是有一套对每个入口都最有利的方案。在有多个出口的地图上，点燃或熄灭燎台能让某个入口出发的敌人改往另一个出口。
8. **改道的代价。** 点燃燎台要花火种，燎台烧得住才分出火种（见 2.9 第 2 条），改道是需要权衡代价的决定。

#### 2.8 战斗

1. **阻挡。** 炉卫和鼓风手挡住经过它的敌人，被挡住的敌人停下与它交战。它同时能挡住的敌人数量有限，超出的敌人不被它挡住，继续前进。阻挡不改变路线：路线的显示和预览照常经过阻挡型塔所在的格子；改道后，它只阻挡路线经过它的敌人。它熄灭、撤下或失去阻挡能力的那一刻，被它挡住的敌人立即按当时的路线恢复前进。正被阻挡的敌人遇到改道时怎样处理，由你设计。
2. **互相攻击。** 塔优先攻击沿路线离出口最近的敌人。被阻挡的敌人攻击阻挡它的塔；敌人怎样选择攻击目标由你设计，并写进游戏内的说明。目标熄灭、撤下、离开射程，或敌人改道之后，敌人重新选择目标。伤害的减免、生命值的恢复和护盾按说明结算。燎台上的塔熄灭时，占用随之解除，道路重新打开并按 2.7 第 2 条改道，资源同时结算。例如扑燎熊扑灭西坡上段的火盆的一刻，燎台熄灭、火种计时清零、卡片进入重燃，A 的路线改回西坡。
3. **状态与配合。** 冷与热构成一条连锁：
   - **湿**：敌人走在温泉滩上、被汽笛喷到、攻击地火盆、被熔冠炉卫挡住、被沸水罐或涌泉淋到时带湿，离开后短暂保留。
   - **灼**：熔渣、熔浆池和炽壁让敌人带灼，持续受焰伤害；带灼的敌人发光，隐匿的会显形。
   - **雪泥与散泥**：带湿的敌人被灼的一刻，两种状态消失，化成雪泥：大幅减速、攻击变慢、护甲减半；鼓风手的热风吹散雪泥，造成无视护甲的伤害并溅伤邻格的敌人。
   - **惊火与炫目**：点燃燎台的一刻，正朝它走来、新路线要它掉头的敌人受惊，减速并受伤增加；照野的强光和回风的吸扯让敌人炫目，短暂定住，打断扑火、冻溪和投冰棱。两者之后都有一段免疫期。
   - **其他配合**：地火盆加熔渣炉让扑燎熊化成雪泥、扑火变慢；缆叉打落的雪鸮能被回风吸来。反过来，湿让冰獭打滑，温泉滩一带和熔冠炉卫都挡不住它。
4. **推拉。** 被推拉的敌人不进入、不穿过不可通行的格子，不被推到无路可走处；推进深水的被冲散，算作击杀；之后从新位置寻路。

#### 2.9 资源、波次与流程

1. **波次。** 雪脊坡 14 波、冰河渡 15 波、冰湖窟 16 波，Boss 波见 2.5。前几波逐个引入新敌人；中段不时出现扑燎熊或冻川龟；冰河渡和冰湖窟各有一波三个入口同时大量出兵的“寒潮”。各波的敌人组合、出发入口和节奏随波次变化，不能只是同一组敌人的数值放大。
2. **资源。** 两种资源不能互相兑换：
   - **薪**：随游戏时间自动增长；击杀霜魇，枯枝落地成柴。用于部署和升级塔、沸水罐和添柴。
   - **火种**：点燃燎台只能用心火分出的火种。每波开始时心火分出 1 粒；燎台上的塔每连续燃烧 40 秒再分出 1 粒，熄灭则计时清零；击杀扑燎熊、冻川龟和 Boss，取回体内冻着的火种。每次点燃燎台花 1 粒，选择升级分支、火把、照明弹、让熄灭的塔立即重燃也花火种。
   - 撤下塔退还一半没烧完的薪，卡片短暂整备后可再部署；塔熄灭不退款，卡片进入更长的重燃，已升的等级作废。燎台熄灭后地火口要回气片刻，期间不能再次点燃。
3. **操作时机。**（同现题面）
4. **时长。**（同现题面）
5. **速度控制。**（同现题面）
6. **胜负与结算。** 敌人走进暖门会减弱心火，心火熄灭即失败，撑过全部波次即胜利。其余同现题面。

## 六、需要用户拍板的点

1. **主题和名字。** 推荐火与霜《燎台》。需要确认的名字有：
   - 燎台、心火、暖门、霜魇、守火人、炉灵；
   - 三张地图：雪脊坡、冰河渡、冰湖窟。

   如果选候选二《长夜灯》或候选三《断链》，第三部分要重做。
2. **我方是“炉灵”还是人。** 炉灵是白瓷炉身的火心构装，好处是“生命即火势、熄灭、添火、重燃”一路顺下来，造型也统一、现代。也可以改为人类守火人手持火器，但那样生命和治疗的道理会弱一些。
3. **推进深水即冲散。** 对应方舟的“推坑”，是最有方舟味、又和地形耦合的机制。代价是要在 3.2 第 4 条写出“冲散不算凭空消失”的例外，推拉还要满足“不推到无路处”。保留还是去掉？
4. **新增的方舟式敌人机制是否全要。** 包括：
   - 复凝（复活）；
   - 碎甲（死亡爆炸）；
   - 雪幕（隐匿和加成）；
   - 物理与焰两类抗性。

   嫌多可以先去掉碎甲，它的方舟味最弱，作用也和焰克冰甲重叠。
5. **道具分别花两种资源。** 原来全花闸印，现在用火的花火种、用柴和水的花薪。
6. **地图拓扑沿用原设计。** 冰湖窟暗溪冻成冰面后的行程按道路计。建议用原验算脚本复核一次（只影响改道收益，判定阈值预计仍成立）。
7. **Boss 多阶段做到什么程度。** 现在是：负雪三段（卸雪、狂奔）、冰笙过半血后裂管、寒螭唤獭。也可以只保留召唤。
8. **评分指南是否补一句。** 即“机制类型与现有游戏同类不算照搬”。
9. **题面篇幅。** 草稿已压到与现题面第一、二节等长，代价是删去了三处举例。是否允许略超，把冻川龟绕开封锁的举例加回来？
10. **完整设计文档是否按新主题整篇重写。** 指 `调研\具体设计\动态寻路塔防.md`，包括数值表、波次表、联动情境。本方案只给主要设计；波次表可以按“敌人一一对换”机械替换，冻川龟只在冰湖窟出现，与原来的蚀盐蠕相同。
