## 一、总体设计

### 1.1 作品是什么

一个在浏览器里运行的图形动效编辑器，名为 **「帧坊」**，给动效设计师制作二维图形动画。它的工作方式是“AE 风味”的：合成里叠放图层，图层的各项属性用关键帧做动画，在时间轴上排时间，在曲线编辑器里调速度，用父子层级、预合成、蒙版和轨道遮罩组织画面，用修剪路径、形状变形、文字动画器和运动模糊做出常见的图形动效，播放预览后导出成视频。

它不追求功能面广（没有特效、表达式、三维、音频、外部素材），追求两件事：

- **所有功能叠在一起时依然正确、四处一致。** 例如：在一个旋转过、非等比缩放过、自身还在动的父级下面，在两个关键帧之间的某一帧拖动子图层，图层跟着鼠标走；松开后，时间轴、曲线编辑器和属性面板同时出现一个新关键帧；把这些图层预合成、加时间重映射倒放、开运动模糊，画面和导出依然逐帧相同。
- **工程很大时依然快。** 一个合成里有十几万个图层、上百万个关键帧时，复制、缓动、撤销重做和导出都在秒级完成。

界面气质是**深色、哑光、像一台精密仪器**：大面积是低饱和的墨蓝灰，层次靠明度区分；只有两种强调色——**熔岩橙**代表“时间与动画”（播放头、当前时间、已开启的动画、当前帧上的关键帧、主按钮），**冰蓝**代表“选择”（选中的图层、关键帧、画布上的选择框）。默认示例动画的主强调色也是熔岩橙，作品和工具出自同一套视觉语言。

### 1.2 整体结构

**界面是一屏六区，不弹出浮动窗口来完成日常工作：**

```
┌──────────────────────────────────────────────────────────────────────┐
│ 菜单栏                                                                │
│ 工具栏                                                                │
├─────────────┬──────────────────────────────────────┬─────────────────┤
│ 项目面板     │ 合成面板：标签页 / 层级路径             │ 属性面板          │
│ 项目|历史|性能│          画布                          │                 │
│             │          画布底栏                       ├─────────────────┤
│             │                                        │ 缓动预设面板      │
├─────────────┴──────────────────────────────────────┴─────────────────┤
│ 时间轴面板（全宽）：头部（当前时间、播放控制、视图切换）                     │
│   图层与属性列表 │ 时间区域：时间轴 / 曲线编辑器 / 上下分屏                 │
├──────────────────────────────────────────────────────────────────────┤
│ 状态栏（操作提示、选择摘要、性能读数、未保存标记）                          │
└──────────────────────────────────────────────────────────────────────┘
```

- 画布居中、最大；时间轴横贯整个窗口底部，给时间最多的横向空间。
- 曲线编辑器不另占位置，与时间轴共用底部的时间区域、同一把时间标尺和同一个播放头，一键切换或上下分屏。
- 画布、时间轴、曲线编辑器、属性面板是同一份工程在同一时刻的四个视图，任何一处的修改其余三处同时变化。

**工程里的东西是一棵树加三种关系：** 工程 → 合成 → 图层 → 属性 → 关键帧；图层之间有父级、轨道遮罩两种关系，合成之间有预合成引用一种关系。四类图层（形状、文字、空对象、预合成）在能用的范围内享有同样的功能，所以每项功能都要和其他功能叠加着正确工作（见 2.2 的组合表）。

### 1.3 体验流程

1. **打开。** 编辑器启动后直接载入示例工程「一点成字」，画布显示第 0 帧，播放头停在开头，底部出现提示“按空格键播放示例”。按空格，5 秒的动画在画布上实时播放：中央一个橙色圆点蓄力、爆发成一群几何图形，慢动作里变形、汇聚成光带，扫出标题“万物始于一点”，最后收回成圆点落在标题末尾。
2. **拆开看。** 在时间轴上展开任何一个图层，看到它的关键帧和缓动；切到曲线编辑器看速度曲线；双击「图形群」进入预合成，看到层级路径变成“一点成字 › 图形群”；选中「图形群」，在曲线编辑器里看到时间重映射的快—慢—快。
3. **从空工程做。** 新建工程，新建合成，用矩形、椭圆、钢笔、文字工具画图层；打开位置的动画开关，换个时刻拖动图层，画布上出现由逐帧点组成的运动路径；在曲线编辑器里拉出过冲；建一个空对象作父级；选几个图层按 `Ctrl+Shift+C` 预合成，复制几份，各自错开、变速、倒放；加蒙版、轨道遮罩、修剪路径、文字动画器、运动模糊。
4. **随时预览和撤销。** 空格播放，播放中继续拖动、改数值；任何一步都能撤销重做，历史面板里每一步都有名字。
5. **保存与导出。** `Ctrl+S` 存成工程文件，下次打开接着做；`Ctrl+M` 导出工作区为视频或无损图像序列，导出对话框显示逐帧进度。
6. **看性能读数。** 每次导出、每个改动工程的操作完成后，状态栏右侧显示这次操作的实测耗时；项目面板的“性能”页列出全部记录，可以选中几条看合计。

### 1.4 贯穿全部功能的四条行为

这四条是编辑器的“性格”，第二部分各节都按它们写：

1. **画面为准。** 在画布上拖、转、缩放，被抓住的东西始终在光标下面；不论上面有几层父级、父级怎样旋转缩放、是否在动，都是如此。
2. **写入当前时刻。** 已开启动画的属性，无论在画布、属性面板、时间轴还是曲线编辑器里修改，都只在当前时刻新建或更新一个关键帧，别的关键帧纹丝不动。
3. **一个状态，四个视图。** 拖动途中、播放途中、撤销重做之后，画布、时间轴、曲线编辑器、属性面板显示的永远是同一时刻的同一个工程。
4. **完整画质，实时。** 预览就是成片：播放和拖动播放头时不降低分辨率、不关闭蒙版和运动模糊；跟不上时少画几帧，但时间不放慢。导出的每一帧与在编辑器里停在这一帧时看到的相同。

## 二、具体内容（题面第二节正文）

### 2.1 概览

要做的编辑器名为「帧坊」，供动效设计师在浏览器中制作二维图形动画。一次典型的工作是这样的：新建合成，设好尺寸、帧率、时长和背景；画矩形、椭圆和钢笔路径，写文字，加空对象；为位置、缩放、旋转等属性开启动画，在不同时刻修改数值，留下关键帧；在画布上拖出并调整运动路径，在时间轴上安排图层和关键帧的时间，在曲线编辑器里调速度和缓动；用父子层级让一个图层带着别的图层运动，把一组图层预合成后整体复用、变速、倒放；用蒙版和轨道遮罩决定哪里显露，用修剪路径和形状变形让线条生长、图形变形，用文字动画器让文字逐字运动，给快速的运动加上运动模糊；随时播放预览，边播边改；保存工程，之后打开接着做；最后导出成视频。

这些步骤没有固定顺序，可以随时回到任何一步，在任意时刻修改。第二节的全部功能都必须能从新建的空工程开始、只用编辑器的界面完成，评审会从空工程开始验证。打开编辑器时自动载入 2.19 规定的示例工程，可以直接播放。

编辑器要承载的工程规模很大：3.5 的任务 5 里，一个合成有十几万个图层、上百万个关键帧。

### 2.2 工程里有什么

- **合成**：一个工程里可以有多个合成。每个合成有名称、尺寸、帧率、时长和背景色，有自己的运动模糊总开关和快门设置，还有工作区（预览和导出的范围）、标记和参考线。合成的帧是时刻 0、1/帧率、2/帧率……直到时长之前的每一个时刻。
- **图层**：合成里是一叠上下排列的图层，上面的盖住下面的。图层有四类：
  - **形状图层**：一个矩形、一个椭圆或一条钢笔路径，带填充和描边；
  - **文字图层**：一段可以多行的文字；
  - **空对象**：不出现在画面和导出里，只用来带动别的图层；
  - **预合成图层**：显示另一个合成的内容。
  每个图层在时间上有入点和出点，只在两者之间出现。
- **属性与关键帧**：图层的各项设置都是属性，例如五项变换、填充和描边、路径形状、修剪路径、蒙版、文字和文字动画器的设置、时间重映射。能做动画的属性随时间变化，变化由它的关键帧和关键帧之间的插值决定。
- **图层之间的关系**：
  - **父级**：图层可以指定另一个图层为父级，跟随父级的位置、旋转和缩放；父级还可以有自己的父级（2.5）。
  - **轨道遮罩**：图层可以用正上方的图层决定自己哪里显示（2.11）。
  - **预合成**：预合成图层显示另一个合成的内容；同一个合成可以被多处引用，被引用的合成里还可以有预合成图层，层层嵌套（2.12）。
- **合成的背景色**只在这个合成作为最外层被显示、导出时出现；作为预合成嵌套在别的合成里时，背景是透明的。
- **组合**：这些关系和第二节的各项功能可以同时用在同一个图层上，下表列出各类图层能用的功能。预合成图层和形状、文字图层一样，可以有父级、做别的图层的父级、带变换动画、加蒙版、做或使用轨道遮罩、开运动模糊，也可以再被预合成。

| 功能 | 形状图层 | 文字图层 | 空对象 | 预合成图层 |
|---|---|---|---|---|
| 五项变换、父级（作为子级或父级） | ✓ | ✓ | ✓ | ✓ |
| 填充、描边 | ✓ | 文字颜色 | — | — |
| 修剪路径 | ✓ | — | — | — |
| 形状变形（路径关键帧） | 钢笔路径 | — | — | — |
| 蒙版 | ✓ | ✓ | — | ✓ |
| 使用轨道遮罩 / 作为轨道遮罩 | ✓ / ✓ | ✓ / ✓ | — / — | ✓ / ✓ |
| 运动模糊 | ✓ | ✓ | — | ✓ |
| 文字动画器 | — | ✓ | — | — |
| 时间重映射 | — | — | — | ✓ |
| 被预合成、被复制、被粘贴 | ✓ | ✓ | ✓ | ✓ |

### 2.3 界面

界面按下面的设计制作。图标由你自己绘制，风格按 2.3.2；不要照搬任何现有软件的界面外观。

#### 2.3.1 整体布局

窗口被分成以下区域，彼此紧贴、不重叠，没有日常工作需要的浮动窗口。

| 区域 | 位置 | 默认尺寸 | 能否调整 |
|---|---|---|---|
| 菜单栏 | 最上方，全宽 | 高 32 像素 | 不可调 |
| 工具栏 | 菜单栏下方，全宽 | 高 44 像素 | 不可调 |
| 项目面板 | 左侧，工具栏与时间轴之间 | 宽 248 像素 | 拖动右边界调到 200–400 像素；可以收起成 28 像素宽的竖条 |
| 合成面板 | 中央，项目面板与属性面板之间 | 占据其余空间 | 随窗口和相邻面板变化 |
| 属性面板 | 右侧上部 | 宽 320 像素 | 拖动左边界调到 280–480 像素 |
| 缓动预设面板 | 右侧下部，属性面板下方，同宽 | 高 232 像素 | 拖动上边界调高度；可以收起成 28 像素高的标题条 |
| 时间轴面板 | 下部，全宽 | 高为窗口高度的 36% | 拖动上边界调到 180 像素至窗口高度的 70% |
| 状态栏 | 最下方，全宽 | 高 24 像素 | 不可调 |

- 面板之间的分隔线宽 4 像素。悬停时中间亮起一条 2 像素宽的冰蓝线，光标变成调整大小的双箭头；双击分隔线恢复默认尺寸。
- 调整后的尺寸和收起状态在下次打开编辑器时保持。
- 窗口变大变小时，只有合成面板和时间轴的时间区域改变大小，其余面板保持自己的宽度。
- 选择变化、展开折叠属性、切换时间轴与曲线编辑器时，各区域的位置和大小不变。

| 曲线颜色 | 位置 X `#FF6B6B`、位置 Y `#5BD18B`；其余属性依次取 `#5AA9FF`、`#F5C542`、`#C77DFF`、`#4FD1C5`、`#FF9F43` |

新建图层的默认标签色：形状图层蓝，文字图层紫，空对象灰，预合成图层黄。

**文字。** 界面文字用几何感的无衬线字体，中文用清晰的黑体类字体。正文 12 像素，次要标注 11 像素，面板标题 13 像素半粗。所有数值、时间码和帧号用等宽数字，数字变化时不左右跳动。当前时间显示为 18 像素。

**图标。** 16 像素线性图标，线宽 1.5 像素，圆头圆角，单色（次要文字色）；激活时变为熔岩橙，并带一层 16% 不透明度的熔岩橙圆角底。可点击区域至少 24×24 像素。

**控件。** 圆角 4 像素（面板和对话框 6 像素）。按钮分三种：主按钮（熔岩橙底、深色字）、次按钮（`#1A1E27` 底加 1 像素边框）、图标按钮（无底，悬停出现底色）。输入框获得焦点时边框变为冰蓝，外侧有 2 像素的冰蓝光晕。下拉框、复选框、分段按钮、滑块、滚动条（8 像素宽，半透明，悬停变粗）都按这套风格绘制，不使用浏览器默认外观。界面紧凑：图层行高 26 像素，属性行高 22 像素，面板内边距 8 像素。

**画布上的辅助元素。** 选择框、手柄、锚点、运动路径、参考线、安全框在任何缩放比例下都保持固定的屏幕尺寸和线宽（1 像素线，8 像素手柄），并且一律是“浅色线芯加 1 像素深色外描边”的双层画法，叠在纯白或纯黑的画面上都清楚。

#### 2.3.3 菜单栏

菜单栏左端是「帧坊」的标志（一个熔岩橙的菱形关键帧与一道弧线组成的 20 像素图形，由你绘制）和菜单名；中间是工程名，有未保存的修改时工程名前出现一个熔岩橙圆点；右端是“操作说明”按钮。

菜单项右侧显示快捷键，当前不可用的项显示为不可用色，悬停时提示不可用的原因（例如“没有选中关键帧”）。撤销和重做两项显示将要撤销或重做的操作名称。

| 菜单 | 菜单项（快捷键） |
|---|---|

#### 2.3.4 工具栏

从左到右分为五组，组间用 1 像素竖线隔开：

1. **工具**：选择（`V`）、抓手（`H`）、缩放（`Z`）｜旋转（`W`）、锚点（`Y`）｜矩形（`Q`）、椭圆（再按 `Q` 在矩形和椭圆之间切换）、钢笔（`G`）、文字（`T`）。当前工具高亮。
2. **绘制目标**：分段按钮“形状 | 蒙版”。选“蒙版”且选中了形状、文字或预合成图层时，矩形、椭圆、钢笔工具在这个图层上画蒙版；否则画新的形状图层。
3. **新形状的样式**：填充色块、描边色块、描边宽度输入框。色块显示当前颜色，填充为“无”时显示为带一道红色斜线的空格。点击色块弹出取色器：饱和度—明度方块、色相条、十六进制输入框、最近使用的 8 种颜色，填充取色器多一个“无”。选中图层时，这一组改为显示并修改所选图层的填充和描边。
4. **右侧命令**：撤销、重做、预合成三个图标按钮，以及主按钮“导出”。
5. **最右端**：操作说明按钮（问号图标）。

工具栏上每个按钮悬停 0.5 秒后出现提示，写明名称和快捷键（例如“钢笔工具　G”）；不可用时按钮变暗，提示写明原因。

#### 2.3.5 项目面板

面板顶部有三个页签：**项目**、**历史**、**性能**。

**项目页**列出工程里的全部合成：

- 顶部一行：“新建合成”按钮和按名称筛选的搜索框。
- 下面是当前选中合成的预览：160×90 的缩略图（显示它当前时刻的画面），旁边写尺寸、帧率、时长。
- 列表每行一个合成：合成图标、名称、“1920×1080 · 60 帧/秒 · 0:00:05:00”，以及被引用的次数（例如“×8”，没有被引用时不显示）。当前在合成面板中打开的合成高亮。
- 双击一行，在合成面板中打开这个合成。把一行拖到时间轴或画布上，在当前合成中新建引用它的预合成图层；会形成循环引用时，拖到的地方显示红色禁止标志，松开没有效果，并提示“不能把合成放进它自己里面”。
- 右键菜单：打开、合成设置…、重命名、创建副本、删除。创建副本得到一个独立的新合成。删除被引用的合成时先确认：“『图形群』被 3 处引用，删除后这些预合成图层也会删除。”

**历史页**按顺序列出撤销步骤，每步一行，写明操作名和规模，例如“缓入缓出（589,824 个关键帧）”。当前所在的步骤高亮，已撤销的步骤显示为弱提示色。点击某一步，工程直接回到这一步之后的状态。

**性能页**见 2.3.12。

#### 2.3.6 合成面板

从上到下：

1. **合成标签页**（高 30 像素）。每个打开的合成一个标签：合成图标、名称、关闭按钮。当前标签顶部有一条 2 像素的熔岩橙线。关闭标签不删除合成。最右端的“+”新建合成。
2. **层级路径**（高 26 像素）。左端是“返回上一层”按钮（在最外层时不可用），后面是从外到内的合成名称，用“›”连接，例如“一点成字 › 图形群”。最后一级加粗并带熔岩橙下划线；点击前面任一级回到那一层。进入预合成内部时，这一行带一层淡淡的冰蓝底色，画布上合成的边框也从灰色变为冰蓝，一眼看出“现在在里面”。层级太深放不下时，中间的层级收进一个“…”按钮，点击展开列表。
3. **画布**，占据其余空间：
   - 合成画框之外是纸板区（`#0C0E13`）。画框画出合成的背景色，四周有 1 像素灰色边框和一圈柔和的投影。图层伸出画框的部分在纸板区里以 25% 不透明度显示，画框内外一眼可分。
   - 标尺（开启时）贴在画布的上边和左边，宽 20 像素，以合成左上角为原点、以合成像素为单位标注，光标所在的位置在标尺上有一条短的指示线。
   - 参考线是贯穿画布的 1 像素青绿线。从标尺上往画布里拖出一条参考线，拖动可以移动，拖回标尺即删除；悬停时显示它的坐标。
   - 安全框（开启时）画出合成的动作安全框（90%）、字幕安全框（80%）和中心十字。
   - 合成里还没有图层时，画框中央浮着一行提示：“用工具栏的矩形、椭圆、钢笔或文字工具在这里绘制”。工程里还没有合成时，画布区域显示一个线性插图和三个按钮：“新建合成”“打开工程…”“打开示例”。
4. **画布底栏**（高 30 像素）：缩放比例下拉框（5%–1600% 的常用档位和“适应窗口”）；标尺、参考线、安全框、运动路径四个开关；播放状态胶囊（见 2.3.13）；合成的尺寸和帧率；光标在合成中的坐标。

画布上的操作、选择框和运动路径的样子见 2.9。

#### 2.3.7 时间轴面板

时间轴面板分为**头部**、**左侧的图层与属性列表**、**右侧的时间区域**。列表和时间区域共用一条纵向滚动条，逐行对齐。

**头部**（高 40 像素）：

- 左段与列表同宽：合成的标签色圆点和合成名；当前时间（18 像素熔岩橙等宽数字，例如“0:00:02:30”），下方一行 11 像素灰字“帧 150 / 600 · 60 帧/秒”。时间显示为帧号时，两行对调。点击当前时间可以直接输入（2.7）。
- 中段：播放控制，依次为跳到起点、上一个关键帧、上一帧、播放/暂停、下一帧、下一个关键帧、跳到终点、循环播放；然后是运动模糊总开关、只显示有动画的属性、吸附三个开关；然后是视图切换的分段按钮“时间轴 | 曲线 | 分屏”。
- 右段：按名称筛选图层的搜索框（160 像素）、时间缩放滑块（120 像素）、“显示整个合成”按钮。

**列表的表头与时间标尺同高**（34 像素）。列表各列从左到右：

| 列 | 宽 | 内容 |
|---|---|---|
| 显示 | 24 | 眼睛图标；隐藏时为闭眼 |
| 锁定 | 24 | 锁图标；未锁定时空白，悬停显出淡锁 |
| 运动模糊 | 24 | 三道斜线图标；开启时熔岩橙 |
| 标签色 | 12 | 4×16 像素的色条，点击换色 |
| 编号 | 32 | 图层自上而下的序号 |
| 名称 | 弹性，最小 140 | 展开三角、类型图标（矩形、椭圆、钢笔、文字、空对象、预合成各一个）、图层名 |
| 父级 | 112 | 链形图标和父级名称（“无”为弱提示色），点击弹出下拉列表 |
| 轨道遮罩 | 96 | 遮罩模式图标和名称，点击弹出下拉列表 |

名称、父级、轨道遮罩三列的宽度可以拖动表头分隔线调整。名称太长时末尾显示“…”，悬停显示全名。

**图层行**（26 像素）：列表里是上表各列；时间区域里是**图层条**——高 16 像素、圆角 3 像素，从入点画到出点，填标签色（45% 不透明度）。

- 选中的图层：行底为 14% 的冰蓝，左端有一条 2 像素冰蓝竖线，图层条加深到 80% 并带 1 像素冰蓝描边。
- 锁定的图层：名称为弱提示色，图层条上有斜线纹，关键帧半透明。
- 隐藏的图层：名称为弱提示色，图层条只剩轮廓。
- 预合成图层：被裁掉、但内部合成还有内容的部分，在图层条两侧以浅色斜线纹画出，表示还能拉长。
- 作为轨道遮罩的图层：图层条为虚线轮廓，列表里名称前有遮罩标志，与它下面使用它的图层之间有一道竖括号相连。
- **图层折叠时**，图层条上在每个有关键帧的时刻画一道 2×8 像素的白色短刻痕（选中的关键帧所在时刻为冰蓝），一眼看出它在哪些时刻有动画。

**属性行**（22 像素）：展开图层后，属性按固定的分组和顺序列出（变换、形状、填充、描边、修剪路径、文字、文字动画器、蒙版、时间重映射），每级缩进 14 像素。分组行可以单独折叠，折叠的分组在时间区域里同样显示关键帧刻痕。可以做动画的属性，列表里从左到右是：

- **动画开关**：一个 12 像素的小圆环，里面套一个菱形。未开启动画时为空心灰色；开启后菱形实心熔岩橙。
- **关键帧导航** “‹ ◆ ›”：左右箭头跳到这个属性的上一个/下一个关键帧（没有时变暗）；中间的菱形在当前帧没有关键帧时为空心，点击即在当前帧添加关键帧（属性未开启动画时，同时开启动画）；当前帧正落在关键帧上时为实心熔岩橙，点击删除这个关键帧。
- **属性名**，以及当前时刻的**数值**（可以左右拖动擦洗，点击后输入，见 2.3.9）。

时间区域的属性行里画这个属性的关键帧，标示见 2.3.13。同一属性相邻两个关键帧之间，如果数值在变化，用一条 1 像素、40% 不透明度的白线连起来；数值相同或离开插值为定格时不画线。

**时间标尺**（34 像素）分上下两条：

- 上面 10 像素是**工作区条**：起点和终点之间是一段 30% 不透明度的冰蓝条，两端各有一个 6 像素宽的把手。工作区以外的时间，各行底色略暗。
- 下面 24 像素是**刻度**：主刻度带标签，相邻标签至少相隔 64 像素，间隔从 1 帧、2 帧、5 帧、10 帧、1 秒、2 秒、5 秒、10 秒、30 秒、1 分钟中自动选择；主刻度之间有次刻度。时间码模式下标签写成“秒:帧”（例如“01:30”），超过一分钟写全“0:01:05:00”；帧号模式下写帧号。标尺最左端用弱提示色标出单位“秒:帧”或“帧”。
- **标记**画在刻度条上：一面黄色（`#FFC53D`）小旗，旗旁写标记名，一条 15% 不透明度的虚线向下贯穿各行。
- 合成时长以外的时间区域铺深色斜线纹。
- **播放头**：一条 2 像素熔岩橙竖线，贯穿标尺、各行和曲线编辑器；它在标尺上的头部是一个朝下的五边形（14×18 像素）。

**空状态**：合成里没有图层时，列表区中央写“合成里还没有图层”，下面一行弱提示“在画布上绘制，或从项目面板拖入合成”。

#### 2.3.8 曲线编辑器面板

头部的视图切换选“曲线”时，时间区域换成曲线编辑器；选“分屏”时，时间区域上 40% 仍是关键帧行，下 60% 是曲线编辑器。曲线编辑器与时间轴共用上方的时间标尺、横向缩放和播放头。

- **工具条**（高 28 像素，在曲线区域顶部）：分段按钮“值 | 速度”；显示范围下拉框“所选属性 / 所选图层的全部动画属性”；“适配所选”“适配全部”；“手柄联动/断开”开关；“缓动数值…”；插值快捷按钮“定格、线性、自动、缓入缓出、缓入、缓出”。
- **左侧刻度**：曲线区域左边 48 像素宽的竖向刻度，标数值和单位（像素、%、°、秒；速度视图为“像素/秒”“%/秒”“°/秒”）。值为 0 的刻度线比其他网格线亮。
- **曲线**：1.5 像素粗，每条一种颜色（2.3.2）。曲线左端贴一个小标签，写“图层名 · 属性名”（例如“圆点 · 缩放 X”）。悬停某条曲线时它加粗，列表里对应的属性行同时高亮。定格段画成台阶。
- **列表里的对应**：曲线编辑器显示时，左侧列表里每个显示曲线的属性行前多一个与曲线同色的色块和一个眼睛图标；点眼睛单独隐藏这条曲线。
- **关键帧**：曲线上 7 像素的方点，填曲线色；选中后为冰蓝、带白描边，并露出手柄。手柄是 1 像素的线，端点是 6 像素的圆点；联动的两侧手柄画成一条直线，断开的两侧各自独立。
- **当前时刻**：播放头与每条曲线的交点上有一个小标签，写这条曲线在当前时刻的数值。
- **缓动预览**：悬停缓动预设时，所选关键帧之间的曲线上叠一条白色虚线，显示应用后的样子。
- **空状态**：没有可显示的曲线时，区域中央写“选中有动画的属性后，在这里显示曲线”。

| 多个图层 | 图层和变换的共同项；所选图层类型全部相同时，加上这一类型的分区 |
| 选中了关键帧 | 最上方多一个“关键帧”分区：“已选 3 个关键帧（2 个属性）”。只选中一个时，显示它的时刻和数值（都可以修改）、进入和离开的插值（下拉框）、进入和离开的速度与影响；下面一排按钮：缓入缓出、缓入、缓出、线性、定格 |

**图层分区**：名称、类型、入点、出点、时长（预合成图层另有起始时间）、父级、轨道遮罩、运动模糊开关、标签色。

**属性行**：与时间轴列表的属性行用同一套部件——动画开关、关键帧导航“‹ ◆ ›”、属性名、数值。改动任何一处，另一处同时变化。

**数值的编辑**：

- 在数值上左右拖动即擦洗：每移动 1 像素改变 1 个单位，按住 `Shift` 为 10 倍，按住 `Ctrl` 为 0.1 倍；光标为左右箭头，拖动中数值实时变化。
- 单击数值进入输入。`Enter` 确认，`Esc` 取消，`Tab` 跳到下一个输入框。可以输入算式，例如“160+24”“-10”“100/3”；以“+=”“-=”“*=”“/=”开头表示在原值上运算，例如“+=24”在原值上加 24。
- 缩放有一个链形开关：链合上时等比，改一个方向另一个方向按原比例跟着变；链断开时两个方向分别设置。
- 颜色属性显示色块和十六进制值，点击色块弹出 2.3.4 的取色器。
- **多选与混合值**：选中多个图层时，各图层数值相同的属性正常显示；数值不同的显示为斜体的“—”，底纹为细斜线，悬停提示取值范围（例如“60.0%–100.0%”）。在混合值上输入一个数，所有选中图层都设为这个数；输入“+=24”这类相对算式，各图层在各自的原值上运算；拖动擦洗时各图层同步增减同样的量。一次输入或一次拖动对全部图层算一步撤销。

**输入的合法性**：

- 无法识别的输入（例如在数字框里输入“abc”）：输入框边框变红，下方弹出红色气泡“请输入数字”，数值不生效；按 `Esc` 或点击别处后恢复原值。
- 超出范围的输入：按范围限制，边框闪一次琥珀色，气泡写“已限制为 0–100”。各项范围：不透明度 0–100%；缩放 −10000% 至 10000%；描边宽度 0–1000 像素；羽化 0–1000 像素；合成尺寸 16–8192 像素；帧率 1–120 帧/秒的整数；时长 1 帧至 1 小时；快门角度 0–720°；快门相位 −360° 至 360°；修剪路径的开始和结束 0–100%。
- 不合法的输入在任何情况下都不会改变工程。

**空状态**：既没有选中图层也没有打开合成时，面板中央写“未选择”，下方一行弱提示“在画布或时间轴中选择图层；选中关键帧可以查看插值”。

#### 2.3.14 过渡

- 关键帧出现时从 60% 大小弹到原大，删除时缩小淡出，各 120 毫秒；
- 分区和属性分组展开、折叠时高度变化 150 毫秒；
- 时间轴、曲线、分屏三种视图切换时交叉淡化 150 毫秒；
- 对话框出现时从 98% 放大到原大并淡入 140 毫秒；提示框淡入 80 毫秒。

所有过渡都不超过 180 毫秒，只是视觉上的过渡：操作的结果立即生效，过渡期间可以继续操作，读数和性能计时不等过渡结束。播放、擦洗播放头、拖动中的实时变化没有过渡。

#### 2.3.15 四个视图的联动

画布、时间轴、曲线编辑器和属性面板是同一份工程的四个视图，始终显示播放头所在时刻的同一个状态：

- 在任何一处修改属性或关键帧——在画布上拖动、在属性面板或时间轴里输入或擦洗数值、在时间轴上拖动关键帧、在曲线编辑器里拖动关键帧和手柄、应用缓动、撤销重做——其余各处立即跟着变；拖动的途中就跟着变，不等松开。
- 播放和拖动播放头时，画布的画面、属性面板和时间轴里的数值、曲线编辑器里的当前时刻一起变化。
- 选择也是共享的：在画布上选中图层，时间轴里同一行高亮、属性面板显示它；在时间轴里选中关键帧，曲线编辑器里同一个关键帧也选中。

### 2.4 合成与图层

**合成设置。** “新建合成”和“合成设置”对话框（2.3.11），以及没有选中图层时属性面板里的“合成”分区，都可以设置和修改合成的名称、尺寸、帧率、时长、背景色和快门。修改合成设置算一步撤销。

- 改尺寸：图层的数值不变，相对合成左上角的位置不变。
- 改短时长：超出新时长的图层和关键帧都保留（时间轴上落在斜线纹区域里），工作区超出的部分截到新时长。
- 多个合成：项目面板里新建、打开、重命名、创建副本、删除合成；合成面板顶部的标签页在打开的合成之间切换，时间轴和属性面板随之切换到这个合成。

**时间的显示。** 时间可以按时间码或帧号显示，在“视图 › 时间显示”或右键单击当前时间切换，全工程统一，随工程保存。时间码写作“时:分分:秒秒:帧帧”，例如 60 帧/秒下的“0:00:02:30”；帧号从 0 开始，例如“150”。显示的时间码和帧号永远是这个合成里真实存在的帧，不会出现“第 12.5 帧”或超出帧率的帧数。

**帧率。** 关键帧、图层的入点和出点、工作区和标记都落在时间上，与帧率无关。修改合成帧率后：

- 动画的时长、运动路径和每个关键帧的时刻都不变，画面在同一时刻看起来完全一样；预览、逐帧步进和导出改在新帧率的帧上取画面。
- 播放头移到离原时刻最近的新帧上。
- 原来落在帧上、改了帧率后落在两帧之间的关键帧，在时间轴上画在它真实的时刻；悬停提示写“约 0:00:00:12（不在帧上）”。当前帧与这样的关键帧相差不到半帧时，算作“当前帧在关键帧上”：导航菱形为实心，此时修改属性更新的就是这个关键帧，不会在半帧之外另建一个。`J`/`K` 跳到离它最近的帧。拖动这个关键帧时，它落到新帧率的整帧上。
- 工作区包含的帧，是时刻不早于工作区起点、早于工作区终点的那些帧。

**创建图层。** 新图层放在所选图层的正上方（没有选中时放在最上面），入点为 0，出点为合成时长，创建后被选中。

- **矩形、椭圆**：用矩形或椭圆工具在画布上拖出。按住 `Shift` 为正方形或正圆，按住 `Alt` 从中心向外拖。拖动中画出形状和尺寸读数，松开得到图层：锚点在图形中心，填充和描边取工具栏的当前样式（初始为填充熔岩橙、无描边，描边宽度 4 像素）。只点击不拖动，不创建图层。新图层依次命名为“矩形 1”“椭圆 1”……
- **钢笔路径**：用钢笔工具单击放一个尖角点，按住拖动放一个平滑点并拉出两侧手柄；直线段与曲线段可以任意组合。单击起点闭合路径；按 `Enter` 或 `Esc` 结束为开放路径。绘制中下一段以虚线跟随光标。锚点在路径外接框的中心。命名为“路径 1”……
- **文字**：用文字工具在画布上单击，在单击处新建文字图层并进入文字编辑，可以输入中文（输入法组字时显示带下划线的组字）、按 `Enter` 换行。按 `Esc`、`Ctrl+Enter` 或在别处单击结束编辑。文字为空时结束编辑，图层自动删除，不产生撤销步骤。新文字默认 72 像素、中等字重、无衬线、左对齐、颜色 `#E7EAF0`。文字图层的名称跟随内容的前 16 个字，直到被重命名。锚点在插入点，即第一行基线上的对齐点。
- **空对象**：“图层 › 新建 › 空对象”，放在合成中心，在编辑器中显示为一个 100×100 的冰蓝虚线方框（未选中时 40% 不透明度）。这个方框只是编辑辅助，不出现在导出里，也不出现在外层合成通过预合成图层看到的画面里。命名为“空对象 1”……
- **预合成图层**：把项目面板里的合成拖进时间轴或画布；拖进时间轴时起始时间为松手处的时刻，拖进画布时为 0。名称取所引用合成的名称。
- **转换为钢笔路径**：矩形和椭圆可以转换成外观相同的钢笔路径（矩形四个尖角点，椭圆四个平滑点），之后可以编辑路径和做形状变形。尺寸和圆角上的动画在转换时按当前时刻的样子定下来。

**管理图层。**

- **重命名**：双击图层名或按 `Enter`，就地编辑，`Enter` 确认，`Esc` 取消；名字为空时恢复原名。最长 64 个字。
- **显示和隐藏**：点眼睛图标。隐藏的图层不出现在画布和导出里，在画布上点不中，在时间轴里照常可以选中和编辑。
- **锁定**：点锁图标。锁定的图层照常显示，在画布上点不中；在时间轴里可以点选查看属性，但它的属性、关键帧、图层条都不能修改，不能被删除，`Ctrl+A` 不选中它。
- **调整上下顺序**：在列表里上下拖动图层行，两行之间出现一条 2 像素冰蓝插入线；或用“排列”菜单和 `Ctrl+]`、`Ctrl+[`、`Ctrl+Shift+]`、`Ctrl+Shift+[`。轨道遮罩和使用它的图层总是成对移动（2.11）。
- **复制**：`Ctrl+D` 把每个选中的图层复制一份，放在原图层正上方，连同全部属性、关键帧、蒙版、修剪路径、文字动画器和父级设置；复制完成后**只选中新复制出的图层**。新图层的名称把末尾的数字加 1（“矩形 1”的副本叫“矩形 2”，已被占用就继续往后找）；名称末尾没有数字时加“ 2”。父级和子级一起被复制时，副本子级的父级是副本父级；只复制子级时，副本的父级仍是原父级。
- **复制粘贴**：没有选中关键帧时，`Ctrl+C` 复制选中的图层，`Ctrl+X` 剪切；`Ctrl+V` 把它们粘贴到当前合成（可以是另一个合成）所选图层的上方，入点出点和关键帧的时刻保持原样，粘贴后选中粘贴出的图层。父级没有一起粘贴、且目标合成里没有这个父级时，粘贴出的图层解除父级，当前时刻的画面保持不变。
- **删除**：`Delete` 删除选中的图层。被删除图层的子图层解除父级，当前时刻的画面保持不变。
- **标签色**：点标签色条或用右键菜单换色，决定它在时间轴上的图层条颜色。

**图层的时间。** 每个图层在时间轴上是一段从入点到出点的图层条，只在入点（含）到出点（不含）之间出现在画面里。

- 拖动图层条中段，整段平移，图层的关键帧随之平移；预合成图层的起始时间也随之平移。
- 拖动图层条的左端或右端，分别裁剪入点或出点，关键帧不动。入点不能晚于出点，两者至少相隔一帧。
- 形状、文字和空对象图层的入点出点可以放在任何时刻，包括合成时长之外。预合成图层没有开启时间重映射时，只能在内部合成的时长以内裁剪（伸到外面会停住）；开启时间重映射后不受限制。
- 键盘：`[`、`]` 把入点、出点移到当前时刻（整段平移）；`Alt+[`、`Alt+]` 在当前时刻裁剪入点、出点；`Alt+PageUp`、`Alt+PageDown` 把选中的图层整体提前、推后 1 帧，加 `Shift` 为 10 帧；`I`、`Shift+I` 把播放头跳到所选图层的入点、出点。
- 选中多个图层时，以上操作对全部选中图层同时进行，拖动其中任意一个的图层条，其他的跟着平移同样的帧数，算一步撤销。
- 关键帧可以位于入点出点之外，在时间轴上照常显示和编辑，只是那段时间图层不出现在画面里。

### 2.5 变换、锚点与父级

**变换。** 每个图层（包括空对象和预合成图层）都有五项变换属性：

| 属性 | 单位 | 新图层的默认值 |
|---|---|---|
| 锚点 | 像素，图层自己的坐标 | 图形中心（文字为插入点，预合成为内部合成的中心） |
| 位置 | 像素，父级的坐标（没有父级时为合成坐标） | 锚点在画面上所在的位置 |
| 缩放 | %，水平和垂直两个值，可以等比，也可以分别设置 | 100%, 100% |
| 旋转 | 度，可以超过 360° | 0° |
| 不透明度 | % | 100% |

缩放和旋转都以锚点为中心。五项都可以在画布上拖动修改，也可以在属性面板或时间轴里擦洗、输入。

**在画布上编辑。** 用选择工具：

| 手势 | 结果 |
|---|---|
| 拖动选中图层的内容或选择框内部 | 平移全部选中的图层；按住 `Shift` 锁定水平或垂直方向 |
| 拖动角手柄 | 以锚点为中心缩放；按住 `Shift` 保持原来的宽高比 |
| 拖动边手柄 | 只沿这条边的法线方向缩放 |
| 在角手柄外侧 8–24 像素处拖动 | 以锚点为中心旋转；按住 `Shift` 以 15° 为步进 |
| 拖动锚点 | 移动锚点，画面不动（见下文“锚点”） |
| 方向键 / `Shift`+方向键 | 平移 1 / 10 像素，每按一次算一步撤销 |
| 旋转工具（`W`）拖动画布任意处 | 旋转选中的图层 |

拖动时图层跟着鼠标走：被抓住的点（平移时是按下处，缩放时是手柄，旋转时是光标方向）始终留在光标下面；只能沿一个方向变化的边手柄，落在光标在这个方向上的投影处。拖动中看到的就是松开后的结果，松开后播放到这一时刻，画面与松开时相同。

在**任何时刻**编辑都是如此；图层上面有几层父级、父级旋转过、非等比缩放过、自身带着动画，或者图层位于嵌套合成之中（进入预合成后在它的画布上编辑），也都是如此。修改写进变换属性：属性已开启动画时写进当前时刻的关键帧（2.6），没有开启时改固定值。

选中多个图层时：每个图层都显示自己的选择框和锚点，手柄只画在主选图层（最后点选的那个）上。平移时所有选中图层在画面上移动同样的距离；拖动主选图层的手柄缩放或旋转时，每个选中图层各自绕自己的锚点，在画面上缩放同样的比例、旋转同样的角度。选中的图层超过 200 个时，画布上不再逐个画选择框，只画一个包住它们的总外框，框的左上角标“已选 4,096 个图层”，仍然可以拖动整体平移。

**锚点。** 锚点在画布上显示为一个 12 像素、带十字的圆圈。用选择工具直接拖动锚点，或用锚点工具（`Y`）拖动，可以单独移动锚点：锚点相对图层内容移动，同时位置做相应的补偿，**当前时刻的画面一点不动**。锚点或位置已开启动画时，改动写进当前时刻的关键帧，其他时刻按各自的数值计算。之后的旋转和缩放绕新的锚点进行。

**父级。** 图层可以指定同一合成中的另一个图层为父级。设定方式：

- 在时间轴的“父级”列点击，从下拉列表里选；
- 按住“父级”列的链形图标，拖到另一行上松开，拖动中有一条冰蓝的线从图标连到光标；
- 属性面板“图层”分区的父级下拉框；
- 选中多个图层后设定，它们同时以这个图层为父级。

子图层跟随父级的位置、旋转、缩放（包括父级自身的动画和它上面各级父级），不跟随不透明度。父级可以多层嵌套，深度不限。

设定、更换或解除父级时，**子图层当前时刻的画面不变**：子图层的位置、旋转、缩放按父级在当前时刻的变换换算成相对新父级的数值；这些属性有关键帧时，全部关键帧按同一换算一起换算，父级静止时整段动画看起来都不变。父级的非等比缩放会让旋转过的子图层产生斜切，图层没有斜切属性，这时位置和旋转照样保持，缩放取最接近的值，并弹出提示条“父级的非等比缩放造成的斜切无法保留”。

**不能形成循环**：图层的子级、子级的子级都不能被选为它的父级。下拉列表里这些图层显示为不可用，悬停提示“会形成循环”；把链形图标拖到这些行上时，行变成红色，松开没有效果。

### 2.6 关键帧与插值

**开启动画。** 每个可以做动画的属性都有动画开关（2.3.7）。开关关着时，属性只有一个固定值，修改的就是这个值。打开开关时，在当前时刻以当前数值建立第一个关键帧。开关打开后，属性随时间变化：**在哪个时刻修改它，就在那个时刻新建一个关键帧；那里已有关键帧，就更新它。** 别的关键帧原样不动，整段动画不会平移。在画布上拖动、在属性面板或时间轴里输入或擦洗、在曲线编辑器里上下拖动关键帧、在画布上拖动运动路径上的点、用方向键平移，任何方式的修改都是这样。同一属性在同一时刻最多只有一个关键帧。

关掉开关时，这个属性的全部关键帧被删除，属性停在当前时刻的数值上，成为固定值。

快速添加：点属性行里的空心菱形；或按 `Alt+Shift+P`（位置）、`Alt+Shift+S`（缩放）、`Alt+Shift+R`（旋转）、`Alt+Shift+O`（不透明度）、`Alt+Shift+A`（锚点），为选中的图层在当前时刻添加关键帧（属性未开启动画时同时开启）。

**时间插值。** 两个关键帧之间的数值怎样过渡，由时间插值决定。每个关键帧的**进入**一侧和**离开**一侧可以分别设为：

- **线性**：匀速变化；
- **贝塞尔**：按手柄决定的速度变化，可以缓入、缓出、预备、过冲；
- **定格**：数值保持不变，到下一个关键帧时一下跳过去。

贝塞尔分**自动**和**手动**两种：自动贝塞尔让曲线在关键帧处平滑通过、不越过相邻关键帧的数值，相邻的关键帧移动或改值时自动重新调整；手动拖过手柄、应用过缓动的关键帧成为手动贝塞尔，此后不再自动调整。手动贝塞尔的两侧手柄可以**联动**（一侧改变时另一侧保持在同一条直线上，速度连续）或**断开**（两侧各自独立）。新建的关键帧默认两侧都是线性。

改插值的方式：

- **一键缓动**：`F9` 缓入缓出（所选关键帧两侧的速度都变为 0，影响都为 33.3%）；`Shift+F9` 只改进入一侧；`Ctrl+Shift+F9` 只改离开一侧。
- `Alt`+单击关键帧：在线性和自动贝塞尔之间切换；`Ctrl+Alt+H`：在定格与原来的插值之间切换。
- 关键帧菜单和右键菜单的“线性”“自动贝塞尔”；“关键帧插值…”对话框分别设置进入、离开和手柄（2.3.11）。
- **缓动预设**和**缓动数值**：预设和贝塞尔数值都是一段缓动的四个数（x1, y1, x2, y2）。应用时，对每一段**首尾两个关键帧都被选中**的区间，把前一个关键帧的离开侧设为（x1, y1），后一个关键帧的进入侧设为（x2, y2）；一个被选中的关键帧，若它某一侧的相邻关键帧没有被选中，只改它自己这一侧（离开侧用 x1, y1，进入侧用 x2, y2）。“速度与影响”页直接设定所选关键帧进入、离开两侧的速度和影响。

**位置的路径与速度。** 位置的运动由两样东西共同决定：**运动路径**决定图层经过画面上的哪些地方，**时间插值**决定它在什么时刻走到路径上的哪里。

- 路径在每个位置关键帧处可以是**尖角**，也可以是**平滑**的曲线，这叫空间插值；平滑处的曲线形状由空间手柄决定，空间手柄同样分自动、联动和断开。新建的位置关键帧默认为平滑·自动。空间插值在画布上编辑（2.9），也可以在“关键帧插值…”对话框里设置。
- 两样东西分开编辑，**互不牵动**：改时间插值、拖速度曲线、在时间轴上移动关键帧的时刻，路径的形状不变；在画布上拖动路径上的关键帧或空间手柄，图层到达每个关键帧的时刻不变。
- 时间插值为线性时，图层沿路径**匀速**前进，路径弯曲时也一样；缓入缓出时，图层沿同一条路径先慢后快再慢。

**选择关键帧。** 在时间轴和曲线编辑器里：

- 单击关键帧单选；`Shift`+单击加选或减选；
- 在空白处拖出选框，框住的关键帧被选中（`Shift` 加选）；
- 单击属性名，选中这个属性的全部关键帧；
- `Ctrl+Alt+A` 选中所选图层全部属性的全部关键帧（包括没有展开的属性）；
- 拖动或单击折叠图层上的关键帧刻痕，选中并移动这个图层在这一时刻的全部关键帧；
- 单击空白处或按 `Esc` 取消选择。

**编辑关键帧。**

- **拖动**：选中的关键帧一起移动，在时间轴上按整帧移动；读数显示目标时刻和移动的帧数；可以吸附（2.7）。拖到同一属性另一个未选中关键帧所在的帧上时，那个关键帧描出红边，松开后被替换掉——同一属性在同一时刻始终最多只有一个关键帧。
- **按比例拉伸**：选中一组关键帧后，按住 `Alt` 拖动组里最早或最晚的那个关键帧，整组以另一端为基准按比例拉伸或压缩时间，读数显示倍数；或用“按比例缩放时间…”输入百分比。拉伸后每个关键帧落在最近的整帧上，各段缓动的形状随时间按比例保持（影响的百分比不变，速度按比例变化）。压缩到同一属性的两个关键帧将落在同一帧时，拉伸停在那里，不再继续压缩。
- **复制粘贴**：选中关键帧时，`Ctrl+C` 复制关键帧；`Ctrl+V` 粘贴到当前时刻——最早的那个关键帧落在播放头上，其余保持相对间隔，插值和手柄原样保留。粘贴的目标是当前选中的图层：关键帧放进同名属性（例如从“矩形 1 · 位置”复制，粘贴到“椭圆 3”就进入“椭圆 3 · 位置”），没有开启动画的属性自动开启；目标图层没有这个属性时跳过，并提示“3 个关键帧没有可粘贴的属性”。只复制了一个属性的关键帧、而目标图层选中了另一个同类属性（例如另一个数值属性）时，粘贴进选中的那个属性。粘贴落在已有关键帧的帧上时替换它。
- **删除**：`Delete` 删除选中的关键帧。一个属性的关键帧全部删掉后，它仍然开着动画开关，数值停在删除前当前时刻的数值上。

`Delete`、`Ctrl+C`、`Ctrl+V` 作用的对象依次是：正在编辑的路径点 > 选中的关键帧 > 选中的蒙版或文字动画器 > 选中的图层。

### 2.7 时间轴

**图层与属性。** 时间轴的列表和时间区域逐行对齐（2.3.7）。

- 单击图层行的展开三角，展开它的属性分组；`Ctrl`+单击三角，连同所有分组一起展开或折叠。
- 选中图层后按 `P`、`S`、`R`、`A`、`O`、`M`，只展开位置、缩放、旋转、锚点、不透明度、蒙版；按 `U` 只显示有动画的属性，再按一次 `U` 全部折叠。没有选中图层时，这些键作用于全部图层。头部的“只显示有动画的属性”开关与 `U` 相同，开着时新开启动画的属性立即出现。
- 图层折叠时，图层条上的刻痕显示它的关键帧所在的时刻（2.3.7）。
- 头部的搜索框按名称筛选图层，只显示名称包含输入内容的图层，清空后恢复。

**播放头。**

- 单击时间标尺，播放头跳到那一帧；在标尺上或按住播放头拖动，播放头随光标擦洗，画面和各处数值随之变化。
- `PageDown` / `PageUp` 后一帧 / 前一帧，加 `Shift` 为 10 帧；`Home` / `End` 跳到合成的第一帧 / 最后一帧，`Shift+Home` / `Shift+End` 跳到工作区起点 / 终点前的最后一帧。到头时停住。
- `J` / `K` 跳到上一个 / 下一个关键帧：在所选图层的全部关键帧中找（没有选中图层时在全部图层中找），跳到离这个关键帧最近的帧。
- 单击头部的当前时间，变成输入框，可以直接输入：时间码模式下输入“0:00:02:30”，也可以省略前面的部分，例如“2:30”是 2 秒 30 帧，“230”按右对齐解释为 2 秒 30 帧；输入“2.5秒”按秒数；帧号模式下输入帧号；输入“+10”“-10”相对当前帧前后移动。超出合成范围时停在首帧或末帧；无法识别时输入框变红并提示，播放头不动。
- 播放头总是停在帧上。

**缩放与平移。**

- 在时间区域按住 `Alt` 滚动滚轮，以**光标所在的时刻**为中心缩放：缩放前后，光标下面的时刻不变。
- `=` / `-` 和头部的缩放滑块，以播放头为中心缩放（播放头不在视野内时以视野中心为中心）。
- `;` 或“显示整个合成”按钮：缩放到整个合成恰好占满时间区域的宽度。
- 最大放大到一帧占 200 像素，最小缩小到整个合成只占时间区域宽度的 1/4。
- 滚动滚轮上下滚动图层，`Shift`+滚轮左右平移时间；按住鼠标中键拖动也可以平移。

**吸附。** 头部的吸附开关打开时，拖动播放头、关键帧、图层条（中段和两端）、工作区两端和标记，会吸附到以下目标：播放头、其他关键帧（时间区域里显示出来的关键帧，包括刻痕）、各图层的入点和出点、标记、工作区起点和终点、合成的起点和终点。离目标不到 8 屏幕像素时吸上去；吸附时，一条 1 像素的青绿竖线贯穿时间区域，标尺上出现一个青绿小标签，写明吸到了什么，例如“吸附：标记『爆发』”“吸附：『圆点』出点”。拖动中按住 `Ctrl` 暂时关闭吸附，松开 `Ctrl` 恢复。吸附与时间轴的缩放比例无关：任何缩放下吸上去的都是目标所在的那一帧。

**工作区与标记。**

- 工作区：拖动工作区条两端的把手调整起点和终点，拖动中段整体平移；`B` / `N` 把起点 / 终点设到播放头；双击工作区条设为整个合成。起点终点之间至少一帧。工作区决定循环播放和导出的范围。
- 标记：`*`（小键盘或 `Shift+8`）或右键单击标尺“添加标记”，在播放头处添加一个标记，依次命名为“标记 1”……；拖动标记移动它；双击标记就地改名；右键菜单删除。
- 工作区和标记的修改都算撤销步骤，随工程保存。

### 2.8 曲线编辑器

**显示什么。** 曲线编辑器显示所选属性的曲线：在时间轴或曲线编辑器里选中属性或它的关键帧，这个属性就是“所选属性”；没有所选属性时，显示所选图层全部有动画的属性。工具条的“显示”下拉框可以固定为“所选图层的全部动画属性”。同时显示的曲线超过 50 条时，只画前 50 条（按时间轴中的顺序），曲线区域右上角写“另有 N 条曲线未显示”。

**两种视图：**

- **值曲线**：横轴时间，纵轴属性数值。位置、缩放这类有两个分量的属性画成两条曲线（X、Y 或水平、垂直），各用自己的颜色。缩放的两条曲线共用同一套缓动，拖动其中一条的手柄，另一条按比例一起变化。
- **速度曲线**：纵轴是数值变化的快慢。一维属性（旋转、不透明度、时间重映射等）的速度有正负；位置的速度是沿运动路径前进的速率（像素/秒），恒为非负；缩放的速度按两个分量合起来计算。时间重映射的速度同时用百分比标注（100% 为正常速度，负数为倒放）。
- 路径类属性（形状路径、蒙版路径）和颜色属性没有单一的数值，在两种视图里都画成一条从 0% 到 100% 的“进度”曲线，同样可以调缓动。

**编辑：**

- 单击、`Shift`+单击、框选关键帧，与时间轴相同，选择在两处同步。
- 拖动关键帧：左右改变时刻（按整帧），上下改变数值；按住 `Shift` 只沿开始拖动的那个方向移动。在值曲线里上下拖动位置的关键帧，就是改变这个关键帧在画面上的位置，运动路径随之改变。
- 拖动手柄：值曲线里，手柄的方向决定速度、长度决定影响；速度曲线里，上下拖动改速度、左右拖动改影响（0.1%–100%）。拖动线性一侧的关键帧手柄，这一侧变为手动贝塞尔。
- 手柄**联动**时，拖动一侧，另一侧跟着保持在同一条直线上；按住 `Alt` 拖动手柄即**断开**，两侧各自独立；工具条的“手柄联动/断开”开关或右键菜单可以重新联动。
- 值曲线里可以把手柄拖到相邻关键帧的数值之外，做出**过冲**（例如缩放从 0% 冲到 120% 再回落到 100%）；过冲在播放、拖动播放头和导出中都按曲线正确呈现。
- 双击关键帧打开“缓动数值”对话框；工具条和缓动预设面板的按钮作用于所选关键帧（规则见 2.6）。

**视图：**

- 按住 `Alt` 滚动滚轮横向缩放（与时间轴共用横向缩放），按住 `Ctrl` 滚动滚轮纵向缩放，按住中键或空格拖动平移。
- `F` 或“适配所选”：纵横都缩放到恰好包住所选关键帧（没有选中关键帧时包住所选曲线）；`Shift+F` 或“适配全部”：包住全部显示的曲线。适配时把过冲的峰谷和手柄端点都算在内，四周留 10% 余量，过冲完整可见。

### 2.9 画布与运动路径

**画布。** 画布显示播放头所在时刻的合成画面，画质始终完整（2.15）。

- 缩放：`.` / `,` 放大 / 缩小，`/` 100%，`Shift+/` 适应窗口；按住 `Ctrl` 滚动滚轮以光标为中心缩放；缩放工具单击放大、`Alt`+单击缩小。范围 5%–1600%。
- 平移：抓手工具拖动，按住空格拖动，按住中键拖动。
- 标尺、参考线、安全框用画布底栏的开关或快捷键显示和隐藏（2.3.6）。

**选择。**

- 单击图层看得见的部分，选中盖在最上面的那个图层；空白、被蒙版遮掉、完全透明的地方点不中这个图层，会选中下面的图层。描边只有几像素宽时，点在它两侧 3 像素以内也算点中。预合成图层按它在画面上看得见的内容点选。
- `Shift`+单击加选或减选；`Alt`+单击在光标下重叠的图层中依次选中下面一层。
- 在空白处拖出选框，外框与选框相交的图层被选中。
- 双击文字图层进入文字编辑，双击钢笔路径图层进入路径编辑（2.10），双击预合成图层进入预合成（2.12）。
- 点中和拖动的准确程度与画布的缩放比例无关。

**选择框、手柄与锚点。** 选中的图层显示：

- 选择框：图层内容的外框（形状含描边，文字为字形范围，预合成为内部合成的画框，空对象为它的方框），经过图层自身和各级父级的变换画在画面上——旋转时跟着转，父级非等比缩放造成斜切时是平行四边形；
- 8 个缩放手柄（四角和四边中点，8×8 像素白色方块、冰蓝边框）；
- 锚点（2.5）。
它们与当前时刻的画面严丝合缝，播放和擦洗时跟着图层一起动。画法见 2.3.2，在任何缩放比例下、在深浅不同的画面上都清楚。

**运动路径。** 位置有动画的图层被选中时，画布上显示它的运动路径（同时选中多个时，最多显示 20 个图层的路径）：

- 路径由**逐帧的点**组成：图层在入点到出点之间每一帧所在的位置画一个 3 像素的白点，相邻的点之间连一条 30% 不透明度的细线。点的疏密反映运动的快慢：慢处点密，快处点疏，匀速处等距。
- 每个位置关键帧画一个 8 像素的空心方块，比逐帧点明显得多；选中的关键帧为实心冰蓝。
- 平滑的关键帧露出空间手柄：从方块伸出的 1 像素线，端点是 6 像素的圆点。
- 当前帧所在的点外面套一个 8 像素的熔岩橙圆环。
- 图层有父级时，路径画在父级的坐标里，随父级在当前时刻的位置、旋转、缩放一起显示；父级在动时，路径跟着父级移动。

在运动路径上编辑：

- 拖动路径上的关键帧方块：改变这个关键帧的位置数值，路径随之变形，这个关键帧的时刻不变；
- 拖动空间手柄：改变路径在这里的弯曲，关键帧的时刻不变；联动的两侧手柄同时转动，按住 `Alt` 拖动断开；
- `Alt`+单击关键帧方块：在尖角和平滑之间切换；按住 `Ctrl` 从尖角的关键帧上拖出，拉出一对新的空间手柄；
- 拖动中逐帧点实时重新分布，时间轴、曲线编辑器（速度曲线随路径长度变化）和属性面板同步更新。

### 2.10 形状变形与修剪路径

**路径编辑。** 双击钢笔路径图层、点属性面板的“编辑路径”，或用钢笔工具点选中的钢笔路径图层，进入路径编辑：路径画成 1 像素冰蓝线，每个点是 7 像素方块（未选中白色、选中冰蓝），**起点**外面多一个圆环，选中点的贝塞尔手柄露出来。

| 手势 | 结果 |
|---|---|
| 单击点 / `Shift`+单击 / 在空白处框选 | 选中点 / 加选减选 / 框选点 |
| 拖动选中的点 | 一起移动 |
| 拖动手柄 | 改曲线；平滑点的两侧手柄联动，按住 `Alt` 拖动断开 |
| `Alt`+单击点 | 在尖角和平滑之间切换 |
| 双击路径段，或钢笔工具单击路径段 | 在这里加一个点，形状不变 |
| 钢笔工具单击已有的点，或选中点后按 `Delete` | 删除点（开放路径至少留 2 个点，闭合路径至少 3 个） |
| 右键单击点 › 设为起点 | 这个点成为路径的起点 |
| `Esc` 或单击路径外 | 退出路径编辑 |

一次拖动、一次加点或删点算一步撤销。

**形状变形。** 钢笔路径的“路径”属性可以开启动画。开启后，在某一时刻编辑路径（移动点、拖手柄、加点、删点、改起点），就在这一时刻新建或更新一个路径关键帧，**只影响这一时刻的路径关键帧**，别的路径关键帧的形状和点数都不变。

- 两个路径关键帧之间，形状平滑地从一个变成另一个：前一个关键帧的起点对应后一个的起点，其余的点沿路径顺序依次对应。
- 两个关键帧的点数不同时也平滑过渡：例如 3 个点的三角形变成 4 个平滑点的圆形，过渡中的每一帧都是一条完整、连续的路径，不突跳，不出现乱线，编辑器不出错。
- 改变起点会改变对应关系，变形的旋向随之改变，用它可以控制变形时图形“转”的方向。
- 一个关键帧闭合、另一个开放时，过渡期间按前一个关键帧的开闭显示，到达后一个关键帧时切换。
- 路径关键帧和其他关键帧一样，有时间插值和缓动，在曲线编辑器里画成进度曲线（2.8）。
- 矩形的尺寸和圆角、椭圆的尺寸也可以做动画；要在矩形、椭圆和任意形状之间变形，先“转换为钢笔路径”。

**修剪路径。** 形状图层可以添加修剪路径（属性面板“+ 添加修剪路径”或图层菜单），它有三个可以做动画的值：

| 值 | 范围与默认 | 作用 |
|---|---|---|
| 开始 | 0–100%，默认 0% | 保留部分在路径上的起始位置 |
| 结束 | 0–100%，默认 100% | 保留部分在路径上的结束位置 |
| 偏移 | 度，默认 0°，360° 为绕路径一整圈 | 让保留的部分沿路径整体移动 |

- 只画出路径上“开始”到“结束”之间的那一段，百分比按路径的长度计算；开始大于结束时等同于两者对调。
- 偏移让保留的那段沿路径移动，越过路径终点的部分从起点接上（开放路径因此可能分成首尾两段）。
- 描边沿路径正确地生长或消退，两端用描边的端点样式（平、圆、方）；填充只填保留的那段路径首尾相连围成的区域。
- 路径的方向：钢笔路径从起点开始、按绘制的顺序；矩形和椭圆从最上方的中点开始，顺时针。
- 例如“结束”从 0% 动到 100%，线条从起点长到终点；随后“开始”从 0% 动到 100%，线条从起点一侧收回消失。

### 2.11 蒙版与轨道遮罩

**蒙版。** 形状、文字和预合成图层可以添加一个或多个蒙版（空对象不能）。

- 添加：工具栏的绘制目标选“蒙版”，选中图层后用矩形、椭圆工具拖出，或用钢笔工具画出自由路径；或者“图层 › 添加蒙版 › 矩形 / 椭圆”，加一个正好框住图层内容的蒙版。
- 时间轴里图层下多一个“蒙版”分组，每个蒙版一行：名称（“蒙版 1”……可以改名）、边线颜色、模式、反转，展开后有三个可以做动画的属性——**蒙版路径**、**羽化**（像素）、**不透明度**（%）。属性面板的“蒙版”分区与之相同，还可以上下拖动调整蒙版的顺序。
- 多个蒙版自上而下组合：第一个蒙版决定图层哪里显示；之后每个蒙版按自己的**模式**——相加（并上它的区域）、相减（去掉它的区域）、交集（只留重叠的区域）——与前面的结果组合。第一个蒙版就是相减时，从整个图层可见开始减。**反转**把这个蒙版自己的区域内外对调后再参与组合；**不透明度**决定它参与的程度。
- **羽化**让蒙版边缘从完全显示柔和地过渡到完全隐藏，过渡带的宽度等于羽化值；羽化按图层自己的像素计算，图层放大时过渡带随之变宽。
- 蒙版画在图层自己的坐标里，随图层的变换和各级父级一起移动、旋转、缩放。预合成图层的蒙版在内部合成的坐标里；文字图层的蒙版作用在文字动画器之后的整段文字上。
- 在画布上编辑：选中图层后，它的蒙版以各自的边线颜色画出。单击蒙版的边选中整个蒙版，拖动整体移动；单击点进入点编辑，操作与路径编辑（2.10）相同。蒙版路径开启动画后，在某一时刻编辑只写进这一时刻的关键帧；点数不同的蒙版关键帧之间同样平滑过渡。在时间轴或属性面板里选中一个蒙版，画布上的这个蒙版加粗显示。

**轨道遮罩。** 图层可以把它**正上方**的图层用作轨道遮罩。在时间轴的“轨道遮罩”列、图层菜单或属性面板里，选择：

| 模式 | 图层在哪里显示 |
|---|---|
| Alpha 遮罩 | 遮罩图层不透明的地方，按遮罩的不透明程度显示 |
| Alpha 反转遮罩 | 遮罩图层透明的地方 |
| 亮度遮罩 | 遮罩图层亮的地方：白处完全显示，黑处完全隐藏，遮罩透明处按黑处算 |
| 亮度反转遮罩 | 遮罩图层暗的地方 |

- 被用作遮罩的图层自己不出现在画面里（眼睛列换成遮罩标志），但它的一切都照常生效：自身的变换和动画、父级、蒙版和羽化、不透明度、运动模糊、预合成的内容和时间重映射。在遮罩图层的入点出点之外，遮罩图层不存在，相当于一张全透明、全黑的遮罩：使用 Alpha 遮罩或亮度遮罩的图层完全隐藏，使用两种反转遮罩的图层完全显示。
- 空对象不能做遮罩；已经做了别的图层遮罩的、或自己正在使用遮罩的图层，不能再被下面的图层用作遮罩；最上面的图层没有可用的遮罩。这些情况下选项显示为不可用，提示写明原因。
- 遮罩图层和使用它的图层**始终成对**：
  - 调整上下顺序时两者一起移动，别的图层不能插到它们中间（插入线会跳过）；
  - `Ctrl+D` 或复制粘贴其中任何一个，两个一起复制，新的一对彼此相连；
  - 预合成时两个一起移入（2.12）；
  - 删除遮罩图层后，下面图层的轨道遮罩设为“无”，并提示；删除使用遮罩的图层后，遮罩图层恢复为普通的可见图层；
  - 撤销重做、保存打开之后，关系与之前完全相同。

### 2.12 预合成与时间重映射

**预合成。** 选中图层后按 `Ctrl+Shift+C`（或合成菜单、工具栏按钮），打开预合成对话框。对话框的检查清单：

| 检查项 | 情况与处理 |
|---|---|
| 父子关系 | 选中的图层与没选中的图层之间有父子关系（选中图层的父级没选中，或没选中的图层以选中图层为父级）时显示红叉，列出这些图层，旁边有按钮“把相关图层一并选入”，点击后把相连的父子图层都加入，清单重新检查。 |
| 轨道遮罩 | 选中了成对遮罩中的一个时，自动把另一个一并移入，显示绿勾和“已自动包含 2 个遮罩图层”。 |
| 是否相邻 | 选中的图层中间夹着没选中的图层时显示琥珀色感叹号：“中间的 3 个图层会移到预合成图层下方，画面可能改变”，旁边有按钮“一并包含中间的图层”；不处理也可以确定。 |

确定后：

- 新建一个合成：尺寸、帧率、时长、运动模糊总开关和快门与当前合成相同，工作区为整个合成，出现在项目面板里。
- 选中的图层移入新合成，上下顺序、全部属性、关键帧、父子关系、蒙版和遮罩关系原样不变。
- 原来的位置（选中图层中最上面那个的位置）换成一个引用新合成的预合成图层：名称同新合成，锚点和位置都在合成中心，缩放 100%、旋转 0°、不透明度 100%，起始时间 0，入点出点为整个合成；选中的图层中有开启运动模糊的，它也开启。它被选中。
- 合成的每一帧画面与预合成之前完全相同（存在琥珀色感叹号而直接确定的情况除外）。
- 勾选了“完成后进入新合成”时，直接进入新合成。

**进入和返回。** 双击预合成图层（画布或时间轴）、按 `Ctrl+Shift+↓`，或点属性面板“来源”分区的“进入”，在合成面板中进入它引用的合成，层级路径加上一级。进入时，内部的播放头放在与外层当前时刻相对应的内部时刻上（经过这个预合成图层的起始时间和时间重映射换算，取最近的内部帧）。在内部可以像在任何合成里一样编辑。按 `Ctrl+Shift+↑` 或点层级路径的上一级返回外层，外层的播放头仍在进入前的位置。从项目面板直接打开一个合成时，层级路径只有它自己。

**修改立即传到各处。** 在内部的任何修改，所有引用这个合成的预合成图层（在任何合成里、任何打开的标签页里）立即更新，项目面板的缩略图随之更新。

**多处引用。** 同一个合成可以被同一个或不同合成中的多个预合成图层引用，每个预合成图层有自己的起始时间、入点出点、变换、父级、蒙版、轨道遮罩、运动模糊和时间重映射，互不影响。不能形成循环引用：合成不能直接或间接地包含自己，相关的拖入和预合成会被拒绝并提示。

**时间重映射。** 预合成图层可以开启时间重映射（`Ctrl+Alt+T`、图层菜单、属性面板）。开启时自动加两个线性关键帧：在起始时间处值为 0:00:00:00，在起始时间加内部合成时长处值为内部合成时长，所以画面不变。之后：

- 时间重映射的**值就是这一时刻在内部合成中取样的时间**，以内部合成的时间码显示。
- 它和别的属性一样可以加关键帧、设插值和缓动、在曲线编辑器里调。值上升得比时间快就是加速，慢就是慢动作，下降就是倒放，定格插值或两个相同的值就是定格。速度曲线上同时标出百分比（100% 为原速，负数为倒放）。
- 开启后图层可以拉长到内部合成的时长之外。
- 关闭时间重映射删除它的全部关键帧，图层恢复按起始时间对应内部时间；超出内部合成时长的入点出点收回到范围内。

**嵌套的时间关系。** 外层合成在时刻 T 显示的，是内部合成在下面这个时刻的画面：

- 没有时间重映射时：内部时刻 = T − 预合成图层的起始时间；
- 有时间重映射时：内部时刻 = 时间重映射在 T 时的值。

入点和出点决定预合成图层在外层哪段时间出现。内部时刻小于 0 或超过内部合成最后一帧时，取最近的端点。内部合成按算出的时刻精确取值，不对齐到内部合成自己的帧，所以 25% 速度的慢动作是平滑的，不会一格一格地跳；内部合成的帧率不影响外层的画面。多层嵌套时逐层如此，任意一层带起始时间偏移、裁剪和时间重映射，结果都正确。

### 2.13 文字动画器

**文字。** 文字图层的设置：内容（支持中文和多行）、字体风格（无衬线 / 衬线 / 等宽）、字重（常规 / 中等 / 粗 / 特粗）、字号（像素）、行距（像素，默认为字号的 1.2 倍）、字间距（像素）、对齐（左 / 中 / 右，以插入点为基准）、颜色。字号、行距、字间距、颜色可以做动画。

- 在画布上双击文字进入编辑：文字周围出现一圈虚线框，插入光标为 2 像素冰蓝竖线、每 0.53 秒闪烁一次，选中的文字底色为 35% 冰蓝；可以用鼠标和方向键移动光标、拖选文字，输入法组字时显示带下划线的组字。`Enter` 换行，`Ctrl+A` 全选这段文字，`Ctrl+Z` 只撤销正在输入的文字；`Esc`、`Ctrl+Enter` 或在别处单击结束编辑，整次编辑在工程里算一步撤销。
- 编辑中，文字暂时按不带动画器偏移的样子排版显示，方便看清内容；结束编辑后恢复当前时刻的动画效果。
- 属性面板“文字”分区的“内容”是一个多行输入框，在这里修改效果相同。

**动画器。** 文字图层可以添加一个或多个动画器（属性面板“+ 添加动画器”或图层菜单），在时间轴的“文字”分组下各占一个子分组。每个动画器：

- **属性**：用“+ 属性”从下列四项中添加：**位置**（像素偏移 X, Y）、**旋转**（度）、**缩放**（%，例如 60% 表示完全受影响的字缩到 60%）、**不透明度**（%，例如 0% 表示完全受影响的字完全透明）。
- **范围**：
  - **单位**：按字符（不计空格和换行）、按词（以空格、标点和换行分隔，连在一起的汉字算一个词）或按行划分；
  - **起点**、**终点**（0–100%）和**偏移**（−100% 至 100%，同时加到起点和终点上）：把全部单位从头到尾排成 0–100%，起点到终点之间的单位受影响；
  - **形状**：方形（范围内完全受影响、范围外不受影响）、三角（范围中间完全受影响，向两端减弱到 0）、平滑（同三角，但两端以柔和的钟形过渡）；
  - **柔和度**（0–100%，只用于方形）：在范围的两端各加一段渐变带，使边缘平滑过渡。
  - 范围的边缘只盖住一个单位的一部分时，这个单位按被盖住的比例受影响，所以起点、终点、偏移连续变化时，文字的变化也是连续的，不是一个字一个字地跳。
- 起点、终点、偏移、柔和度和四项属性都可以设置关键帧；单位和形状不能。
- 每个字符（按词、按行时为其中的每个字符）受到的作用 = 属性值 × 它所在单位受影响的程度：位置偏移和旋转按比例施加；缩放和不透明度从 100% 向设定值按比例变化。**每个字符绕自身的中心旋转和缩放**（字符的字身框的中心），不是绕整段文字的中心。
- 多个动画器同时作用时，效果相加：位置和旋转的偏移相加，缩放和不透明度各自偏离 100% 的部分相加，不透明度限制在 0–100% 之间。
- 修改文字内容、增删字、换行或改变对齐之后，单位重新划分，动画仍然正确：起点 50% 仍然是全部单位的一半处，字符仍然绕自己新的中心转动。

**在画布上看到范围。** 在时间轴或属性面板里选中一个动画器时，画布上的文字上出现两条竖线，分别标着“起”“终”，位于范围起点和终点所在的单位边界；拖动它们就是修改起点和终点（已开启动画时写进当前时刻的关键帧）。属性面板的动画器卡片上有一条“范围预览条”：一排小格子，每格代表一个单位，按当前时刻受影响的程度填色。

### 2.14 运动模糊

**开关与快门。**

- 每个图层（空对象除外）有运动模糊开关：时间轴的运动模糊列、属性面板“图层”分区、图层菜单。
- 每个合成有运动模糊总开关（时间轴头部、合成菜单、合成设置），以及快门角度（0–720°，默认 180°）和快门相位（−360° 至 360°，默认 −90°）。
- 图层自己的开关和它所在合成的总开关都开着时，这个图层才有运动模糊。

**模糊是什么样。** 开启后，图层在每一帧画面上呈现的，是快门打开期间它在画面上扫过的痕迹：快门从“这一帧的时刻 + 相位 ÷ 360 帧”打开，持续“快门角度 ÷ 360 帧”。默认的 180° 和 −90° 就是以这一帧为中心、前后各四分之一帧。

- 模糊沿图层在画面上的实际运动方向：平移时沿运动方向拉出拖影，沿弧线运动时拖影是弯的，旋转时绕锚点呈弧形，缩放时从锚点向外放射。
- 模糊的长度随运动速度和快门角度变化：越快越长，快门角度加倍时拖影加倍；静止的图层、静止的那几帧完全清晰。
- 运动不论来自图层自身的变换动画，还是来自旋转、缩放、各级父级带动、形状变形、修剪路径、文字动画器或时间重映射，模糊都按画面上的实际运动产生。
- 模糊平滑连续，看不出一格一格可数的重影。

**嵌套时。** 快门的时刻和长度以正在显示或导出的最外层合成为准。预合成图层自己的开关管它自身变换和父级带来的运动；内部图层的开关和内部合成的总开关管内部的运动。内部的运动按快门期间经过时间重映射换算出的内部时刻呈现：重映射加速时内部的模糊变长，慢动作时变短，定格时消失，倒放时照样沿运动方向模糊。

遮罩图层开启运动模糊时，遮罩的形状同样带模糊，从而影响下面图层的显示范围。

### 2.15 预览与播放

- **播放与暂停**：按空格（轻按，不拖动鼠标）或点播放按钮，从播放头处开始播放；播放头在工作区之外时从工作区起点开始。再按一次暂停，播放头停在当时显示的那一帧上。按住空格同时拖动鼠标是平移视图，不切换播放。
- **循环**：循环开关打开时，播到工作区终点后回到起点继续；关闭时播到工作区最后一帧停住。
- **实时**：播放时合成时间与真实时间同步推进，1 秒的动画用 1 秒播完。来不及画出每一帧时，跳过一些帧，但合成时间不放慢；画布底栏的播放状态胶囊显示实际画出的帧率（2.3.13）。
- **完整画质**：播放和拖动播放头时，画面与停在这一帧时完全相同：不降低分辨率，不关闭蒙版、羽化、轨道遮罩、运动模糊，不简化嵌套的合成。
- **四处同步**：播放中，时间轴的播放头和当前时间、属性面板和时间轴里的数值、曲线编辑器里的当前时刻随画面一起变化。
- **边播边改**：播放过程中可以继续编辑，不需要停止播放，修改从下一帧起反映在画面上。改动已开启动画的属性时，关键帧写在**这次操作开始时**（按下鼠标或按键的那一刻）画面所在的那一帧上，读数框里写明“写入 0:00:01:24”；没有开启动画的属性直接改固定值。在画布上拖动、在属性面板里擦洗、在时间轴上拖动关键帧、在曲线编辑器里拖手柄，都可以在播放中进行。
- 播放中按 `PageUp`、`PageDown`、`J`、`K`、`Home`、`End`，或单击时间标尺，先停止播放，再移动播放头。

### 2.16 撤销重做与工程文件

**撤销重做。** 所有改变工程内容的操作都能撤销（`Ctrl+Z`）和重做（`Ctrl+Shift+Z` 或 `Ctrl+Y`），包括：创建、删除、复制、粘贴、重命名、显隐、锁定、换标签色、调整顺序；变换和所有属性的修改；开关动画、关键帧的增删、移动、拉伸、粘贴；插值、缓动、手柄、空间手柄；图层时间的移动与裁剪；父级；轨道遮罩；预合成与进入后的编辑；时间重映射；蒙版；路径编辑与起点；修剪路径；文字内容与排版；文字动画器的增删和设置；运动模糊开关与快门；合成的新建、删除、复制、设置；工作区、标记、参考线。

- 每次以一个完整的操作为单位：一次拖动（不论拖了多远、中间经过多少帧画面）、一次输入、一次擦洗、一次应用缓动、一次复制、一次预合成，各算一步；对很多图层、很多关键帧同时进行的操作也只算一步。
- 播放头位置、视图的缩放和平移、选择、面板尺寸、展开折叠、打开的标签页、曲线的显示隐藏、时间显示方式不产生撤销步骤。
- 撤销后，选择恢复为这个操作之前的选择；重做后，恢复为这个操作完成时的选择；已经不存在的对象从选择中去掉。播放头不动。
- 撤销和重做后，工程内容与对应时刻完全相同；画布、时间轴、曲线编辑器和属性面板立即一致；所有图层、关键帧、手柄和路径照常可以选中和编辑。
- 至少保留最近 100 步。历史页（2.3.5）可以一次跳到任意一步。
- 拖动途中按 `Ctrl+Z` 不起作用，按 `Esc` 取消这次拖动。
- 撤销和重做的菜单项和工具栏按钮的提示写明将要撤销或重做的操作，例如“撤销：复制图层（4,096 个）”；没有可撤销或重做的步骤时显示为不可用。

**工程文件。**

- **保存**（`Ctrl+S`）：第一次保存时让用户选择位置和文件名，默认文件名是工程名，扩展名 `.zfp`；浏览器不提供选择位置时，下载到浏览器默认的下载位置。之后再保存时写回同一个文件（浏览器不允许时再次下载）。保存后未保存标记消失。**另存为**（`Ctrl+Shift+S`）总是重新选择位置和文件名。
- **打开**（`Ctrl+O`，或把 `.zfp` 文件拖进编辑器窗口）：当前工程有未保存的修改时先确认。文件无法识别或已损坏时，弹出“无法打开：这不是帧坊工程文件，或文件已损坏”，当前工程不受影响。
- **保存的内容**：全部合成（设置、工作区、标记、参考线）；全部图层及其全部属性和关键帧，包括每个关键帧的插值、自动或手动、手柄是否联动、空间手柄、路径的起点；蒙版、轨道遮罩、父级、标签色；文字和动画器；时间重映射；运动模糊开关和快门；时间显示方式；每个合成的播放头位置和打开的标签页。不保存撤销历史、选择、视图缩放和性能记录。
- 打开后，工程的全部内容与保存前一致，画面逐帧相同；之后的编辑得到与保存前同样的结果（例如自动贝塞尔的关键帧仍会自动调整，断开的手柄仍是断开的）。
- **新建工程**：当前工程有未保存的修改时先确认，然后得到一个没有合成的空工程（2.3.6 的空状态）。**打开示例工程**同样先确认，再载入 2.19 的示例。

### 2.17 导出

`Ctrl+M`、工具栏的“导出”按钮或文件菜单打开导出对话框（宽 520 像素）：

| 项 | 内容 |
|---|---|
| 合成 | 下拉框，默认是当前合成 |
| 范围 | 工作区，只读显示“0:00:00:00 – 0:00:10:00 · 600 帧” |
| 尺寸 / 帧率 | 只读，与合成相同 |
| 格式 | 两张可选的卡片：“视频文件”（网页常用的视频格式，另有画质“高 / 极高”）和“PNG 图像序列”（每帧一张无损 PNG 图片，打包成一个压缩文件） |
| 文件名 | 默认是合成名 |
| 按钮 | “取消”“开始导出”（主按钮） |

- **导出的内容**：尺寸与合成相同；帧数等于工作区包含的帧数（工作区时长乘以帧率），从工作区的第一帧开始；背景为合成的背景色；画面与在编辑器中停在同一帧时看到的合成画面相同，蒙版、遮罩、运动模糊、嵌套合成全部按完整画质呈现；不包含选择框、手柄、锚点、运动路径、参考线、安全框、空对象的方框、蒙版边线等编辑辅助元素，隐藏的图层和作为轨道遮罩的图层不出现。
- **逐帧渲染**：每一帧都渲染出来，一帧不少；结果不受导出过程中电脑的负载、窗口大小、视图缩放和页面是否切到后台的影响。
- **进度**：点“开始导出”后，对话框变成进度视图，编辑器其余部分压暗、不能操作：熔岩橙进度条；“正在导出第 312 / 600 帧”；已用时间和预计剩余时间；右侧一张 192×108 的缩略图，显示刚导出的那一帧；“取消导出”按钮。
- **取消**：半秒内停止，不生成文件，提示“已取消导出，没有生成文件”。

### 2.19 默认示例动画

打开编辑器时自动载入一个示例工程，其中的主合成是一段 5 秒的炫技动效：

1. 合成时长 5 秒，工作区为整个合成。动画从第 0 帧开始，到第 5 秒正好收尾：开头没有多余的空白，结尾没有被截断的动作。
2. 示例动画禁止预制，必须用你设计的这个编辑器实现：全部由编辑器中可编辑的图层和关键帧构成，由编辑器自己播放和导出，在时间轴、曲线编辑器和属性面板中都能查看和修改；预览和导出的结果与之一致。不能用预先渲染的视频或图片序列、其他工具做好的动画，也不能用写死的绘制代码代替。
3. 整段讲一个完整的故事：中央的一个圆点蓄力、爆发成一群几何图形，图形在慢动作中变形并归为一体，化作一道光带扫出标题，最后重新收成那个圆点，落在标题末尾。各段由同一批形体的运动和变形接续：前一段的结束状态就是下一段的开始，在同一位置、同一时刻接上，看不出替换；不用淡入淡出或硬切把互不相关的画面拼在一起。节拍如下（时间为大致范围）：

| 时间 | 画面 | 用到的功能 |
|---|---|---|
| 0–0.9 秒 | 圆点从第 0 帧起带过冲地弹出，随即挤压变形、加速收缩蓄力，外圈光晕慢半拍跟随；画面随蓄力缓缓推近 | 缩放关键帧（含不等比缩放）；在曲线编辑器中调出的预备、过冲与跟随 |
| 0.9–1.4 秒 | 圆点收缩到最小时炸开：十几个大小分级的圆形、三角形、方形从圆点处沿同一旋向的弧线高速飞出，边飞边转，出发时刻相互错开；描边拖尾沿弧线长出又收回；冲击环扩散消失；画面猛地拉开并短促震动 | 运动路径、运动模糊、修剪路径、时间错落 |
| 1.4–2.4 秒 | 时间放慢成慢动作：图形悬停在弧线末端，整群缓缓旋转，模糊随速度降低而消失；图形沿一个方向依次在圆形、三角形、方形之间变形，每次变形带轻微弹动 | 预合成与时间重映射、形状变形、父子层级 |
| 2.4–3.2 秒 | 时间重新加速：全部图形变成同一种细长条并转为水平，略向后撤蓄力，再依次加速飞向标题行左端，沿运动方向拉长，汇聚成一道光带 | 形状变形、运动路径、运动模糊 |
| 3.2–4.1 秒 | 光带自左向右横扫标题行，边缘柔和发光；光带经过之处显露文字，显露的边缘柔和；每个字在光带经过时从偏移状态弹入，依次落定 | 带羽化的蒙版、轨道遮罩、文字动画器、运动模糊 |
| 4.1–5 秒 | 光带在标题右端急停，压缩回最初的圆点，弹跳着落在标题末尾；一条细线从圆点出发在标题下方画出；一行较小的副标题依次出现；画面缓缓推近，在第 5 秒停住 | 修剪路径、文字动画器、关键帧缓动 |

4. 表中每项功能都要在画面上起到所写的作用，并能在编辑器中查到。另外：
   - 父子层级：整幅画面的推近、拉开和震动由一个父级统一带动；飞散的图形由一个共同的父级带动整群旋转；文字的显露范围跟随光带移动。
   - 预合成与时间重映射：从爆发到汇聚的图形放在一个预合成中，快—慢—快的变速由这个预合成图层的时间重映射完成；运动模糊随变速变化，高速时明显，慢动作时清晰。
   - 主合成在每段节拍的起点设有标记，图层按用途命名。
5. 动效质量：
   - 节奏：快慢交替，爆发和扫字两次高潮之间有慢动作的呼吸，结尾逐渐收势；主要动作有预备、过冲与跟随，没有匀速的线性起止（匀速自转等有意为之的运动除外），没有跳帧、穿帮或突兀的停顿。
   - 错落：同组元素的动作有层次地错开，错开的方向与视线一致；大的图形显得更重、更慢。
   - 焦点：任一时刻只有一个视觉焦点，视线从中央的圆点出发，经爆发、悬停、汇聚和横扫，一路被引到最后的标题。
   - 色彩与构图：有明确的色彩体系，一种主强调色贯穿圆点、主要图形、光带和末尾的圆点，另有少量辅助色和中性色，明度层次清楚，光带看得出发光感；开头留白充足，爆发时图形铺开而不拥挤，结尾的标题组合层级清楚、四周留白充足；构图、配色和字体与编辑器的视觉语言相称。
   - 定格：最后一帧是一张完整、停稳的画面：所有元素都已到位并完全显示，没有半透明的残影、画到一半的描边或仍在运动的字符；最后的收势恰在第 5 秒结束，不提前停成长时间的静止画面。

- 圆点缩放：0 秒 10% → 0.15 秒 122% → 0.25 秒 92% → 0.33 秒 100%（带过冲地弹出，第 0 帧就能看到一个小点）→ 0.42 秒（128%, 76%）→ 0.50 秒（86%, 118%）→ 0.57 秒 100%（先压扁再拉高的挤压变形）→ 0.90 秒 22%（强缓入，越缩越快，到 0.90 秒最快）。这些缓动在曲线编辑器里调出，值曲线上看得到过冲和回落。
- 光晕的缩放比圆点晚 0.05 秒、过冲更大（最高 134%），0.97 秒缩到 0。
- 镜头缩放：0 秒 100% → 0.88 秒 107%，缓入缓出，画面缓缓推近。

**0.90–1.40 秒 爆发。**
- 0.90 秒圆点到出点；同一帧，「图形群」从入点出现，内部 0 秒时全部图形以 20% 的大小叠在中心 (960, 540)，看起来就是那个缩到最小的圆点，随即炸开。
- 每个图形按上表的出发时刻离开中心，沿一条向同一侧弯的弧线（全部顺时针旋出，弧高约为弦长的三分之一）飞到悬停点，边飞边自转，缩放从 20% 长到 100%，强缓出（出发最快、到点前减速）。小图形先走、飞得最远、转得最多，大图形最后走、最重最稳。弧线用运动路径的空间手柄调出。
- 拖尾：每条的“结束”从图形出发时 0% 动到出发后 0.32 秒 100%，跟着图形长出；“开始”从出发后 0.10 秒 0% 动到 0.42 秒 100%，从后面追上收回；内部 0.55 秒前全部收完。

**1.40–2.40 秒 慢动作。**
- 「图形群」的时间重映射把内部 0.50–0.85 秒铺满这 1 秒（平均约 35% 速度），图形悬停在弧线末端，随群旋转缓缓转动，并略向外漂 12 像素；模糊随速度降低而消失，画面清晰。

**2.40–3.20 秒 汇聚。**
- 时间重映射从 30% 一路加速到 220%，把内部 0.85–1.85 秒放进这 0.8 秒。
- 内部 0.85–1.05 秒：全部图形变成同一种 120×10 的胶囊长条（路径变形），颜色都变为熔岩橙，旋转到画面上的水平方向（抵消群旋转的 −24°），同时向远离标题行（y = 537）的方向后撤 40 像素蓄力。

- 长条高速时运动模糊沿运动方向拉长，加速越快拖影越长。

**3.20–4.10 秒 扫字。**

### 草稿一：第一节“任务”

> ## 一、任务
>
> 制作一个在浏览器中运行的动效设计编辑器「帧坊」，供动效设计师制作二维图形动画。它的工作方式与专业的合成与动效软件相当：在合成中创建图层，用关键帧为图层的属性制作动画，在时间轴和曲线编辑器中精确调整时间与速度，预览后导出成视频。
>
> 第二节描述要做的编辑器：2.1 是一次完整工作的概览，2.2 是工程里有哪些东西，2.3 是界面的布局、外观、各个面板和各种状态的样子，2.4–2.17 是各项功能的具体行为，2.18 是快捷键，2.19 是打开编辑器时自动载入的示例动画。第三节是要达到的质量，以及性能测试。
>
> 本题看重功能之间的配合和编辑器的性能：每项功能与其他功能组合使用时也要正确，界面各处始终一致；图层和动画的规模很大时，编辑器仍要保持高性能。具体要求见第三节。
>
> 除第二节写明的内容外，本题不要求特效、表达式、三维图层和音频，也不要求导入图片、视频等外部素材。
>
> 编辑器的界面按第二节的设计制作，实现方式由你决定。图标等素材都由你自己制作，不要照搬任何现有软件的界面外观。浏览器自己保留了一些组合键（例如 `Ctrl+N`、`Ctrl+T`、`Ctrl+W`），网页无法拦截，第二节的快捷键已经避开了它们。
>
> 本测试是 AI 模型能力竞赛。建议充分利用全部时间，把作品做到完成度尽量高、各方面都优秀。

### 草稿二：第三节 3.1、3.2

> ### 3.1 组合与一致性
>
> 第二节的每项功能，单独使用时正确还不够，与其他功能组合使用时也必须正确。这是本题的重点。
>
> - **组合下成立**：图层位于旋转过、非等比缩放过并且自身带动画的多层父级之下，或位于带起始时间偏移、裁剪和时间重映射的多层嵌套合成之中，同时带着蒙版、轨道遮罩、运动模糊，在任意时刻编辑；以及经过撤销重做、保存打开和导出之后，第二节描述的结果都照样正确。
> - **始终一致**：任何操作之后，包括拖动途中、播放之中、撤销重做之后，画布、时间轴、曲线编辑器和属性面板显示的都是同一个状态（2.3.15）。
> - **预览与导出一致**：画面只由工程内容和帧号决定，与视图缩放、播放速度和电脑负载无关；导出结果的任一帧，与在编辑器中停在同一帧时看到的合成画面相同。
> - **与视图无关**：在任何画布缩放比例和时间轴缩放比例下，点击命中、拖动手柄、拖动关键帧和吸附都同样准确，结果不随缩放比例变化。
> - **始终可编辑**：任何操作组合之后，所有图层、关键帧、手柄和路径仍能正常选中和编辑；不会出现选不中、拖不动、手柄错位或无法恢复的对象。
>
> ### 3.2 界面质量
>
> 编辑器自身的界面要达到一款精心打磨的专业动效软件的水准：
>
> - **按设计做到位**：2.3 规定的布局、配色、字体、图标、控件、画布辅助元素和各种状态都如实做出，工具栏、各个面板、时间轴、曲线编辑器、菜单、对话框、提示和图标属于同一套协调的视觉语言；不是浏览器默认控件和样式的堆砌，也没有哪一部分明显粗糙或风格脱节。
> - **布局**：作品画面始终最突出，时间轴有足够的横向空间来呈现时间；选择、展开折叠、切换视图时布局不跳动。
> - **整齐与可读**：文字、数值、刻度和图标在各种状态下都清晰可读，元素的对齐和间距有规律；图层很多、嵌套很深、名称很长时，界面依然整齐。时间刻度在任何缩放比例下疏密合适、单位清楚。选择框、手柄、锚点、运动路径和参考线在任何缩放比例下、在深浅不同的画面上都清晰可见。
> - **状态完整，细节打磨**：2.3.13 列出的状态，以及空工程、无选择、单选、多选、混合值、预合成内部、命令不可用等状态，都按设计完整呈现；各处没有溢出、遮挡、闪烁、残留的辅助元素等瑕疵。
> - **过渡**：2.3.14 的过渡短促、清楚，帮助看清变化，不拖慢操作，不延迟反馈。

## 五、工作量与难度说明

**规模不减，明显增加。** 现行题面只点名功能，本设计把每项功能落到具体的元素和行为上，模型要做的东西因此多出一大截，例如：

- 界面：8 个区域的尺寸与调整规则；7 个菜单约 100 个菜单项和 7 种右键菜单；5 组工具栏和取色器；项目面板 3 个页签（含历史跳转和性能记录合计）；时间轴 8 列、4 种行、两层标尺、标记、刻痕；曲线编辑器的工具条、刻度、曲线标签、交点数值和虚线预览；属性面板 13 个分区和混合值、相对算式；10 个内置缓动预设和悬停动画；8 种对话框；状态栏 5 项。
- 状态：关键帧 4 种半边形状 × 5 种状态，属性的 3 种动画状态，约 20 种光标，14 种拖动读数，播放胶囊，提示条，各处空状态。
- 快捷键：约 100 个（现行题面必须的 16 个全部保留）。
- 示例动画：从 6 段文字节拍变成可以照做的完整制作单：2 个合成、37 个图层、6 个标记、具体的关键帧数值与缓动，以及 8 个可以逐一核对的关键画面。

**耦合仍是难度核心，而且更多了。** 现行题面的组合要求全部保留；本设计在写具体行为时，又把原来含糊的组合情形一一定死，每一条都是新的、可以被评审检查的耦合：

1. 预合成的检查清单：父子关系跨越选择边界时拒绝、遮罩对自动带入、不相邻时警告，从而保证“前后逐帧相同”在任何选择下都成立。
2. 轨道遮罩“始终成对”：调整顺序、复制、粘贴、删除、预合成、撤销、保存打开六种操作下都要维持。
3. 设定父级时全部关键帧一起换算，以及非等比父级造成斜切时的处理。
4. 改帧率后不在帧上的关键帧：显示、半帧内算“在关键帧上”、`J`/`K` 落点、拖动落帧。
5. 播放中编辑：关键帧写在操作开始时的那一帧。
6. 运动模糊在嵌套和时间重映射下的规则：快门以最外层为准，内外两套开关各管一部分运动，模糊随重映射速度伸缩。
7. 进入预合成时内部播放头按起始时间和重映射换算。
8. 嵌套合成按精确时刻取值，慢动作平滑。
9. 多选的混合值、相对算式、多图层同时平移与旋转缩放。
10. 锚点补偿写进当前时刻的关键帧。
11. 文字编辑时暂时去掉动画器偏移；范围线在画布上可拖动；修改文字后范围的百分比含义不变。
12. 撤销重做后选择的恢复规则。
13. 粘贴关键帧的目标规则、`Delete` 和复制粘贴的作用对象优先级。
14. 预合成图层的裁剪受内部时长限制、开启重映射后解除。
15. 缓动预设悬停时在曲线编辑器里预览、关键帧拉伸的压缩极限。

**两处可能减轻负担的设计**（需要拍板，见第六部分第 10 条）：画布上选中超过 200 个图层时只画总外框；曲线编辑器最多同时画 50 条曲线、画布最多显示 20 个图层的运动路径。它们是专业软件常见的做法，但会减轻性能任务 4、5 里“四个视图全部更新”的绘制量。

**性能测试不变。** 3.3–3.6 一字未改；测试步骤用到的每个操作在第二部分都有明确的做法（见 4.5），评审照做不会遇到歧义。

## 六、需要用户拍板的点

1. **界面从“自己设计”改为“照设计做”。** 本设计定死了布局、尺寸、配色、字体风格、图标风格和控件样式，第一节相应改为“界面按第二节的设计制作”。这样模型不再自己做界面设计，界面分项（15 分）考的是还原度和打磨程度。另一种做法是只定布局和状态，把配色和视觉风格留给模型。
2. **产品名「帧坊」**：出现在菜单栏、关于、工程扩展名 `.zfp` 和示例的副标题里。可以换名或去掉。
3. **配色**：深色界面，熔岩橙 `#FF6A2B` 表示时间与动画，冰蓝 `#4CC2FF` 表示选择，示例动画的主强调色也用熔岩橙。
4. **布局**：时间轴横贯全宽、曲线编辑器与时间轴共用底部区域（含上下分屏）；属性面板在右上，缓动预设在右下。也可以让曲线编辑器单独占一个面板。
5. **“在嵌套合成之中编辑”取进入预合成后在它自己的画布上编辑**，外加进入时按起始时间和重映射换算内部播放头。更难的另一种是“上下文编辑”：在预合成内部时，画布按预合成图层的变换把内部画面叠在外层画面上，直接在外层画面里拖动内部图层也跟手。它会引出“内部时刻与外层时刻不是一一对应时怎样联动”等新问题，本设计没有采用。
6. **预合成的规则取严格版**：父子关系跨越选择边界时拒绝（给出一键扩选），以保证前后逐帧相同。另一种是同类软件的做法：直接断开跨边界的父子关系，画面可能改变。
7. **轨道遮罩始终成对**（顺序、复制、粘贴、删除时一起处理），且做遮罩的图层不能再用遮罩。
8. **运动模糊在嵌套中的规则**（2.14“嵌套时”）：快门以最外层合成为准，预合成图层的开关管它自身的运动，内部图层的开关管内部的运动，内部的模糊随重映射速度伸缩。
9. **几处原文的解释**：
   - “关闭动画时属性保留当前值”取“停在当前时刻的数值上”；
   - 改帧率后“时间码和帧号始终合法”取“播放头只停在帧上，不在帧上的关键帧按真实时刻画出、半帧内算在关键帧上”；
   - 播放中编辑，关键帧写在操作开始时的那一帧；
   - 删除一个属性的全部关键帧后，动画开关仍开着。
10. **显示上限**：画布选中超过 200 个图层只画总外框；曲线最多 50 条；运动路径最多 20 个图层。若希望性能任务 4、5 更难，可以去掉这三条上限。
11. **示例动画的具体内容**：标题“万物始于一点”、副标题、60 帧/秒、配色、光带最后就是末尾的圆点（同一个图层）、长条从右向左沿标题行冲到左端后光带再向右横扫、标题用两个动画器做弹入和过冲。这些都可以换。
12. **在现行题面之外补的小功能**（都不属于特效、表达式、三维、音频、外部素材，用来把已有功能做完整）：蒙版的相加/相减/交集模式、字体风格和字间距、描边端点与拐角、“转换为钢笔路径”、“设为起点”、标签色、历史页、剪切、`Alt`+单击循环选择、数值框的算式和相对算式、文字动画器的三角和平滑形状。可以删掉其中任何一项。
13. **快捷键与同类软件的差异**：因为浏览器保留 `Ctrl+N`、`Ctrl+T`，新建合成改为 `Ctrl+Alt+N`，文字工具改为 `T`，于是不透明度的展开键改为 `O`，跳到出点改为 `Shift+I`；画布缩放用 `.` `,` `/`，避开浏览器的网页缩放。
14. **导出**：格式定为“视频文件（不指定编码）”和“PNG 图像序列打包”；导出时编辑器锁定、不能编辑。另一种是导出时允许继续编辑（导出按开始时的工程渲染），难度更高。
15. **面板写了像素尺寸**（默认宽高和可调范围）。这些是界面设计的一部分，不是对显示器分辨率或窗口大小的要求；题面里没有加任何分辨率条款。
16. **测试步骤的一处细节（不在本设计范围，供参考）**：场景 B 第 0–3 个预合成图层开启时间重映射时，按 2.12 会在起始时间和起始时间加 10 秒处自动生成两个关键帧；评审按“在第 0、5、10 秒设为 0、5、0 秒”操作时，第 1–3 个图层还需要删掉起始时间处自动生成的那个关键帧，结果才是“前 5 秒正放、后 5 秒倒放”。可以在评分指南里提醒评审一句。
