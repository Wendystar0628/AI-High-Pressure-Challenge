## 一、总体设计

### 1.1 作品是什么

《盐闸》（Saltgate）是一款三维网格塔防。

- **舞台：** 海边制盐小镇"澜盐镇"。镇子靠地下的一眼淡泉活下去。
- **敌人：** 每隔几十年，近海的黑卤海沟会涌起"锈潮"：一群由锈铁、卤水和贝壳长成的怪物，爬上岸去污染淡泉。
- **玩家：** 镇上的"闸守"。手里有盐砖垒成的守卫、旧电报站拆下来的铜线圈、盐场的熬卤炉、守夜的灯塔和排水用的排潮泵。
- **最重要的工具：** 地图上的"闸位"（即题面说的关键点位）。在闸位上落闸，那一段路就断了，锈潮只能改道。

锈潮会反击：
- 砸闸，叼走闸板，溶穿盐柱；
- Boss 会掀翻闸门、筑起珊瑚墙、让湖水漫上岸；
- 闸一倒，路又打开，敌人的路线随之再变。

### 1.2 玩家同时经营两条线

1. **打赢交战。**
   - 盐垒卫和铜钩手在路上挡住敌人；
   - 潮弩台、铜线圈、熬卤炉在高台上输出；
   - 守灯塔为塔治疗或加护盾；
   - 卤水、电、热三种手段叠出"浸湿 → 结壳 → 碎壳"和"导电"的连锁。
2. **经营路线。**
   - 在哪个闸位落闸，什么时候落；
   - 落了以后用什么守住，挡不挡得住破闸鳌；
   - 要不要用排潮泵抽干卤沟，开出一条新路，好让本来会封死的两个闸可以同时关上。

两条线通过三样东西咬合：
- **"闸印"资源：** 落闸要花闸印，闸守得住才产闸印；
- **"迷途"：** 掐准时机落闸，正走过来的敌人被迫掉头，会获得"迷途"；
- **卤滩地形：** 改道往往把敌人赶进卤滩，敌人一浸湿，导电和结壳就能发挥。

### 1.4 一局的体验流程

1. **关卡选择。** 三张地图卡片并排，每张有一个缓慢旋转的地图微缩模型。任意一张都能直接进入。
2. **进图。**
   - 镜头从默认视角俯瞰整张地图。入口在远处（画面上方），出口在近处（画面下方）。
   - 每个入口的路线是一条朝出口流动的彩色箭头带，A 珊瑚橙、B 海玻璃青、C 藤紫。
   - 闸位是路面上一对青铜闸柱。
   - 右侧"来袭预报"列出第 1 波的构成和入口，顶部写着"距第 1 波 25 秒"。
3. **准备期。**
   - 玩家把底部卡片拖到地图上。
   - 拿起卡片的一刻游戏放慢，镜头滑回默认视角。能放的格子亮起青色描边。
   - 拖到闸位上时，画面同时显示虚线的"预览路线"和当前路线。
4. **波次进行。**
   - 敌人沿路线前进，被盐垒卫挡下交战。喷卤蛞边走边朝高台吐卤液。
   - 玩家看准时机落闸。路线改道时，旧路线变灰淡出，新路线从改道处一路画向出口，入口旁弹出"B 改道 → 出口 Y"。
   - 正在转向的敌人头顶出现转向标记。被迫掉头的敌人陷入迷途，被高台火力收割。
5. **反击。**
   - 破闸鳌盯上闸位，红色虚线连到闸上，闸位亮起"被盯"标记。
   - 闸倒下时，碎木飞散，闸柱升起，路线再次改道，闸位的闸印计时清零。
6. **Boss 波。** 画面边缘泛起暗红，Boss 名牌横扫而过，顶部出现 Boss 血条；Boss 的地形能力在生效前 3 秒就标出将受影响的格子。
7. **结算。** 撑过全部波次即胜利；净泉归零即失败。结算画面列出胜负和统计，可以重开本图或返回选关。

### 1.5 三张地图怎样递进

| 地图 | 时间与氛围 | 结构 | 这张图新带来的挑战 |
|---|---|---|---|
| 一 白盐坡 | 晴朗清晨，白色盐田梯田 | 2 入口 1 出口；中央卤沟把地图分成东西两坡，北桥、中浅滩两道横向连接 | 学会"关一边、压另一边"。⑤号闸同时改动两个入口。①②互斥，会封死。排潮泵升到 2 级后抽干中央卤沟，①②才能同时关闭。 |
| 二 铜潮渡口 | 黄昏，铜屋顶仓库和渡船 | 3 入口 2 出口；一条卤河横贯地图，过河只有西桥和中浅滩两处 | 多出口：落闸能把敌人整批送往另一个出口。两处断桥位置可以用泵抽干造新渡口。Boss 潮钟会筑珊瑚墙，强行改道。 |
| 三 沉钟盐窟 | 夜，地下盐窟，矿灯和发光卤水 | 3 入口 2 出口；中央沉钟湖，环湖路加上南北东西多条矿廊 | 盐柱会被蚀盐蠕溶穿，形成绕开闸位的新路。Boss 渊冕会溶柱，还会让湖水漫过一段湖岸。第 11 波锈母重临。闸位 7 个，互相牵连最多。 |

### 1.6 原创性

- **与《明日方舟》的区别：** 题面规定的"阻挡型塔在路上、远程塔在高台、技能靠受击充能"，在《明日方舟》里也有。本设计的题材、单位、资源和系统都与它不同：
  - 题材是制盐小镇对锈潮；
  - 单位都是盐、铜、卤水做的器械；
  - 第二资源闸印与闸位挂钩；
  - 核心系统是改道，并且有地形改造（抽干卤沟）和卤水—热—电的状态链；
  - 没有干员、职业、部署费用这类设定，也没有沿用其名称。
- **与其他塔防的区别：** 也区别于《王国保卫战》的兵营阻挡、《Defense Grid》的自由迷宫和《植物大战僵尸》的分行推进。
- **素材：** 全部素材由受测模型自制。

## 二、具体内容

### 2.1 题材与世界观

- **澜盐镇：** 建在海边坡地上。北面是海，南面是镇子。镇民世代晒盐、熬卤，靠镇下的淡泉饮水。
- **锈潮：** 从近海黑卤海沟涌起的腐蚀潮。它把沉船、锚链、贝壳和卤水"长"成会爬的怪物。所有敌人的造型都由这四样东西组成：
  - 锈红和油黑的甲壳、锚链，
  - 灰白的藤壶，
  - 病态的青绿色荧光斑。
- **闸守的器械：** 用镇上现成的东西造。
  - 盐砖：白色，粗糙，带结晶闪点；
  - 铜：橙铜色，带铜绿；
  - 风化木板；
  - 黄铜灯具和管道。
- **出口：** 守护的是"泉门"。泉门是石拱门，门楣上是一颗水滴纹章，门内泛蓝光。敌人走进泉门，"净泉"值下降。
- **三张地图的故事：**
  - 一、锈潮第一次上岸，冲上白盐坡的晒盐梯田；
  - 二、锈潮沿卤河涌进铜潮渡口；
  - 三、锈潮从地下盐窟的沉钟湖里涌出。湖底沉着一口古钟，最终 Boss 渊冕从这里现身。
- **游戏内文案：** 简体中文，语气是盐场工人的口吻，短句、实在。例如：
  - 关卡副标题"潮头已到坡下"；
  - 闸位被砸开时提示"西坡闸破了！"。

### 2.2 美术方向

#### 2.2.1 整体画风：盐与铜的微缩模型

- **观感：** 像一套精致的桌面微缩模型。
  - 地块是有厚度的方砖，侧面露出分层的盐土剖面；
  - 塔和敌人造型饱满、轮廓清楚，边角有倒角，比例略带"棋子感"，头和手持器械略大，便于在场上辨认。
- **渲染：** 写实材质，略做风格化。光照统一，有实时阴影。
- **轮廓光：** 塔和敌人边缘有一圈很淡的轮廓光：塔为暖金，敌人为青绿。这样在混战中也能把单位从地面上分出来。

#### 2.2.2 配色

| 用途 | 颜色 |
|---|---|
| 盐面、盐砖、塔的主体 | 盐白 #F2EEE6，阴影偏暖灰 #BDB3A3 |
| 卤水、卤滩 | 卤青 #2E8C8A、浅卤 #7FD1C7 |
| 铜件 | 铜橙 #C8743A、铜绿 #4FA38A |
| 木件 | 风化木 #8C6A4A |
| 敌人 | 锈红 #8A3B24、油黑 #1E1A1C、荧光斑 #6CF2C2 |
| 灯光、可交互强调、技能就绪 | 暖金 #F3C25B |
| 入口 A / B / C（路线、入口旗、来袭预报一律同色） | 珊瑚橙 #F08A4B / 海玻璃青 #3FC6C0 / 藤紫 #A88BEB |
| 危险（封死、血量危急、Boss 预警） | 警示红 #E5484D |
| 预览路线 | 白色虚线描边，填充为入口色的 50% |

#### 2.2.3 材质

- **盐砖：** 哑光，粗糙，表面有细碎结晶在光下闪点。
- **铜：** 金属感，边缘磨亮，凹处积铜绿。
- **木：** 纹理明显，钉头生锈。
- **卤水：**
  - 半透明青色，水下能看到浅色盐床；
  - 表面有缓慢的波纹和高光；
  - 卤沟更深，颜色更暗，有朝一个方向流动的水纹。
- **锈甲：** 粗糙的橙褐色，带剥落层。
- **贝壳与藤壶：** 半光泽的灰白。
- **荧光斑：** 自发光，在夜图里会照亮周围一小片。

#### 2.2.4 光照与各图的天气

1. **白盐坡：**
   - 清晨暖阳从东侧低角度照来，影子长而清楚；
   - 天空浅蓝，薄云投下缓慢移动的云影；
   - 盐面明亮但不过曝。
2. **铜潮渡口：**
   - 黄昏橙色斜阳从西侧照来；
   - 河面有雾，第 4 波后渡口的路灯和仓库灯笼逐盏亮起；
   - 暗部偏紫蓝。
3. **沉钟盐窟：**
   - 地下夜景，环境光很暗。
   - 光源有三类：
     - 矿灯：暖黄点光源，挂在矿柱上；
     - 卤水和盐柱自身的青色微光；
     - 守灯塔和熬卤炉的暖光。
   - 湖底沉钟发出缓慢呼吸的青光。

#### 2.2.5 界面风格："盐场搪瓷工牌"

- **面板：** 像旧搪瓷铭牌，盐白底，四角有铜铆钉，外框是细铜边；标题栏是一条深铜色压印带。
- **文字：**
  - 标题用窄体、带雕刻感的衬线风格；
  - 正文用清楚的无衬线风格；
  - 数字用等宽数字风格，便于读数。
- **图标：** 统一是"铜印章"风格：单色压印，圆角方形底。
  - 盐晶：一颗白色多面晶体；
  - 闸印：一枚铜色闸门印章；
  - 净泉：一颗蓝色水滴。
- **按钮：** 冲压铜片的质感。
  - 悬停：铜边发暖金光，按钮上浮 2 像素；
  - 按下：下沉；
  - 不可用：去饱和，并叠一层斜线网纹。
- **面板动画：** 打开时从所在屏幕边缘滑入（0.2 秒，缓出），关闭时滑回。

### 2.3 格子与地形

所有格子都是方形地块。下表中"高度"指地块顶面相对地面的高度，以一格边长为 1。

| 格子 | 网格符号 | 外观 | 地面敌人能否通行 | 能部署什么 |
|---|---|---|---|---|
| 道路 | `.` | 高度 0。白盐坡是压实的盐土路铺木栈板；渡口是铺石码头路；盐窟是矿道地面，带一段段矿车轨道 | 能，行程 1 | 盐垒卫、铜钩手 |
| 高台 | `H` | 高度 0.9 的盐砖台，侧面有砖缝和铜包边；顶面是平整的方形台座纹，一眼看出"能放东西" | 不能 | 潮弩台、铜线圈、熬卤炉、守灯塔、排潮泵 |
| 障碍 | `#` | 高度 1.2–2.0、顶面不平的物体：盐堆、礁石、仓库、矿岩壁、晒盐架 | 不能 | 无 |
| 关键点位（闸位） | `①`–`⑦`（网格里写作数字） | 道路格，两侧立一对青铜闸柱，地面嵌一块刻着闸门纹的铜板（详见下文"闸位的状态"） | 空闲时能；被占用时不能 | 盐垒卫、木闸桩、道具"闸板" |
| 卤滩（特殊地形） | `w` | 比地面低 0.1 的浅卤水。水下可见浅色盐床，水面有涟漪和少量芦苇 | 能。地面敌人速度降到六成（潮影鳗反而加速）；计入路线时一格算 5/3 格行程；站在上面会浸湿 | 无 |
| 卤沟 | `~` | 比地面低 0.6 的深卤水，颜色更暗，有流动水纹，两岸有木护岸 | 不能 | 无。可被排潮泵抽干 |
| 干卤床 | 网格中不出现 | 抽干后的卤沟：湿润的灰色盐泥，有水洼和结晶，边缘有一圈泵蓝色细描边，表示"被泵改过" | 能，行程 1 | 无 |
| 盐柱 | `P` | 高度 1.8 的半透明粉白色盐晶柱，多棱面，内部微光 | 不能 | 无。可被蚀盐蠕和渊冕溶掉，溶后变成卤滩（"溶穴"：卤滩中残留几块碎晶） |
| 入口 | `A` `B` `C` | 塌开的海堤缺口或矿道口，里面是缓慢旋转的暗卤水涡；旁边插一面入口色旗，写着入口字母 | 只作起点 | 无 |
| 出口（泉门） | `X` `Y` | 石拱门，门楣上是水滴纹章和出口字母，门内泛蓝光 | 终点 | 无 |

**Boss 造成的临时地形（不在网格中）：**
- **珊瑚墙：** 锈红色的尖刺珊瑚从路面拱出，高 1.5，不可通行。
- **渊水：** 湖水漫上湖岸，暗青色水面，不可通行。
- 两者都带倒计时环。

**闸位的状态：** 一眼可辨，并实时更新。

| 状态 | 外观 |
|---|---|
| 空闲 | 闸柱收起，铜板上的闸纹泛青光 |
| 被塔占用 | 闸柱升起并挂上铁链。塔脚下一圈细环，是"闸印计时"（满 40 秒产 1 闸印） |
| 被闸板占用 | 一块木闸板横在两柱之间，板上有剩余时间环 |
| 此刻占用会封死 | 铜板变红，叠一个交叉的闸门图标。拖着闸型卡片时尤其醒目 |
| 复位冷却 | 闸纹变灰，显示剩余秒数 |
| 被盯上 | 被破闸鳌、锈母或潮钟盯上的闸位，上方浮一个红色爪形标记 |

**辨识原则：**
- 能部署的格子顶面平整、有台座纹或栈板纹；
- 能走但不能部署的格子是水或泥；
- 不能走的格子顶面不平或明显高出。
- 拿起卡片时，地图叠一层很淡的格线。

### 2.4 地图

**坐标与图例：**
- 坐标写作（行, 列），都从 0 开始。行 0 在北边、离镜头最远；最后一行在南边、离镜头最近。

#### 2.4.5 验算方法（供出题人复核，不进题面）

- **建模：** 网格按上表逐格建模。道路、关键点位、入口、出口和干卤床的行程为 1，卤滩为 5/3。四邻接移动。从各入口求到各出口行程最短的路线。
- **核对：** 默认路线、每个闸位单独占用的结果、两两占用的封死组合，以及泵抽干、盐柱溶掉后的变化，都与上表一致。
- **等长路线：** 只有一种情形，即渡口图关①时，A 在 2 格宽的中浅滩里走哪一列。这属于同一处渡口，不影响"改走哪条路"的判定。
- **单个闸位的改道幅度：** 新路线比原路线至少多走 8 个不在原路线上的格子，符合"不是在原路线旁边绕开一格"。

**通用规则：**
- 伤害 = 攻击 ×（1 − 护甲）。真实伤害无视护甲。护盾先于生命吸收伤害。
- **攻击塔的选目标规则：**
  - 选范围内沿当前路线离出口剩余行程最短的敌人（飞行敌人按航线剩余距离）。
  - 改道后剩余行程按新路线计算。
  - 熬卤炉瞄准这个敌人的脚下。
- **数量上限：**
  - 全场塔数：白盐坡 10、渡口 12、盐窟 14；
  - 每种塔最多 3 座，排潮泵最多 2 座。
- **范围单位：** 范围按格计，从塔所在格中心量起。
- **排潮直线：**
  - 从排潮泵所在高台的相邻格起，沿朝向数 3 格（2 级为 5 格），遇到高台、障碍或盐柱即止；道路、卤滩、卤沟不会截断这条直线。
  - 直线上的卤沟和卤滩被抽干，变成干卤床。其他格子不受被动影响。
  - 排潮泵可以放在任何高台上；只有朝向上有水的位置才有效果。

#### 2.5.4 每种塔的外观、行为和动画

1. **盐垒卫**
   - **外观：** 一具矮壮的盐砖守卫，约 1.1 高。身体是层层白盐砖，用铜箍扎紧。头部是一盏方形铜灯笼，灯里亮青光，充当眼睛。左臂扛一面圆形结晶盐盾。
   - **待机：** 盾牌随呼吸轻微起伏，灯笼明暗。
   - **攻击：** 向前半步，用盾猛撞，再退回原位，共 0.4s。
   - **受击：** 盐屑飞溅，身体后仰。
   - **技能：** 白色晶体从盾面向全身蔓延（0.5s）。持续期间全身晶亮，有一圈缓慢旋转的碎晶。
   - **被摧毁：** 盐砖崩落成一堆，灯笼熄灭滚落，扬起一团盐尘。
   - **闸位上：** 盐垒卫站在闸位上时，闸柱在它两侧升起。它朝相邻格挥盾，是一座"会还手的闸"。
2. **铜钩手**
   - **外观：** 瘦高的盐场工人形象，约 1.3 高。穿油布长外套，戴兜帽和黄铜护目镜。双手握一根长柄铜钩镰。
   - **朝向：** 有朝向，面朝的一侧是它的攻击区。
   - **待机：** 缓慢转动钩镰。
   - **攻击：** 一记水平横扫，留下一道铜色弧光。
   - **技能：** 甩出带链铜钩，链条伸长、钩住、猛收。
   - **受击：** 踉跄。
   - **被摧毁：** 跪倒，钩镰脱手，砸在地上。
3. **木闸桩**
   - **外观：** 两根木桩夹着几块厚木闸板，板上有铁扒钉，顶上插一面小三角旗。
   - **待机：** 旗子飘动，木板偶尔吱呀一下。
   - **受击：** 木屑飞溅，板面出现裂纹，裂纹随生命下降增多。
   - **铁闸：** 2 级换成铁板，挨打时从板缝喷出卤水雾。
   - **被摧毁：** 闸板从中间断开，向两侧倒下，闸柱降回地面。
4. **潮弩台**
   - **外观：** 盐砖底座上一个可以旋转的木铜转台，架着一张大弩。弩身是木头，弩臂包铜，旁边有一个绕绳鼓。弩矢的箭羽是青色的。
   - **朝向：** 有朝向，只能在设定的 90° 扇形内转动。
   - **待机：** 在扇形内缓慢左右扫视。
   - **攻击：** 拉弦、松弦，弩身后坐，绳鼓转一圈。
   - **受击：** 弩身震动。
   - **被摧毁：** 弩臂折断，转台歪倒。
5. **铜线圈**
   - **外观：** 一根高约 1.6 的铜柱，外绕密集线圈，中段有几片玻璃绝缘盘，顶端是一颗玻璃晶球，球里有电光翻滚。
   - **待机：** 细小电弧沿线圈爬动，发出嗡鸣。
   - **攻击：** 一道锯齿状的蓝白电弧从晶球跳到目标，再在目标之间跳跃。
   - **技能：** 线圈烧得发白，电弧暴密，火花四溅。
   - **被摧毁：** 晶球炸裂，线圈冒出最后一串火花后熄灭。
6. **熬卤炉**
   - **外观：** 一座矮胖的砖炉，炉口透出橙红火光，上面立一根铜烟囱。炉顶装一只长柄铜勺抛臂。
   - **待机：** 烟囱冒烟，炉口的火光一明一暗，像在呼吸。
   - **攻击：** 勺臂从炉口舀起一团发光的盐渣，抛出一道弧线，落地溅开。
   - **技能：** 炉火猛地窜高，勺里的盐渣变成熔融的亮橙色。
   - **被摧毁：** 烟囱倒塌，炉体裂开，散出一地火星。
7. **守灯塔**
   - **外观：** 一根约 1.8 高的半透明盐晶柱，顶上托一盏黄铜框灯笼。灯笼外有一圈缓慢旋转的棱镜。
   - **待机：** 暖金光束缓缓扫过周围。
   - **治疗：** 一道暖金光带连到目标，目标身上升起光点，飘出绿色的"+数值"。
   - **技能：** 一圈光幕从灯笼向外铺开，罩住范围内的塔。
   - **被摧毁：** 灯罩碎裂，光熄灭，晶柱折成两段。
8. **排潮泵**
   - **外观：** 一座黄铜泵房，上有一只大辐条飞轮和两组活塞。两根长长的铆钉排水管从台边伸出，越过台沿探进水里。
   - **朝向：** 有朝向，排水管朝向就是作用方向。
   - **待机：** 飞轮转动，活塞起落，管口不断向远处喷出水流。
   - **排潮生效时：** 被排干的格子水位在 1.5s 内降下去，露出盐泥床。
   - **技能：** 飞轮反转，管口改为向朝向直线上猛灌卤水。
   - **受击：** 管子漏出水雾。
   - **被摧毁：** 飞轮崩裂倒下，管子爆开喷水。

#### 2.5.5 塔与改道和其他系统的关系

| 塔 | 关系 |
|---|---|
| 盐垒卫 | 能上闸位。放在闸位上既封路，又能对相邻格敌人盾击，还能用结晶反壁把破闸鳌的仇恨拉到自己身上。比木闸桩贵，但能打 |
| 铜钩手 | 不能上闸位。是改道后"新路线"上的主要阻挡者：改道时，它只挡路线经过它所在格的敌人。潮镰分支能制造浸湿，但会让潮影鳗滑过它；锚链分支能让被挡住的破闸鳌和蚀盐蠕失去能力 |
| 木闸桩 | 最便宜的封路手段。铁闸让砸闸的敌人浸湿，与铜线圈配合可以麻痹并打断砸闸 |
| 潮弩台 | 默认打离出口最近的敌人，改道后按新路线重新排序。鱼叉炮把飞行敌人拉到地面，让只打地面的塔和铜钩手也能处理它 |
| 铜线圈 | 敌人走进卤滩、被潮镰或铁闸浸湿、被卤水桶或倒灌淋湿，都会让它的连锁变强 |
| 熬卤炉 | 灼热遇上浸湿结成盐壳。熔盐泼落在卤滩上变成沸卤 |
| 守灯塔 | 保住闸位上的塔，就保住闸印计时。镜幕分支的护盾会被潮钟的回响打掉 |
| 排潮泵 | 唯一能改变地形的塔：抽干卤沟或卤滩，开出新路；倒灌把道路暂时变成卤滩，抬高行程，能让敌人自己换路。它的部署、升级、撤下和被摧毁都会改变通行，都要预览、都受禁止封死约束 |

#### 2.6.2 逐个说明

1. **锈螺**
   - **外观：** 膝盖高的大海螺。锈橙色螺旋壳上粘着藤壶，下面是油黑的软足，两根眼柄顶端亮青光。
   - **动画：** 爬行时软足波浪起伏，壳左右摇晃。攻击时伸出齿舌往前一啄。死亡时壳裂开，软足化成一摊泡沫。
   - **行为：** 沿路线走，被挡就攻击挡住它的塔。
2. **钳卒**
   - **外观：** 半直立的蟹兵，锈甲板，一只钳子大得像盾牌，护在身前，关节泛盐白。
   - **能力"钳盾"：** 受到潮弩台弩矢和鱼叉的伤害 −40%。溅射、电弧、灼热不受影响。图鉴写明"拿炉子和线圈对付它"。
   - **动画：** 走路时身体侧着 30°，大钳在前。攻击是大钳砸下。死亡时翻倒，腿蜷起。
3. **喷卤蛞**（远程敌人）
   - **外观：** 臃肿的海蛞蝓，喉部挂着半透明的青绿色喉囊，囊里卤液晃荡，背上长着锈管状的鳃。
   - **能力"边走边吐卤"：** 不停步。每 2 秒朝 3 格内的一座塔吐一团卤液，卤液走抛物线，命中造成 22 伤害并附加锈蚀。打得到高台上的塔。
   - **选目标：** 被阻挡时打阻挡它的塔；没被阻挡时，打 3 格内离它最近的塔，距离相同时打生命比例最低的。
   - **画面：** 选定目标后，它与目标之间有一条细红虚线。
   - **动画：** 吐之前喉囊胀大，作为预备。死亡时瘪成一滩卤水。
4. **破闸鳌**（攻击挡路塔的敌人）
   - **外观：** 巨大的龙虾怪。两只锤形大钳缠着锚链，背上嵌着半截船锚。步子沉重，每走一步地面微震。
   - **能力"破闸"：** 它出发时和每次通行变化后，比较两条路线：
     - 现在的路线；
     - 把所有被占用的闸位当作可通行时的最短路线，称"破闸路线"。
   - **进入破闸状态的条件：** 同时满足两点：
     - 破闸路线比现在的路线短至少 6 格行程；
     - 破闸路线上第一个被占用的闸位，离它不超过 8 格行程。
   - **破闸状态下的行为：**
     - 走到破闸路线上紧挨这个闸位的那一格，开始砸闸位上的塔或闸板，伤害 ×3；
     - 闸一倒，按新路线继续前进；
     - 半路被阻挡时，先打阻挡它的塔；
     - 被锚链分支阻挡、被麻痹或眩晕时不能砸。
   - **画面：** 进入破闸状态时，头顶亮起红色锤形标记，一条红色虚线连到目标闸位，闸位上浮起"被盯"爪印。
   - **动画：** 砸闸时人立而起，双钳交替猛砸，锚链迸出火星。死亡时轰然倒地，锚链散落。
5. **潮影鳗**（与阻挡的关系不同的地面敌人）
   - **外观：** 细长的黑绿色鳗鱼，背鳍像撕破的帆，身侧有一排磷光条纹。在陆地上呈 S 形蜿蜒前进。
   - **能力"滑过"：** 身上有浸湿时不能被阻挡，走到阻挡塔的格子直接滑过去。没有浸湿时与普通敌人一样会被阻挡。在卤滩上不减速，反而加速到 1.8。
   - **画面：** 浸湿时身体发亮，身后拖一道水痕。被阻挡塔放过的那一刻，阻挡塔上方飘出"滑过"字样。
   - **动画：** 攻击是快速咬噬。死亡时翻滚两下，化作一道湿痕消失。
6. **蚀盐蠕**（能力与地形有关、会改变通行情况）
   - **外观：** 苍白的分节蠕虫，每节有一圈铜绿锈环，口器是旋转的锉齿。爬过的地面留下一道湿痕。
   - **能力"溶柱"：** 每次重新寻路时，检查离它当前路线不超过 3 格的盐柱。若溶掉某根盐柱能让它到出口的行程缩短至少 4 格，它就走到这根盐柱旁边（离它最近的可通行邻格），用 5 秒溶掉盐柱。
   - **溶柱的结果：** 盐柱格变成卤滩，所有路线按新通行重新计算。溶柱只会增加可通行的格子，不会造成封死。
   - **打断：** 溶柱途中被眩晕、麻痹或钩走，进度清零。被锚链分支阻挡时不能溶柱。
   - **画面：** 决定溶柱时，它与盐柱之间连一条紫色虚线。盐柱表面出现发光裂纹和 5 秒倒计时环。同时，用淡紫色虚线预示"溶掉之后"相关入口的新路线。
   - **动画：** 溶柱时锉齿高速旋转，向盐柱喷吐卤沫，盐柱从上往下塌成一摊卤水。
7. **拾荒鸥**（不受地形约束的敌人）
   - **外观：** 一具铁丝扎起来的海鸥骨架，翅膀上补着锡皮，钩状喙，爪下吊着一只装满破烂的网兜。
   - **能力"飞行"：**
     - 飞行高度约 1.6，地面有它的投影圆斑。
     - 从入口沿直线飞向本图规定的出口（见 2.4 各图"飞行敌人航线"），飞越障碍、高台、卤沟和被占用的闸位。
     - 不能被阻挡。
   - **能攻击它的：** 只有潮弩台和铜线圈。有缠网或坠地时，所有远程塔都能打它；坠地时铜钩手的钩回也能钩它。
   - **能力"叼走闸板"：** 航线经过的闸位上如果有闸板（闸位中心到航线的水平距离不超过 1 格），它飞到最近处时悬停 2.5 秒，放下钩爪把闸板叼走。闸板消失，闸位解除占用，道路重新打开。
   - **航线不变：** 叼板时它只在航线上停一停，航线本身不变。
   - **打断：** 悬停中被打死、坠地或麻痹，这次叼板作废，闸板保住；它起飞后不会回头再叼同一块。
   - **画面：** 悬停前 1 秒，闸板上出现红色爪印和 2.5 秒倒计时。
   - **坠地：** 坠到正下方。下方是道路、闸位或卤滩，就落到地面；下方是高台或障碍，就落在它们顶上。
   - **动画：** 扑翅与滑翔交替。被击落时锡皮和羽毛打着旋落下，摔在地上散架。
8. **藤壶工**（辅助敌人，能力影响状态）
   - **外观：** 驼背的寄居蟹，背着一只装满藤壶浆的木桶，一只钳子是抹刀。
   - **能力"藤壶壳"：** 每 7 秒给 2 格内最近的、没有壳的另一个敌人抹上一层藤壶壳：
     - 壳吸收 120 伤害，打破为止；
     - 带壳期间，身上的浸湿立即消失，也不会再被浸湿；
     - 灼热对壳造成三倍伤害。
   - **画面：** 抹壳时，一团灰白浆从桶里甩出，落在目标身上，硬化成一簇簇藤壶。壳有自己的小护盾条。
   - **动画：** 走路摇摇摆摆。死亡时木桶翻倒，藤壶浆洒一地，随即干掉。

| Boss | 出场 | 生命 | 护甲 | 速度 | 攻击 | 阻挡占用 | 到达出口扣净泉 | 击杀奖励 |
|---|---|---|---|---|---|---|---|---|
| 锈母 | 白盐坡第 14 波；沉钟盐窟第 11 波 | 7000 | 45% | 0.35 | 120 / 2.5s，并波及相邻格的塔 | 3 | 10 | 盐晶 20、闸印 3 |
| 潮钟 | 铜潮渡口第 15 波 | 9000 | 30% | 0.3 | 80 / 2.0s | 3 | 10 | 盐晶 25、闸印 3 |
| 渊冕 | 沉钟盐窟第 16 波 | 14000 | 35% | 0.3 | 150 / 2.5s | 4 | 10 | 盐晶 30、闸印 4 |

**Boss 的通用规则：**
- **阻挡：** Boss 只会被剩余阻挡名额不少于它的阻挡占用的塔挡住。名额不够时，它把这座塔挤开走过去，并对它造成 100 伤害。
- **免疫：** Boss 不受眩晕和麻痹。盐壳对它的减速减半。
- **血条：** Boss 出场后，画面顶部中央出现大血条，下面列出它的能力图标和每个能力的冷却。

#### 2.7.1 锈母

- **外观：** 一只房子大小的巨蟹，约 2.5 格宽。背甲上驮着一座锈蚀的灯塔灯室和几块船壳钢板，像一顶王冠。一只大钳是船锚，眼睛是炉火般的橙光，甲缝里不停渗出卤水。
- **行走：** 每一步都让镜头轻微震动，脚下扬起盐尘。

**能力：**

1. **掀闸**（与闸位有关）
   - 每 18 秒，选离它 4 格以内（直线距离）最近的、被占用的闸位。
   - 预警 3 秒：闸位上出现红色锚形标记和收缩的圆环，锈母举起锚钳。
   - 然后砸下：闸位上的塔受到 400 真实伤害；闸位上的闸板直接粉碎。
   - 塔被砸毁时，闸位立即解除占用，路线改道。
   - 4 格内没有被占用的闸位时，这次不发动。
2. **锈潮召**
   - 生命降到 2/3 和 1/3 时，背壳打开，放出 4 只锈螺，落在它四周的可通行格上。
3. **重甲**（被动）
   - 即上面的通用免疫。

**动画：**
- 攻击：横扫大钳。
- 死亡：缓缓瘫倒，背上灯室的灯闪几下熄灭，甲壳裂开流出卤水。

#### 2.7.2 潮钟

- **外观：** 一只钟形的巨型水母状软体，约 2 格宽、2.5 高。半透明的伞盖里裹着一口青铜古庙钟，用一丛粗触手在地上"走"。伞盖边缘垂着发青光的丝。
- **行走：** 伞盖一张一缩，古钟随之摇晃，偶尔自己"当"地一响。

**能力：**

1. **钟鸣筑礁**（会改变通行情况）
   - **触发：** 每 22 秒发动一次。
   - **选格：**
     - 范围：它前方 6 格行程以内、任一入口当前路线经过的普通道路格；
     - 排除：闸位、入口、出口、有塔或道具的格子；
     - 从中选相邻的 2 格，优先选能让最多入口改道的位置；
     - 选格前先确认这 2 格变成不可通行后，所有入口和所有地面敌人仍有路。
   - **预警 3 秒：**
     - 这 2 格地面裂开，冒出珊瑚尖，叠加倒计时环；
     - 两格从预警开始就不再计入路线；
     - 正在格上的敌人沿新路线走出去。
   - **成墙：** 3 秒后两格隆起珊瑚墙，持续 15 秒，墙上有倒计时，结束后碎裂塌回地面。
   - **找不到合格的位置：** 这次改为在相同位置铺 15 秒卤滩，不封路。
2. **回响**（作用于塔和道具）
   - 每 12 秒，以自己为中心发出半径 3 的声波环。
   - 范围内的塔：护盾全部消失，技能充能减少当前值的 25%。
   - 范围内的闸板：受到 150 伤害。
   - 画面：一圈青铜色的波纹扫过地面，被影响的塔身上闪一下裂纹光。

**动画：**
- 攻击：触手鞭打。
- 死亡：伞盖萎缩，古钟坠地，裂开一道缝，最后一声闷响。

#### 2.7.3 渊冕

- **外观：** 一条巨大的锈蚀海蛇。身体约 3 格长，蜿蜒前进。头上的冠由熔在一起的盐柱和几口小沉钟组成，身体是一节节锈甲板，腹部透出青光。
- **体积：** 身体后段会随头部沿路线拖行，占住视觉上的 3 格；判定以头部为准。

**能力：**

1. **溶冠**（与地形有关）
   - 头部 2 格内的盐柱，在 3 秒预警后溶成卤滩，规则同蚀盐蠕。
   - 预警时，冠上的盐晶亮起，目标盐柱出现裂纹和倒计时。
2. **涨渊**（会改变通行情况）
   - **触发：** 每 26 秒发动一次。
   - **选段：**
     - 选它当前路线将要经过的那一段湖岸：西岸（6,7）（7,7）（8,7）、南岸（9,8）–（9,14）、东岸（5,15）–（8,15）、北岸（4,8）–（4,14），闸位和有塔的格子除外；
     - 若这一段变成不可通行会封死任何入口或地面敌人，改选离它次近的一段；
     - 四段都不行时，这次不发动。
   - **预警 3 秒：** 湖水沿那段湖岸上涨，岸边水纹翻涌，叠加倒计时。
   - **成水：** 3 秒后那段湖岸成为"渊水"，持续 12 秒，不可通行，有倒计时，结束后水退。
3. **唤鳗**
   - 生命降到 60% 和 30% 时，从湖里各唤出 6 只潮影鳗，跃上最近的湖岸格。
   - 它们落地时身带浸湿，所以一出来就能滑过阻挡。

**动画：**
- 攻击：昂头扑咬。
- 涨渊：仰起上身，朝湖面长啸。
- 死亡：身体盘起，缓缓沉进地面，冠上的盐柱逐根碎裂。

**外观：**
- **闸板：** 一块带铁箍的厚木板。放置时从空中落下，插进两根闸柱之间。

- **雾网：** 一团白雾在空中展开成渔网形状，网眼发微光。网的地面投影有虚线圆和剩余时间。

- 闸板是唯一能放在闸位上的道具。
- 闸板放下、到期、被打坏、被叼走，都会改变通行（见 2.12）。
- 卤水桶和倒灌改变的是行程，可能让敌人自己换路，但不会让任何格子变得不可通行。

- 护盾：一层半透明的多面盐晶薄壳，吸收伤害时出现裂纹。
- 嘲讽：盐垒卫技能，敌人头顶出现指向盐垒卫的小盾标。

**状态的通用规则：**
- 状态一经施加就与来源无关。来源被撤下或摧毁，已施加的状态照常持续到时间结束。
- 持续区域效果随来源离场立即消失，包括熔盐池和倒灌的卤滩。
- 敌人带着状态改道，状态不变。
- 走进卤滩重新获得浸湿；走上干卤床不会浸湿。
- 敌人头顶的状态图标排成一行，每个图标外圈是剩余时间。

| 叉钩落鸥 | 鱼叉炮 + 铜钩手或熬卤炉 | 飞行敌人坠地 | 铜钩手的钩回能把它拖到面前一格（它仍然不可阻挡，坠地结束后从那里起飞，航线从新位置直指原出口）；熬卤炉能炮击它 | 塔与塔 |
| 盐闸泼卤 | 铁闸 + 铜线圈 | 敌人攻击铁闸 | 攻击者浸湿，被铜线圈导电麻痹，砸闸被打断 | 闸位 |
| 倒灌沸卤 | 排潮泵倒灌 + 铜线圈或熬卤炉 | 倒灌把一段道路变成卤滩 | 整段路上的敌人浸湿，接着导电或结壳；熔盐泼落在这段卤滩上变成沸卤 | 地形改变 |

**画面：** 每种配合效果触发时都有单独的表现，并飘出两字标签（导电、结壳、碎壳、回卷）。
- **导电：** 一串跳跃电弧在敌人之间连成网，脚下的水面泛起一圈蓝光。
- **结壳：** 一团白色蒸汽"噗"地冒起。
- **碎壳：** 白色晶片向四周炸开。
- **回卷：** 敌人脚下卷起一小圈水花。

- **闸印：** 稀缺，每局总收入约 30–40，主要花在落闸、分支和道具上。一枚闸印就是"一次改道"或"一次道具"。

**改道的代价：**
- 每次在闸位上落闸都要花 1 枚闸印。
- 闸位被释放后有 6 秒复位冷却，期间不能再次占用。

- 被摧毁：不退款，卡片进入 30 秒"修复"（花 1 闸印可跳过），已升的等级作废。

### 2.12 改道与通行规则

1. **路线怎样得出。**
   - 每个入口有一条地面路线：从入口到出口行程最短的路线。一格卤滩算 5/3 格。
   - 有多个出口时，去行程最短的出口。
   - 场上每个地面敌人从自己当前所在的位置，按同样规则求自己的路线。
   - 拾荒鸥的路线是从入口到规定出口的直线，不随通行变化。
2. **通行因什么改变。** 下面这些事都会触发"通行变化"：
   - 在闸位上部署或撤下塔；闸位上的塔被摧毁；
   - 放下闸板；闸板到期、被打坏、被叼走；
   - 排潮泵部署、升级、撤下、被摧毁（排潮生效或回潮）；
   - 蚀盐蠕和渊冕溶掉盐柱；
   - 潮钟筑礁和渊冕涨渊的预警开始、成墙或成水、结束；
   - 卤水桶、倒灌的开始和结束：这些不改变能否通行，只改变行程，按同样流程重算。

   普通道路上的盐垒卫和铜钩手只阻挡，不改变通行；路线照常画过它们所在的格子。
3. **改道。** 每次通行变化发生的那一刻：
   - 所有入口的路线重算，画面上的路线同步更新；
   - 场上每个地面敌人从当前位置重算路线，继续前进；
   - 之后出发的敌人按新路线走；
   - 凡是以路线或剩余行程为依据的规则都按新路线重算，包括：塔的选目标、破闸鳌和蚀盐蠕的决策、潮钟和渊冕的选格、闸前回卷的判定。
   - 同一刻发生的几件事，例如两座闸位上的塔同时被砸毁，合在一起只重算一次，结果按全部变化之后的通行情况。
4. **格子变得不可通行时，格上的敌人怎样处理。**
   - **闸位：** 格内有地面敌人时，不能在上面部署塔或放闸板，提示"闸下有敌"。其余情况立即占用；正要踏进这一格的敌人就地转向。
   - **其他会变得不可通行的格子：** 包括回潮的干卤床、珊瑚墙、渊水。
     - 先进入 3 秒"封闭中"：格子从这一刻起不再计入任何路线，正在格上的敌人沿新路线走出去；
     - 3 秒后，空了的格子立即封闭，还有敌人的格子等到敌人离开再封闭，画面显示"等待清空"。
   - 任何敌人都不会停在不可通行的格子里，也不会穿过它。
5. **禁止封死。** 任何时候，每个入口和场上每个地面敌人都要有通往出口的路线。
   - 在闸位上部署塔或放闸板、部署或升级排潮泵、撤下排潮泵时，若操作后会让某个入口或某个地面敌人无路可走：
     - 预览时就标红，并直接指出会被封死的入口（入口旗闪红）或敌人（敌人头顶出现红色叉）；
     - 松手不生效，不扣任何资源，并提示"这样会封死入口 B"或"会困住 3 个敌人"。
   - "封闭中"的格子按已经封闭计算。
   - 拾荒鸥的位置不参与这项判断。
6. **排潮泵离场与回潮。**
   - **撤下：** 撤下排潮泵时，它抽干的格子回潮。回潮要经过上面第 4 条的"封闭中"。会造成封死的撤下不能完成。
   - **被摧毁且回潮会封死：** 被抽干的格子变成"淤床"，原样保持可通行。淤床上插一根歪倒的木标，显示"淤床滞留"。
     - 之后每次通行变化都重新检查；
     - 一旦回潮不再会封死，淤床开始 3 秒回潮。
   - **两座泵抽干同一格：** 两座都离场后才回潮。
7. **阻挡与改道。**
   - 改道后，阻挡塔只阻挡路线经过它所在格的敌人。
   - 被阻挡的敌人遇到改道：新路线仍经过这座塔的格子，就继续被挡；新路线不再经过这一格，它立即脱离阻挡，沿新路线离开。
8. **不能靠反复开关拖住敌人。**
   - 每次占用都花闸印；
   - 每次释放后有 6 秒复位冷却；
   - 迷途有 10 秒免疫。
   - 因此不能几乎零成本地反复开关同一个闸位。敌人改道只按真实的通行变化发生，不会自己来回折返。

### 2.13 战斗规则

1. **阻挡。**
   - **阻挡的触发：** 盐垒卫和铜钩手站在道路格上。地面敌人沿路线走进它们的格子时，如果它们剩余的阻挡名额不少于这个敌人的阻挡占用，敌人就停在格子边缘与之交战，并占去相应名额。
   - **名额不够时：** 名额不够的敌人直接走过；Boss 的情况见 2.7。
   - **释放：** 阻挡塔被摧毁或撤下的那一刻，被它挡住的敌人立即按当时的路线继续前进。
   - **画面：**
     - 阻挡塔头顶有一排名额点，实心是已占，空心是剩余；
     - 被挡的敌人与塔之间有一条短而细的暖金连线；
     - 阻挡开始时连线"啪"地出现，解除时断开。
   - **在闸位上：** 盐垒卫站在闸位上时，闸位不可通行，它不阻挡任何敌人，改为盾击相邻 4 格内的地面敌人。
2. **敌人选目标。** 规则写进图鉴：
   - 近战敌人（锈螺、钳卒、潮影鳗、蚀盐蠕、藤壶工、Boss）只攻击正在阻挡它的塔；
   - 喷卤蛞：见 2.6；
   - 破闸鳌：被阻挡时打阻挡者，否则在破闸状态下打目标闸位；
   - 嘲讽期间，1.5 格内的喷卤蛞和破闸鳌改打盐垒卫；
   - 目标被摧毁、撤下、离开射程，或敌人改道后，立即重新选目标；
   - 拾荒鸥不攻击塔。
3. **伤害、护盾与治疗。**
   - 伤害先扣护盾，再扣生命。护甲只减少扣生命的部分；真实伤害无视护甲。
   - 治疗和急修铆都不会让生命超过上限。
   - 护盾不叠加，重复获得时取较大值并刷新时长。
4. **技能充能。**
   - 受击充能只在塔实际受到攻击时增加，被护盾吸收的伤害也算。
   - 治疗、时间、命中、击杀各按表中规则充能。
   - 塔离场后，它的充能和持续效果不残留。
5. **塔被摧毁。**
   - 生命归零的一刻，判定为摧毁。
   - 播放 0.8 秒摧毁动画，残骸 2 秒后消失，残骸不挡路，不影响通行。
   - 闸位上的塔被摧毁时，闸位立即解除占用。
6. **到达出口。**
   - 敌人踏进出口格的一刻扣净泉，然后消失。
   - 泉门闪一下红光，飘出"−1"。
7. **时间。**
   - 攻击、命中、状态、技能充能、各种冷却、闸印计时、盐晶增长，都按游戏时间计算；
   - 暂停时一同停止；放慢和加速时一同变化。

### 2.14 经济流程与波次

**波次计时：**
- 开局有 25 秒准备，可以点"开潮"立即开始第 1 波。
- 每波开始后，过了表中"波长"秒数，下一波自动开始，不需要等场上清空。
- 玩家可以点"提前召潮"立即开始下一波，奖励盐晶 = 剩余秒数 ÷ 4，向下取整。
- 最后一波在全部敌人被消灭或到达出口后结束，结束即胜利。

**速度：**
- 可选 1×、2×、3×，默认 1×。
- 可以暂停。暂停期间可以查看一切，也可以部署、升级、撤下、放技能、用道具。这些操作立即生效，路线立即更新；敌人在恢复后从当前位置按新路线行进。

**一局时长：** 按默认速度、不提前召潮计算。
- 白盐坡约 25 + 575 + 末波约 80 = 680 秒，约 11.3 分钟；
- 渡口约 25 + 680 + 90 = 795 秒，约 13.3 分钟；
- 盐窟约 25 + 705 + 110 = 840 秒，约 14.0 分钟。

**表格写法：**
- 写作"入口：敌人×数量（第 t 秒起，每 Δ 秒一只）"。不写起始时间的，即从第 0 秒起。
- 带 ★ 的是该敌人在本图第一次登场。登场时，屏幕右侧滑出它的说明卡。

### 2.15 系统联动情境

下面每个情境都是一局中会实际出现的局面，写清楚各系统按什么顺序、以什么结果联动。这些情境同时是检验系统正确性的抽查路线。

1. **白盐坡·关①把 A 压到东坡**
   - **局面：** 第 7 波，A 的 3 只喷卤蛞正走在西坡路第 3 行，玩家在①（4,6）放下木闸桩。
   - **扣费与占用：** 扣 6 盐晶、1 闸印，闸柱升起。
   - **改道：** A 的路线从①处折回北桥。旧路线变灰淡出，新路线 0.8 秒内从（2,6）画过北桥，再沿东坡路画到泉门，A 入口旁弹出"A 改道"。
   - **掉头与迷途：** 三只喷卤蛞的新路线要从（3,6）掉头北上，三只都获得迷途。东坡高台上的潮弩台按新的剩余行程重新排序目标。
   - **闸印计时：** 40 秒后，①产出 1 闸印，闸位上飘出铜印图标。
2. **破闸鳌砸闸，闸倒路开**
   - **判定破闸：** 接上例。第 9 波 A 的破闸鳌出发，计算两条路线：
     - 现在的路线：经北桥、东坡，行程 24；
     - 破闸路线：直穿①，行程 14。
     短了 10 格，①离它 4 格，于是进入破闸状态。红虚线连到①，①亮起"被盯"。
   - **砸闸：** 它走到（3,6）开砸，每下 60 × 3 = 180，经木闸桩 40% 护甲后实扣 108。木闸桩的倒刺每下回敬 10。
   - **闸倒：** 约 18 秒后，木闸桩被砸毁。同一刻：
     - ①解除占用，闸印计时清零；
     - 木闸桩卡片进入 30 秒修复；
     - A 的路线改回西坡；
     - 走在北桥上的 A 敌人从当前位置重算：有的掉头回西坡，有的已过桥、离东坡更近，继续沿东坡走。
   - **另一种结局：** 如果①上放的是铁闸，破闸鳌每砸一下自己就浸湿 2 秒。射程内的铜线圈打到它时触发麻痹，砸闸被打断，计时重来；同时导电会跳到它身边其他浸湿的敌人。
3. **封死被拒绝，排潮泵让它变得可行**
   - **被拒绝的操作：** 白盐坡上①已关，玩家又把盐垒卫拖到②。预览显示 A、B 两条路线都画不出来，②的铜板变红，A、B 两面入口旗闪红，提示"这样会封死入口 A、B"。松手不生效，不扣资源。
   - **打通渠底：** 玩家在泵亭台（0,9）部署排潮泵，朝南。预览显示（2,9）（3,9）将被抽干。部署后，这两格水位降下，露出盐泥。再花 20 盐晶升到 2 级，（4,9）（5,9）也被抽干，渠底路打通，A 的路线立即改走渠底。
   - **两闸同关：** 此时再把盐垒卫放到②，预览通过：A、B 都走渠底路，经中浅滩进入西坡下段。
   - **撤泵被拒：** 选中泵点撤下，预览显示渠底回潮后 A、B 无路，撤下被拒绝，按钮上写"撤下会封死入口 A、B"。
   - **泵被摧毁：** 喷卤蛞把泵打掉。渠底四格变成"淤床滞留"，路线不变。
   - **重新回潮：** 之后玩家撤下②上的盐垒卫，B 的路线回到东坡。系统检查发现回潮已不会封死，于是：
     - 淤床进入 3 秒"封闭中"；
     - 正走在渠底的 A 敌人沿新路线走出来，回到北桥或中浅滩；
     - 最后一只离开后，四格回潮成卤沟。
4. **渡口·关②把两路送往西门**
   - **改道与换出口：** 铜潮渡口第 10 波，C 的两只破闸鳌和藤壶工正走向中浅滩，B 的喷卤蛞在北码头路上。玩家在②（9,11）放盐垒卫：
     - C、B 两条路线都折向西桥，出口由 Y 换成 X；
     - 入口旁分别弹出"C 改道 → 出口 X""B 改道 → 出口 X"；
     - 原来通往 Y 的路线段变灰，X 的泉门亮起"来袭增加"的提示。
   - **破闸鳌的判断：** 破闸鳌计算破闸路线：直穿②，比现在的路线短 7.7 格，②离它约 4 格，于是开始砸②。玩家对盐垒卫放结晶反壁：
     - 受到伤害 −60%；
     - 破闸鳌受到 30% 反伤；
     - 1.5 格内的喷卤蛞也改打盐垒卫。
   - **回响：** 到了第 15 波，同样的布置会遇到潮钟。潮钟在②的 3 格内时，回响会清掉守灯塔给盐垒卫的护盾，并扣掉盐垒卫当前技能充能的 25%。
5. **东仓台造渡改变全图流向**
   - **东渡：** 玩家在东仓台（4,17）放排潮泵，朝南。（6,17）（7,17）抽干后，B 的路线从"西行到中浅滩"改为"直接过东渡去 Y"，行程从 26.3 降到 17。中浅滩上只剩 C。
   - **代价：** B 更快到达 Y。
   - **好处：**
     - ①②、③⑤、④⑥不再互斥，最多可同时关 5 个闸位；
     - 关②时只有 C 改道，B 不受影响。
6. **拾荒鸥叼走闸板**
   - **放板：** 白盐坡第 11 波，玩家在⑤放了一块闸板，A、B 分别走西泽和东绕路。
   - **叼板：** A 的拾荒鸥航线正好掠过⑤上方。到达⑤前 1 秒，闸板上出现红爪印和 2.5 秒倒计时；拾荒鸥在⑤上方悬停，放下钩爪。
   - **两种结局：**
     - 玩家用鱼叉炮把它打成坠地：它坠到正下方，这次叼板作废，闸板保住。坠地 3 秒内，正前方 3 格内正对着它的铜钩手能用钩回把它拖到面前，熬卤炉也能炮击它。
     - 没打下来：闸板被叼走，⑤解除占用，A、B 同时改回泉门路，已经在西泽和东绕路上的敌人就地转向。
7. **卤水、电、热的连锁**
   - **浸湿与导电：** 白盐坡关③后，A 的钳卒群涉中浅滩，全员浸湿。东坡高台上的铜线圈打到其中一只，电弧在所有相距 2 格以内的浸湿钳卒之间连成网，每只麻痹 0.8 秒，过载充能 +3/只。
   - **结壳：** 熬卤炉的盐渣弹落进去，被灼热的浸湿钳卒"噗"地冒白汽，结成盐壳：速度只剩三成，护甲减半。
   - **碎壳：** 下一道电弧把盐壳打碎，每只受 120 真实伤害，碎晶溅到相邻格的同伴。
   - **藤壶壳打断连锁：** 如果队伍里有藤壶工，它抹上壳的那只钳卒浸湿立刻消失，不再导电。此时熬卤炉的灼热对壳造成三倍伤害，先把壳烧掉。
8. **潮影鳗与潮镰的取舍**
   - 铜钩手选了潮镰分支后，横扫会让被挡住的潮影鳗浸湿，下一刻鳗就从它身边滑过去；而锈螺和钳卒照样被挡。
   - 玩家若想挡住鳗，就要把铜钩手放在卤滩之外、离卤滩至少 3 秒行程的位置（浸湿已过期），或者改选锚链分支。
9. **蚀盐蠕溶柱绕开封锁**
   - **溶柱：** 沉钟盐窟关④后，C 的路线改走东渗廊、环湖、钟下路去 X，行程 26。第 6 波 C 的蚀盐蠕出发，发现东廊盐柱（8,18）离它的路线 1 格，溶掉能省 12 格，于是走到（7,18）旁开始溶柱。紫虚线连到盐柱，盐柱出现 5 秒倒计时，淡紫色的预示路线显示溶掉后 C 将经（8,18）（9,18）（10,18）下到南矿廊去 Y。
   - **两种结局：**
     - 玩家用铜线圈麻痹它，进度清零；或用锚链分支的铜钩手挡住它，它就溶不了。
     - 溶成功：盐柱变成卤滩（溶穴），通行变化，C 的路线改走溶穴，④的封锁被绕开。
10. **潮钟筑礁不能封死**
    - **选格：** 渡口第 15 波，潮钟从 C 出发，走到中坡（8,11）时发动筑礁。前方 6 格行程内、各入口当前路线经过的普通道路格中，（10,11）（10,12）这一对是 C、B 去 Y 的必经段，封住它能让两个入口同时改道，于是被选中。
    - **合格检查：** 两格成墙后，C、B 还能经北码头路和西桥去 X，A 不受影响，没有封死，所以合格。
    - **成墙与改道：** 珊瑚尖在这两格冒出，3 秒倒计时，期间两格就不再计入路线。C、B 改走北码头路去西桥，出口换成 X，入口旁弹出改道提示。
    - **墙碎：** 15 秒后珊瑚墙碎裂，路线复原。
    - **不合格的情形：** 如果此时玩家已关了①，过河只剩中浅滩一处，封住（10,11）（10,12）会让三个入口都无路。潮钟就放弃这一对，改选（10,14）（10,15）这类只截断去 Y 的东段的格子：三个入口都改去 X，仍有路。
    - **找不到合格位置：** 改在原位置铺 15 秒卤滩。
11. **同一时刻多座闸位上的塔被摧毁**
    - **局面：** 沉钟盐窟第 11 波，锈母在钟下路附近，③和⑦上都有塔。锈母的掀闸只砸一个闸位，但第 13 波三只破闸鳌可能在同一刻砸毁③和⑦。
    - **同一刻的结算：** 两个闸位同时解除占用，两次闸印计时同时清零，两张卡片同时进入修复，路线只重算一次，按两者都打开后的通行情况。
    - **不会出现的情况：** 不会先按"③开、⑦关"算一遍，让敌人转一下向，再按都打开算第二遍。
12. **暂停中操作**
    - 玩家按空格暂停，在⑥上放闸板、升级排潮泵、给守灯塔放灯幕。
    - 暂停中这些操作都立即结算：闸板落下，闸位占用，路线重画，泵抽干新格，护盾出现。但护盾的 10 秒倒计时不走。
    - 恢复后，敌人从各自位置按新路线前进，护盾开始倒计时。
13. **切换标签页**
    - 浏览器标签页被切走时，游戏自动暂停。
    - 切回后，画面中央显示"已暂停"，玩家点继续或按空格才恢复。
    - 不会出现切回时一下子补算很长一段时间、敌人瞬移的情况。

     - 在场数"1/3"。
   - 卡片状态：
     - **可部署：** 铜框明亮。
     - **盐晶不足：** 卡片变暗，价格变红，底部写"盐晶不足"。
     - **整备中、修复中：** 灰色遮罩加扇形倒计时，写"整备 6s"或"修复 24s"。修复中的卡片右下有"1 闸印加速"小按钮。
     - **达到上限：** 写"已满 3/3"或"全场已满"。
   - 悬停时卡片抬起，并在上方浮出简短说明。
   - 快捷键：1–8 拿起对应卡片，Z、X、C、V 拿起道具。
4. **选中面板**（屏幕左缘或右缘）
   - 选中场上的塔时，面板从离这座塔较远的那一侧边缘滑入：塔在画面左半，面板就从右边出来。面板高度不超过屏幕的 60%，保证不挡住这座塔和它的作用范围。
   - **塔面板：**
     - 头像、名字、等级和分支；
     - 生命数值和条，护盾值叠在生命条上；
     - 护甲、攻击、间隔、范围、阻挡（已占/上限）、当前目标规则；
     - 技能：名称、说明、充能条和数值，"释放"按钮，充满时发金光；
     - 升级：1 级时显示升级按钮和价格。有分支的塔显示两张并排的分支卡，各写效果、价格（盐晶 + 2 闸印）、外观变化小图；
     - 闸位上的塔：额外显示闸印计时；
     - 底部"撤下"按钮：需要按住 0.8 秒，按钮上有进度条，并显示"退还 N 盐晶"；排潮泵、闸位上的塔还会预览撤下后的路线。
   - **敌人面板：** 生命、护甲、速度、阻挡占用、攻击、射程、攻击目标规则、能力说明，以及当前身上的状态（图标、名字、剩余时间）。Boss 另列能力冷却。
   - **地块面板：** 格子类型，能否通行，能部署哪些塔，当前状态（干卤床、淤床滞留、卤滩剩余时间、封闭中、闸位状态和闸印计时）。
5. **性能读数**
   - 按 F3，或在"设置"里打开，屏幕左下角出现一块小面板：
     - 帧率：近 1 秒平均；
     - 每帧耗时：近 1 秒的平均和最大，毫秒；
     - 场上对象数：敌人、塔、弹道、特效粒子，分项和合计。
   - 操作说明里写明查看方法。

#### 2.16.3 镜头

- **默认视角：**
  - 从南向北俯视，俯角约 55°，透视；
  - 入口在画面上方远处，出口在下方近处；
  - 整张地图完整落在界面之间的空白区域里。
- **操作：**
  - 左键按住拖动空地：平移；
  - 右键按住拖动：旋转视角。水平可绕地图中心转一整圈，俯角在 30°–80° 之间；
  - 滚轮：缩放；
  - 键盘：WASD 平移，Q、E 旋转。
- **回到默认视角：** 按 R 或点右上角的"归位"按钮，0.4 秒平滑回到默认视角。
- **点选与部署：** 镜头转到任何角度，点选和拖放都按鼠标下实际指着的格子判定。
- **拿起卡片：** 点击或开始拖动卡片时，镜头若不在默认视角，0.4 秒平滑回到默认视角，然后才能放下。

#### 2.16.4 部署流程

1. **拿起。** 按下卡片，卡片上浮。游戏进入放慢，时间流速 0.25：
   - 画面四周出现浅青色暗角，顶栏速度区显示沙漏和"缓时"；
   - 放慢在 0.25 秒内渐入，所有动画和特效一起变慢。
2. **拖动。**
   - 鼠标下的格子出现这座塔的半透明模型，模型吸附在格子上。
   - 这种塔能放的格子亮起青色描边；不能放的格子覆一层淡灰。
   - 范围预览：
     - 圆形和扇形范围画在地面上，用半透明的塔色；
     - 朝向类的塔先按默认朝向预览，默认朝向是面对最近的路线。
   - 拖到闸位上时：
     - 当前路线变暗到 50%；
     - 每个入口的预览路线用"白描边 + 入口色"的虚线画出；
     - 入口旁写"A：→ X，+10 格"之类的变化。
   - 拖到会封死的闸位上时：
     - 塔模型变红，闸位铜板变红；
     - 被封死的入口旗闪红，会被困住的敌人头顶出现红色叉；
     - 鼠标旁写"这样会封死入口 B"。
   - 排潮泵：预览将被抽干的格子（蓝色虚框加下降的水位图标）和抽干后的路线。
3. **放下。**
   - 没有朝向的塔，松手即确认部署。
   - 有朝向的塔（铜钩手、潮弩台、排潮泵），松手后进入"定向"：
     - 塔周围出现四个箭头，鼠标靠近哪个就朝哪个方向；
     - 范围和排潮直线随之实时更新，排潮泵同时更新路线预览；
     - 左键点击确认。
   - **取消：** 右键或 Esc，或拖回底栏后松手，都会取消。取消不扣任何资源。
   - **放到不能放的位置：** 不生效，鼠标旁说明原因：
     - "这里是高台，铜钩手只能放在道路上"；
     - "闸下有敌"；
     - "盐晶不足"；
     - "闸位复位中 4s"。
4. **完成。**
   - 扣费，盐晶和闸印数字跳动减少。
   - 塔从地面"长"出来：盐晶从格子里结晶升起，0.6 秒内拼成塔。落地有一圈尘环和一声沉闷的落地声。
   - 放慢在 0.25 秒内渐出。
5. **选中场上的塔。**
   - 同样进入放慢；
   - 塔脚下出现金色选择环，作用范围显示出来；
   - 点空地或按 Esc 取消选中，放慢结束。
6. **暂停时：** 以上操作都能做，不会再叠加放慢。

#### 2.16.5 其他界面

1. **图鉴**
   - 全屏覆盖，背景是虚化的战场。
   - 七个页签：塔、敌人、Boss、道具、状态、配合效果、地形。
   - 每个条目左边是可以拖动旋转的三维模型，右边是全部属性和说明：
     - 塔：每个等级、每个分支的属性和外观，技能；
     - 敌人：攻击什么目标、能力规则原文；
     - 地形：每种格子能否通行、能部署什么、与哪些塔和状态有关。
   - 未遇到的敌人显示剪影，名字写"未见"，但能力说明照常可读。
   - 暂停时可以打开。
2. **暂停菜单**
   - 半透明遮罩加中央的搪瓷面板。
   - 按钮：继续、重新开始、返回选关、图鉴、设置、操作说明。
   - "重新开始"和"返回选关"都弹出确认框："本局进度将丢失"，要再点一次红色确认按钮。
3. **Boss 登场**
   - 画面上下各滑入一条细黑边，持续 2 秒。
   - Boss 名牌从右向左横扫过画面中部，例如"锈母 — 锈潮之冠"，同时一声低沉的钟或号角。
   - 顶部 Boss 血条展开。
   - 不夺走镜头，不暂停游戏。
4. **结算**
   - **胜利：** 镜头缓慢拉高，泉门喷出一股清水，搪瓷面板写"淡泉无恙"。
   - **失败：** 泉门流出黑卤，面板写"淡泉失守"。
   - **统计：**
     - 用时，波次，剩余净泉；
     - 击杀数，按敌人种类列出；
     - 部署、升级、被摧毁的塔数；
     - 改道次数；
     - 闸印获得和花费；
     - 输出最高的塔；
     - 每个入口漏过的敌人数。
   - **按钮：** "再守一次"（重新开始本图）、"返回选关"。重开和返回都不刷新页面。

#### 2.17.2 动画的连续性

- **移动：** 敌人沿路线平滑移动，转弯时身体平滑转向，不在格子之间跳。
- **转身：** 改道掉头时，敌人先原地转身（0.3 秒）再走。
- **朝向：** 塔和敌人攻击时转向目标；潮弩台只在自己的扇形内转。
- **空间关系：**
  - 地面单位贴地。
  - 飞行单位离地 1.6，有地面投影；坠地时有下坠和触地动作。
  - 被高台或障碍挡住的单位，透过遮挡物显示一层描边剪影，生命条始终画在最上层。

#### 2.17.3 混战与加速时的可读性

- **路线：** 路线箭头带画在地面之上、单位之下，箭头流速随游戏速度加快。
- **特效：** 半透明，不遮挡生命条、状态图标、闸位状态。
- **合并显示：** 同一格内超过 3 个敌人时，它们的生命条横向错开排列。

## 三、题面草稿

### 3.0 组装方式

- **新题面的结构：**
  - 一、任务（下文 3.1）；
  - 二、游戏内容（下文 3.2）；
  - 三、要做到什么（下文 3.3）；
  - 四至七：运行环境、交付、规定、评分标准，保持现状。
- **表格的处理：**
  - 第二节正文中写着"【插入 x.x】"的地方，原样放入本文第二部分对应的表格或网格。
  - 数据表的内容就是游戏内容本身，用表格比用散文更准确，所以不改写成散文。
- **不进题面的内容：** 第二部分的 2.4.5（验算方法）、2.15（联动情境）和 2.18（对照表）。2.15 的要点已压缩进下文 3.3 的"必须正确的情形"。

### 3.1 一、任务

制作一款在浏览器中运行的三维塔防游戏《盐闸》。

- **玩法核心：**
  - 战场是三维的网格地图，地图自带地形。敌人沿可通行的道路自动寻路前往出口。
  - 地图上有若干"闸位"（关键点位）。在闸位上部署塔或放下闸板，就截断那一段道路，敌人只能改道。
  - 塔有生命值，敌人会攻击塔。闸位上的塔被摧毁后，道路重新打开，敌人的路线随之改变。
- **设计已给定：** 第二节给出这款游戏的完整设计，包括题材、美术、三张地图的布局、八种塔、八种敌人和三个 Boss、四种道具、状态与配合效果、两种资源、全部波次、界面与反馈。照这份设计把游戏做出来。
- **原创与素材：** 这是一份原创设计。实现中不得照搬现有游戏；模型、贴图、图标、特效和音效等素材全部由你自己制作。
- **两节的分工：** 第二节描述游戏的内容，第三节说明这些内容要做到什么、哪些情形必须正确。

本测试是 AI 模型能力竞赛。建议充分利用全部时间，把作品做到完成度尽量高、各方面都优秀。

### 3.2 二、游戏内容

**2.1 题材与一局游戏**

1. **题材：**
   - 海边制盐小镇"澜盐镇"靠镇下的淡泉活命。
   - 近海黑卤海沟涌起"锈潮"：由锈铁、卤水和贝壳长成的怪物，上岸去污染淡泉。
   - 玩家是镇上的"闸守"，用盐砖、铜、木和黄铜造的器械守住泉门。
   - 游戏内文字为简体中文，用盐场工人的口吻，短句。
2. **一局：**
   - **进图：** 玩家从关卡选择界面进入一张地图。默认视角下，整张战场完整可见：入口和出口，道路、高台和障碍，闸位，以及每个入口此刻的路线。
   - **来袭：** 每一波开始前，右侧"来袭预报"列出这一波的敌人和出发入口。
   - **部署：** 玩家把底部的塔卡片拖到地图上，放在道路、高台或闸位上；升级、选分支、放技能、用道具。
   - **落闸：** 在闸位上落闸会让敌人改道，有时还会改去另一个出口。落闸前能预览改道后的路线，会封死道路的操作不能完成。

### 3.3 三、要做到什么

第二节描述的每一项都要做到。多个系统同时起作用时，结果依然正确、一致。下列情形尤其要正确。

**3.1 区分与计数**
1. 塔、敌人、道具、升级分支、技能、配合效果的作用和行为，按第二节的描述实现。不能做成只有数值不同、作用相同的东西。
2. 三张地图的布局按第二节的网格实现，各自的环境主题清楚可辨。

**3.2 路线与通行**
1. 任何时候，每个入口和场上每个地面敌人都有通往出口的路线。因会封死而被拒绝的操作不扣任何资源。
2. 每张地图的默认路线，以及在其余闸位空闲时单独占用每个闸位后的路线和出口，与 2.4 各图的闸位表一致；表中的互斥组合会被拒绝。排潮泵抽干、盐柱溶掉后的路线变化，与表中描述一致。
3. 预览与操作后的实际结果一致。
4. 改道时，敌人不瞬移、不穿过不可通行的格子、不卡住，也不会无故来回往返。格子变得不可通行时，按 2.10 第 4 条处理，不出现敌人停在里面、从上面穿过或凭空消失。
5. 敌人实际走的路线与画面上显示的一致，经过卤滩、干卤床、溶穴时同样如此。拾荒鸥的航线与它实际的飞行一致，不随通行变化。

**3.3 同时发生与结算**
1. 几个通行变化在同一时刻发生时（例如两座闸位上的塔同时被砸毁），占用解除、闸印计时、卡片修复和路线重算都正确，路线只按全部变化后的结果重算一次。
2. 撤下或摧毁闸位上的塔或排潮泵、闸板被叼走或打坏时，资源结算与通行变化同时发生，不重复、不遗漏。
3. 不存在几乎零代价反复开关同一闸位、让敌人来回折返的打法。

**3.4 战斗与状态**
1. 敌人攻击哪座塔，与 2.11 第 2 条和图鉴一致；不会继续攻击已经不存在的塔，也不会攻击射程以外的塔。
2. 生命值不超过上限；护盾不叠加。
3. 受击充能只在塔实际受到攻击时增加；塔离场后，它的技能和持续区域效果不残留。
4. 以下情形的结果都符合 2.8 的规则：
   - 同一状态重复施加；
   - 浸湿和灼热结壳；
   - 盐壳被电碎；
   - 藤壶壳清除并阻止浸湿；
   - 麻痹抗性；
   - 敌人带着状态改道，或走进、走出卤滩；
   - 潮钟的回响清除护盾、扣减充能。
5. 阻挡名额、潮影鳗浸湿时滑过、Boss 名额不够时挤过、被阻挡的敌人遇到改道，都按 2.11 第 1 条和 2.10 第 7 条处理。

**3.5 时间与重开**
1. 攻击、状态、充能、冷却、闸印计时、盐晶增长和波次计时都按游戏时间计算，暂停时一同停止，放慢和加速时一同变化。
2. 3 倍速时规则和判定与 1 倍速一致：敌人不会因为速度加快而穿过刚变得不可通行的格子、跳过格子，或越过出口却不扣净泉。
3. 暂停期间的操作在暂停中立即结算；恢复后，敌人按新路线前进。
4. 快速连续操作时，不出现重复扣费、重复结算或状态错乱。
5. 浏览器标签页切走时自动暂停，切回后不出现敌人瞬移、判定跳过或波次错乱。
6. 重新开始或返回选关后，新的一局不残留上一局的敌人、塔、状态、计时、资源或路线。

**3.6 画面**
1. 看不出拼凑的痕迹，没有未完成或占位的部分；所有控件都经过设计。
2. 塔、敌人、弹道和特效处在正确的位置和高度。地面单位不悬空、不陷地，飞行单位离地并有投影；被遮挡的单位仍能看出位置和生命值。
3. 敌人的移动、转向和攻击，塔的攻击、技能和被摧毁，都是连续的动画。不能是静止模型平移、图标在格子间跳动，或只靠缩放、闪烁表示动作。
4. 画面表现与判定一致：攻击命中、状态生效、塔被摧毁、敌人到达出口、通行变化的表现，出现在判定实际发生的时间和位置。
5. 混战和 3 倍速时，以下内容依然清楚：
   - 路线、闸位状态；
   - 塔和敌人的生命与状态；
   - 阻挡关系；
   - Boss 和来袭信息；
   - 顶栏常驻信息。
6. 同一种塔、敌人、资源和状态，在卡片、图鉴、面板和场上的形象与图标一致。

**3.7 说明与实际一致**

图鉴和面板里每种塔（含等级、分支、技能）、敌人（含攻击目标和能力规则）、Boss、道具、状态、地形和配合效果的说明与属性，都与游戏中的实际表现一致。升级或选择分支后，显示的属性随之更新。

**3.8 必须正确的关键情形**

以下情形评审会实际操作检查：
1. 白盐坡：
   - 单独关①、③、⑤时的改道和迷途；
   - ①②被拒绝；
   - 泵升 2 级后①②可以同时关；
   - 撤泵被拒绝；
   - 泵被摧毁后淤床滞留，条件解除后回潮，渠底的敌人先走出来再回潮。
2. 破闸鳌按破闸规则选闸、砸闸；闸倒的一刻占用、计时、卡片、路线同时结算；铁闸配铜线圈能打断砸闸。
3. 渡口：
   - 关②或③时，C、B 改去 X；
   - 东仓台造渡后，B 改走东渡，原本互斥的组合变得可行；
   - 潮钟筑礁在会封死时改选其他格子。
4. 拾荒鸥叼走闸板，以及被坠地、打死时叼板作废。
5. 盐窟：
   - 关④后，蚀盐蠕溶东廊盐柱，溶前有预警和预示路线，溶后 C 改道；
   - 麻痹或锚链能阻止溶柱；
   - 渊冕涨渊不会封死。
6. 浸湿 → 导电、浸湿 + 灼热 → 盐壳 → 碎壳，以及藤壶壳打断这条链。
7. 暂停中部署、升级、放技能，恢复后按新路线行进。

## 五、工作量与难度说明

### 5.1 规模

全部不低于现题面下限，多数明显增加，见 1.3 表。另有几项规模：
- **美术变体：**
  - 塔：8 种 1 级造型，加 11 个 2 级或分支造型，共 19 个可区分的塔模型状态；
  - 敌人：8 种普通敌人，3 个大体量 Boss；
  - 地图：3 套完全不同的场景与光照，晨、黄昏、地下夜景各一。
- **界面：** 关卡选择、战斗 HUD 五块区域、图鉴七个页签、暂停、Boss 登场、结算，另有性能面板。
- **音效：** 二十余种程序合成音效。这是新增工作量，是否保留见第六部分第 6 条。

### 5.2 耦合

难度的核心仍在耦合，而且每一处都写成了可以检验的具体结果：

1. **路线结果从"会改道"变成"按表改道"。** 现题面只要求单独占用会改道；本设计给出每个闸位改道后的确切路线和出口，以及互斥组合。寻路、行程计算（卤滩按 5/3）、多出口选择，只要有一处不对，就和表对不上。
2. **地形塔的完整生命周期。** 排潮泵的部署、升级（2 级才打通渠底）、撤下被拒、被摧毁后淤床滞留，滞留的条件解除后回潮（回潮前先清空格上的敌人）。白盐坡的泵亭台把这条链做成了必经的玩法：要同时关①②，必须用到它。
3. **四类敌人改变通行，各有规则：**
   - 破闸鳌：以路线差为依据决定砸不砸；
   - 拾荒鸥：叼走闸板，但航线固定；
   - 蚀盐蠕：以行程收益为依据溶柱；
   - 潮钟和渊冕：选格选段时要做封死检查，并且有备选。
   每一种都要和预览、改道、资源结算同时正确。
4. **资源与闸位双向挂钩。** 落闸花闸印，守住闸位产闸印，闸倒计时清零；修复可以花闸印跳过。破闸鳌和锈母因此直接打击经济。
5. **状态链横跨地形、塔和敌人能力：**
   - 卤滩、潮镰、铁闸、卤水桶、倒灌都能造成浸湿；
   - 浸湿通向导电、结壳、碎壳；
   - 藤壶壳清除并阻止浸湿；
   - 潮影鳗浸湿时滑过阻挡，所以潮镰对它是反效果。
6. **改道与战斗的接口：**
   - 闸前回卷：改道的一刻判定迷途；
   - 塔的选目标按新路线的剩余行程排序；
   - 被阻挡的敌人遇到改道的脱离规则；
   - Boss 需要的阻挡名额不够时挤过。
7. **时间与操作：**
   - 战术暂停中可以操作；
   - 放慢、加速、切页时自动暂停；
   - 多个变化同一时刻发生时只重算一次。

### 5.3 与现题面相比

- 规模不减，多数加大。耦合不减，而且由抽象条款变成具体的、能对照的结果。
- 受测模型省下了"想做什么"的时间，但要实现的内容和必须正确的情形都多于以前。按"限时高压、有的模型做不完"的定位，这个量是合适的。

## 六、需要用户拍板的点

1. **题材与名称。** 我选了"制盐小镇对锈潮"，游戏名《盐闸》。这个题材的好处是卤水、盐、铜、热天然能组成状态链，闸门天然对应关键点位。备选题材：运河水城对淤泥怪，或山地梯田灯会对雾魇，但都不如这个能把机制和题材咬合在一起。
2. **地图数量。** 题面下限是 2 张，本设计做了 3 张，其中盐窟最复杂。如果担心总量过大，可以只保留白盐坡和铜潮渡口，把盐柱、蚀盐蠕和渊冕并入渡口；但那样第三张图带来的"敌人溶穿封锁"就要另找位置。
3. **数值能否调整。** 建议：允许受测模型为平衡调整数值，但不得改变：
   - 任何塔、敌人、道具、状态的作用和规则；
   - 地图网格；
   - 波次构成；
   - 闸位表的改道结果。
   游戏内说明以实际数值为准。另一种做法是数值也锁死，评审对照表格抽查，但平衡问题就由出题人负责。
4. **地图网格是否原样规定。** 建议原样规定。这样"单独占用改道"可以直接对照闸位表评分，不必再判断"算不算另一条路"。
5. **暂停中可以操作。** 我选的是"可以"，这让暂停期间的变化如何生效成为必考项，难度更高。也可以改成"暂停只能查看"，降低一项难度。
6. **音效。** 现题面不要求声音；本设计加入了程序合成音效（2.17.1）。保留就增加工作量，也需要在评分的"画面与美术"或"信息呈现与反馈"里提一句。也可以删去声音这一列。
7. **闸印的产出机制。** "闸守满 40 秒产 1 枚"让守住闸位有收益，也让破闸鳌打击经济。代价是会鼓励玩家尽量多关闸位。备选：闸印只靠波次和精英击杀获得，闸位只花不产，这样更简单，但资源与改道的联系变弱。
8. **改变地形的塔用"排水"而不是"架桥"。** 排水的恢复（回潮）有画面过程，能自然地容纳"等待清空"和"淤床滞留"；架桥的恢复是收桥，表现上更突兀。如果更喜欢架桥，规则可以照搬。
9. **拾荒鸥兼任"会改变通行的敌人"。** 它叼走闸板，但航线固定，不随占用改变。这是为了同时满足"不受地形约束的敌人路线不随占用改变"和"有敌人改变闸位占用"。如果觉得一身二职不清楚，可以把叼板能力交给一种新的地面敌人。
10. **Boss 三个，锈母在盐窟重临。** 题面下限是 1 个。三个 Boss 的模型和能力工作量不小，可以按需删减。
11. **操作细节：**
    - 放慢倍率 0.25；
    - 速度档 1×、2×、3×；
    - 左键拖空地平移、右键拖旋转；
    - 撤下按住 0.8 秒；
    - 性能读数按 F3。
    这些都是我定的，可以改。
12. **题面篇幅。** 把第二部分的表格和描述全部放进题面，题面正文约 2.5–3 万字，是现在的 3 倍左右。可以接受，或者拆成"题面正文 + 设计附录"两个文件，一起交给受测模型。
13. **评分资料的连带修改（建议，不在本次范围）：**
    - "关卡与波次"和"系统正确性"两个方向，可以改成直接对照闸位表和 3.8 关键情形抽查；
    - "玩法与策略"里的"设定是否有创意"不再评受测模型，因为设计已经给定。这 4 分可以改评"设计还原度"，或并入其他分项。
