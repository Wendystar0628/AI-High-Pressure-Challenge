![初态与各零件](01.png)

图中两个初态视角使用同一坐标系。单件图保持初始朝向，坐标为该件局部坐标；标题列出初始位置。图像用于观察，下面的分层图与 JSON 提供精确占据关系。

## 初始装配分层图

字母表示对应零件，`.` 表示空位。横向是 x 正方向，行号按 y 正方向递增，各层按 z 正方向递增。
x = 0..5, y = 0..3；每行从 x 小到大，行按 y 从小到大。

z = 0
```text
     012345
  0  ......
  1  CCCCC.
  2  BBBBB.
  3  ......
```

z = 1
```text
     012345
  0  .DDDDD
  1  CCCDDD
  2  BDBBBD
  3  .DDDDD
```

z = 2
```text
     012345
  0  .AAAAA
  1  CAA.CA
  2  BA..AA
  3  .AAAAA
```

z = 3
```text
     012345
  0  ......
  1  CCCCC.
  2  BBBBB.
  3  ......
```
