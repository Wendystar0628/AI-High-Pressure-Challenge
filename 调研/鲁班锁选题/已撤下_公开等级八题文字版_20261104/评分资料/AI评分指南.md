# 鲁班锁拆解 · 评分指南

- 材料：受测作答目录里的题面 `鲁班锁拆解.md`、`题目\01.json`–`08.json` 和 `答案\第01题.json`–`第08题.json`；出题端参考路线见本目录 `标准解答/`，来源与基准说明见 `参考答案.md` 和 `references.json`。
- 判定：用本目录的 `check.py` 和出题端原始题目检查整棵拆解树。完整合法拆解才得分，接受任何合法路线。
- 路线要靠推理找出。先读受测会话记录：运行题目自带的 `题目/工具/check.py`（路线检查器）和 `题目/工具/positions.py`（位置记账）是允许的；自己编写或运行程序来搜索路线、模拟移动、计算碰撞，使用求解器，或改动这两个工具，都算违规，这样的作答记 0 分，在 notes 写明依据。几何检查器只判断路线，不能代替对工具使用的检查。

## 计分

合法完整路线记步数 N。每题的基准步数 B 是 `references.json` 中该题的 `best_moves`，由出题方在看过本轮结果后确定，确定后固定不变。每题得分为 `w × min(1, B / N)`，w 为该题分值：步数等于 B 得满分，比 B 少也只得满分。没有完整合法解记 0 分。分项保留两位小数，总分用未舍入的分项求和后保留两位小数。

计步按题面规则：同一组零件沿同一轴、同一方向连续移动计一步，距离不限；接着沿同方向移出到无限远合并计一步；分开后的两个组件分别计步。同形件编号按数据判定，框架也要拆开。不另按首次分离、解释文字或代码给分。

## 运行

`grade.py` 可以一次评一个或多个作答目录，目录是包含 `答案/` 的题目工作目录，输出各题是否合法、步数、得分和总分：

```powershell
python grade.py <作答目录> --output 评分.json
```

缺失某题只影响该题。文件名略有出入时可以人工找到对应答案后再检查，核心内容按题面协议。结果文件的 items 用“第01题”至“第08题”作分项名，max 填该题分值。
