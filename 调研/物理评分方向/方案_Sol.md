## 2. 为什么这样分

### 2.1 四个维度分别回答什么

| 维度 | 独立判断的问题 | 能与其他维度分开的例子 |
|---|---|---|
| 现象形态与运动层次 | 形状、传播、振动和轨迹实际展开到什么程度？ | 球的反弹关系成立，但果冻只出现很浅的坑、各部位同步缩放；作用关系与形态表现会得到不同评价。 |
| 材质与光影 | 已有几何与运动被怎样着色、透光和照亮？ | 同一组形变可以呈现胶体体积，也可以呈现不透明塑料；更换外观不会补出缺少的形变。 |
| 作用关系 | 运动是否对应当时的接触、密度和驱动状态？ | 波面起伏很多，但推板尚未运动就持续造浪，或球沿与水体无关的路径移动；可见形态与因果关系是两种事实。 |
| 演示与交付 | 观看者能否调用和控制这些内容，交付接口是否工作？ | 三种模式的形变可以很好，暂停或导出恢复仍可能有问题。 |

这里的独立是**评价的问题和事实归属独立**，不是要求作品的各项质量在统计上互不相关。同一段截图可以用于观察不同事实，但不能把“底球动得小”“高光遮住接触区”等同一句理由复制到几个小点。

没有再设“物理可信度”作为包住所有运动的方向，也没有保留横跨所有现象的“动态过程质量”方向。物理不是另加一层笼统印象分，而是明确落在五种作用关系中；形变、回弹、波浪和运动层次的可见展开，则获得独立而更高的分量。

### 2.2 视觉表现力拆成哪些可分别判断的事

A 项的八个小点，分别观察八种变化：**接触处的局部几何、远离接触处的整体轮廓、受压传播的到达先后、恢复振动的错时关系、入水瞬间的局部扰动、持续造浪的波面形态、不同深度的轨迹对比、停止输入后的振幅包络**。

这些差异不能用一个“形变很真实”或“水很漂亮”代替。例如，深坑很明显不证明侧面也有鼓出；整体变扁不证明有传播延迟；能弹回不证明各部位有错时振动；水面动得大不证明水中、底部形成不同的运动轨迹。小点因此能分别给分，而不是反复奖励同一个“大幅晃动”。

B 项把原来的“材质表现”拆开，是因为果冻、重球、玻璃、水体可以各自做得好或差。把四者装在 8 分的一格里，很容易以最显眼的果冻代表全部材料。灯光单看场景的明暗塑形，风格单看跨场景的一致性；取景与分组辨识也拆开，各 1 分。

表现力不等于幅度越大、球越多、白沫越多。评分看上述形态和时空层次；符合当前物性的克制运动也可以有清楚的层次。题面允许的轻缓波、定向流、沉底球滚动，不应被统一改成巨浪、湍流或离底跳跃。

### 2.3 最容易交叉的地方，具体归到哪里

| 同一演示中可能混评的内容 | 唯一归属 |
|---|---|
| 坑的形状、范围、边缘变化 | A1；不是 C1 的理由。C1 只看重球自身是否因接触改变运动。 |
| 压缩与侧鼓、不对称倾斜 | A2；不再另以“三种冲击差异”重复评价。 |
| 接触开始后，变形依次到达各处 | A3。 |
| 各处回弹不同步，多球时前后振动并存 | A4；不再另设“连续冲击叠加”分。 |
| 新冲击到来时旧振动仍存在 | A4；D1 只管阶段承接，不再次评价叠加效果。 |
| 球入水造成的局部波纹 | A5；A6 限于持续造浪阶段。 |
| 波峰波谷和传播中的形态变化 | A6；C3 只看扰动输入与装置运动的对应关系。 |
| 三层都在动，但底层运动难以辨出 | A7；不能因此再说 C4 的流体作用不成立。 |
| 球运动明显，却与当时水流无关 | C4；A7 不评价推动关系对不对。底部回流也不必与表层同向。 |
| 低密度上浮、中性悬浮、高密度沉底 | C2；A7 只看持续造浪期间的运动对比，不重复评价分层位置。 |
| 振幅逐次减小、最终停留 | A8；A4 不再评价衰减，D1 不再评价归稳的质量。 |
| 球与果冻穿透、失去接触仍被反弹 | C1；C5 只管刚体之间及刚体与硬边界。 |
| 果冻的透光深浅、水的表面反光 | B1、B4；不把这些外观当作几何变化。 |
| 高光、反射或界面遮住关键事件 | B7；不能仅凭遮挡推断 A 项所需的几何或运动不存在。 |
| 球色被水下阴影改变到难以分组 | B8；B5 评价光线塑形，不再以分组辨识为理由。 |
| 参数按钮能改、运动确实改变 | D3；改变后的接触或浮沉关系是否合理，分别归 C 项。 |
| 多球待释放时重球被裁切 | B7；不再次作为 D4 导出接口的缺陷。 |
| 调用导出 end 后物体消失、操作未恢复 | D4；不再次作为 D2 的常规重置问题。 |

共享条件不形成额外分数。例如，某种模式能触发属于 D2，触发后出现怎样的形状属于 A 项，不能再增设“模式齐全分”。也不设跨方向的“稳定性”大项，把已有的接触、衰减、操作恢复重新评一遍。

### 2.4 分数怎样变化

| 现行方向或分项 | 现行分值 | 推荐处理与新分值 |
|---|---:|---|

| 动态过程 | 23 | 不再成方向。三模式的形态差别归 A2—A4；三层动态归 A7；阶段衔接 7→D1 的 2；运行控制与调参 3→D2、D3 合计 4。 |
| 材质表现 | 8 | 拆成果冻 6、重球 3、玻璃 3、水体 4，合计 16。 |
| 灯光与背景 | 6 | 光照塑形 4；背景的跨场景一致性归 B6，不为背景装饰数量另给分。 |
| 统一风格 | 4 | B6 为 2。 |
| 构图与可读性 | 10 | 撤销方向。关键过程取景 1、密度组辨识 1，合计 2，进入 B。 |

旧表的前三方向合计 68，但把外观层次、因果成立和流程完整混在一起，不能都称作“纯物理分”。新表重新划清后，**动态现象的可见形态占 44，材质、光影和基本观看条件占 24，作用关系占 22，演示与交付占 10**。这是评价重点的转移，不是把旧方向简单改名。

按相同归类，旧表材质 8＋灯光 6＋风格 4＋构图可读性 10＝28；新 B 为 24。其内部从容易接近完成的布局、一致性，转向可分别拉开差距的材料外观。视觉的另一大块通过 A 的 44 分明确表达，不能仅把“画面与音效 22”加到三十几分就算完成改版。

26 个小点比旧表的 18 个多，增加主要来自材质和形变的拆分。每点仍只保留一行，不新增附表计分或第二套分值。

### 2.5 评分条件下能怎样判断

A 项、B 项主要用固定演示视角的截图序列和录屏判断。A3、A4、A8 必须看前后状态，单张峰值截图不足以判断传播、相位和衰减；不从录屏卡顿推断运动质量，不评价帧率或流畅度。

C 项通过观察接触前后、静水与造浪、启动与停机等状态的对应关系判断；有疑问时结合参数对比和源码核实驱动来源。源码只能补证因果，求解器名称、网格数量、粒子数量和代码篇幅不能代替可见结果。题面允许合理简化与现成物理引擎，不比较谁使用的算法更“高级”。

D5 评价的是事件音效的实际接入与输出控制。评分员听不到声音，可结合源码中的事件调用、运行后实际创建和触发的音频节点或输出信号判断；只看到一个声音按钮或未被调用的函数，还不能证明事件有输出。不评价音色好不好听、空间混音效果或听觉感染力，也不因评分员不能听到而固定给某个分数。

本次研究没有执行上述运行检查；这是将来重评时可用的取证方式。

### 3.4 已有结果暴露的评判偏移

旧理由中有 FEM、APIC、XPBD、光线追踪等技术名称。这些可以帮助确认实现，但不能直接成为 A、B 项的高分理由。新报告的视觉判断只使用看得见的形状、时间关系和表面外观。

Sonnet 的旧理由把“没有破碎”写为波浪不足、把“水槽小球偏塑料”写为材质不足。题面要求持续波浪或定向流，未要求破碎波；只要求小球颜色能区分密度，未指定它们必须是什么材料。推荐表不把这两条变成隐含目标。Sol 的波幅较大也不能单独证明表现更好或物理更差，需结合当时水槽尺度、驱动与波形看。

两评委对 Sol 的旧总分相差 16.17，对 Sonnet 相差 13.17；已有评分不是一致的质量标尺。本方案能提供更清楚的差异归属，但只有三份作品、没有新口径实评，不能声称已经验证新方案的一致性或确定它会产生怎样的新排名。

### 5.2 怎样复用已有材料

采用新口径后，先用现成四段截图序列复看 A、B 项；这些素材能复用，无需为了改权重把所有演示重新渲染一遍。对时间层次不足、只有单张帧的部分，以及 C 项因果、D 项交互和导出恢复的矛盾记录，待允许运行时补证。

两位评分员应面对同一版本作品、同一份新表独立给分。重评用于纠正“看什么”和“归哪里”，不以拉大模型分差或维持旧排名为目标。若原评分副本与当前只读源目录有差异，应先确定与旧截图一致的被评版本，不能混用不同版本的优点。

新旧结果应分开标明评分口径与日期：旧结果反映旧任务权重下的表现，新结果反映视觉优先的新权重。若第 4 节最后引入了实质新增要求，应明确这是新题面版本，不把旧作品未承担过的新增内容伪装成原本缺项；可以保留旧题面作品的重评分作参考，但不与未来新题面作品当作完全同条件样本。

音效事件接入、四段导出帧数、各组稳定位置、已成功的控制操作等**观察事实**可以复用。得分仍需依据新小点重新判断。若暂时不能运行，只能标为“基于已有材料的试评”，不能发布成已完整核实的新正式分数。
