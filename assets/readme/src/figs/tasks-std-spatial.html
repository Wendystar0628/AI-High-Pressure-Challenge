8副锁

零件保持初始朝向，只能沿 x、y、z 轴平移；
可以几件一起移动，但不能整体搬动整个组件。

01
每一步都不碰撞移动经过的整个区间都检查，不能跳过中间的碰撞位置
02
分离要移到无限远一组零件沿某个轴一直移出、途中不碰其余零件，才分成两组
03
拆到每组只剩一个零件分开的两组都要继续拆，框架也要拆开；只找到首次分离不算
