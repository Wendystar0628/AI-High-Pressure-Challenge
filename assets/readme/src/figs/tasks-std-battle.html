Algorithm Battle

算法对抗：攻城略地

用 C++ 写一个双人对战程序，与五档固定对手在 96 张隐藏地图上各打一局、轮换座位，按胜负估出的实力值计分：和最强一档相当得 80 分，比它高 200 实力值才满分。

The Game

对局规则

双方同时行动，结算代码随题给出

01
节点16–24 个节点，中心对称；双方各占一个起始节点，其余中立
02
派兵每回合双方同时下命令，从己方节点向任意节点派兵；路程是两点距离向上取整
03
增长己方节点每回合按增长率加兵，中立节点不增长
04
到达部队到达后按归属合计，兵力最多的一方占有节点，剩下最多减第二多
05
胜负一方没有节点也没有在途部队即被消灭；200 回合后比总兵力

480 Games

480 局怎样计分

5 档 × 96 张地图，每图一局、按地图顺序轮换座位；胜 1、平 0.5、负 0，由全部胜负估出实力值

实力值 r：使 480 局的预期总分 Σ 1 / (1 + 10(R − r)/400) 等于实际总分；r = R1 − 200 得 0 分，R1…R5 得 10、20、40、60、80 分，R5 + 200 得 100 分，其间线性插值

胜平负每格一局，每列上下两格是相邻的两张地图：上格奇数张图（你的程序为甲方），下格偶数张图（为乙方）；对局结果和 R1–R5 都是示例（示例取相邻两档相差 300）。真实的 R1–R5 由五档基线在同样的 96 张地图上两两循环对打、用 Bradley–Terry 拟合后冻结；r 限制在 R1 − 200 到 R5 + 200，和第 5 档相当得 80 分，比它高 200 才满分。判负：崩溃、异常退出、一回合 5 秒内没交出命令或连续 3 回合超时的那一局；记 0 分：编译失败或违反题面规则。
