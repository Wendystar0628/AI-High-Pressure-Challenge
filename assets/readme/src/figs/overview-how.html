一道题怎么测

12 道题都走同样的四步；两类题在交付、评分员和计分方式上不同。

1

拿到题面

作答目录里只放这道题的题面和材料
目录是一个 git 仓库

2

独立作答

新会话从拿到题面起计时
无人答疑，模型看不到限时

3

到时中止

时间一到立即结束，不延长
可用的阶段由模型自己 git 提交

4

评分与合成

评完整的工作目录或最近的提交
每题折算 0–100，按权重加总

标准评判题6 题
主动设计题6 题
类别
数学推理 算法竞赛 空间推理
复杂交互应用 游戏设计与开发 物理模拟 视觉设计与渲染 系统架构与实现
交付
Lean 证明、数学竞赛解答、极值构造、CUDA 或 C++ 源码、鲁班锁拆解路线
网页作品（双击 index.html 运行）或 Windows 桌面项目
限时
60 分钟
90 或 100 分钟，物理 60 分钟
评分员
程序校验生成分数
编译、检查器和评测脚本给出分数
Claude Opus 5.5 与 GPT 6.1 Sol 各评，逐项取平均
计分
编译检查、按 IMO 惯例阅卷、锚点表、加速比、拆解步数
每个分项在分值内直接打分，相加满分 100
