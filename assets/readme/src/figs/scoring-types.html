Scoring by Task Type

六种题型怎样计分

各题型先得出原始分，再折算成 0–100 分。每块最下一行是需要单独说明的情形。

Formal Proof

形式化证明题

8 题，每题只有 0 分或 12.5 分。单独编译没有错误和 sorry 警告、有主定理才得 12.5 分。

缺文件：这一题 0 分，不影响其他题

Olympiad

数学竞赛原创试题

18 题，每题 0–7 的整数分，满分 126，再乘以 100/126 折算。

多种做法未注明：按得分最低的一份评

Extremal Construction

极值构造题

以固定的参考值为满分基准查锚点表。低段到中高段斜率逐段加大，逼近参考值的最后一段不额外加权。

记 0 分：提交无效，如点数不对、点在正方形外

Performance Engineering

性能工程题

性能输入各算加速比 s = 基线用时 ÷ 提交用时，在对数尺度上查锚点后取平均（Transformer 8 个，电路 24 个）；电路再乘以正确性输入的通过比例 k/7。

记 0 分：编译失败或违反题面规则；单个输入失败只丢这个输入

Burr Puzzle

鲁班锁拆解

8 题分三档，每题分值 w 为 8、12 或 18，合计 100。完整合法的拆解按总步数 N 得 w × min(1, B/N)，B 是这一题固定的基准步数。

记 0 分：没有完整拆开的题；
自编程序搜索、模拟或用求解器的整份作答

Design

设计题

每题 19–37 个分项，分值合计 100。评分员在每个分项的分值内直接打分，相加为总分。

不分档、不扣分
