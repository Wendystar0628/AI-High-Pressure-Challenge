Scoring by Task Type

七种题型怎样计分

各题型先得出原始分，再折算成 0–100 分。每块最下一行是需要单独说明的情形。

Formal Proof

形式化证明题

8 题，每题只有 0 分或 12.5 分。单独编译没有错误和 sorry 警告、有主定理才得 12.5 分。

缺文件：这一题 0 分，不影响其他题

Olympiad

数学竞赛原创试题

24 题，每题 0–7 的整数分，满分 168，再乘以 100/168 折算。

多种做法未注明：按得分最低的一份评

Performance Engineering

性能工程题

加速比 s = 基线用时 ÷ 提交用时，在 ln s 上查锚点。光追只有一个性能输入，速度分再乘画面系数 c 和隐藏输入系数 h；电路 9 个输入各按 s 查锚点、取平均，再乘正确性通过比例 k/7。

记 0 分：编译失败或违反题面规则
单个失败：光追只把这一次画面判定记 0；电路只丢这个输入

Algorithm Battle

攻城略地

与五档固定对手各打 96 局（96 张隐藏地图，每图一局、按地图顺序轮换座位），共 480 局；每局胜 1、平 0.5、负 0。由全部胜负估出 Elo 尺度的实力值 r，对照五档基线冻结的实力值 R1–R5 换算成 10、20、40、60、80 分，R1 − 200 为 0 分，R5 + 200 为 100 分，其间线性插值。

判负：崩溃、异常退出、一回合 5 秒内没交出命令或连续 3 回合超时的那一局
记 0 分：编译失败或违反题面规则

Burr Puzzle

鲁班锁拆解

8 题分三档，每题分值 w 为 8、12 或 18，合计 100。完整拆开的按总步数 N 得 w × max(0.6, min(1, B/N))，B 是这一题固定的基准步数；没拆完的按已合法完成的分离计部分分，最多 50%。

记 0 分：一次分离都没完成的题；
自编程序搜索、模拟或用求解器的整份作答

Drawing to Model

工程图纸三维还原

25 题分三档，每题分值 w 为 3.5、4 或 4.4，合计 100。0.2 毫米和 2 毫米两档各求表面吻合度 F，合成 F* = 0.8F0.2 + 0.2F2，每题得 w × min(1, F*/0.99)；只平移、不旋转。

记 0 分：缺文件或生成不出实体的题；
用程序算尺寸、推导或重建几何，用 CAD 或改工具的整份作答

Design

设计题

每题 19–30 个分项，分值合计 100。评分员在每个分项的分值内直接打分，相加为总分。

不分档、不扣分
