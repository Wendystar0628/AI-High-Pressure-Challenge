# 以 NVIDIA B200 为题材的网页艺术

## 一、任务与定位

以 NVIDIA B200 数据中心 GPU 为题材，制作一个单页、纵向长滚动的网页。

**本测试不是做一份产品发布页。** 这是一次网页艺术的炫技：请把你对网页视觉、动效、交互、叙事与氛围的理解发挥到极致，做出一件让人印象深刻的网页作品。产品只是题材，信息是否完整不是重点。

视觉风格与表现方式全部由你自己决定。

## 二、整体结构

1. 全页由第三节的 9 个章节按顺序组成，整体叙事由微观到宏观。
2. 页面总长度不少于 12 屏。

## 三、章节内容

### 3.1 开场

- 呈现产品名称和一句核心主张。

### 3.2 微观起点

- 表现从芯片内部的微观电路结构到整颗芯片。

### 3.3 双芯片架构

- 表现两颗芯片通过高速互连组成一个统一的 GPU。
- 包含一个可交互的芯片剖析视图，用户能查看其中各部分的说明，至少包括计算单元、显存堆栈和芯片间互连。

### 3.4 算力

- 表现算力的规模，至少包含一个图表。

### 3.5 显存与带宽

- 表现数据在显存与计算单元之间的高速传输。

### 3.6 Transformer 引擎与 FP4

- 包含一个可交互的精度对比，至少涵盖 FP16、FP8、FP4，体现不同数值格式的位宽及由此带来的差异。

### 3.7 互连与扩展

- 表现从单颗 GPU 到 HGX B200 平台、再到数据中心的扩展。
- 呈现 NVLink 的连接关系。

### 3.8 应用场景

- 至少 3 个 AI 应用场景，每个场景有独立的视觉表现。
- 用户可以在各场景之间切换。

### 3.9 收尾

- 包含核心规格概览和结束画面。
- 在这一章注明："本页为概念设计作品，非 NVIDIA 官方页面。"

## 四、视觉与交互的通用要求

1. 每一章都至少有一处动态元素。
2. 全页至少有 3 处用户可以交互的元素，第三节中规定的芯片剖析视图、精度对比和场景切换都计入在内。
3. 所有交互都用鼠标和键盘完成。
4. 动画要流畅，不能有明显卡顿。
5. 本题只做 PC 端，不考虑手机和平板。
6. 页面语言为简体中文，产品名和技术名词可以保留英文。

## 五、约束

1. 最终交付一个网页，入口文件为 `index.html`。
2. 不得使用 NVIDIA 官方的标志、图片和视频素材；品牌名称以文字呈现。
3. 页面中的素材都由你自己制作。
4. 在 Google Chrome 和 Microsoft Edge 中正常运行，控制台没有报错。

## 六、规定

1. 开发时间为 45 分钟，从拿到题目开始计算。
2. 开发期间预览和测试页面时，优先使用你所在 Agent 工具自带的内置浏览器；它不可用时，使用本机的 Google Chrome；仍不可用时，使用本机的 Microsoft Edge。
3. 全程不得访问 GitHub 上的任何仓库，无论通过网页、`git`、`gh` 命令行还是 API。
4. 工作目录限定为 `H:\AI_OneShot_Model` 下你自己的模型代号文件夹：所有文件都在这个文件夹内创建和修改，不得访问本机的其他文件夹；运行所需的编译器、解释器、库和浏览器时必须访问的安装路径除外。
5. 开发期间如需启动本地网页服务器，使用 18103 端口。
6. 时间结束时，以当时的网页文件作为最终提交。

## 七、评审方式

评审时，会从页面顶部完整滚动浏览到底部并录屏，同时操作页面中的交互元素。

评审看重的是作品的艺术表现力、创意和完成度。

## 八、评分标准

### 8.1 计分方法

总分 100 分，由下表 6 个分项组成。多名评审独立打分，每项按 0–10 分评定后乘以占比折算，最终得分取各评审的平均值。

| 分项 | 占比 | 评分要点 |
|---|---|---|
| 视觉审美 | 25% | 整体视觉水准与风格统一性 |
| 创意与叙事 | 20% | 作品的创意，以及由微观到宏观的叙事 |
| 动效 | 15% | 全页动效的观感与流畅度 |
| 交互 | 15% | 三处规定交互及其他交互的完成度与手感 |
| 内容完成度 | 15% | 9 个章节及各章规定元素是否齐全，页面长度是否达标 |
| 技术质量 | 10% | 加载是否正常，控制台有无报错，运行有无卡顿 |

### 8.2 违规处理

- 页面无法打开或白屏：总分记 0 分。
- 使用了 NVIDIA 官方的标志、图片或视频素材：总分记 0 分。
- 缺少"本页为概念设计作品，非 NVIDIA 官方页面"的声明：总分扣 5 分。
