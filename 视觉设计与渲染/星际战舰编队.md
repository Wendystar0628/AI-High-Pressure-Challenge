# 星际战舰编队：旗舰与护卫舰

## 一、目标总览

在网页中实时渲染一支正在宇宙中航行的星际战舰编队，做成一部有规模、有空间纵深、运镜连贯的舰队展示片。数十艘战舰沿同一航向铺开，一艘巨大的旗舰居于阵列中心，近卫舰环绕身旁与后方，前卫舰在前方和外层展开。近处舰船从画面边缘掠过，中间的旗舰逐渐显露出长大的舰身，后方更多舰列仍在向远处延伸。舰尾的推进光穿过深色空间，小艇沿旗舰外壳飞行，经过主炮、机库开口与层层装甲，将巨舰的体积衬托出来。

镜头随着航行靠近舰队，从舰外的庞大阵列进入旗舰内部：宽阔的舰桥、多层的动力核心中庭、纵深很长的小艇机库，以及通向武器的能量装填与导能长廊。近处构架从镜头两旁退去，跨越大空间的装置和远处开口先后展开。舰内呈现的是战舰特有的概念空间，乘员不出现，自动机械采用抽象构件，不做成人形。

一轮展示的高潮是舰队向附近陨石群开火。旗舰的光束主炮、脉冲炮台与两类护卫的近防炮、导弹接续发射，弹道从舰体延伸到岩块，亮光沿裂口扩开，大块岩体分开、翻滚，体素碎块飞散。开火余波尚未散尽，各舰依次开启通透的能量护盾，推进尾焰增强，整支编队向前加速。镜头顺着舰列和后掠的碎块继续前行，接入下一轮航行。

本题重在第一眼的造型冲击、巨型尺度、丰富层次与完整的观看效果。舰船、武器、陨石与舰内结构使用同一尺寸的体素搭建，光束、尾焰和护盾等光效可以连续流动。舰队的具体轮廓、配色、美术风格与装饰细节由你设计，近卫舰和前卫舰各有多少艘也由你安排。作品打开后自动循环播放，没有操作环节；只设计镜头能够展示的内容，不附加任务和故事背景，不按真实战舰的功能与工程逻辑拆解。

## 二、作品内容

### 2.1 舰队的设计语言与尺度

为这支舰队确定一种贯穿全作的形态母题，例如向前延伸的分叉、围绕空腔展开的层片，或相互嵌合的阶梯体块，再把它发展成自己的造型语言。旗舰把这一母题铺展成大范围的主壳、侧部和上层结构；近卫舰与前卫舰各自收拢、改变其中的比例，小艇与炮台提取简练醒目的部分。三种舰型彼此有亲缘，也各有容易辨认的剪影。

舰队是数十艘战舰组成的阵列，整体可按二三十艘至四十余艘的量级展开，两类护卫的具体数量由你决定。旗舰在同一空间中明显压过护卫舰：它是一艘约一千至一千二百格长的巨型结构，主要护卫的长度约为它的五分之一至七分之一，小艇则只有它的三十分之一至五十分之一。大小来自共同网格上不同的体素数量与结构跨度，近看仍能辨出同样大小的方块。

这些大小关系直接出现在画面里。一艘护卫沿旗舰侧方经过时，陪伴它的是一段舰身而不是整艘旗舰；几艘小艇从机库深处飞到舱口，周围的装甲开口和上方梁架显得高大。镜头从近处一组构件向前掠行，旧的结构退到身后，另一片壳层、炮台或巨大喷口才逐渐展开。

舰体外壳以大面积主色承托结构，用第二种色调划分嵌入的深层构件，再以少量高亮颜色串起炮口、推进与结构缝隙。色相和冷暖由你选择，实体表面、内部暗槽和发光部分各有自己的色彩位置。这种形态与光色关系延续到四处舰内空间、武器、护盾和航行尾焰中。

### 2.2 旗舰的外形、推进与小艇

旗舰具有从舰首延伸至舰尾的完整轮廓，长大而有厚度。厚重主体、向外伸展的侧部和高低错落的上层体块围绕主要走向铺开，宽窄、厚薄和高低沿舰身变化。远处先看见大轮廓与转折，中景出现多段壳层与空腔，近处才展开构件之间的阶面、深槽和细小结构。

- **舰首**：向航行方向伸出，收束、分叉或展开成为最醒目的轮廓之一。厚实的外缘由层层错开的体素阶面塑出，深槽或贯通空隙分开相邻体块。光束主炮从舰首或舰身主体中生长出来，宽大的基部、沿射向延伸的炮身与深处发亮的发射口连成完整造型，占据全舰最大的武器体量。
- **舰身**：装甲以成片的大区段延伸，区段之间露出更深的槽带、连接梁和嵌入构件。凸起的背脊、退叠的外壳和局部通透的空腔形成中尺度变化；侧面与腹部有另一组壳层、肋架与凹入结构，镜头降到舰腹或绕到斜侧时仍有新的形体展开。细节集中在轮廓转折、开口与重要装置附近，大块表面留出安静区域。
- **舰尾**：多组推进喷口嵌在逐层退让的尾部结构里，深内腔、层叠口沿与发亮的内部形成鲜明的明暗。数量和形状由你设计。尾焰靠近喷口处凝聚明亮，向后拉长并逐渐透明，细流与光屑在外缘散开；稳定航行时缓慢起伏，加速时从内层开始增强、拉长，附近壳面和漂浮物接住变化的推进光。
- **脉冲炮台**：沿舰体上层、侧缘或周围空间有节奏地展开。每座炮台有自己的底部体块、炮身和发射口；采用悬浮形式时，间距和姿态构成旗舰周围的另一层结构。相邻炮台之间留出能看清壳层和炮口的空间。
- **小艇与起降口**：小艇具有清楚的前部、主体与喷口，用较少方块概括舰队母题。旗舰侧面或尾部的机库口向内退让，露出深处停泊位、桥架和远端光线。几艘小艇持续停泊、驶出、伴飞和返回，可以由不同小艇完成一轮中的这些动作。小艇飞过舰壳时与外缘保持可见间距，经过武器、壳层和喷口，形成从微小载具到巨大舰体的连续尺度对比。

### 2.3 两种护卫舰与阵列航行

近卫舰围在旗舰两侧、后方与不同高度，体量紧凑厚实。中央主体与短翼、叠层壳片咬合，前后端有明确的收束。速射近防炮成组布置在突出的炮座上，炮管从壳层之间伸出，形成密集短促的节奏；舰尾喷口与较短有力的尾焰延续完整轮廓。

前卫舰在编队前方与外围铺开，轮廓更舒展。沿航行方向延伸的主体配以外伸的导弹发射部，成排的槽列、开口与导弹形成有方向性的重复结构。它在长宽比例、外缘姿态和构件疏密上与近卫舰拉开差别，同时保留旗舰的壳层做法与形态母题。两类护卫的具体外形由你发展。

阵列有前、中、后的多重编组，也有上下错开的高度。近处几艘护卫从画面边缘经过，中层旗舰在它们之间展开，远处更多舰列延续到背景中，尾焰的疏密与明暗勾出阵列走向。有的舰被前景暂时遮挡，随着镜头移动又从间隙显露；远舰不是一圈相同大小的亮点，也不把所有战舰排成同一个平面。

全队朝同一方向推进，舰船以缓慢偏转和位置微调维持编组，小艇的轻快运动与战舰的沉稳形成节奏差。开火前，部分护卫向外展开，舰列之间的间隙逐渐变宽；射击后的编队重新组织成向前延伸的航行姿态。最后的加速沿舰列传开，前后各层仍保持清楚关系，镜头能感到整个阵列正在一起前进。

### 2.4 宇宙环境与附近陨石

宇宙环境从宽阔的远景色层延伸到镜头旁的微小漂浮物，为舰阵提供明暗背景与运动参照。远处星点有疏密和亮度变化，星云或天体弧面展开成大面积色层，局部明亮、局部沉入深色空隙。主光天体从一侧照向舰队，朝光的壳面和阶面接住亮边，背光面保留较弱的环境色。

一簇体素陨石分布在编队附近的前方或侧前方，大块岩体之间夹着中小岩块。它们有不规则的轮廓、层叠断面、凹入裂隙和局部贯通的空隙，朝光面与暗面分开，远近相互遮挡。镜头先让观众看见它们与舰队的相对位置，开火时其中几块成为清楚可见的目标。

近处漂浮物快速掠过，中距离陨石较慢错开，远景天体近乎稳定。推进、炮火与命中亮光使附近颗粒短暂显现，随后退入暗部。舰队加速时，近处岩块和碎片更快向身后退去，远处舰列仍保有沉稳的体量。

### 2.5 四种武器、命中与碎裂

一次开火由旗舰的一种武器率先发起，再接上另一种旗舰武器和两类护卫。具体先后、交叠和节奏由你设计，四种武器在同一轮攻击中各有清楚的形态与展示时刻。发射位置、最初的弹道和附近目标建立连续关系，视线能从炮口跟到陨石；开火既有起势和增强，也有命中之后的退潮。

- **旗舰光束主炮**：炮身发光槽逐段亮起，炮口聚集浓亮光团，短暂蓄势后拉出持续能量束。中央亮核与外侧较透明的辉光分开，沿射向流动的细纹、起射光环和粗细脉动增强力度。光束抵住较大的陨石，受击处逐渐发亮，裂口沿体素断面扩大，大块岩体被分开。停射时束身收细、从炮口断开，余辉和光屑继续向前散去。
- **旗舰脉冲炮台**：短促聚光后分组送出一串串能量弹，亮核外包薄光晕与短尾。相邻炮台错开半拍，沿不同但彼此关联的射向推进；能量弹接连击中岩面，爆闪沿一组缺口跳动，中小块从边缘崩落，炮口和附近壳面随着每次发射短暂亮起。
- **近卫速射近防炮**：炮管转向附近较小岩块或已分出的碎块，交替炮口闪光连成紧促的短点射。细密弹流以有间距的线带穿过空间，击出连续的小碎屑和短闪，与主炮的持续亮束、脉冲的分组亮弹形成不同节奏。停射后末端弹迹继续前行，炮座上的微光稍后熄去。
- **前卫导弹**：导弹从成列发射口依次离开，拉开间距后尾部亮起，沿弧线或错层路径加速，拖出浓淡变化的长尾迹。几枚导弹先后抵达较大的岩体，命中亮光从表层向裂隙扩展，随后引出较大块的分离与翻滚；尾迹在爆闪后仍短暂留在空间里，再松散消退。

陨石被击中后仍有可看的形状变化：大块沿裂面分离，中块带着不同方向的翻滚，小块向外飞散，原来的岩体出现真实空隙。明亮裂面、冲击光和尘屑从强到弱退去，碎块在暗处继续运动，不能只用一团强光盖住目标再让它整体消失。具体裂纹、破碎姿态、爆闪形状和光色由你设计，重点是命中的力度、层次与余波，不做真实破坏物理的推演。

### 2.6 宽阔的舰桥

舰桥是一座具有中庭和侧层的指挥大厅，横向约一百三十格、纵深约一百三十格、挑高约六十格的空间量级。它围绕视觉中心的指挥中枢展开，但中枢之外仍有宽阔距离，近处结构、中央平台与远处观景开口层层展开。

中枢由层叠基座与悬起的显示结构组成，前方呈现舰队的简化立体图形，舰船光点、航迹和线带持续移动。成组控制台沿两侧和不同高度的平台向远处排开，台面有发光界面，上方悬着大小不同的显示板与投影层；近处一组设备可以遮住画面边缘，后方仍有连续几组台面、梁架与开口可见。

前方宽阔的观景开口外是航行中的舰列与宇宙，两侧框架和上方跨越的构件把中枢包围起来。显示的光映在台面边缘和框架内侧，暗缝托起明亮内容。镜头沿平台侧方移动、升降或绕过近处构架时，投影、中枢、侧层与窗外舰队先后错开，让观众看见大厅的跨度与深度。

### 2.7 动力核心中庭

动力舱展开成一座纵向贯穿多层的巨大中庭，横向约二百五十格、高度约二百五十格的空间量级。中央核心与周围平台之间保留宽阔空隙，四五层以上的环形或分叉平台沿高度展开，远处舱壁与厚重支撑把空间围合起来。

核心有体素外构架和发光内层，能量沿内部纹路流动、聚拢再散开。多重环带、套层或分段构件围绕它缓缓旋转、错位，近处看见粗大的口沿和连接节点，升高或拉远后才显出它们与上下各层的整体关系。几组巨大的支撑从舱壁伸向核心，近处构架遮去局部边缘，远处构架逐层退入暗处。

核心的明暗按自己的节奏呼吸，流光顺连接结构向外延伸，把平台底部、深处舱壁和悬置构件染出由亮到暗的色层。镜头从一层平台旁掠过或沿核心抬升，近处结构快速退去，上下更多层次继续显露；核心轮廓、构件组合和运动方式由你设计。

### 2.8 贯通式机库与能量长廊

**小艇机库**从舰侧开口向内部延伸，形成约占旗舰长度三分之一的长大空间。数排停泊凹位沿两侧后退，小艇停在其中显得轻巧；上方横跨的桥架、侧边伸出的抽象维修构架和深处第二重舱口把机库分出几段。近处地面与导引光向远端收拢，较暗的顶层中露出梁架和局部发亮的内壁。

小艇从深处泊位离开，经过桥架下方与宽阔舱口，飞到舰外伴飞；另有小艇沿入口返回。镜头可以跟随一艘艇移动，也可以从舱口斜向进入，经过近处停泊结构后望向远端。小艇、泊位、跨舱构件和开口在同一画面中建立大小关系。

**能量装填与导能长廊**是一处沿舰身延伸的武器概念空间，长度约三百至四百格，横向约八十至一百二十格，挑高约六十至八十格。多列高大的装填装置、成组槽列或悬置导能构件围绕中央空隙排列，几个粗大的框架跨间向远处连续后退，尽头是一处更宽阔的发光腔口。装置有厚重外构架、深色夹层与内部亮核，近处的口沿和连接结构大到从镜头旁擦过，远处相同母题逐渐缩小。

能量光块或发亮构件在槽列中分批前进，几组抽象机械缓慢合拢、分开，流光沿上下层的连接结构持续传递。它们形成独立运转的视觉节奏，不要求在舰外开火时再切回这里解释过程。镜头沿装置间的空隙穿行，侧面的结构不断遮挡和显露远端，让长廊有明显的长度与层层深入的观感。

四处舰内空间都以画面能看到的结构、装置、光与运动自成一景；不建模人，不给机械加人形，也不补充镜头外的完整功能系统。

### 2.9 全队护盾与加速航行

攻击结束、命中亮光开始退去时，旗舰与所有护卫舰依次开启各自的能量护盾。细亮弧线或分片光纹先贴近舰体出现，再向外撑开，连成包住各舰的通透曲面。旗舰展开最大的一层，前后舰列的护盾接续亮起，在不同距离上形成明暗和大小变化。

护盾表面有流动纹路、扩散波纹和沿曲面滑过的亮边，正面轻薄，轮廓交叠处发光较浓，舰体始终透在后面。展开亮波掠过舰首、侧部与舰尾，附近壳层接住柔和反光，随后进入仍有细微流动的稳定状态。形状、纹样与色彩呼应舰队的设计语言。

盾光尚在流动，推进器从内层开始增强，尾焰逐渐拉长，整支舰队沿原航向向前加速。近处舰船更快从镜头旁经过，远处舰列相继向前，碎块和漂浮物向身后退去。相机顺着这一运动跟随、拉开或回望，带出完整阵列，再接入下一轮航行。开头延续上一轮加速后的稳定航行状态，让护盾余辉在继续前进中自然变薄，新的陨石群与航路在前方展开，被击碎的陨石不在镜头前复原。

### 2.10 体素、细节、光与材质

舰船外壳与结构、四种武器与导弹实体、舰载小艇、陨石及其实体碎块、舰内设备与机械都使用同一尺寸的体素。透明、发光的实体构件也使用这一尺寸，不在局部换更细的网格，不用平面贴图或光滑网格代替。大小差别由格数、阶面的疏密、体块厚度与空隙构成。舰体内部看不到的地方不用填满。

远景以旗舰轮廓、舰列、尾焰和环境色层组织画面；中景展开成片装甲、重复炮台、机库开口与舱内跨层构架；近景才看见壳片叠压、喷口内腔、台座、接合和单个体素阶面。每次靠近都出现新的结构层次，细节围绕视觉中心聚集，安静表面和暗部保留呼吸空间。

光束、脉冲能量弹、近防弹迹、炮口火光、导弹尾迹、推进尾焰、护盾、爆闪、烟尘、冲击光、星空、远景天体与细小漂浮光屑等光和介质效果不受体素限制。实体陨石碎块继续保持原来的体素尺寸。

舰体主壳面有宽而柔和的反光，深色构件吸收更多光，突出的金属边缘留下一线较锐利的高光；透明构件透出后方层次，发光槽从深处亮起。舰外侧光塑造体积，推进和炮火照出附近阶面；舰桥由显示和窗外光组织明暗，动力中庭由核心照亮层层框架，机库和长廊的光沿纵深后退。强光周围保留有颜色的过渡，辉光中仍能读出体素轮廓、武器和碎裂形状，画面边缘平稳，减少明显锯齿、闪烁和噪点。

### 2.11 连贯的镜头程序

作品打开后自动循环播放，一轮通常约七十至八十秒，最长不超过九十秒。镜头数量和顺序由你设计，可以有较长的连续段，也可以剪接；导出分块不决定镜头切点。整轮像一部完整的舰队展示片，有展开、深入、开火、开盾与继续航行的节奏，每段时间都用来揭示新的尺度、空间或动作。

舰外有一段持续展开尺度的运动：镜头从近处护卫或小艇旁经过，沿旗舰的舰首、侧壳、腹部或舰尾掠行，在同一次运动中由局部逐渐带出巨舰与后方阵列。相机的速度、距离和高度随着观看重点变化，近物快速擦过、远处舰列缓慢错开。环绕不是始终以同样距离盯住一个点，跟拍也让观众看见主体与周围空间的关系。

进入舰内时，可以跟着小艇穿过机库口，沿可见空隙接近内部；不同舱室之间可以用梁架、舱口或构件擦过画面的遮挡，或者相近方向与形态的运动接续。镜头不穿过实心舰壳与设备。四处内景都在移动中展开空间，近处结构先经过，中部装置逐渐显露，远端仍有纵深，不只在中央装置前轻轻摇动。

开火时，镜头先让发射舰船、武器与起始弹道的关系清楚，再沿弹道或导弹的方向把视线引向附近陨石，命中和碎裂接住前面的运动。四种武器可以交叠在同一段里，持续亮束、分组脉冲、密集短弹流与长尾导弹各有清楚的展示时刻；相机不必为每种武器重新停住、等待、起拍。

剪接前后的航向、视线重点或动作有承接。连续移动的镜头经过分块边界时保持原有运动，不每到边界都归零再启动；有意换景时，新画面迅速接住上一画面的运动。结尾全队开盾、加速后的方向与速度感接入开头，不靠黑场、片尾停顿、闪白或清楚物体突然复原来掩盖循环。

观看画面里始终有清楚焦点，重要主体在较小播放画面中仍有足够大小和明暗层次。造型、动态与光效围绕实际镜头安排；画面没有界面控件，少量场景内标注可以作为装置本身的细节，空间用途由结构与装置的观感传达。

### 2.12 视频导出

作品提供以下固定接口：

```js
window.videoExport.runs                          // 按播放顺序列出导出分块名称，可只有 ['tour']
await window.videoExport.begin(runId, { fps })   // 重建该分块的全局起始状态，返回 { frames }
await window.videoExport.frame(i)                // i 从 0 起依次调用；完成时该帧已经完整显示
window.videoExport.end()                         // 恢复正常自动播放
```

导出方按 `runs` 顺序逐块原速导出，依次拼成完整的一轮，不重排镜头、不补转场、不慢放。分块只是导出组织，可以覆盖一个镜头、多个镜头或一个连续镜头的一部分；没有每块十五秒的限制，所有分块合计不超过九十秒。导出全片与正常自动播放的时间、剪辑、运镜、舰船和特效状态一致。

所有分块来自同一条全局时间线。`begin` 重建该分块在整轮中的起始状态，按传入的 `fps` 返回 `frames`。第 `i` 帧对应这一分块起点之后的 `i / fps` 秒；连续分块之间接续全局时间，不能重新从开火、碎裂或飞行动作的第零秒开始。每块只导出 `0…frames−1`，不要额外重复结束端点。分块前后既不丢帧，也不插入额外等待帧。

支持预览的 3 帧/秒和正式导出的 60 帧/秒，时长和运镜速度不随帧率变化。导出模式下，时间只由 `frame(i)` 推进，实时播放不再额外改变同一场景；每次返回前，相机、动态、特效和画面都已更新，可以直接定位指定帧，不依赖先按真实时间播放到那里。`end()` 退出导出模式，恢复自动播放。

分辨率由调用方设置的窗口大小决定，作品适应到最高可能的 3840×2160。以 Chrome 本地文件方式打开时接口也可用，不需要导出按钮，也不用交付视频文件。
