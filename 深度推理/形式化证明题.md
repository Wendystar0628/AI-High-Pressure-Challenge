## 第 1 题

设正整数 $n$，$k$ 满足 $n<k<2n$，正整数 $a_1,a_2,\dots,a_k$ 满足 $2^{a_1}+2^{a_2}+\cdots+2^{a_k}$ 能被 $2^n-1$ 整除。证明：$a_1,a_2,\dots,a_k$ 中至少有三个数除以 $n$ 的余数相同。

```lean
theorem problem1 (n k : ℕ) (hnk : n < k) (hk : k < 2 * n) (a : Fin k → ℕ)
    (ha : ∀ i, 0 < a i) (hdiv : 2 ^ n - 1 ∣ ∑ i, 2 ^ a i) :
    ∃ i j l : Fin k, i ≠ j ∧ i ≠ l ∧ j ≠ l ∧
      a i % n = a j % n ∧ a i % n = a l % n := by
  sorry
```

## 第 2 题

设 $f$ 是从非负整数集到非负整数集的无界函数（即对每个非负整数 $N$，都存在非负整数 $n$ 使 $f(n)\ge N$）。已知对任意非负整数 $m$，$n$，只要

$$
f(m+n)=\max\{f(0),f(1),\dots,f(m+n)\},
$$

就有 $f(m+n)=f(m)+f(n)$。证明：存在正整数 $A$，$B$，$C$，$D$，使得对所有非负整数 $n$，都有 $f(An+B)=Cn+D$。

```lean
theorem problem2 (f : ℕ → ℕ) (hunb : ∀ N, ∃ n, N ≤ f n)
    (hf : ∀ m n, (∀ i ≤ m + n, f i ≤ f (m + n)) → f (m + n) = f m + f n) :
    ∃ A B C D : ℕ, 0 < A ∧ 0 < B ∧ 0 < C ∧ 0 < D ∧
      ∀ n, f (A * n + B) = C * n + D := by
  sorry
```

## 第 3 题

设 $n$ 为正整数，$a_1,a_2,\dots,a_n$ 是互不相同的整数。满足 $1\le i<j\le n$ 且 $a_i>a_j$ 的数对 $(i,j)$ 称为逆序；$j-i$ 为奇数的逆序称为奇逆序。设逆序的总数为 $A$，奇逆序的个数为 $B$。证明：$A\le 5B$。

```lean
theorem problem3 (n : ℕ) (a : Fin n → ℤ) (ha : Function.Injective a) :
    (Finset.univ.filter fun p : Fin n × Fin n => p.1 < p.2 ∧ a p.2 < a p.1).card ≤
      5 * (Finset.univ.filter fun p : Fin n × Fin n =>
        p.1 < p.2 ∧ a p.2 < a p.1 ∧ (p.2.val - p.1.val) % 2 = 1).card := by
  sorry
```

## 第 4 题

设 $f\colon\mathbb{R}\to\mathbb{R}$ 是有界连续函数，$a>0$ 是常数，且函数

$$
g(x)=f(x)+a\int_{x-1}^{x}f(t)\,\mathrm{d}t,\qquad x\in\mathbb{R}
$$

是常数函数。证明：$f$ 是常数函数。

```lean
theorem problem4 (f : ℝ → ℝ) (hf : Continuous f) (hb : ∃ M, ∀ x, |f x| ≤ M)
    (a : ℝ) (ha : 0 < a) (c : ℝ) (hg : ∀ x, f x + a * ∫ t in (x - 1)..x, f t = c) :
    ∃ d, ∀ x, f x = d := by
  sorry
```
