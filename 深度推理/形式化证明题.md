# 题目

共 5 题，每题都要用 Lean 4 和 Mathlib 写出能通过编译检查的形式化证明。每题先给出中文表述，再给出对应的 Lean 命题；中文表述只帮助理解，两者有出入时以 Lean 命题为准。各题按难度从低到高排列，标题中标注了难度等级（1 级最易，5 级最难）。

题量和难度可能超出限时内能全部完成的范围，做不完全部题目是正常的。每道题都值得尝试，能证出几道就拿几道的分。请用好全部时间，尽可能多证出几道题。

## 第 1 题（难度 1 级）

设 $p$ 是次数不超过 $n$ 的实系数多项式，且对所有 $x\in[-1,1]$ 有 $|p(x)|\le1$。证明：对所有 $x\in[-1,1]$，有 $|p'(x)|\le n^2$。

```lean
theorem problem1 (p : Polynomial ℝ) (n : ℕ)
    (hdeg : p.natDegree ≤ n)
    (hb : ∀ x ∈ Set.Icc (-1 : ℝ) 1, |p.eval x| ≤ 1) :
    ∀ x ∈ Set.Icc (-1 : ℝ) 1,
      |p.derivative.eval x| ≤ (n : ℝ) ^ 2 := by
  sorry
```

## 第 2 题（难度 2 级）

设 $n$ 是正整数。证明：任给 $4n-3$ 个 $\mathbb{Z}_n\times\mathbb{Z}_n$ 中的向量（允许重复），总能从中选出恰好 $n$ 个，使它们的和为零向量。

```lean
theorem problem2 (n : ℕ) (hn : 1 ≤ n)
    (f : Fin (4 * n - 3) → ZMod n × ZMod n) :
    ∃ s : Finset (Fin (4 * n - 3)),
      s.card = n ∧ ∑ i ∈ s, f i = 0 := by
  sorry
```

## 第 3 题（难度 3 级）

设 $d\ge1$，实系数线性不等式组 $\sum_j A_{ij}z_j\le b_i$（$i=1,\dots,m$）恰有 $k$ 个整数解 $z\in\mathbb{Z}^d$。证明：可以从中保留至多 $\lceil 2(k+1)/3\rceil(2^d-2)+2$ 条不等式，使保留后的不等式组的整数解集与原来完全相同。

```lean
theorem problem3 (d m k : ℕ) (hd : 1 ≤ d)
    (A : Fin m → Fin d → ℝ) (b : Fin m → ℝ)
    (S : Set (Fin d → ℤ))
    (hS : S = {z | ∀ i, ∑ j, A i j * (z j : ℝ) ≤ b i})
    (hfin : S.Finite) (hcard : S.ncard = k) :
    ∃ I : Finset (Fin m),
      I.card ≤ ((2 * (k + 1) + 2) / 3) * (2 ^ d - 2) + 2 ∧
      S = {z | ∀ i ∈ I, ∑ j, A i j * (z j : ℝ) ≤ b i} := by
  sorry
```

## 第 4 题（难度 4 级）

设 $K$ 是域，$A,B$ 是两个可交换的 $n$ 阶 $K$ 上矩阵。证明：由 $A,B$ 生成的含单位元的 $K$-代数，作为 $K$ 上线性空间的维数不超过 $n$。

```lean
theorem problem4 (K : Type*) [Field K] (n : ℕ)
    (A B : Matrix (Fin n) (Fin n) K) (hAB : Commute A B) :
    Module.finrank K (Algebra.adjoin K ({A, B} : Set (Matrix (Fin n) (Fin n) K))) ≤ n := by
  sorry
```

## 第 5 题（难度 5 级）

证明：存在常数 $C$，使得对任意自然数 $k$ 和任意有限简单图 $G$，要么 $G$ 中有 $k$ 个顶点两两不交的圈，要么可以删去至多 $Ck\lfloor\log_2(k+1)\rfloor$ 个顶点，使剩下的图中没有圈。

```lean
theorem problem5 : ∃ C : ℕ, ∀ k n : ℕ,
    ∀ G : SimpleGraph (Fin n),
    (∃ s : Fin k → Finset (Fin n),
      Pairwise (fun i j => Disjoint (s i) (s j)) ∧
      ∀ i, ¬ (G.induce (s i : Set (Fin n))).IsAcyclic) ∨
    ∃ s : Finset (Fin n), s.card ≤ C * k * Nat.log 2 (k + 1) ∧
      (G.induce (↑s : Set (Fin n))ᶜ).IsAcyclic := by
  sorry
```

## 作答格式与要求

1. 每题一个文件：在开始作答时所在的工作目录下，第 k 题写入 `Problemk.lean`，即 `Problem1.lean` 到 `Problem5.lean`。
2. 导入哪些模块由你决定，但只能导入 Mathlib 及其依赖库中的模块。文件中必须有题面给出的那条定理，定理名和命题与题面完全一致（命题前的 `open … in` 照抄），只把 `sorry` 换成证明；不得用新的记号、实例、宏等手段改变命题的含义。定理之前可以添加辅助的定义和引理。
3. 证明中不得出现 `sorry`、`admit`，不得声明新的公理，不得使用 `native_decide` 或其他引入额外公理的手段，也不得用 `set_option`、元编程等方式跳过或绕过 Lean 内核的检查。对每题的定理运行 `#print axioms`，结果中只能出现 `propext`、`Classical.choice`、`Quot.sound`（不出现任何公理也可以）。
4. 每个文件单独编译时没有错误；警告不影响。
5. 每题单独评分：某一题的文件缺失或不满足以上要求（例如保留了 `sorry`），只影响这一题。

## 作答建议

- 开始作答前，先通读全部题目，判断哪几道自己相对有把握，先挑这些题做。
- 一次只做一道题。选定一道题后就专心把它证完，尽量不要做到一半临时切换到别的题目；这道题证完、编译通过后，再挑下一道。
- 经常编译检查，让每个文件随时都能通过编译；做完一题，确认这一题已经满足全部要求，再开始下一题。
- 推导较长时，可以把纸面推导写进工作目录里的草稿文件（例如 `草稿.md`）。草稿不计分。

## 运行环境

- Windows 11。Lean 4（v4.35.0）和 Mathlib（v4.35.0）已安装在 `C:\Lean`，Mathlib 已预先编译好。
- 编译检查一个文件：在工作目录中运行 `C:\Lean\lean.cmd Problem1.lean`，其他文件同理。有错误时会列出错误并以非零退出码结束。请按需导入用到的模块，不要导入整个 `Mathlib`。

- Mathlib 源码在 `C:\Lean\mathlib\.lake\packages\mathlib\Mathlib\`，可以读取和搜索。
