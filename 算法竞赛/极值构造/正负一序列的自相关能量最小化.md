# 题目

取 $N=251$。对序列

$$
s=(s_1,s_2,\ldots,s_N)\in\{-1,+1\}^N,
$$

定义其第 $k$ 阶非周期自相关为

$$
C_k(s)=\sum_{i=1}^{N-k}s_i\,s_{i+k},\qquad k=1,2,\ldots,N-1,
$$

能量为

$$
E(s)=\sum_{k=1}^{N-1}C_k(s)^2.
$$

求 $s\in\{-1,+1\}^N$，使 $E(s)$ 最小。

在开始作答时所在的工作目录下，提交 `answer.md`。文件只包含下面规定的内容，不加标题、代码块等 Markdown 标记。

- 文件内容为一行长度为 $N$ 的字符串，第 $i$ 个字符为 `+` 或 `-`，分别表示 $s_i=+1$ 和 $s_i=-1$。
- 除这一行外，文件中只允许出现两样东西：开头的 UTF-8 BOM，以及末尾的一个换行（`\n` 或 `\r\n`）。其他任何字符，包括空格和空行，都不允许出现。

## 评价

- 按定义精确计算 $E(s)$，越小越好。
- 文件不存在或格式不符合要求时，本题判为无效。

## 注意事项

1. 使用 nvcc 前，需要先执行 `C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\VC\Auxiliary\Build\vcvars64.bat` 进入 MSVC 的 x64 开发环境。本机系统代码页为 936（简体中文），编译时加上 `-Xcompiler /utf-8` 可以避免 CUDA 头文件触发大量 C4819 警告。
2. 单个 GPU 内核执行超过约 2 秒，会触发 Windows 的 GPU 超时检测与恢复（TDR）：显卡驱动被重置，程序运行失败。
3. 部分命令行环境设置了环境变量 `NoDefaultCurrentDirectoryInExePath`，此时 `cmd` 不会在当前目录中查找可执行文件。运行当前目录下的程序时，请写成 `.\程序名.exe`。
