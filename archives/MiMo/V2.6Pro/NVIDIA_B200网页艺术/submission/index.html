操作说明

  • 滚动 — 推进全页进度；七处章间转场随滚动连续衔接，可停住、可倒放。
  • 拖动 / 方向键 — 在三维场景中旋转观看角度；R 复位视角。
  • 点击部件 — 选中封装部件，三维、线稿与说明同步高亮。
  • Tab / Enter — 键盘可达所有导航与控件，焦点可见。
  • 数字键 1–6 — 切换全页精度（FP64/TF32/FP16/BF16/FP8/FP4）。
  • 0 / $ — 跳到开头 / 结尾；← → 上一章 / 下一章。
