# 果冻冲击与造浪水槽

在 Chrome 中双击 `index.html` 即可运行，不需要网页服务器和网络。需要支持 WebGPU 的 Chrome。

## 场景

- **场景一 · 重球冲击果冻台**：果冻为四面体有限元软体（Stable Neo-Hookean + Kelvin-Voigt 粘弹性，显式积分），重球为 6 自由度刚体，接触以节点冲量双向传递；平台可带弹簧悬挂。提供单球正中、偏心、多球连续三种冲击。
- **场景二 · 多密度球与造浪水槽**：水体为 GPU 上的三维 APIC 流体（MAC 网格 + 红黑 SOR 压力投影，约 200～300 万粒子），刚性球以体素边界推动水体，水体以浮力、阻力和流体加速度反作用于球；画面对密度场逐像素光线追踪（折射、全反射、吸收、掺气、焦散）。

## 操作

| 操作 | 按键 |
| --- | --- |
| 触发 / 暂停 / 继续 | 空格 |
| 重置 | R |
| 慢动作（1×、0.5×、0.25×、0.1×） | S |
| 切换场景 | 1、2 |
| 再次释放球（场景二） | B |
| 开始 / 停止造浪（场景二） | W |
| 打开 / 关闭声音 | M（或走带条上的“声音”按钮） |
| 旋转 / 缩放 / 平移 / 复位镜头 | 拖动 / 滚轮 / Shift+拖动 / 双击 |

## 音效

全部由 Web Audio 实时合成，不加载音频文件，本地文件方式和离线都可用。浏览器要求先操作页面，第一次点击或按键后开始发声。

- 场景一：撞击闷响、脱离时的回弹声、果冻振荡、球与球 / 台面 / 挡边的碰撞（钢、花岗岩、黄铜音色不同）、滚动、下落风声、释放与接球。响度和音高取决于当时的冲击能量、质量、半径和果冻硬度。
- 场景二：入水（拍水、空腔闭合、水滴、气泡）、球与球 / 槽底 / 玻璃的碰撞（水下发闷，密度越大越亮）、造浪电机与推板推水、水面波动、波峰拍壁、托板抽出。
- 慢动作时音高和时长随之拉伸；暂停时持续声淡出；视频导出时静音。

## 视频导出接口

```js
window.videoExport.runs                          // ['jelly-center', 'jelly-multi', 'jelly-offset', 'tank-full']
await window.videoExport.begin(runId, { fps })   // 返回 { frames }
await window.videoExport.frame(i)                // 第 i 帧对应仿真时刻 i / fps
window.videoExport.end()                         // 回到可操作状态
```

## 目录

- `js/core.js`：数学工具、WebGPU 设备、轨道相机
- `js/shaders-common.js`：两个场景共用的灯光与舞台着色
- `js/post.js`：泛光、色调映射、抗锯齿
- `js/jelly-sim.js`、`js/jelly-view.js`：场景一的物理与渲染
- `js/tank-sim.js`、`js/tank-view.js`：场景二的物理与渲染
- `js/audio.js`：音效合成
- `js/ui.js`、`js/app.js`：界面、主循环与导出接口
