# 流形 · AE 风味动效设计编辑器

双击 `index.html` 即可在 Chrome 中运行（无需网页服务器，无外部依赖）。打开时自动载入 15 秒示例《流形》。

## 结构

| 目录 | 内容 |
|---|---|
| `js/core` | 数学/噪声/随机（`util`）、工程数据模型（`model`）、关键帧插值（`anim`，速度+影响、定格、空间贝塞尔与弧长匀速）、表达式（`expr`，自研词法/语法分析并转写为支持向量运算的 JS）、求值（`eval`，表达式环境、依赖与循环检测、父级链、实例覆盖、时间重映射） |
| `js/geom` | 路径（修剪/重采样/形变/偏移）、多边形（耳切三角化、布尔运算）、字形轮廓追踪（`font`，含项目自带的几何矢量字）、图层内容（形状组、文字排版与动画器、路径文字）、三维网格（挤出+倒角+孔洞、参数化实体、弯曲/扭转/场变形）、网格图钉变形（`puppet`，MLS 刚性 + 局部刚性 + 前后关系） |
| `js/sim` | 程序节点与空间场（`nodes`，类型化端口、节点组封装/复用/公开参数）、粒子（`particles`，确定性固定步长 + 检查点、表面发射、力场、网格碰撞、事件、拖尾） |
| `js/render` | WebGL 2：二维合成（模板填充、蒙版、效果、五种混合、遮罩、调整层、运动模糊多次取样）、三维（PBR + 程序环境反射、阴影贴图、景深、粒子与拖尾、拾取） |
| `js/io` | 音色合成与播放同步、离线混音；工程保存/打开；WebM（VP9/VP8 + Opus，自写 EBML 封装）与 PNG 序列（ZIP）导出；`window.videoExport` 逐帧接口 |
| `js/ui` | 查看器（手柄、运动路径、蒙版/路径/图钉编辑、四视图）、时间轴、属性面板、曲线编辑器、节点编辑器、项目面板与菜单 |
| `js/demo` | 15 秒示例工程（只使用编辑器自身的图层、关键帧、表达式、节点、材质与模拟设置构建） |

## 使用要点

- 工作区：顶部右侧“动画 / 曲线 / 节点 / 三维”（数字键 1–4），各面板可折叠（视图菜单）。
- 快捷键：按 `?` 查看。空格播放、F9 缓入缓出、Ctrl+A、Ctrl+Alt+A、Ctrl+D、Ctrl+Shift+C、Ctrl+Z / Ctrl+Shift+Z、J/K 跳关键帧、PageUp/PageDown 逐帧、U 只显示动画属性。
- 表达式：属性行右侧 `ƒx` 开关；支持 `time value wiggle loopOut linear ease valueAtTime toWorld fromWorld thisComp.layer("名").transform.rotation` 等，循环引用与错误会提示并退回关键帧值。
- 预合成：双击预合成图层进入其内部（播放头对应该实例的内部时间）；“空间模式”可选独立画面 / 保留三维。
- 字体与字符范围：内置几何体（项目自带矢量字：A–Z、0–9 及常用符号）；系统黑体/宋体/楷体/等宽/展示体（基本拉丁、CJK 统一汉字、全角标点）。字形轮廓可挤出为三维文字。
- 导出：文件 › 导出工作区（WebM 带音轨或 PNG 序列），尺寸等于合成，按工程时间逐帧取样，可取消。

## 逐帧接口

```js
window.videoExport.runs                 // ['demo']
await window.videoExport.begin('demo', { fps: 60 })  // → { frames: 900 }
await window.videoExport.frame(i)       // 整个编辑器落在第 i/fps 秒
window.videoExport.end()
```
