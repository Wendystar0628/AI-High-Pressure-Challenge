# 太阳雨中的小渔港堤岸（汐見漁港 · 天気雨の午後）

Three.js 三渲二微缩场景。直接双击 `index.html` 即可在 Chrome 中运行（无需服务器，所有贴图均为运行时用 Canvas 绘制）。

## 操作
- 左键拖拽：旋转
- 右键拖拽：平移
- 滚轮：向光标处缩放（可推近观察船舱、仓库、候船室内部与水下剖面）

## 结构
- `index.html` + `app.js`：交付入口与打包后的脚本（`npm run build` 由 `src/` 生成）
- `src/core/`：自写卡通着色（分段明暗、湿润高光、云影、焦散、水下雾化）、自建阴影贴图、法线/深度描边后处理、平面反射、Canvas 贴图
- `src/world/`：底座与剖面、码头岸壁、水体与色块化倒影、建筑与室内、船只与驾驶舱、山坡民家、道具、雨/滴水/光柱/彩虹、海鸥/港猫/鱼群
- `src/director.js`：事件调度（阵风、云影、雨势起伏与彩虹、港猫散步、渔船出港兜圈、暗天灯塔亮灯），同一时刻只发生一件较明显的事
