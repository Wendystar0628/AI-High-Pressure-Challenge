造浪 WAVE MAKER
幅度调低为平缓长波，调高后浪变陡、翻卷、破碎，浮球被抛得更远；频率改变浪的间距。
各组密度 DENSITY
相对水的密度：<1 上浮、=1 悬浮、>1 下沉。改变某组密度，该组浮沉方向与浸入深度随之改变。

操作说明

本作品包含两个可独立演示的三维物理模拟场景，点击顶部标签切换。左侧可播放四段预置演示，或手动触发冲击 / 释放小球 / 造浪。

场景一 · 果冻冲击：三种冲击（正中 / 偏心 / 连续）可分别触发。右侧调节果冻软硬、结实程度、重球质量与下落高度。重击而果冻不够结实时开裂，碎块仍是有弹性的果冻。

场景二 · 造浪水槽：五组同尺寸、不同密度的小球（颜色区分）在透明水槽中浮沉。调节各组密度、造浪幅度与频率；幅度调高后浪翻卷破碎成白水。

镜头：按住鼠标左键拖动旋转，滚轮推拉，右键拖动平移。快捷键：空格暂停/继续，1 / 2 切换场景，R 重置，S 音效开关。

声音需先与页面交互后才会播放（浏览器策略）。演示导出接口 window.videoExport 供自动评测逐帧调用。
