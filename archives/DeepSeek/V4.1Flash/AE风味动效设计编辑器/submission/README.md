# PRISM 棱镜 · AE 风味动效设计编辑器

直接用 Chrome 双击打开根目录的 `index.html` 即可，无需服务器，不依赖网络或外部库。

## 默认示例

打开后自动载入 `星核 · NOVA CORE` 工程：主合成 15 秒 / 1920×1080 / 60fps，工作区覆盖全段。按空格播放，时间轴、播放头、属性面板会与画面同步。

示例包含独立的「标题排版」「数据屏」「能量舞台」「光环组」等合成，使用预合成实例、保留三维、父级、表达式、音色配乐、粒子碰撞、时间置换、回声与运动模糊等机制。所有内容都可在编辑器内继续修改。

## 工作区

- **合成**：画布直接选择 / 拖动、矩形 / 椭圆 / 钢笔 / 文字 / 蒙版 / 锚点 / 图钉工具、三维轴向手柄、路径节点、场范围与相机灯光提示。
- **曲线**：值曲线、速度曲线、空间路径；关键帧与空间 / 时间手柄拖动，侧栏数值与缓动预设，表达式求值与关键帧曲线同时显示。
- **节点**：拖拽节点、连接 / 断开、复制、删除、封装节点组；组可公开数值参数，并在不同实例上独立调整。
- **三维**：同一画布的前 / 顶 / 侧 / 透视辅助视图，地面网格、可见网格、相机与场范围辅助显示。

## 逐帧接口

```js
window.videoExport.runs                    // ['demo']
await window.videoExport.begin('demo', { fps })
await window.videoExport.frame(i)          // i 从 0 开始
window.videoExport.end()
```

`begin` 回到第 0 秒，返回 `{ frames: 15 * fps }`；支持 3fps 预览与 60fps 正式取样。`frame(i)` 会把合成、播放头、时间轴与属性面板同步到 `i / fps` 秒，画布可直接截图。`end()` 恢复交互与普通播放状态。

## 成片导出

右上角「导出」或 Ctrl+E：可导出带音轨的 WebM，或将图像序列打包为 ZIP；范围、帧率、分辨率可设置，带进度与取消。
