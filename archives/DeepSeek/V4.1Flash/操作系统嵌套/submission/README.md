# NESTED OS

一个可递归嵌套的 Windows 风格桌面操作系统。根系统由 Electron 宿主实现；其下每个子系统都由父系统文件系统中的内核程序（NPL/1）真实运行，拥有自己的进程表、调度器、虚拟时钟、消息队列、文件系统、桌面、播放器与图表。

## 启动

```bash
npm install
npm start -- --data-dir "C:\temp\nested-os-data" --width 1440 --height 900 --remote-debugging-port=19106
```

- `--data-dir`：独立测试数据目录；所有运行数据（state.json、Chromium 配置、网页存储）均写入该目录，不写回源码目录。缺省为 Electron `userData/nested-os-data`。
- `--width` / `--height`：主窗口客户区大小。
- `--remote-debugging-port`：Chromium 调试端口；未传入时默认 19106。
- 自动化约定见根目录 [automation.json](./automation.json)；主渲染上下文提供 `window.bench.version`、`ready()`、`reset()`、`inspect()`。

首次启动为干净的根系统桌面，不自动播放演示。桌面左下角“开始”可启动全部应用；桌面右键可新建文件/文件夹、打开操作说明或创建直属子系统。

## 主要能力

- **递归系统树**：任意层可视、可操作；暂停/继续/单步/调速/重启/关闭；关闭窗口前确认停止子树；各层有独立桌面、文件、时钟、进程与通知。
- **内核即程序**：`/System/inner-N.kernel.prog` 位于父系统文件系统；内核负责调度、消息、文件策略、自定义 syscall 和服务程序启动。修改后重启生效；内核错误仅停止该子树。编译器 `/System/compiler.prog` 的后启动规则真实生效。
- **预算与配额**：每个逻辑步 0.05s；根默认 18000 逻辑单位。内核、应用服务、自定义程序与直属子系统承载进程竞争同一预算；逐级拨付、兄弟共享。任务管理器可调总预算、内存/存储配额、进程额度与子系统拨付。
- **三维 24 号机**：紫黄配色直升机，15 秒默认演出（起飞、转向、故障、坠毁、余波），完整场景资源 \`.scene\` 由 Three.js 显示设备解释；地形、机身、旋翼、投影、下洗尘土、烟尘、火与碎片均按提交状态绘制。
- **飞行排演**：飞控进程 `/System/flight.prog` 读取传感器并写入控制量；预算、时间速率、风场、故障与调度影响实际飞行；可保存 \`.flight\` 记录并回放/续演。
- **跨层投送**：播放器/图表可投送到任一祖先桌面；计算和状态属于源系统，目标只有外框、显示与输入转发；暂停源子树时冻结。
- **实时图表**：子系统图表工作台从根电子表格已打开的工作簿建立显式连接，接收完整选区的版本；接收与绘制是两个可分别挂起的进程。
- **快照**：子树快照包含内核执行位置、进程/消息/文件/窗口/播放器/图表状态；可恢复、分叉、导入导出。
- **真实浏览器**：自制多标签 Chromium 界面，可加载 bilibili 等外部网站；网页不向内容暴露宿主文件系统/Node。
- **桌面应用**：文件管理器、电子表格（公式/撤销/选区/存盘）、小组件（时钟/日历/倒计时/秒表/便笺/剪贴板/通知/快捷设置）、设置（壁纸/强调色/缩放/名称）、编辑器、任务管理器。

## 源码结构

- `main.js` / `preload.js`：Electron 主进程、独立数据目录、IPC、webview 新窗口。
- `src/core/os.js`：系统树、调度、预算、消息、文件、窗口模型、数据连接、快照/恢复/分叉。
- `src/core/bindings.js`：NPL 程序可见的系统服务。
- `src/core/programs.js` / `src/core/seed.js`：内核、窗口管理器、应用服务、飞控、示例程序与资源。
- `src/lang/vm.js`：字节码编译器与可序列化 VM（暂停/快照恢复执行位置）。
- `src/ui/shell.js`：嵌套桌面、窗口、任务栏、开始菜单、通知、投送外框。
- `src/apps/`：各桌面应用。
- `src/scene/`：共享 WebGL 显示设备与场景资源解释器。
- `styles*.css`：统一视觉语言。

## 说明

- 不使用宿主已有的桌面系统或浏览器成品界面；Chromium 仅作为网页内核嵌入。
- 外部网页按真实时间与网络状态运行，不纳入虚拟时钟、逻辑预算或完整快照。
- 宿主的像素绘制和 Chromium 网页执行不计入逻辑执行预算。
- 三维视图通过一个共享 WebGL 上下文渲染到各自画布，避免超过 Chromium 的每线程上下文上限。
