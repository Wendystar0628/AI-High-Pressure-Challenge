# Nested OS

一个可嵌套的 Windows 式图形操作系统，运行在 Electron 45.2.1 中。
根系统之外，每个子系统都由父系统文件系统中的一份 **巢语（NestLang）内核程序** 运行；
三维 24 号直升机场景、飞行排演、实时数据图表和跨层窗口投送都作为真实进程参与调度、预算、暂停与快照。

## 启动

```bash
npm start
```

自动测试 / 录制时：

```bash
npm start -- --data-dir D:\nested-data --width 1920 --height 1080 --remote-debugging-port=19106
```

- `--data-dir`：独立运行数据目录（状态、导出与快照）。不指定时写入 `%APPDATA%/nested-os-data`。
- `--width` / `--height`：主窗口客户区尺寸。
- `--remote-debugging-port`：Chromium 调试端口（建议 19106）。
- Electron 依赖已在 `node_modules` 中；断网时除根系统浏览器的外部网页外，所有本地应用与三维场景均可运行。

`automation.json` 记录了启动命令、窗口定位、`window.bench` 接口与示例素材路径。
`window.bench` 提供 `ready()`、`reset()`、`inspect()`；`inspect()` 返回
`systems / windows / browsers / players / charts / projections`。

## 第一次使用

初次启动显示根系统 `outer` 桌面。双击「系统管理」创建 `inner-1`，父桌面会打开一个包含完整子桌面的系统窗口；
子桌面默认打开三维播放器。继续在子系统里创建 `inner-2`，即可得到多层嵌套。
桌面图标、任务栏、开始菜单、右键菜单、窗口贴靠与最小化都在每一层独立工作。

完整中文说明见桌面上的 **操作说明**，或仓库内的 [docs/操作说明.md](docs/操作说明.md)。

## 关键目录

| 路径 | 用途 |
|---|---|
| `src/js/model.js` | 系统树、文件、进程、窗口、快照 |
| `src/js/kernel.js` | 子系统内核运行时与系统调用分发 |
| `src/js/lang.js` | 巢语词法/字节码编译器/可快照虚拟机 |
| `src/js/services.js` | 播放器时序、飞行场景、特效、图表、飞控服务 |
| `src/js/scene3d.js` | 单 WebGL 上下文 → 多视图渲染（不受 16 上下文限制） |
| `src/js/scene-data.js` | 直升机场景资源（纯数据，随项目交付） |
| `src/js/ui/` | 桌面、窗口、任务栏、开始菜单与全部应用 |
| `docs/操作说明.md` | 用户与开发者说明 |

运行中的系统文件位于虚拟文件系统内（文件管理器可见）：

- 根系统 `/Demo/sample.sheet`、`/Demo/helicopter-24.scene`
- 子系统 `/System/programs/*.nest`、`/System/programs/controller.nest`
- 子系统内核在 **父系统** 的 `/System/subsystems/<实例 id>/kernel.nest`
- 快照在父系统 `/Snapshots/*.snap`，飞行记录在 `/Demo/*.flight`

## 设计要点

- **内核是程序**：每个子系统由一份巢语内核程序调度。内核维护轮转、配额、消息分发与计时唤醒；
  修改内核并重启子系统即改变行为，语法/运行错误会显示内核错误且只影响该子树。
- **预算逐级拨付**：墙钟每 50 ms 一个逻辑步；根系统预算逐级下拨给承载进程，兄弟子树共享剩余预算；
  内核、窗口管理、显示提交、公式重算、场景取样与飞行物理都按实际工作计费。
- **共享资源与隔离**：每个实例有独立时钟、进程表、消息、文件、内存/存储配额；暂停冻结整棵子树。
- **完整嵌套**：每层桌面都是实际 DOM，窗口被祖先裁剪；3D 视图通过 2D 画布合成，遮挡与点击正确。
- **实时数据**：根系统表格每次提交/粘贴/撤销重做并重算后发布完整选区新版本；
  子系统里的数据接收进程与图表进程通过消息协作处理。
- **投送**：播放器/图表可投送到任意祖先桌面；外框归目标桌面，状态与输入回源系统。
- **快照**：子树状态、内核虚拟机、进程、消息、文件、窗口和场景状态都可以保存、恢复和分叉。
- **飞行**：默认演出为 15 秒资源记录；排演由不稳定物理和可编辑的飞控进程闭环控制；
  低预算/高时间速率会拉长控制周期并导致发散；记录保存实际输入与控制时序。

## 自绘资源

壁纸（SVG 程序化风景）、应用图标、窗口材质、巢语语言、直升机模型（几何/涂装/贴图）、
场景地形与特效全部由本项目生成，不复制任何现有桌面系统或浏览器界面素材。
Three.js 仅作为 WebGL 图形库随项目打包。

## 已知边界

- 根系统 Chromium 网页由宿主 Electron 执行，占用真实网络与时间，不参与自定义预算、完整快照或子系统升级暂停。
- 自定义操作系统不实现硬件启动、指令集或兼容现有操作系统；程序由巢语 VM 执行。
- 作品面向 PC 桌面鼠标 + 键盘操作，界面为简体中文。
