# 动态路由塔防 · 网络安全攻防战

纯前端 3D 塔防项目。直接双击根目录的 `index.html` 即可在 Chrome 中运行，不需要网页服务器。

## 操作

- **左键**：点选设备/敌人/地块，拖动底部卡片部署。
- **中键拖动**：环绕镜头。
- **Shift + 中键拖动**：平移镜头。
- **滚轮**：缩放。
- **1–6**：快速选择塔卡片。
- **Q / W / E**：应急隔离器 / 协议降级 / 备份还原。
- **[ / ]**：降低 / 提高游戏速度。
- **Space**：暂停 / 继续；**M**：静音；**C**：设备手册。
- **Esc**：取消部署或关闭弹窗。

## 机制

- 在交换节点上部署防火墙或网闸会隔离该节点，所有入口路线按 Dijkstra 重新计算；确认前会显示新路线预览。
- 隔离、撤下和节点被摧毁后都有 12 秒再隔离冷却。
- 三张地图有不同拓扑：分段内网的节点影响单入口或双入口；骨干流域三路汇入双出口；气隙深层围绕中央物理隔离区展开。
- 全部波次结束后按中枢完整度结算；Boss 拥有独立阶段技能和改道/黑洞/锁路能力。

## 实战演示

主菜单 / 关卡选择页底部有三个演示入口，正常 1× 速度下总时长 54 秒：

- `demo-1` 分段取舍
- `demo-2` 旁路直通
- `demo-3` 蛰影现身

## 视频导出接口

```js
window.videoExport.runs                          // ['demo-1', 'demo-2', 'demo-3']
await window.videoExport.begin(runId, { fps })   // 返回 { frames }
await window.videoExport.frame(i)                // i 从 0 开始，按 i/fps 推进
window.videoExport.end()                         // 回到正常可操作状态
```

接口在 `file://` 下可用，支持 3840×2160；逐帧调用会逐帧渲染完整页面（含 HUD、字幕、演示鼠标）。
