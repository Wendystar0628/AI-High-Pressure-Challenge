# 软物质实验室 · 果冻冲击与造浪水槽

一个以软体、刚体与流体相互作用为主题的单页三维交互作品。直接双击根目录的 `index.html`，在 Chrome 中以本地文件方式打开即可运行，不需要服务器，也不会从网络加载任何内容。

## 场景

### 01 重球冲击果冻台

- 果冻由晶格 PBD 软体（结构 / 剪切 / 弯曲约束）驱动，表面使用 FFD 变形，局部凹陷会向整体传播，并叠加受冲击激发的低阶软体振荡模式。
- 重球与果冻之间是双向弹簧—阻尼接触：重球压出凹陷、反弹、滑落或停在果冻上；果冻的反作用改变球的速度。
- 三种演示模式：正中撞击、偏心撞击、多球连续冲击。
- 果冻材质使用透射 + 衰减 + clearcoat，内部有气泡和柔光核；金属球使用环境反射和软阴影。
- 可选连续多次撞击、自由放置底边，果冻色有薄荷 / 莓果 / 蜜桃。

### 02 同尺寸多密度球造浪水槽

- 线性浅水方程（水位 + 深度平均流速）实时求解水面，并叠加推板体积源、入水冲击、底部环流和湍流扰动。
- 四组同半径、不同密度的小球（0.32 / 0.76 / 1.00 / 1.85）：低密度漂浮、近中性近水面漂浮、中性悬浮漂移、高密度沉底；包含浮力、阻力、附加质量、球球碰撞、壁面与底部滚动。
- 造浪装置支持推板活塞、摆式波板、垂直活塞三种形态。
- 完整实验时序：各密度组的球从水面上方依次释放；最后一组最后一颗球首次触水记为 `t_last`，在 `t_last + 1s` 自动启动造浪，持续 5s 后自动停止，随后水体波动衰减、球群重新分层。
- 水面有高光、泡沫、浪花、飞溅粒子、水下气泡、底部焦散、玻璃边缘高光和水位刻度。

## 操作

- 顶部标签切换两个场景。
- 左键拖动旋转，滚轮缩放。
- 空格暂停 / 继续；`R` 重置；`1` / `2` 切换场景。
- 速度按钮支持 `1× / 0.5× / 0.25×` 慢动作。
- 右上角“声音”开关控制 WebAudio 合成音效（首次点击页面后解锁）。
- 右侧“参数”面板可调所有对象参数；结构参数重建实验，动态参数即时生效。
- 场景一可单独触发重球；场景二可完整实验、重新释放小球、手动开始 / 停止造浪。

## 视频导出接口

页面暴露固定接口，用于逐帧导出画面（不处理声音）：

```js
window.videoExport.runs
// ['jelly-center', 'jelly-multi', 'jelly-offset', 'tank-full']

const { frames } = await window.videoExport.begin('jelly-center', { fps: 60 });
for (let i = 0; i < frames; i++) {
  await window.videoExport.frame(i); // 第 i 帧已渲染到画布
}
window.videoExport.end();
```

- 每个片段都会回到重置后的初始状态，使用预置的演示参数和演示镜头。
- `frame(i)` 对应仿真时刻 `i / fps`，与真实时间、机器速度无关；进入导出模式后实时循环不再推进同一仿真。
- 导出时页面只显示场景画面，没有 HUD / 面板；画面随窗口尺寸自适应，最高支持 3840×2160。

## 技术

- WebGL / Three.js（随项目交付的 `vendor/three.min.js`，无网络依赖）。
- 所有纹理（环境反射、背景、光斑、粒子、标牌、刻度）在运行时由 Canvas 2D 生成，避免 `file://` 下的图片纹理限制。
- 全部脚本为经典 `<script>`，不使用模块导入，保证本地双击可运行。
- 仿真使用固定时间步长，导出可确定性重放。
