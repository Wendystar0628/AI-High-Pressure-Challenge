# 棱镜嵌套操作系统（Nested OS）操作与开发说明

欢迎使用 **Nested OS（棱镜嵌套图形操作系统）**。本说明可随时从根系统桌面双击 **《操作说明.md》** 或通过编辑器打开查阅。

---

## 一、快速上手与递归系统树操作

1. **根系统（`outer`）**：提供文件管理器、电子表格、小组件面板、文本与程序编辑器、任务管理器、系统设置及内置真实 Chromium 浏览器。
2. **创建与管理子系统（`inner-1`, `inner-2`, ...）**：
   - 在任意一层桌面点击桌面/任务栏上的 **“新建子系统”** 或在任务/进程管理器中点击 **“新建直属子系统”**，即可在该系统内创建并启动一个直属子系统承载进程。
   - 支持 **4 层及以上** 深度嵌套以及同一父系统下并行的兄弟子系统分支。
   - 每层任务/进程管理器均可对直属子系统执行：**暂停、继续、单步（固定逻辑步长 `0.05s = 50ms`）、调速（`0.25x ~ 8.0x`）、调整拨付上限、打开内核源码、重启、关闭、创建子树快照、恢复到原实例、从快照分叉新子树**。
3. **窗口与桌面操作**：
   - 桌面图标单击选中、双击打开；桌面空白处与文件项支持右键菜单（按 `Esc` 收起）。
   - 窗口支持标题栏拖动、八向边缘缩放、双击标题栏最大化/恢复、拖至桌面左右边缘半屏贴靠、最小化与关闭。

## 二、执行边界、预算计量与配额说明

### 1. 宿主与系统的执行边界
- **根系统（`outer`）** 由宿主直接驱动日常应用，同时运行 `NosVM` 执行根系统自定义程序及一级子系统的承载进程。
- **所有非根子系统** 完全由父系统文件系统中的内核程序 `/Subsystems/<id>/kernel.nos` 在 `NosVM` 虚拟机内驱动：进程表、调度、虚拟时间唤醒、IPC 消息队列、VFS 文件系统、系统调用分发、窗口管理（`/System/wm.nos`）、文件管理器（`/Apps/files.nos`）、编辑器（`/Apps/editor.nos`）、进程管理器（`/Apps/tasks.nos`）、三维播放器三进程协作组（`player_timeline.nos` + `player_scene.nos` + `player_fx.nos`）、闭环飞控（`/Apps/flight_ctrl.nos`）以及图表双进程组（`charts.nos` + `chart_recv.nos`）均为真实运行在 `NosVM` 中的系统程序。
- **不计入自定义逻辑预算的边界**：
  1. 宿主显示设备根据程序已提交的场景/图元数据执行底层 WebGL 2 光栅化与屏幕合成；
  2. 根系统 Chromium `<webview>` 内外部真实网页的脚本、排版与音视频解码（按真实时间与网络运行，在任务管理器中单独列出，不计入自定义指令读数，也不纳入子树完整快照）。
- **跨层窗口投送边界**：
  - **投送外框**（移动、缩放、最小化、贴靠、关闭投送视图）归属**目标祖先桌面**；
  - **应用内容、状态与计算**（播放推进、物理演化、飞控、图表重算与过渡）始终归属**源子系统进程**，按逐级拨付消耗源子系统预算；投送窗口内的交互经跨层接口送回源进程消息队列。

### 2. 逻辑预算、部分进度续行与配额单位
- **固定逻辑步长**：每次逻辑推进步长为 **`50ms`（`0.05` 秒）**；单步执行按钮（`单步 +50ms`）精确推进直属子树一个 `0.05s` 逻辑步。
- **逻辑工作量单位（`ops`）**：
  - 基本字节码算术、控制流与变量读写：每条指令 `1 op`；
  - 字符串拼接、切片、查找、数组拷贝、JSON 编解码、深拷贝 `clone`、系统调用封送与显示提交：按实际数据规模附加 `ceil(N / K)` 的规模计费；
  - **按进度付费续行**：若某项高开销操作需 `C` 单位而当前分片剩余预算仅 `B < C`，虚拟机先扣除 `B` 并记录剩余未完成工作 `remainingWork = C - B`，暂不提交结果；待下次分片取得额度补足差额后立即完成提交并继续推进。
- **内存与存储配额（字节 `Bytes`）**：
  - 虚拟机实时统计栈帧、局部变量、全局变量、字符串及堆内数组/对象的字节占用，超出系统或进程内存配额时触发 `E_MEM_QUOTA` 错误；
  - VFS 文件写入实时校验系统存储配额（`storageQuota`），超出时返回 `E_STORAGE_QUOTA` 并拒绝写入，不影响配额范围外的兄弟或祖先系统。

## 三、NosLang 程序格式、自举编译器与系统调用接口

### 1. 语言语法（`.nos`）
`NosLang` 采用类 C / JS 过程式语法：
- 变量与函数：`let x = 10;`、`fn add(a, b) { return a + b; }`，入口函数为 `fn main(arg0, arg1) { ... }`；
- 控制流：`if (...) { ... } else { ... }`、`while (...) { ... }`、`for (let i = 0; i < n; i++) { ... }`、`break;`、`continue;`；
- 数据结构：数组 `[1, 2, 3]`，对象 `{ key: "val", count: 4 }`，支持 `.` 与 `[]` 访问及 `=`, `+=`, `-=`, `*=`；
- 内置纯函数：`len`, `push`, `pop`, `shift`, `slice`, `substr`, `char_at`, `char_code`, `from_char_code`, `index_of`, `split`, `join`, `trim`, `replace`, `keys`, `has_key`, `delete_key`, `clone`, `json_encode`, `json_decode`, `num`, `parse_num`, `is_nan`, `str`, `type_of`, `sin`, `cos`, `tan`, `atan2`, `sqrt`, `abs`, `min`, `max`, `clamp`, `floor`, `ceil`, `round`, `pow`, `rand`。

### 2. 自举编译器（`/System/compiler.nos`）
编译器自身使用 `NosLang` 编写，编译产物存放在 `/System/compiler.nbc`。
- 在编辑器中打开 `/System/compiler.nos` 修改规则（例如修改 `COMPILER_VERSION` 或扩展语法糖），保存后点击 **“运行”**，编译器会在系统内编译自身并更新 `/System/compiler.nbc`，此后编译并启动的任何程序均使用新编译器。

### 3. 核心系统调用（`syscall(name, ...args)`）
| 系统调用 | 参数与返回说明 |
|---|---|
| `syscall("time_now")` | 返回本系统当前虚拟时间（秒，浮点数） |
| `syscall("sleep", seconds)` | 阻塞等待指定虚拟时长，到时唤醒 |
| `syscall("get_pid")` | 返回当前进程在本系统内的唯一 PID |
| `syscall("proc_spawn", path, args, opts)` | 编译并启动新进程，返回 `{ ok, pid, error }` |
| `syscall("proc_exit", code)` / `syscall("proc_kill", pid)` | 结束自身或指定进程 |
| `syscall("send_msg", targetPid, data)` | 向目标 PID 发送深拷贝消息，目标不存在时返回 `{ ok: false, error: "ERR_NO_TARGET..." }` |
| `syscall("recv_msg")` / `syscall("recv_msg_wait", timeout)` | 非阻塞接收 / 阻塞等待下一条消息 `{ from, seq, time, data }` |
| `syscall("fs_read", path)` / `syscall("fs_write", path, text)` | 读写本系统 VFS 文件 |
| `syscall("fs_list", dir)` / `syscall("fs_delete", path)` | 列出目录项 / 删除移入回收站 |
| `syscall("report_result", text)` / `syscall("report_error", text)` | 报告进程执行结果或错误（在编辑器与进程管理器可见） |
| `syscall("surface_submit", winId, surfacePacket)` | 向所属应用窗口提交二维界面/矢量图或三维场景时刻状态 |

### 4. 修改内核与系统程序的方法
1. **修改直属子系统内核**：在父系统进程/任务管理器中点击对应子系统的 **“内核源码”**（打开 `/Subsystems/<id>/kernel.nos`）：
   - 修改 `SCHED_POLICY`（如改为 `"favor_low_pid"` 或 `"favor_high_pid"`）或 `DEFAULT_TIME_SLICE` 改变调度策略；
   - 在 `dispatch_syscall` 中添加新的 `if (callName == "my_syscall") { __vm_resume(proc.vmId, "ok"); return null; }` 增加系统调用；
   - 修改 `deliver_message` 中的 `MSG_ORDER = "lifo"` 或 `MSG_PREFIX = "[TAG] "` 改变消息投递规则；
   - 修改 `vfs_list_dir` 改变文件列表可见性规则。
   保存后点击该子系统的 **“重启”**，新内核立即生效；若改出语法或运行错误，子系统将显示内核错误面板并停止，父系统与兄弟子系统不受影响，改回保存再点重启即可恢复。
2. **修改窗口管理器与应用行为**：在子系统编辑器中打开 `/System/wm.nos`（如将 `FOCUS_POLICY` 改为 `"hover"` 悬停获焦，或 `RAISE_ON_FOCUS = false`）、`/Apps/files.nos`（如改 `SORT_MODE = "size_desc"`）或 `/Apps/charts.nos`（如改 `VALUE_SCALE = 2.0` 或 `SORT_CATEGORIES = "desc"`），保存并重启子系统或重开应用即按新规则运行。

## 四、飞控接口与编写自定义飞控程序

排演模式下，`player_scene.nos` 每步将传感器数据写入会话通道 `sid`（作为 `main(sid)` 参数传入飞控进程），飞控进程通过以下两个系统调用实现闭环控制：

1. **读取传感器**：`let s = syscall("fc_read_sensors", sid);`
   - `s.timestamp`：传感器采样虚拟时间戳（秒）
   - `s.pos` / `s.vel`：世界坐标位置 `[x, y, z]` 与线速度 `[vx, vy, vz]`
   - `s.rot` / `s.angVel`：姿态角 `[pitch, yaw, roll]`（弧度）与角速度
   - `s.groundY`：机体正下方真实地形高度；`s.pad2`：二号停机坪 `[x, y, z]` 坐标
   - `s.wind`：当前风速向量；`s.targetHeading`：目标航向角（度）；`s.faultStage`：故障阶段
2. **写入舵面与总距**：
   ```js
   syscall("fc_write_controls", sid, {
     collective: 0.56,   // 总距 [0.0 ~ 1.0]
     cyclicPitch: -0.08, // 纵向周期变距 [-1.0 ~ 1.0]
     cyclicRoll: 0.02,   // 横向周期变距 [-1.0 ~ 1.0]
     tailPedal: 0.25     // 尾桨脚蹬量 [-1.0 ~ 1.0]
   });
   ```
在编辑器中将新飞控保存至 `/Programs/my_ctrl.nos`，即可在播放器排演栏的飞控下拉框中选择并切换驾驶。

## 五、三维场景格式（`.scene`）与最小场景示例

场景与排演记录均为纯 JSON 数据文件（无宿主代码）。最小合法场景示例（已预置在 `/Demo/minimal.scene`，一个物体、一盏灯、一台相机）：

```json
{
  "format": "nestedos-scene-v1",
  "meta": { "name": "最小三维示例场景", "duration": 8.0, "fps": 30 },
  "environment": {
    "skyTop": "#0f172a",
    "skyHorizon": "#334155",
    "lights": [{ "type": "directional", "color": "#fff7ed", "intensity": 1.8, "pos": [12, 20, 10], "castShadow": true }],
    "terrain": { "size": 40, "segments": 24, "baseY": 0, "hillAmp": 0, "color": "#1e293b" }
  },
  "cameras": { "defaultEye": [4.5, 3.4, 5.5], "defaultTarget": [0, 1.1, 0], "fov": 46 },
  "nodes": [
    {
      "id": "cube_1",
      "label": "示例多面体",
      "parentId": null,
      "pos": [0, 1.2, 0],
      "rot": [0, 0, 0],
      "scale": [1, 1, 1],
      "geometry": { "type": "box", "size": [1.5, 1.5, 1.5] },
      "material": { "color": "#8b5cf6", "roughness": 0.32, "metalness": 0.25 },
      "castShadow": true
    }
  ],
  "tracks": [{ "nodeId": "cube_1", "spinSpeed": 1.2, "bobAmp": 0.25, "baseY": 1.25 }]
}
```

工作簿文件（`.sheet`）采用 JSON 存储行列尺寸、单元格原始公式（支持四则运算、括号、单元格/区域引用与 `SUM`）及对齐加粗格式；排演记录（`.rec`）保存完整场景资源、初态与实际控制输入时序，重开后可任意跳转回放或从中继续排演分叉出新的后续过程。
