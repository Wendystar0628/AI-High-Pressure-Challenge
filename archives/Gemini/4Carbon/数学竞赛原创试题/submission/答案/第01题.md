最小实数为 $K_n = 3n^4 - 3n^2 - 8n$。

全部取等数组刻画如下：设 $h = n/2$。实数数组 $x = (x_{ij})_{0\le i,j<n}$ 使不等式取等，当且仅当存在实数 $\lambda \ge 0$、网格 $(\mathbb Z/n\mathbb Z)^2$ 的一个 $h$ 元划分 $B_1, B_2, \ldots, B_h$，以及每个 $B_m$（$1\le m\le h$）上的三个函数 $\alpha^{(m)}, \beta^{(m)}, \gamma^{(m)} : B_m \to \{0,1\}$，同时满足：
1. 每个 $B_m$ 与每行、每列、每条循环对角线 $D_d$ 的交集都恰含 $2$ 个格点；
2. 在每行与 $B_m$ 的 $2$ 个交点上 $\alpha^{(m)}$ 取遍 $\{0,1\}$，在每列与 $B_m$ 的 $2$ 个交点上 $\beta^{(m)}$ 取遍 $\{0,1\}$，在每条 $D_d$ 与 $B_m$ 的 $2$ 个交点上 $\gamma^{(m)}$ 取遍 $\{0,1\}$；
3. 每个 $B_m$ 中至多有 $2$ 个（从而必恰有 $2$ 个）格点处 $\alpha^{(m)}, \beta^{(m)}, \gamma^{(m)}$ 不全相等；
4. 对每个 $1\le m\le h$ 及一切 $(i,j)\in B_m$，有
$$
x_{ij} = \lambda\Bigl(3(4m - n - 3) + 2\bigl(\alpha^{(m)}_{ij} + \beta^{(m)}_{ij} + \gamma^{(m)}_{ij}\bigr)\Bigr).
$$
（特别地，$\lambda = 0$ 对应全零数组。）

---

### 证明

#### 一、上界估计与取等必要条件

记权集 $W_n = \{w_1 < w_2 < \cdots < w_n\}$，其中 $w_k = 2k - n - 1$（$1\le k\le n$）遍历绝对值不超过 $n-1$ 的全体奇数。易算得
$$
\sum_{w\in W_n} w^2 = \sum_{k=1}^n (2k-n-1)^2 = \frac{n(n^2-1)}{3}.
$$
对任意实数数组 $x$，在每条线 $L$ 上将其 $n$ 个格点按 $x_p$ 从小到大排列，依次赋予权值 $w_1,\ldots,w_n$，得到双射 $w_L : L \to W_n$，使得 $w_L(p) < w_L(q) \implies x_p \le x_q$，且
$$
\sum_{\substack{\{p,q\}\subseteq L\\p\ne q}} |x_p - x_q| = \sum_{p\in L} w_L(p)x_p.
$$
对格点 $(i,j)$，分别记 $r_{ij} = w_{R_i}(i,j)$、$s_{ij} = w_{C_j}(i,j)$、$t_{ij} = w_{D_{j-i}}(i,j)$（第 $i$ 行、第 $j$ 列、对角线 $D_{j-i}$ 在 $(i,j)$ 处的权），并令 $c_{ij} = r_{ij} + s_{ij} + t_{ij}$。于是
$$
T(x) = \sum_{i,j=0}^{n-1} c_{ij}x_{ij}.
$$
由 Cauchy–Schwarz 不等式，
$$
T(x)^2 \le \left(\sum_{i,j=0}^{n-1} c_{ij}^2\right)\left(\sum_{i,j=0}^{n-1} x_{ij}^2\right).
$$

利用恒等式 $(r+s+t)^2 = 3(r^2+s^2+t^2) - \bigl((r-s)^2 + (s-t)^2 + (t-r)^2\bigr)$，记 $\Delta_{ij} = (r_{ij}-s_{ij})^2 + (s_{ij}-t_{ij})^2 + (t_{ij}-r_{ij})^2$，对全体格点求和得
$$
\sum_{i,j=0}^{n-1} c_{ij}^2 = 3\cdot 3n\cdot \frac{n(n^2-1)}{3} - \sum_{i,j=0}^{n-1} \Delta_{ij} = 3n^2(n^2-1) - \sum_{i,j=0}^{n-1} \Delta_{ij}.
$$

对每个 $w\in W_n$，记 $R_w = \{(i,j) : r_{ij} = w\}$、$C_w = \{(i,j) : s_{ij} = w\}$、$T_w = \{(i,j) : t_{ij} = w\}$，它们各含 $n$ 个格点。断言 $R_w$ 中不可能所有格点都满足 $\Delta_{ij} = 0$。否则 $R_w = C_w = T_w$，记此 $n$ 元集为 $S$，则 $S$ 每行、每列、每条 $D_d$ 各含一点。在模 $n$ 下求和，一方面
$$
\sum_{(i,j)\in S} (j - i) \equiv \sum_{j=0}^{n-1} j - \sum_{i=0}^{n-1} i = 0 \pmod n,
$$
另一方面 $j - i \bmod n$ 遍历 $0,1,\ldots,n-1$，故
$$
\sum_{(i,j)\in S} (j - i) \equiv \sum_{d=0}^{n-1} d = \frac{n(n-1)}{2} \equiv \frac{n}{2} \not\equiv 0 \pmod n
$$
（因 $n$ 为偶数），矛盾。

由于 $r_{ij}, s_{ij}, t_{ij}$ 均为奇数，只要三者不全相等，就至少有两个相差非零偶数，从而 $\Delta_{ij} \ge 0^2 + 2^2 + 2^2 = 8$。结合 $\{R_w\}_{w\in W_n}$ 构成网格的划分，且每个 $R_w$ 至少含一个 $\Delta_{ij} \ge 8$ 的格点，得
$$
\sum_{i,j=0}^{n-1} \Delta_{ij} \ge 8n, \qquad \sum_{i,j=0}^{n-1} c_{ij}^2 \le 3n^2(n^2-1) - 8n = 3n^4 - 3n^2 - 8n.
$$
故 $T(x)^2 \le (3n^4 - 3n^2 - 8n)\sum_{i,j} x_{ij}^2$ 对一切实数数组成立。

现设非零数组 $x$ 使不等式取等（全零数组已对应 $\lambda = 0$）。则 Cauchy–Schwarz 不等式取等，结合 $T(x) > 0$ 知存在 $\lambda > 0$ 使 $x_{ij} = \lambda c_{ij}$；同时必有 $\sum_{i,j}\Delta_{ij} = 8n$。记 $E = \{(i,j) : \Delta_{ij} > 0\}$，分别对划分 $\{R_w\}$、$\{C_w\}$、$\{T_w\}$ 应用上述下界可知：
- $|E| = n$，且对每个 $e\in E$ 有 $\Delta_e = 8$，即 $(r_e, s_e, t_e)$ 形如 $(u, u, u\pm 2)$ 的排列；
- $r|_E, s|_E, t|_E$ 均为 $E \to W_n$ 的双射，故在多重集 $\{r_e, s_e, t_e : e\in E\}$（共 $3n$ 个数）中，每个 $w\in W_n$ 恰出现 $3$ 次。

将 $W_n$ 按大小分为 $h = n/2$ 对相邻奇数 $P_m = \{w_{2m-1}, w_{2m}\} = \{4m-n-3, 4m-n-1\}$（$1\le m\le h$）。对 $m = h, h-1, \ldots, 1$ 倒序归纳证明：$E$ 中恰有两个格点使 $(r_e, s_e, t_e)$ 的分量全落在 $P_m$ 内，且与其余格点分量互不相交。事实上，在尚未配对的 $2m$ 个格点中，最大权 $w_{2m}$ 共出现 $3$ 次，而在每个格点处至多出现 $2$ 次（因 $\Delta_e = 8$），且与其同处一格点的另一权只能是 $w_{2m}-2 = w_{2m-1}$。故必有一格点分量重排后为 $(w_{2m}, w_{2m}, w_{2m-1})$，另一格点重排后为 $(w_{2m-1}, w_{2m-1}, w_{2m})$。这两点恰好耗尽 $w_{2m}$ 和 $w_{2m-1}$ 的全部各 $3$ 次出现，归纳成立。

由此，对网格中每个格点 $p$，无论 $p\notin E$（此时 $r_p = s_p = t_p$）还是 $p\in E$，三数 $r_p, s_p, t_p$ 都属于同一个对 $P_m$。令 $B_m = \{p : r_p \in P_m\}$，则 $B_m = \{p : s_p\in P_m\} = \{p : t_p\in P_m\}$。于是 $\{B_m\}_{1\le m\le h}$ 构成网格的划分，且满足条件 1；在 $B_m$ 上令
$$
\alpha^{(m)}_p = \frac{r_p - w_{2m-1}}{2},\quad \beta^{(m)}_p = \frac{s_p - w_{2m-1}}{2},\quad \gamma^{(m)}_p = \frac{t_p - w_{2m-1}}{2},
$$
即满足条件 2、3、4。必要性得证。

#### 二、取等条件的充分性

反过来，设 $\lambda \ge 0$、$\{B_m\}$ 及 $\alpha^{(m)}, \beta^{(m)}, \gamma^{(m)}$ 满足条件 1–4。当 $\lambda = 0$ 时 $x = 0$ 显然取等；下设 $\lambda > 0$。

固定 $m\in \{1,\ldots,h\}$，简记 $\alpha = \alpha^{(m)}, \beta = \beta^{(m)}, \gamma = \gamma^{(m)}$ 及 $u = 4m - n - 3$。令 $F_m = \{p\in B_m : \alpha_p, \beta_p, \gamma_p\text{ 不全相等}\}$。由条件 3 知 $|F_m| \le 2$。
- 若 $|F_m| \le 1$，由于 $\sum_{p\in B_m}\alpha_p = \sum_{p\in B_m}\beta_p = \sum_{p\in B_m}\gamma_p = n$，在 $B_m\setminus F_m$ 上三者相等迫使在仅剩的一点处三者也相等，即 $F_m = \varnothing$。此时 $\{p\in B_m : \alpha_p = 1\}$ 每行、每列、每条 $D_d$ 各含一点，已证这在偶数 $n$ 时不可能。
- 故必有 $|F_m| = 2$，记 $F_m = \{e^-, e^+\}$。设 $I_1 = \{p\in B_m\setminus F_m : \alpha_p = \beta_p = \gamma_p = 1\}$ 的元素个数为 $k$，则 $\alpha_{e^-} + \alpha_{e^+} = \beta_{e^-} + \beta_{e^+} = \gamma_{e^-} + \gamma_{e^+} = n - k$。若 $n - k \in \{0, 2\}$，则 $e^-, e^+$ 处三者全为 $0$ 或全为 $1$，矛盾；故 $k = n - 1$，且 $\alpha, \beta, \gamma$ 在 $\{e^-, e^+\}$ 上各取一次 $0$ 和 $1$。因 $e^-, e^+$ 处三者不全相等，不妨设 $(\alpha, \beta, \gamma)_{e^-}$ 是 $(1,0,0)$ 的排列，则 $(\alpha, \beta, \gamma)_{e^+} = (1,1,1) - (\alpha, \beta, \gamma)_{e^-}$。

定义 $r_p = u + 2\alpha_p, s_p = u + 2\beta_p, t_p = u + 2\gamma_p$（$p\in B_m$），拼合全部 $m$ 后每条线 $L$ 上的权 $w_L$ 恰构成到 $W_n$ 的双射，且 $x_p = \lambda c_p$，$\sum_{i,j}\Delta_{ij} = h\cdot(8 + 8) = 8n$，故 $\sum_{i,j} c_{ij}^2 = 3n^4 - 3n^2 - 8n$。只需验证对每条线 $L$ 及 $p, q\in L$，有 $w_L(p) < w_L(q) \implies c_p \le c_q$（此时 $T(x) = \sum c_{ij}x_{ij} = \lambda\sum c_{ij}^2$，自动取等）：
1. 若 $p\in B_m, q\in B_{m'}$ 且 $m < m'$，则 $c_p \le 3u + 6 = 12m - 3n - 3 < 12m' - 3n - 9 \le c_q$。
2. 若 $p, q\in B_m$ 且 $w_L(p) = u < u + 2 = w_L(q)$，则 $c_p \in \{3u, 3u+2, 3u+4\}$，$c_q \in \{3u+2, 3u+4, 3u+6\}$，且 $p\ne q$。唯一可能出现 $c_p > c_q$ 的情形是 $c_p = 3u + 4$（即 $p = e^+$，且 $e^+$ 在 $L$ 方向指标为 $0$）同时 $c_q = 3u + 2$（即 $q = e^-$，且 $e^-$ 在 $L$ 方向指标为 $1$），并且 $e^+, e^-$ 同在 $L$ 上。但记 $\{p_1\} = \{z\in B_m : \alpha_z = 1\}\setminus I_1$、$\{p_2\} = \{z\in B_m : \beta_z = 1\}\setminus I_1$、$\{p_3\} = \{z\in B_m : \gamma_z = 1\}\setminus I_1$，并记 $p_k = (i_k, j_k)$，对这三个每行、每列、每条对角线各含一点的 $n$ 元集作模 $n$ 求和：
   $$
   \sum_{(i,j)\in I_1} i + i_1 \equiv \frac{n}{2},\quad \sum_{(i,j)\in I_1} j + j_2 \equiv \frac{n}{2},\quad \sum_{(i,j)\in I_1} (j-i) + (j_3-i_3) \equiv \frac{n}{2} \pmod n,
   $$
   相减即得 $(j_3 - i_3) - (j_2 - i_1) \equiv \frac{n}{2} \pmod n$。设 $e^- = (i_-, j_-), e^+ = (i_+, j_+)$：
   - 若 $(\alpha, \beta, \gamma)_{e^-} = (1,0,0)$（此时 $L$ 只能是行），则 $p_1 = e^-, p_2 = p_3 = e^+$，上式化为 $i_- - i_+ \equiv \frac{n}{2} \not\equiv 0 \pmod n$，故 $e^-, e^+$ 不同行；
   - 若 $(\alpha, \beta, \gamma)_{e^-} = (0,1,0)$（此时 $L$ 只能是列），则 $p_2 = e^-, p_1 = p_3 = e^+$，上式化为 $j_+ - j_- \equiv \frac{n}{2} \not\equiv 0 \pmod n$，故 $e^-, e^+$ 不同列；
   - 若 $(\alpha, \beta, \gamma)_{e^-} = (0,0,1)$（此时 $L$ 只能是对角线），则 $p_3 = e^-, p_1 = p_2 = e^+$，上式化为 $(j_- - i_-) - (j_+ - i_+) \equiv \frac{n}{2} \not\equiv 0 \pmod n$，故 $e^-, e^+$ 不在同一条循环对角线上。
   因此必有 $c_p < c_q$，充分性得证。

#### 三、非零取等数组的存在性构造（证明 $K_n$ 可达到）

对任意偶数 $n = 2h \ge 2$，将每个坐标 $(i,j)\in \{0,1,\ldots,2h-1\}^2$ 唯一表为
$$
i = a + \epsilon h \quad(0\le a < h,\ \epsilon\in\{0,1\}), \qquad j = 2b + \delta \quad(0\le b < h,\ \delta\in\{0,1\}).
$$
对 $1\le m\le h$，定义
$$
B_m = \bigl\{(i,j) : b - a \equiv m - 1 \pmod h\bigr\},
$$
并在 $B_m$ 上定义（记 $\oplus$ 为模 $2$ 加法）：
$$
\bigl(\alpha^{(m)}_{ij}, \beta^{(m)}_{ij}, \gamma^{(m)}_{ij}\bigr) =
\begin{cases}
(\epsilon\oplus\delta,\ \epsilon\oplus\delta,\ \epsilon\oplus\delta), & 0\le a\le h-2,\\
(\delta,\ \epsilon,\ \epsilon), & a = h-1.
\end{cases}
$$
验证条件 1–3：
- 固定行 $i = a + \epsilon h$，$b = (a+m-1)\bmod h$ 唯一确定，$\delta\in\{0,1\}$ 给出 $B_m$ 在该行的 $2$ 点，且 $\alpha^{(m)}$（为 $\epsilon\oplus\delta$ 或 $\delta$）均取遍 $\{0,1\}$；
- 固定列 $j = 2b + \delta$，$a = (b-m+1)\bmod h$ 唯一确定，$\epsilon\in\{0,1\}$ 给出 $B_m$ 在该列的 $2$ 点，且 $\beta^{(m)}$（为 $\epsilon\oplus\delta$ 或 $\epsilon$）均取遍 $\{0,1\}$；
- 固定循环对角线 $D_d$，格点 $(i,j)\in D_d \cap B_m$ 当且仅当 $2b + \delta - (a + \epsilon h) \equiv d \pmod{2h}$ 且 $b \equiv a + m - 1 \pmod h$，消去 $b$ 即
  $$
  a - \epsilon h + \delta \equiv d - 2(m-1) \pmod{2h}.
  $$
  当 $(a,\epsilon)$ 遍历 $\{0,\ldots,h-1\}\times\{0,1\}$ 时，$a - \epsilon h$ 遍历 $\{-h, -(h-1), \ldots, h-1\}$，恰构成模 $2h$ 的完全剩余系。记 $s = (d - 2(m-1))\bmod 2h \in \{0,1,\ldots,2h-1\}$，则 $\delta = 0$ 时唯一解满足 $a_0 - \epsilon_0 h \equiv s \pmod{2h}$，$\delta = 1$ 时唯一解满足 $a_1 - \epsilon_1 h \equiv s - 1 \pmod{2h}$，故 $|D_d\cap B_m| = 2$。进而在两点处检查 $\gamma^{(m)}$（当 $a < h-1$ 时为 $\epsilon\oplus\delta$，当 $a = h-1$ 时为 $\epsilon$）：
  - 若 $s = 0$，两点为 $(a_0,\epsilon_0,\delta) = (0,0,0)$ 和 $(a_1,\epsilon_1,\delta) = (h-1,1,1)$，$\gamma^{(m)}$ 分别取 $0$ 和 $1$；
  - 若 $1\le s\le h-1$，两点为 $(s,0,0)$ 和 $(s-1,0,1)$，因 $s-1 < h-1$，第二点取 $0\oplus 1 = 1$，而第一点无论 $s < h-1$（取 $0\oplus 0 = 0$）还是 $s = h-1$（取 $\epsilon_0 = 0$）均取 $0$；
  - 若 $s = h$，两点为 $(0,1,0)$ 和 $(h-1,0,1)$，$\gamma^{(m)}$ 分别取 $1$（当 $h=1$ 时 $a_0=h-1$ 亦取 $\epsilon_0 = 1$）和 $\epsilon_1 = 0$；
  - 若 $h+1\le s\le 2h-1$，记 $c = s - h \in \{1,\ldots,h-1\}$，两点为 $(c,1,0)$ 和 $(c-1,1,1)$，第二点取 $1\oplus 1 = 0$，第一点无论 $c < h-1$ 还是 $c = h-1$ 均取 $1$。
  故 $\gamma^{(m)}$ 在每条 $D_d\cap B_m$ 上均取遍 $\{0,1\}$。
- 最后，每个 $B_m$ 中仅在 $a = h-1$ 且 $\epsilon\ne\delta$ 的两点处三指标不全相等。

取 $\lambda = 1$，由充分性知所得非零数组使不等式取等，从而 $K_n = 3n^4 - 3n^2 - 8n$ 确为最小值。
