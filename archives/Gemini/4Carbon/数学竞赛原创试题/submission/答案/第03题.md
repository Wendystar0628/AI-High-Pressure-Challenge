满足条件的全部整数 $L$ 如下：
- 当 $p = n + 1$ 时，不存在满足条件的 $L$（解集为 $\varnothing$）；
- 当 $p > n + 1$ 时，满足条件的全部整数 $L$ 为 $n + 1, n + 2, \ldots, p$。

---

### 证明

#### 一、反例构造（排除 $L \le n$，并在 $p = n+1$ 时排除全部 $L$）

1. **当 $1 \le L \le n$ 时**（对任意素数 $p > n$）：
   取 $S_1 = S_2 = \cdots = S_n = \{1, 2, \ldots, L\} \subset \mathbb Z/p\mathbb Z$（因 $L \le n < p$，这些剩余类两两不同），并取：
   - $a_1 = a_2 = \cdots = a_n = 0$；
   - $b_1 = b_2 = 1$，$b_3 = \cdots = b_n = 0$；
   - $c_1 = 1$，$d_1 = -1$，其余 $c_j = d_j = 0$（$2 \le j \le n/2$）。

   假定存在 $x_i \in S_i$ 满足条件 1–3。由条件 1，$x_1,\ldots,x_n$ 是 $\{1,\ldots,L\}$ 中 $n$ 个两两不同的元素，故若 $L < n$ 由抽屉原理直接矛盾；若 $L = n$，则 $\{x_1,\ldots,x_n\} = \{1,2,\ldots,n\}$。令 $A = \{x_1, x_2\}$、$B = \{x_3,\ldots,x_n\} = \{1,\ldots,n\} \setminus A$。由条件 2，$x_1+1, x_2+1, x_3, \ldots, x_n$ 在 $\mathbb Z/p\mathbb Z$ 中两两不同，故 $(A+1) \cap B = \varnothing$。因 $|A| = 2$ 且 $A \subseteq \{1,\ldots,n\}$，必有一元 $z \in A$ 满足 $1 \le z \le n-1$；由于 $n < p$，$z+1 \in \{2,\ldots,n\} \subseteq A \cup B$，结合 $z+1 \notin B$ 知 $z+1 \in A$。故 $A = \{z, z+1\}$，从而 $x_1 - x_2 \in \{1, -1\}$，与条件 3 矛盾。

2. **当 $p = n + 1$ 且 $L = p$ 时**：
   此时只能有 $S_1 = \cdots = S_n = \mathbb Z/p\mathbb Z$，仍取上面相同的 $a_i, b_i, c_j, d_j$。若存在解 $(x_1,\ldots,x_n)$，由条件 1 知 $\{x_1,\ldots,x_n\}$ 恰缺 $\mathbb Z/p\mathbb Z$ 中唯一元素 $u$。令 $y_i = x_i - u$，则 $\{y_1,\ldots,y_n\} = \{1,2,\ldots,p-1\} = \{1,2,\ldots,n\}$，同时 $y_1+1, y_2+1, y_3, \ldots, y_n$ 仍两两不同，且 $y_1 - y_2 = x_1 - x_2 \notin \{1, -1\}$。完全重复 $L = n$ 时的推理即得矛盾。

---

#### 二、当 $p > n + 1$ 且 $n + 1 \le L \le p$ 时的证明

在多项式环 $(\mathbb Z/p\mathbb Z)[x_1,\ldots,x_n]$ 中考察多项式
$$
P(x_1,\ldots,x_n) = \prod_{1\le i<k\le n}(x_i + a_i - x_k - a_k)\prod_{1\le i<k\le n}(x_i + b_i - x_k - b_k)\prod_{j=1}^{n/2}(x_{2j-1}-x_{2j}-c_j)(x_{2j-1}-x_{2j}-d_j).
$$
数组 $(x_1,\ldots,x_n)$ 满足条件 1–3 当且仅当 $P(x_1,\ldots,x_n) \ne 0$。多项式 $P$ 的总次数为 $\binom{n}{2} + \binom{n}{2} + n = n^2$，其最高次齐次部分是整系数多项式
$$
Q(x_1,\ldots,x_n) = \prod_{1\le i<k\le n}(x_i - x_k)^2 \prod_{j=1}^{n/2}(x_{2j-1} - x_{2j})^2 \in \mathbb Z[x_1,\ldots,x_n]
$$
在模 $p$ 下的像。记 $C_n \in \mathbb Z$ 为 $Q$ 中单项式 $x_1^n x_2^n \cdots x_n^n$ 的系数，下在复数域上求 $C_n$ 的精确值。

令 $h = n/2$，定义
$$
F(x_1,\ldots,x_n) = \prod_{1\le i<k\le n}(x_k - x_i)\prod_{j=1}^h (x_{2j-1} - x_{2j}).
$$
利用 $(u - v)^2 = -uv(u - v)(u^{-1} - v^{-1})$，且 $\binom{n}{2} + h = 2h^2$ 为偶数，故 $(-1)^{\binom{n}{2}+h} = 1$，相乘得洛朗多项式恒等式
$$
Q(x_1,\ldots,x_n) = (x_1\cdots x_n)^n F(x_1,\ldots,x_n)F(x_1^{-1},\ldots,x_n^{-1}).
$$
因此 $C_n$ 等于 $F(x)F(x^{-1})$ 的常数项。

令 $N = n + 1$（奇整数 $N \ge 3$），记 $N$ 次单位根群为 $\mu_N = \{1, \zeta, \ldots, \zeta^{N-1}\}$（$\zeta = e^{2\pi i/N}$）。由于 $F$ 关于每个变元 $x_i$ 的次数至多为 $(n-1) + 1 = n < N$，$F(x)F(x^{-1})$ 中每个 $x_i$ 的指数 $e_i \in [-n, n]$ 满足 $e_i \equiv 0 \pmod N \iff e_i = 0$。对全体 $(u_1,\ldots,u_n) \in \mu_N^n$ 求平均，并注意 $u_i \in \mu_N$ 时 $u_i^{-1} = \overline{u_i}$，得
$$
C_n = \frac{1}{N^n} \sum_{(u_1,\ldots,u_n)\in\mu_N^n} |F(u_1,\ldots,u_n)|^2.
$$
仅当 $u_1,\ldots,u_n$ 两两不同时 $F(u) \ne 0$，此时它们恰遗漏 $\mu_N$ 中唯一元素 $u_0$。旋转不变性表明 $N$ 种 $u_0$ 的选取贡献相等；固定 $u_0 = 1$ 时，$\{u_1,\ldots,u_n\} = \mu_N \setminus \{1\}$。对 $P_0(T) = T^N - 1$，由 $|P_0'(\zeta^a)| = N$ 得 $\prod_{0\le a\ne b<N}|\zeta^a - \zeta^b| = N^N$，除去含 $a=0$ 或 $b=0$ 的因子 $\prod_{b=1}^{N-1}|1-\zeta^b|^2 = |P_0'(1)|^2 = N^2$，即得
$$
\prod_{1\le a<b\le N-1}|\zeta^a - \zeta^b|^2 = N^{N-2} = N^{n-1}.
$$
故外层系数恰为 $\frac{N \cdot N^{n-1}}{N^n} = 1$，从而（对双射 $\sigma : \{1,\ldots,n\} \to \mu_N \setminus \{1\}$ 求和）
$$
C_n = \sum_{\sigma} \prod_{j=1}^h |u_{\sigma(2j-1)} - u_{\sigma(2j)}|^2 = \sum_{\sigma} \prod_{j=1}^h \bigl(2 - u_{\sigma(2j-1)}u_{\sigma(2j)}^{-1} - u_{\sigma(2j)}u_{\sigma(2j-1)}^{-1}\bigr).
$$
展开乘积，由对换 $\sigma(2j-1) \leftrightarrow \sigma(2j)$ 的对称性，在每个因子中选取 $-u_{\sigma(2j-1)}u_{\sigma(2j)}^{-1}$ 或 $-u_{\sigma(2j)}u_{\sigma(2j-1)}^{-1}$ 的和相等，故
$$
C_n = \sum_{k=0}^h \binom{h}{k} 2^{h-k}(-2)^k (n-2k)!\, A_k = 2^h \sum_{k=0}^h \binom{h}{k}(-1)^k (n-2k)!\, A_k,
$$
其中 $A_k$ 表示 $\prod_{j=1}^k z_j w_j^{-1}$ 对 $\mu_N \setminus \{1\}$ 中全体有序两两不同 $2k$ 元组 $(z_1,w_1,\ldots,z_k,w_k)$ 的和。记 $B_k$ 为同样乘积对整个 $\mu_N$ 中有序两两不同 $2k$ 元组的和。群 $\mu_N$ 通过同时乘以群元自由作用在全集有序 $2k$ 元组上且保持 $\prod_{j=1}^k z_j w_j^{-1}$ 不变；每条长为 $N$ 的轨道中，恰有 $2k$ 个元素包含 $1$，其余 $N - 2k$ 个落在 $\mu_N \setminus \{1\}$ 中，故
$$
A_k = \frac{N - 2k}{N} B_k.
$$

为求 $B_k$，考虑二元多项式 $G(x,y) = \prod_{u\in\mu_N}(1 + xu + yu^{-1})$。展开知 $x^k y^k$ 的系数恰为 $\frac{B_k}{(k!)^2}$。作形式幂级数代换 $x = -\frac{r_1}{1+r_1r_2}$、$y = -\frac{r_2}{1+r_1r_2}$，利用 $(1 - r_1 u)(1 - r_2 u^{-1}) = (1 + r_1r_2)(1 + xu + yu^{-1})$，得
$$
G\left(-\frac{r_1}{1+r_1r_2}, -\frac{r_2}{1+r_1r_2}\right) = \frac{\prod_{u\in\mu_N}(1-r_1 u)\prod_{u\in\mu_N}(1-r_2 u^{-1})}{(1+r_1r_2)^N} = \frac{(1 - r_1^N)(1 - r_2^N)}{(1 + r_1r_2)^N}.
$$
比较两边满足 $r_1$ 次数与 $r_2$ 次数相等的项，并记 $t = r_1 r_2$，得
$$
\sum_{k=0}^h \frac{B_k}{(k!)^2}\left(\frac{t}{(1+t)^2}\right)^k = \frac{1 + t^N}{(1 + t)^N}.
$$
另一方面，由归纳法易证幂和展开（Waring 公式）：对正整数 $m$ 及变元 $u, v$，有
$$
u^m + v^m = \sum_{k=0}^{\lfloor m/2\rfloor} (-1)^k \frac{m}{m-k}\binom{m-k}{k}(u+v)^{m-2k}(uv)^k
$$
（$m=1,2$ 显然；由 $u^{m+1}+v^{m+1} = (u+v)(u^m+v^m) - uv(u^{m-1}+v^{m-1})$ 及恒等式 $\frac{m}{m-k}\binom{m-k}{k} + \frac{m-1}{m-k}\binom{m-k}{k-1} = \frac{m+1}{m+1-k}\binom{m+1-k}{k}$ 即完成归纳）。取 $m = N, u = 1, v = t$ 并除以 $(1+t)^N$，对比 $\frac{t}{(1+t)^2} = t + O(t^2)$ 的各次幂系数，唯一确定对所有 $0 \le k \le h$ 有
$$
B_k = (-1)^k (k!)^2 \frac{N}{N-k}\binom{N-k}{k} = (-1)^k \frac{N\, k!\, (N-k-1)!}{(N-2k)!}.
$$

代回 $C_n$ 并注意 $N = n + 1$、$N - 2k = n + 1 - 2k$：
$$
\begin{aligned}
C_n &= 2^h \sum_{k=0}^h \binom{h}{k}(-1)^k (n-2k)!\,\frac{n+1-2k}{n+1}\cdot (-1)^k \frac{(n+1)\,k!\,(n-k)!}{(n+1-2k)!} \\
&= 2^h h! \sum_{k=0}^h \frac{(n-k)!}{(h-k)!} = 2^h (h!)^2 \sum_{k=0}^h \binom{n-k}{h} = 2^h (h!)^2 \binom{n+1}{h+1} = 2^{n/2}\frac{(n+1)!}{n/2 + 1},
\end{aligned}
$$
其中倒数第二步用了朱世杰恒等式 $\sum_{k=0}^h \binom{n-k}{h} = \binom{n+1}{h+1}$。

当素数 $p > n + 1$ 时，$2^{n/2}$ 与 $(n+1)!$ 的所有素因子均不超过 $n + 1 < p$，故 $C_n \not\equiv 0 \pmod p$，即 $P(x_1,\ldots,x_n)$ 中 $x_1^n\cdots x_n^n$ 的系数在 $\mathbb Z/p\mathbb Z$ 中非零。引用 **Alon 组合零点定理**（设域 $\mathbb F$ 上多项式 $P(x_1,\ldots,x_n)$ 的总次数为 $\sum_{i=1}^n t_i$，且 $x_1^{t_1}\cdots x_n^{t_n}$ 的系数非零，则对任意满足 $|S_i| > t_i$ 的子集 $S_1,\ldots,S_n \subseteq \mathbb F$，存在 $x_i \in S_i$ 使 $P(x_1,\ldots,x_n) \ne 0$），取 $t_1 = \cdots = t_n = n$，知当 $|S_i| = L \ge n + 1$ 时必存在满足条件 1–3 的选取 $(x_1,\ldots,x_n)$。证毕。
