# 设计逐项复查

当前版本已在本地文件模式的 Chrome 中实际运行并检查，以下时间均指 80 秒全局时间线。表格记录累计完善内容，末尾列出本轮新增验证。

| 题面设计项 | 对照结果与本轮处理 |
| --- | --- |
| 统一设计语言 | 保留双叉、叠甲、空槽及灰白／深蓝／青金配色，新增的舰体、发射架、舱内编号和断块也沿用单位格距。 |
| 旗舰大形与体量差 | 约 1100 格旗舰、168／196 格护卫与约 26 格小艇；肩甲增加外张轮廓，主壳板角部使用整数阶面收束，6 秒近景可见尺度参照。 |
| 旗舰壳层与近景结构 | 肩部多层板、腹部装置和塔楼肋架形成不同层次；12–15 秒展示舰腹，随后沿侧壳接近舱口。入口背板和局部底甲改为真实开口，内部框架、地面导引光和冷暖照明形成可见纵深。 |
| 两类护卫 | 近卫增加厚实短侧甲、折叠前颊和退叠后脊；前卫增加细长分叉脊翼、悬臂和有真实开口的导弹槽，拉开独立剪影。 |
| 舰阵规模与空间 | 1 艘旗舰与 32 艘护卫保留前后、上下分层；开火前外展，之后恢复阵形。 |
| 共同体素媒介 | 所有实体箱体的边界对齐单位整数网格；陨石连续占据体也按该网格的整数步长生成。当前检查 871 组实体几何、2,102,328 个局部顶点，未发现非整数边界；投影模型与新增命中碎屑也使用相同整数体块。 |
| 四种武器实体 | 主炮导轨、独立脉冲炮座、近防双管及导弹槽均可见；按实体炮口面的中心校准弹道起点。导弹在槽内可见，离架后露出空槽，末段从舱内升起衔接下一轮。 |
| 四类发射光效 | 主炮逐段充能并有断开后前行的余辉；脉冲亮核与近防短点射保持独立节奏，新增八处随开火短暂照亮邻近舰壳的局部光。导弹先脱槽约 0.15 秒再点火转弯，亮尾与渐隐三维尾迹分开。 |
| 命中与碎裂 | 连续岩体按空间分区分裂，露出真实断面和空隙。热光从受击处沿不均匀裂纹扩散并冷却，各块按主炮、连发与导弹节奏延迟分离；主炮用射线确定实际接触面。224 次后续命中追向运动断块，并分别产生共 658 个实体碎屑，六处动态照明跟随受击面，烟尘与火星退去后岩块仍可见。 |
| 全队护盾 | 33 个独立护盾依次展开，具有扩散波、流动网格和舰壳反光。网格保持整周期相位；重新按实体顶点检查包络并略扩尺寸，使稳定展开后的舰尾、甲板及发射翼均位于盾内。 |
| 航行、推进与小艇 | 护卫按前后位置错开加速与尾焰拉长。机库先抬升、侧移至主通道再前进，返航完成侧移后降落；舰外伴飞椭圆改为与侧壳保持间距，消除擦入机库侧框的问题。 |
| 舰桥 | 上层侧台、阶梯和透明战术面板构成层次。中枢重做为较大的双叉旗舰与两侧错层护卫投影，具有通透体块、轨迹和旋转扫描线；悬屏也显示对应的舰队层级。投影与局部照明轻微呼吸，窗外舰列继续微动。 |
| 动力中庭 | 五组旋转环带、多层环台与上下支撑；深色外笼包住流动发光内层。核心点光增加实时阴影，旋转结构在外笼和环台间投下运动明暗，保留上下补光。 |
| 贯通机库 | 约 390 格长空间、两排泊位和桥架，具有维修装置、体素泊位编号及起降过程。本轮补出舰外入口后的退叠通道，相机先通过真实空隙，再接入大机库；两段都由地面导引光指向纵深。 |
| 能量长廊 | 约 380 格长空间，悬置装置、重复机械和上下批次光块持续运转；新增四处随光块运动的暖色照明，照亮两侧结构、地面和上层框架，靠近路径两端时渐弱，避免循环移动造成闪变。 |
| 宇宙与原始陨石 | 行星色带增加多层湍流，配合星点、星云与近景光屑；陨石为连续、有起伏断面与局部孔洞的体素岩体。 |
| 舰外基础光照 | 增加 4096 阴影贴图及程序化环境反射；推进、命中与护盾有对应动态照明。 |
| 材质与成像 | 保留 HDR 辉光、环境遮蔽和抗锯齿；处理共面材料的深度冲突及微小色差，消除近景边缘闪烁。 |
| 尺度与景别 | 舰外接近、舱口小艇、四处移动内景、攻击跟随与结尾拉开均已截帧检查。 |
| 路径与转场 | 整轮每 0.5 秒检查一次相机与实体箱体，共 160 次；本轮对 16–19 秒入口段额外按 60 fps 检查 180 帧，均未发现相交。既有机库起降 72 个时刻、舰外小艇 320 个时刻的检查与修正继续保留。 |
| 攻击观看组织 | 53 秒先靠近旗舰炮身，充能时逐步拉开；53–69 秒保持发射端、弹道与目标关系，65 秒镜头跟向导弹命中区。 |
| 加速与循环 | 尾焰根部、推进强度、闭合小艇路径和相机端点速度衔接；护盾网格采用整周期运动。大块岩体与小碎屑共同后掠出画，新岩体从远方进入。 |
| 本地运行与导出 | 无服务器、无运行时网络请求；80 秒单分块，3 fps 为 240 帧，60 fps 为 4800 帧；直接定位与倒序定位均有效。 |

此前验证：在本地文件模式、1440×900 下比较入口、四处舱内和攻击时刻的 3 fps／60 fps 全画布像素；舱内与攻击帧完全一致，护盾画面仅有极少数通道存在最大 1/255 的浮点舍入差异。随机跳转回投影画面完全一致；导出期间实时动画冻结，end() 后相机继续前进。

对 70 发脉冲、140 发近防和 14 枚导弹，共 224 次事件逐一跳到发射／命中时刻：起点与炮口或槽位、终点与断块表面的最大位置误差低于 2×10⁻¹² 格。炮口坐标另从实际发光盒体的前表面取得并核对。33 艘舰船稳定展开后的实体顶点均位于各自护盾内，最紧处仍有余量。

60 fps 循环接缝前、跨接缝、接缝后的相邻帧差保持在同一量级，没有重置引起的大面积跳变。入口、舰桥投影、长廊受光及攻击场景在 3840×2160 实际渲染通过，WebGL 2 错误码为 0，浏览器无错误日志。JavaScript 语法检查通过。

本轮针对攻击余波继续完善，并重新验证：

- 全部 240 个预览帧完成绘制且无 WebGL 错误；每秒检查一次全局相机与所在场景实体箱体，共 80 个时刻，未发现相交。
- 224 次事件逐一跳到发射与命中时刻，实际炮口／槽位误差不超过 1.64×10⁻¹² 格，运动岩面误差不超过 5.47×10⁻¹³ 格。56.4–62.6 秒每隔 0.2 秒检查主炮，有接触的 22 个样本与最近射线交点完全一致，其余样本射线已穿过裂开的空隙。
- 新增 658 个命中碎屑采用三种整数体块轮廓；抽查 35 个出生时刻，碎屑源点与实际岩面误差小于 0.000004 格，实例矩阵的单精度位置误差小于 0.000062 格。
- 1440×900 下比较 0、6、23、32、40、48、56⅔、58⅓、59⅓、60、62⅓、63⅓、65、66、68、75 秒，3 fps 与倒序 60 fps 导出的舱内及攻击帧完全一致；0、75 秒分别仅有 5、8 个通道出现最大 1/255 舍入差。随机跳转返回 66 秒完全一致，导出冻结与结束后恢复播放均通过。
- 3840×2160 下实际绘制入口、四处内景、主炮接触、脉冲、近防、导弹与护盾共十个时刻，全部无 WebGL 错误，浏览器无错误日志。循环接缝另重新比较相邻帧，未出现明显跳变。
