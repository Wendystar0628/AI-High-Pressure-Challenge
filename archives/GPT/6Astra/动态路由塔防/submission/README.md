# 汐域 · 网络安全攻防战

直接用 Chrome 打开根目录 `index.html`。无需安装、联网或启动服务。所有脚本与 Three.js 均在本地，模型、特效、图标、音效与音乐由代码生成。

- 三个区域可直接选择，分别 14 / 15 / 16 波。
- 拖动设备卡片，或点击卡片后点选地块；确认前显示范围及路由预览。
- 中键环绕，Shift + 中键平移，滚轮缩放，Home 复位。
- R 转向，Esc 取消，空格暂停，1–6 选择设备。
- 菜单内有知识库、音量设置、重开与三段实战演示。

固定视频接口：`window.videoExport.runs`、`await begin(runId, {fps})`、`await frame(i)`、`end()`。三段时长为 18、18、20 秒；导出模式使用固定时间推进，完整 UI 与字幕一并呈现。

第三方依赖：Three.js r160（MIT），仅用于本地 WebGL 渲染。游戏代码与美术资源为本项目制作。

开发验证（可选，需要 Node.js）：

```sh
node tests/verify.cjs
node tests/campaign.cjs
node tests/normal-play.cjs
```

`verify` 检查所有节点的替代路线、禁止封路、连续转向、目标优先级、诱敌容量、节点冲击、Boss 安全改选、检测、飞行、护盾、加密、维修与道具时效。`campaign` 用完整布防检查全部波次与结算流程。

`normal-play` 使用正常初始资源（510 算力 / 36 情报），按固定顺序购买设备，并使用实际收入升级、维修与释放技能；不注入资源或修改单位数值。三张图均能完成全部波次。它验证存在可用策略，不代表所有布防方案都能通关。

开局思路：内网可隔离西边界，在中央 DMZ 布置沙箱与拦截器；骨干网先分别覆盖两个核心前的通道，再加维修；工控网在气隙两侧各放检测与火力，不要把所有资源集中在单侧。开局可暂停规划，第一波须手动放行。
