node tests/verify.cjs
node tests/campaign.cjs
node tests/normal-play.cjs

浏览器复核：1440×900 与 3840×2160 均实际截图检查。4K 下页面尺寸恰为窗口尺寸，无页面溢出。三段演示各按 10 fps 全帧调用两遍，180 / 180 / 200 帧，比较战斗状态、镜头与 UI 得到一致结果；另检查 60 fps 下第 630 帧对应 10.5 秒。控制台无运行错误。

声音通过实际音频图采样验证：三张地图均输出非零信号，静音后 RMS 低于 0.000001。该检查验证音频生成与静音，不代替主观听感评价。

## 收尾复核与改进

- 三张地图进一步区分灯光、雾色和环境结构：内网冷却机组与旋转风扇、骨干网多层流量与桥架、气隙区工业管线和警示灯。环境动画按游戏时间推进，支持暂停和逐帧导出。
- 放置预览增加设备全息模型；定向拦截扇形与实际 160° 判定一致。节点显示旁路恢复倒计时，预览列出各入口的出口变化与加权路径代价。
- 增加沙盒弹体、勒索电弧、拦截炮口与穿透光束、护盾与 Boss 出场波纹、重要伤害和维修数字；拦截炮塔追踪目标并回冲。
- 三个应急道具固定在侧栏底部。道具和部署确认按钮在实时刷新时保留原 DOM 节点；在场敌人进入预备隔离点时禁用确认，离开后恢复。预报显示实际待生成和在场单位。
