# B200 — 尺度之内

双击根目录 `index.html`，在 Chrome 中离线打开。全部运行库随项目提供，不需要服务器、构建步骤或网络。

八章沿滚动依次展开；右侧章节编号可跳转。模型可拖动、用方向键旋转，用加减键缩放。第 02 章提供展开、部件隔离、深入与实心剖切，第 04 章提供八堆栈选择和可拖动的三维放大窗。第 05 章编辑矩阵与数值精度，相关输入会延续到第 06 章八卡归约与第 08 章负载。

`window.videoExport` 提供题面指定的 `runs`、`begin`、`frame` 与 `end`。导出使用外部传入的确定性时钟；章节区间依照滚动长度返回。支持直接从本地文件调用。

代码组织：

- `scene.js`：实时 WebGL 几何、材质、灯光、阴影、深度景深、相机与组件投影。
- `compute.js`：浮点量化、共享缩放、矩阵乘法、逻辑容量与八卡任务。
- `app.js`：滚动叙事、SVG、交互、持久化与导出接口。
- `style.css`：响应式桌面排版。
- `vendor/`：离线 THREE.js / MIT 许可。

建模示意范围、精度规则、配置口径与公开来源在网页右上角「资料与说明」中列明。
