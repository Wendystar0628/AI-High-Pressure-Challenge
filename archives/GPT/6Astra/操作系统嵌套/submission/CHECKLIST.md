## 保留的边界

- 常规控件、DOM 界面构造、窗口拖动与若干应用操作仍由 JavaScript 处理，没有把题面要求的全部子系统 UI/系统管理逻辑完全移入 VM。默认程序、内核服务与运行位置可以查看和修改，实际覆盖范围见上表及 README。
- 内存/图形设备用量是逻辑估算，部分基础设备调用以原子操作实现，并非每一次内部计算都精细计费。
- 默认演出使用独立资源中的关键帧；排演采用简化动力学，记录保存实际输入、控制时序与机体采样。尚未把默认演出统一改为通过同一飞行控制记录求解。
- 地形接触支持主要静态基本几何，未实现任意网格、多点机身碰撞或完整损坏模型。部分环境与烟尘仍是风格化近似。
- 核对包括代码检查、针对性运行测试与实际截图；并未穷举每一种嵌套/缩放/遮挡/恢复组合。

## 运行验证

- `npm test`：纯运行时、文件、公式、资源几何、程序修改、预算与显示副本检查。
- 先启动 `npm start`，再运行 `npm run test:ui`：通过 19106 操作实际 Electron 窗口。测试会重置当前测试数据目录；截图仅写入系统临时目录。
- 启动入口：`启动.cmd` 或 `npm start`。自动化参数与素材路径见 `automation.json`。建议使用新的 `--data-dir`，避免已保存的旧虚拟程序覆盖本轮默认程序。
