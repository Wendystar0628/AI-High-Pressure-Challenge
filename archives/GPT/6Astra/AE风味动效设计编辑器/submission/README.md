# 铸场 FORGE

本地动效设计工作台。直接用 Chrome 打开根目录的 **index.html**，无需安装、构建或启动服务器。依赖脚本与字形资源均随项目提供。

## 开始创作

- 初始工程是 15 秒的「永的诞生」，停在成块阶段供查看；首次播放从头开始。底部时间轴可拖动擦洗，空格播放或暂停，左右方向键逐帧。
- 属性左侧的时钟开启动画。之后修改属性、拖动画布或调整挤出节点参数，都会更新当前时刻的关键帧。`ƒx` 打开表达式编辑。
- 点击图层名称前的箭头展开动画属性。Shift 点击关键帧多选；可拖动、复制、粘贴和按比例拉伸。曲线编辑器可拖动关键点和贝塞尔缓动手柄，F9 应用缓入缓出。
- 从左侧创作工具或「图层」菜单添加对象。工具栏支持移动、旋转、缩放、矩形、椭圆与钢笔。钢笔节点双击切换切线，可拖动控制点；图钉在属性面板底部添加。
- 节点编辑器中点击输出端口再点输入端口接线，双击连线断开。几何、标量、向量、颜色、场端口检查类型；重复生成实际网格，支持节点复制、封装与进入节点组。
- Shift 选择两个图形后，可从「图层」菜单执行并集、差集或交集。保存钢笔路径形状 A，再修改轮廓，可创建路径形变。
- 文件菜单提供空工程、打开、保存和恢复本地自动保存。工程以 JSON 文件下载；`Ctrl+Z` / `Ctrl+Shift+Z` 撤销与重做，`Ctrl+D` 复制图层，`Ctrl+Shift+C` 预合成。
- 属性栏的「合成效果」页签提供可排序的逐层高斯模糊、发光、投影、色彩效果，以及可动画羽化蒙版、Alpha / 亮度轨道遮罩。效果采用 GPU 预乘 Alpha 合成。
- Shift 在时间轴空白区域拖动可框选关键帧。开放钢笔路径可描边和挤出，图钉位移、旋转、缩放与影响半径均可设置关键帧。
- 播放时启用 Web Audio 合成声音；多个音色层分别取样，可编辑瞬态事件和音色。锤击时间与音色图层事件同步。

## 逐帧接口

```js
window.videoExport.runs // ['demo']
await window.videoExport.begin('demo', { fps: 60 }) // { frames: 900 }
await window.videoExport.frame(0)
await window.videoExport.frame(449)
window.videoExport.end()
```

3 fps 返回 45 帧，60 fps 返回 900 帧。接口同步画布、时间轴、属性及声音波形所对应的时间；导出时不启动独立播放时钟或音频。`end()` 恢复导出前工程。

## 实现说明

- `engine.js`：统一工程结构、关键帧与表达式求值、轮廓追踪、三角化挤出、材质、灯光阴影、WebGL 2 与深度后处理。
- `app.js`：项目管理、属性、时间轴、曲线、节点、交互、历史、文件和声音。
- `enhancements.js`：路径切线、字符动画器、形变、关键帧多选和缓动手柄、确定性粒子碰撞。
- `evaluation.js` / `workflow.js`：合成内表达式上下文、正确锚点变换、类型化节点数据流、几何节点组与快门取样。
- `compositor.js` / `effects-ui.js`：GPU 逐层效果、柔边蒙版、轨道遮罩、混合模式及参数编辑。
- `geometry-tools.js` / `interaction-upgrades.js`：开放路径、图钉动画、精确拖动、框选、实际轨迹拖尾、碰撞次级发射和多音色播放。
- `presentation.js`：示例版式文字改为可定位、可编辑、可保存的普通文字图层，由 WebGL 渲染；同时提供程序化锻造表面细节。
- 字形与二维轮廓以 512×512 栅格追踪为闭合路径，再生成真实前后面、侧壁和倒角。内置思源宋体子集支持「永锻铸金火木水山工王天光生铁字形」；其他字符使用本机字体。
- 粒子使用固定种子和 60 Hz 积分，逐步与当时的实体网格求交，使用表面法线及运动计算反弹；缓存可重新生成。颜色与拖尾随寿命变化。
- 景深读取真实深度纹理；合成运动模糊按快门角度、相位进行五次场景取样，并恢复中央时刻以供准确点选。

本项目是轻量实现：文字与布尔运算的轮廓精度受追踪分辨率限制，基本形状与钢笔描边直接使用矢量路径。空间变形采用加权图钉和场。完整题面逐项核对及尚有限制见 `DESIGN-AUDIT.md`。

## 验证

在浏览器中加载 `checks.js` 可运行 `runForgeChecks()`。开发期间还实际检查了本地文件加载、普通播放、空工程、节点接线、源字替换、JSON 往返、关键帧编辑、曲线与预合成。

最终回归：15 项断言通过；3 fps 的 45 帧与 60 fps 的 900 帧均完成逐帧取样，无表达式求值错误。900 帧过程中渲染器纹理数量保持 6，几何缓存受控。直线时间插值下，测试贝塞尔路径等时间段的行进距离最大/最小比为 1.0101（离散弦长测量）。

后续质量改进回归：原 15 项断言再次通过；整段 45 帧再次完成。额外验证了逐层模糊不改变另一对象、羽化产生连续半透明像素、含柔边的预合成像素一致、节点组保持网格顶点数、子合成表达式正确寻址，以及碰撞次级发射倒放取样一致。
