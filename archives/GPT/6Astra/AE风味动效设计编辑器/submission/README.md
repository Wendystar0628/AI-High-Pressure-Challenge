# 形序 · FORM / FLOW

一个可离线运行的 WebGL 2 动效设计工作室。打开根目录的 **index.html** 即可使用，无需启动服务器或安装依赖。建议使用 PC 版 Chrome，并开启硬件加速。

默认载入 15 秒作品「形随意动」。按空格播放；第一次播放时浏览器会启用声音。左侧选择合成，中间查看画面，右侧修改属性，下方编辑图层与关键帧。顶部可以切换动画、曲线和节点工作区。

## 开始编辑

- **制作动画：** 选中图层，点击属性旁的秒表，移动播放头并修改数值。已开启动画的属性会在当前时刻写入关键帧。点击 `ƒx` 编辑表达式。
- **曲线：** 切换顶部「曲线」，选择属性，拖动关键帧或贝塞尔手柄；支持值曲线、速度曲线、多属性叠加、缓动与时间拉伸。
- **画布：** 直接拖动对象；使用三维轴限制移动方向。右下的视图菜单可切换前、顶、侧和透视视图。钢笔拖动可建立切线，Enter 闭合路径。
- **节点：** 选中几何图层后进入「节点」，建立流程，点击输出端口再点击输入端口连接；点击连线断开。标量、向量、颜色和场引用可接入相应参数端口，节点显示实时结果；不兼容连接与循环会提示。数值为属性绑定时，修改会写入对应动画属性。
- **网格和场：** 用图钉工具点击形体，拖动控制点；属性面板可为图钉位置、旋转、缩放、半径与深度设置动画，并调整局部刚性。空间场与混合权重可以同时影响实体和粒子。
- **路径和蒙版：** 可编辑轮廓、孔洞、起点与方向，重采样后匹配不同节点数量的形状；修剪按实际弧长推进。自由路径蒙版可取自形状，支持羽化、范围与形变动画。效果面板可调整效果顺序。
- **实例与多选：** 预合成实例可独立覆盖文字、颜色、挤出深度和扭转，或恢复继承。多选属性不同会显示「混合」，输入数值同时修改未锁定的选中图层。
- **声音：** 选中音色图层，点击「编辑音符与节奏」，修改拍位置、音高、时长与力度。音量、声像和 BPM 可设关键帧；本地音频可从文件菜单导入。
- **工程：** 文件菜单可新建空工程、打开、保存、恢复本机自动保存或重新载入示例。保存得到 `.formflow.json`，内含图层、动画、节点、绑定、材质、引用和导入的音频数据。重新打开页面默认展示示例；使用「恢复本机自动保存」取回上次编辑。

## 示例中的编辑入口

| 图层 / 合成 | 可以观察和修改的内容 |
| --- | --- |
| 环形 / 流体陶瓷 | 带孔挤出、倒角、形变、扭转、场、分区材质与动画节点参数 |
| 形态控制器 | 多层父级与主体的连续旋转 |
| 微粒 / 表面发射 | 当前几何发射、重力与旋涡、碰撞火花和轨迹拖尾 |
| 碰撞曲面 / 柔性金属 | 随动画弯曲的真实碰撞网格 |
| 摄影机 / 主视角 | 近远尺度、横向移动、焦点和光圈 |
| 轨道标记 A、B | 同源实例、独立画面 / 保留三维、倒放与定格 |
| 标记 / 签名、标记 / 内层 | 两级嵌套合成 |
| 调色 / 柔光 | 合成发光、调色及以几何亮度控制的时间置换 |
| 标题、中文、注脚 | 可编辑排版及按词、字符、行的范围动画 |
| 配乐、音效 | 内置合成音色、可编辑乐句、与主要动作对应的重音 |

## 导出

「导出作品」提供带 Opus 立体声的 VP9 WebM、当前帧 PNG，以及 PNG 图像序列 ZIP。视频和序列使用合成工作区、合成尺寸与指定帧率，逐帧取样；进度窗口可取消导出。

项目也提供题面要求的整个编辑器逐帧接口：

```js
window.videoExport.runs // ['demo']
const { frames } = await window.videoExport.begin('demo', { fps: 60 });
// frames === 900；fps: 3 时为 45 帧
for (let i = 0; i < frames; i++) {
  await window.videoExport.frame(i);
  // 此时可以截取整个编辑器页面
}
window.videoExport.end();
```

该接口同步画布、播放头、属性与声音电平。取样期间正常播放时钟暂停，任意跳帧仍使用同一确定性模拟。

## 字体与开发

界面与平面文字使用随项目提供的 DM Sans、Noto Sans SC 可变字体，支持拉丁与中文。三维文字采用 Helvetiker 字形轮廓，支持该字体内的拉丁字符、数字和标点；文字模式菜单注明支持范围。

运行只需要 `index.html`、`app.js`、`style.css` 和 `assets`。完整源码在 `src`：`engine.js` 管理工程与求值，`render.js` 负责几何和 WebGL 场景，`material.js`、`effects.js`、`temporal.js` 负责材质与合成，`audio.js` 生成音频，`export.js` 输出视频与序列。

修改源码后，在项目目录执行 `npm install`、`npm run build`。打包产物和字体已包含在交付中，正常使用不需要运行这些命令。第三方授权见 `licenses` 和 `assets/fonts/*-LICENSE.txt`。

`tests/browser-checks.js` 与 `tests/audit-checks.js` 是在已打开页面内执行的异步检查函数，共 35 项，覆盖关键帧、表达式、锚点和父级、节点几何、声音、工程文件、确定性模拟、逐帧接口，以及图钉、路径、蒙版、效果顺序、混合模式、多选和实例参数。逐项核对见 `tests/设计核对.md`，实际运行结果见 `tests/验证记录.md`。
