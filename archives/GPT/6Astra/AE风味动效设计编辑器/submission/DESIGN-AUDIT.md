# 完整题面逐项核对

本记录区分已经实现并检查的行为与仍存在的边界，不把界面入口等同于完整实现。

| 题面 | 当前实现与本轮改进 | 尚有限制 |
|---|---|---|
| 2.1 工程 / 界面 | 多合成、全部基本图层类型、名称、显示、锁定、排序、复制、删除、入出点；属性拆分为图层、合成效果、动画与路径三个页签 | 大量图层通过滚动查看；不是可任意停靠的面板系统 |
| 2.2 变换 / 父级 | 改为 T(position) × R × S × T(-anchor)；切换父级保留当前矩阵；移动使用实际相机射线与父矩阵；支持多选平移 | 缩放为统一缩放，旋转和缩放主要通过工具模式及属性编辑 |
| 2.3 动画 / 曲线 | 当前时刻关键帧、Shift 框选、多选移动、复制粘贴、拉伸、三种插值、独立缓动手柄、弧长路径取样、真实速度曲线 | 复杂时间轴编辑不是完整 AE 工作流；路径关键点主要通过位置属性编辑 |
| 2.4 表达式 | time/value、确定性 wiggle、loopOut、linear/ease、本层和跨层引用、向量分量、valueAtTime；本轮修正预合成上下文与惰性引用 | 表达式求值器以单值属性为入口，不支持任意 AE 脚本 API |
| 2.5 图形 | 矩形、椭圆、开放 / 闭合贝塞尔路径、实际描边带、内孔、挤出、弧长修剪、实际重复网格；路径形变先按弧长重采样 | 布尔运算仍采用栅格轮廓追踪，复杂三维变换后的任意布尔运算及任意操作栈排列仍不完整 |
| 2.6 文字 | 中文多行、字号、字距、行距、对齐；按字符 / 词 / 行选择范围、起终点和软边；位置、旋转、缩放；二维版式和三维轮廓共存 | 三维轮廓中的字符淡出仍受轮廓 Alpha 阈值影响，尚不是连续逐字材质 Alpha |
| 2.7 节点 | 实际按连线和端口类型计算；几何、标量、向量、颜色、场；输入替换、分支、复制、封装、组内编辑；重复网格参与下游变形与碰撞 | 挤出基于源轮廓及操作序列；不是任意拓扑的通用建模节点库 |
| 2.8 场 / 图钉 | 旋涡、距离、噪声场；多个场同时影响几何与粒子；位置、旋转、缩放图钉可动画；弯曲、扭转、法线更新 | 场的嵌套空间组合有限；图钉为加权变形，不是完整骨骼或有限元系统 |
| 2.9 合成 | 本轮加入 GPU 逐层高斯模糊、发光、投影、色彩调整及效果排序；可动画羽化蒙版、自由路径蒙版、Alpha / 亮度与反转遮罩；五种混合模式 | 多层相交半透明三维表面的严格逐像素排序仍有限；柔边蒙版不会重建实体阴影网格 |
| 2.10 预合成 / 模糊 | 原位预合成、外部父级代理、多个引用、倍率 / 倒放 / 定格 / 源时间关键帧；五次快门取样、相位与图层开关 | 同一粒子合成被多个复杂时间映射实例引用时，实例独立模拟仍有边界 |
| 2.11 实体 / 材质 / 灯光 | 真实前后面、侧壁、倒角、孔洞、金属 / 粗糙度 / 发光；程序环境反射、两类灯光和几何阴影；投射 / 接收开关 | 光照不采用离线路径追踪；颜色值本身主要通过颜色控件或节点设置 |
| 2.12 摄像机 / 空间 | 透视、位置、目标、视角、对焦和光圈；父级 / 合成矩阵参与摄像机取样；真实深度景深、最近可见表面点选 | 最复杂的半透明交叠依赖常规深度与合成次序，见 2.9 |
| 2.13 粒子 | 点 / 表面 / 轮廓源、事件与持续发射、固定种子、实际网格碰撞；反弹、摩擦、碰撞寿命倍率、次级发射；拖尾改为实际轨迹带 | 表面发射位置以网格顶点候选取样；拓扑改变时表面速度回退到对象运动；粒子大小寿命曲线仍有限 |
| 2.14 一致性 | 统一项目、撤销 / 重做、JSON 文件、确定性帧取样；碰撞寿命写入帧快照，避免未来碰撞污染过去帧 | 未实现跨页面协作、云存档或任意第三方格式导入 |
| 2.15 声音 | 多音色层、金属 / 钟琴 / 低频瞬态、基频、音量、事件；嵌套合成时间对应音频事件，导出不重复触发 | 以实时合成为主，没有音频文件混音导出 |
| 2.16 快捷键 | 空格、方向键、F9、复制、删除、保存、撤销重做、预合成；输入框不截获编辑器快捷键 | 未覆盖 AE 的全部快捷键 |
| 3 示例动画 | 15 秒「永」：笔画形成 → 厚度与热量 → 三次锻打 / 变形 / 火星 → 冷却停稳；标识、章节和旁注改为普通可编辑文字图层 | 笔顺引导对内置「永」有专用路径，其他字使用通用轮廓揭示 |
| 4 交付 / 导出 | 本地 index.html、所有依赖随附、WebGL 2、3 fps / 60 fps 固定接口、导出结束恢复原工程 | 依赖支持 WebGL 2 的 Chrome |

## 实际验证结果

- 原 `checks.js` 的 15 项断言在本轮变更后再次通过。
- 本轮完整 45 帧取样成功；前一版本曾完整检查 900 帧，接口帧数仍为 900。
- 仅模糊左侧对象时，右侧测试区域的 RGB 平均像素差为 **0**。
- 羽化测试产生 **4290** 个中间 Alpha 像素；含柔边的整组图层预合成前后像素哈希一致。
- 三实例重复节点输出 **16272** 个顶点；封装节点组后顶点数保持一致。
- 子合成内部对同名控制器的属性引用返回所属合成中的值 **23**。
- 开放贝塞尔描边生成 **17148** 个挤出网格顶点。
- 碰撞测试生成 **120** 个次级粒子；修改碰撞寿命后，前后跳转到同一时刻的像素哈希一致。

以上是具体测试场景的结果，不代表所有组合均已穷举验证。
