# 物态实验室

双击根目录的 **index.html**，在 Chrome 中打开即可。无需安装、构建或服务器；所有脚本与 Three.js 均已随项目提供，不会请求网络资源。

两个场景分别保存状态，通过顶部标签切换。

- 果冻冲击：正中、偏心、多球连续三种模式；可调重球、果冻、底部约束和碰撞环境。
- 造浪水槽：四组同尺寸、不同密度球；可重复投放、单独开关造浪，调整水位、密度、尺寸、装置与时序。
- 主按钮负责开始、暂停和继续；重置按钮保留参数并回到初态。参数改变后会准备新实验。
- `空格` 暂停 / 继续，`R` 重置，`M` 音效，`F` 专注观察；鼠标拖动旋转，滚轮缩放。右上角可切换透视、正视、俯视或复位镜头。
- 音效默认关闭，点击声音按钮后启用浏览器 Web Audio。
- 提高释放高度或扩大水槽时，默认镜头会自动留出构图空间；大尺寸、多球组合会错开待释放高度，避免初态重叠。

## 逐帧画面接口

```js
window.videoExport.runs
// ['jelly-center', 'jelly-multi', 'jelly-offset', 'tank-full']

const { frames } = await window.videoExport.begin('tank-full', { fps: 60 });
for (let i = 0; i < frames; i++) {
  await window.videoExport.frame(i);
  // 在这里截取页面。
}
window.videoExport.end();
```

`begin` 使用默认演示参数，独立重置对应片段，先进行同参数数值预演，以持续稳定判据确定时长。第 0 帧是初态，释放自动发生。采样帧率可以是任意正整数；240 Hz 物理步进独立于采样率，非整步时刻使用速度导数重建画面。接口调用不等待真实时间，常规动画循环在导出期间不推进仿真。

导出期间隐藏全部界面，画布随窗口尺寸适应，按窗口像素分辨率绘制，支持 3840 × 2160。果冻镜头在释放后轻缓靠近接触区；水槽镜头同时显示水面、水中和底部。`end()` 恢复之前的交互实验与参数。

水槽默认流程及导出严格使用事件计时：每一颗球首次接触局部水面时记录入水；最后一颗入水后 1 秒启动推板，5 秒后停止，之后继续模拟余波与浮沉。手动造浪可以在不释放球体时独立运行。追加投球重新建立本轮入水计时。

## 模拟与渲染

- **果冻**：圆形弹性场与独立侧壁弹性网格的有限差分积分，含传播、弹性恢复、阻尼、延迟鼓胀、偏心摆动与底部滑移。球与局部表面的接触力反向反馈到形变网格；重球受到表面斜率、重力、刚体碰撞和平台摩擦作用。关闭连续回弹会增加卸载接触时的耗散，抑制二次弹跳。可见形变不是整体缩放。
- **水槽**：交错网格浅水波方程，推板边界速度产生传播与反射波。球体按球缺浸没体积计算浮力，受当地流速、阻力、球间碰撞、壁面和底部摩擦作用；由波能驱动的无散度回流近似表现持续水流。入水扰动反馈到水面，并产生水冠、弹道液滴及回落涟漪；涟漪贴合局部水面且限于槽内。手动启停保留推板相位，重启平滑加速。它是用于视觉实验的简化物理模型，不是工程流体求解器。
- **画面**：WebGL / Three.js、物理材质、环境反射、实时阴影、折射、程序化焦散与气泡。所有纹理在内存中生成，因此 `file://` 与离线环境均可运行。
- **音效**：事件驱动的撞击、回弹、金属接触、入水与水流合成音，碰撞声按球体左右位置分布；推板低频声随装置启停，余波声随波能衰减。导出接口不处理声音。

文件结构：`physics.js` 数值模拟，`visuals.js` 三维场景，`app.js` 交互与导出，`style.css` 界面，`vendor/` 离线依赖和许可证。

可使用 `node verify.cjs` 检查数值稳定性、事件时序、密度分层、回弹开关、飞溅回落、推板重启和密集球体边界；浏览器的只读快照 `window.lab.diagnostics` 可用于检查当前实验。
