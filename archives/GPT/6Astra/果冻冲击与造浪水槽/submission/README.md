# 相态 · 软物质实验室

直接用桌面 Chrome 打开根目录 `index.html`。所有资源随项目提供，离线运行，不需要服务器。

## 操作

- 顶部切换果冻冲击与造浪水槽。
- 果冻面板选择 A / B / C 试样，调整硬度、结实程度、球质量和释放高度，分别触发正中、偏心或连续冲击。后续释放以试样移动后的实际位置为目标。
- 水槽可重复释放三组等尺寸球，独立开关造浪板，并调整幅度、频率和每组相对水密度。
- 底部暂停、继续、重置与 1 / 0.25 / 0.5 倍播放；空格暂停，R 重置。
- 拖动旋转，滚轮缩放。右上角音符开关碰撞、回弹、开裂、入水与造浪声音。
- 四张观察档案卡片运行完整实验。预设包含关键瞬间慢镜，时长仍为 8 / 10 / 8 / 20 秒。

## 逐帧导出

```js
window.videoExport.runs
// ['jelly-center', 'jelly-multi', 'jelly-offset', 'tank-full']
const { frames } = await window.videoExport.begin('tank-full', { fps: 30 });
for (let i = 0; i < frames; i++) {
  await window.videoExport.frame(i);
  // 此时截图：第 i 帧对应演示的 i / fps 秒。
}
window.videoExport.end();
```

导出自动隐藏全部 HTML 界面，按窗口尺寸绘制，支持任意正整数 fps。演示时间与物理时间分开；交互播放和导出使用同一份慢镜时间表。求解步长固定，采样帧率不改变模拟内容。导出期间实时循环停止推进，`frame` 等待 GPU 求解、读回、液面重建和绘制完成后返回。

## 实现与题面逐项核对

| 题面内容 | 当前实现 |
| --- | --- |
| 多种果冻与刚性重球 | 琥珀软块、薄荷圆柱、珊瑚高块；材料硬度有差异；金属重球质量和半径随参数变化 |
| 大变形、包裹、鼓出与回弹 | 每个完整试样含 567 节点、2,304 四面体；柔顺距离约束及体积约束；节点和刚体质量加权双向接触 |
| 正中、偏心、连续冲击 | 独立按钮与预设；偏击可使试样倾斜滑移，并将球送向右侧试样；连续球在前次余振中接触 |
| 材料断裂与弹性碎块 | 冲击能量和应变超过阈值后，由接触区受拉方向决定裂面；运行时切分四面体、插值生成交点并重新四面体化；轻度超限保留底部连接，强冲击完全分离；没有预制碎块替换 |
| 碎块、试样与球接触 | 独立碎块继续参与体积求解；软体表面空间哈希接触、球体接触、台面摩擦与反弹 |
| 透明水槽与可见造浪板 | 玻璃边缘、活塞式造浪板、远端水下斜坡；统一摄影棚照明与实验台 |
| 三维粒子—网格液体 | WebGPU MLS-MPM / APIC；26,962 个物质点，56 × 27 × 21 网格；二次 B 样条 P2G、弱可压缩状态方程、仿射 G2P、体积演化；液体子步 1/240 秒 |
| 自由液面、飞滴、白水 | 从三维粒子密度重建液面；液面重建网格 69 × 33 × 26；稀疏粒子显示为立体飞滴，白水强度来自粒子速度和局部密度；不使用高度场或解析波形驱动水体 |
| 入水、浮沉与三层运动 | 三组等半径球，真实球体积决定质量和浮力；按球所在深度采样三维流速；粒子接触冲量回传刚体，球体排水扰动局部水体；入水气泡与粒子飞滴 |
| 波浪推进、变陡、翻卷与拍壁 | 造浪板移动边界直接向网格和粒子输入动量；壁面、斜坡及回流参与求解；较大幅度产生卷浪、白水和飞滴，停止后衰减 |
| 材质与光影 | 凝胶半透明、动态接触阴影、液面高光及白水着色、透明玻璃；底部焦散从实际粒子液面采样折射光束，不再仅按时间播放纹样 |
| 参数、暂停、继续、重置 | 两场景独立可操作；演示结束后继续按钮可正常推进；参数编辑可接管预设；重复释放支持最多 128 球参与 GPU 接触 |
| 声音 | 真实用户点击后启用 Web Audio；模态碰撞音和滤波噪声区分撞击、开裂、入水、造浪，可关闭 |
| 四段演示与导出 | 固定 runs 顺序、初态重置、预设触发与镜头、慢镜时间表、纯场景导出和本地文件运行 |

## 本轮浏览器验证

- 四段演示全部推进到最终帧，刚体状态保持有限，没有控制台错误；正中和偏击完整，连击在最后一球后分离。
- 30 fps 的帧数为 240 / 300 / 240 / 600；4K 窗口输出 3840 × 2160，HTML 界面隐藏；7 fps 连击返回 70 帧。
- 17 fps 与 60 fps 在演示第 5 秒的刚体状态完全一致；连击裂后软体抽样节点、水槽抽样粒子的状态差值均为 0。
- 暂停后等待真实时间，tick 不变；继续后 tick 增长。重复释放 45 球后状态有限。
- 真实点击声音开关后，AudioContext 状态为 `running`。
- 相同正中冲击，结实程度 5：完整；3：局部开裂但保留连接；1.5：完全分离。
- 同组密度从 0.35 改为 2.2，球心由约 2.15–2.21 m 的水面层变为约 0.46–0.93 m 的底部/斜坡层。
- 同频率造浪，幅度 0.1 时粒子高度第 99 百分位约 2.24 m、飞滴 1 个；幅度 1.2 时约 5.37 m、飞滴 368 个。
- 连击最终帧碎块节点速度均方根约 0.00088 m/s，结尾基本停稳。
- 1366 × 768 下检查了完整控制面板与演示卡片，无遮挡操作项。

水体使用有限分辨率与弱可压缩近似，极细的液膜和湍流采用粒子/表面近似显示；不是工程级精度的 CFD。小于液面网格分辨率的脱落液滴由实际粒子位置绘制。
