# 完整设计核对与质量改进

入口为根目录 `index.html`，直接以 `file://` 打开。所有造型、画布贴图和着色器均在本项目内制作。页面只包含三维画布，没有操作面板或导出按钮。

- 等待期间导出状态不推进；重新 `begin` 恢复同一初态。
- 3840 × 2160 实际绘制与截图正常；在导出期间调整窗口大小，当前室内镜头保持不变。
- 4K 全景重复帧对比：在两次取样之间先运行室内镜头，再重置全景，8,294,400 像素无差异。

- 船体外轮廓沿新航线采样 1001 次，范围约为 x = 6.39～11.37、z = −10.47～−0.95；避开长堤、消波块及底座边界。
- 96 秒周期按 0.1 秒采样：海鸥和猫无位置跳转；猫停步时腿摆动为零。最大惊扰状态下，鱼群中心保持在 x = 1.89～9.28、z = −4.32～2.38。
- 缆绳中心端点与船体连接点的最大误差小于 0.000001 场景单位。
- 退出导出后滚轮缩放正常；双击恢复全景和 36° 视角，鼠标控制启用。
