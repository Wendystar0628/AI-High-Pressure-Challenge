# 太阳雨中的小渔港堤岸

直接用桌面 Chrome 打开根目录的 **index.html**。无需服务器、安装依赖或联网。页面仅显示可交互的三维场景。

鼠标左键拖动旋转，右键拖动平移，滚轮缩放；双击回到全景。

## 场景

完整正方形底座上的 L 形白雨港，包含分层混凝土岸壁、透明青绿水体剖面、四艘泊船、红白灯塔、山坡瓦顶民家、渔协仓库和玻璃候船室。船舱及两处建筑均有实际三维室内陈设。全部模型、画布贴图和材质由代码生成，没有使用外部模型或图片。

细雨、水面倒影、涟漪、海草、鱼群、海鸥和船体持续运动。96 秒的环境周期依次安排海风、云影、雨歇与港猫活动、渔船解缆巡航及返港；各事件错开，船行波按距离传播。镜头推近时，海鸥飞起，鱼群散开，猫抬头观察。

水洼使用实时平面反射，包含建筑、船只及飞鸟的倒影。瓦顶由逐片弧形瓦与瓦当组成；岸壁有分层牡蛎壳、带开口的藤壶和潮渍。各驾驶舱设独立雷达、鱼探仪、海图夹板和生活物件。船舱及建筑顶棚的水纹光斑、仪表扫描、布料形变和缆绳端点均由同一场景时间驱动。

近景道具包括有提手孔的鱼箱、空筒雨靴、搪瓷杯、保温瓶和带调谐刻度的收音机。鱼群有独立摆动的叉尾；港猫有贴合身体的毛色、随步态运动的脚掌与眨眼。移动云影按空间位置依次影响高光和室内光束；船行波在岸壁水线形成轻微的起伏泡沫。

滑道实际切入堤岸，由水下延伸至码头，带防滑横纹、导轨和固定螺栓。倒扣舢板沿坡面放置，港猫在船尾下趴伏避雨，雨弱后起身出游。

完整题面核对及本轮验证记录见 [DESIGN_CHECK.md](DESIGN_CHECK.md)。

## 视频接口

```js
window.videoExport.runs // ['overview', 'tour']

const { frames } = await window.videoExport.begin('tour', { fps: 60 });
for (let i = 0; i < frames; i++) {
  await window.videoExport.frame(i);
  // 此处由调用方截图
}
window.videoExport.end();
```

- `overview`：5 秒固定全景，3 fps 返回 15 帧，60 fps 返回 300 帧。
- `tour`：20 秒连续巡游，3 fps 返回 60 帧，60 fps 返回 1200 帧。
- 巡游依次经过全景、水体剖面与海床、驾驶舱、仓库、候船室，最后回到全景并稳定停留。
- 每帧时间严格取 `i / fps`；导出期间实时循环停止推进动画，返回时反射及透明层已经完成渲染。
- 两段可独立开始，`begin` 重置片段状态，`end` 恢复鼠标操作。
- 分辨率随窗口调整，已实际检查 1920×1080 与 3840×2160。

## 开发

交付的 `harbor.js` 已构建完成。修改 `src/` 后，可使用：

```sh
npm ci
npm run build
```

构建将 Three.js、OrbitControls、Reflector 与全部场景代码打包为普通 IIFE 脚本，因此 `file://` 下不需要模块加载、fetch、图片纹理请求或 Worker。
