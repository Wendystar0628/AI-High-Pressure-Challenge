# 矢量设计编辑器

## 一、任务

制作一个在浏览器中运行的矢量图形编辑器，实现第二节的 10 项功能。

界面、交互细节和实现方式都由你自己设计。

## 二、功能要求

快捷键在焦点位于画布或页面主体时生效，在文本输入框中不生效。

### 2.1 绘制

- 提供选择（`V`）、矩形（`R`）、椭圆（`E`）、直线（`L`）四种工具。
- 用鼠标拖动绘制：矩形和椭圆填满拖出的矩形范围，直线连接拖动的起点和终点。
- 按住 `Shift` 绘制时，得到正方形、圆，或水平、竖直、45° 方向的直线。
- 新画的图形位于最上层。图形的填充和描边样式由你决定。

### 2.2 选择

- 单击图形即选中它：矩形和椭圆点在内部即可，直线点在线上即可。多个图形重叠时，选中最上面的。
- 点击空白处或按 `Esc` 取消选择。
- 按住 `Shift` 单击，加选或取消选中一个对象。
- 在空白处拖出选框，选中框内的对象；按住 `Shift` 框选时，加入原有选择。
- 点中编组里的任何图形，都选中整个编组。选择以顶层对象为单位，不需要选中编组内部的单个对象。

### 2.3 移动、拉伸与旋转

- **移动**：拖动选中的对象时，所有选中的对象一起移动；拖动未选中的对象时，单独选中并移动它。方向键微移选中的对象，按住 `Shift` 时移动距离更大。
- **拉伸**：
  - 单个矩形或椭圆：拖动它的角或边进行拉伸，对面的角或边保持不动；旋转过的对象沿它自身的方向拉伸。按住 `Shift` 拖动角时保持宽高比。
  - 单条直线：拖动端点改变它；按住 `Shift` 时，方向限制为水平、竖直或 45°。
  - 编组或多个对象：拖动角时整体等比缩放，对角保持不动。
- **旋转**：用鼠标拖动旋转选中的内容。单个对象绕自身中心旋转，编组或多个对象绕整体的中心旋转。按住 `Shift` 时以 15° 为步长旋转。

### 2.4 编组

- `Ctrl+G` 把选中的多个对象编为一组，`Ctrl+Shift+G` 解散选中的编组。
- 编组和解组不改变子对象之间的上下顺序；解组后，子对象回到编组原来所在的层级位置。
- 编组可以嵌套。

### 2.5 吸附

- 用鼠标拖动对象时，它的边或中心线靠近其他对象的边或中心线，就自动吸附对齐，并在画布上显示参考线。
- 按住 `Alt` 拖动时不吸附。

### 2.6 对齐与分布

- 选中多个对象时，可以左对齐、水平居中、右对齐、顶对齐、垂直居中、底对齐，以全部选中对象的整体范围为参照。
- 选中 3 个及以上对象时，可以水平分布、垂直分布：两端的对象不动，相邻对象之间的间距相等。

### 2.7 图层顺序与图层面板

- `Ctrl+]` 上移一层，`Ctrl+[` 下移一层，`Ctrl+Shift+]` 置于顶层，`Ctrl+Shift+[` 置于底层。选中多个对象时，它们之间的相对顺序不变。
- 提供图层面板，按从上到下的顺序列出全部对象，编组的子对象缩进显示在编组下方。
- 面板与画布的选择保持同步：在面板中点击顶层对象的条目即选中它；画布上选中的对象，在面板中同样高亮。
- 在面板中拖动顶层对象的条目，可以把它移到别的位置，改变层级顺序。

### 2.8 复制与粘贴

- `Ctrl+C` 复制，`Ctrl+X` 剪切，`Ctrl+V` 粘贴。剪贴板只需在编辑器内部使用，不需要接入系统剪贴板。
- 粘贴得到复制或剪切时所选对象的副本，编组结构完整保留，副本位于最上层。同一份内容可以多次粘贴。

### 2.9 撤销与重做

- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。
- 所有改变文档内容的操作都能撤销和重做，每次以一个完整的操作为单位。
- 撤销和重做后，文档内容与对应时刻完全相同，包括各对象的几何数据、样式、层级顺序和编组结构。选择不属于文档内容。

### 2.10 SVG 导出与导入

- 导出合法的 SVG 文档，在浏览器中打开时，显示效果与画布一致。编组导出为 `<g>` 元素。
- 导入本编辑器导出的 SVG 时，替换当前的整个文档。导入后，对象的类型、几何数据、编组结构、层级顺序，以及填充色、描边色和描边宽度，都与导出前一致。

## 三、交付与运行环境

1. 交付一个网页项目，入口文件为根目录下的 `index.html`。评测时用本地静态服务器打开它。
2. 在最新版 Google Chrome 和 Microsoft Edge 中运行。本题只做 PC 端，不考虑手机和平板，所有操作用鼠标和键盘完成。
3. 打开页面后无需任何额外操作即可使用，控制台没有报错。

## 四、测试流程

1. 开发时间为 1 小时，从拿到题目开始计算。
2. 开发期间运行和测试编辑器时，优先使用你所在 Agent 工具自带的内置浏览器；它不可用时，使用本机的 Google Chrome；仍不可用时，使用本机的 Microsoft Edge。
3. 全程不得访问 GitHub 上的任何仓库，无论通过网页、`git`、`gh` 命令行还是 API。
4. 时间结束时，以当时的项目文件作为最终提交。

## 五、评分标准

### 5.1 计分方法

总分 100 分，由下表 12 个分项组成。评审实际操作编辑器，各分项按 5.2 的评分要点评定，在该项分值内给分；总分为各分项得分之和，再按 5.3 处理违规。

| 分项 | 对应条款 | 分值 |
|---|---|---|
| 绘制 | 2.1 | 6 |
| 选择 | 2.2 | 8 |
| 移动、拉伸与旋转 | 2.3 | 16 |
| 编组 | 2.4 | 7 |
| 吸附 | 2.5 | 7 |
| 对齐与分布 | 2.6 | 6 |
| 图层顺序与图层面板 | 2.7 | 8 |
| 复制与粘贴 | 2.8 | 5 |
| 撤销与重做 | 2.9 | 11 |
| SVG 导出与导入 | 2.10 | 8 |
| 综合场景 | 第二节 | 8 |
| 交互体验与界面 | 第二节 | 10 |

### 5.2 各分项的评分要点

**绘制（6 分）**：各工具画出的图形是否符合第 2.1 项。

**选择（8 分）**：各种选择方式的结果是否符合第 2.2 项。

**移动、拉伸与旋转（16 分）**：移动、拉伸和旋转的结果是否符合第 2.3 项。

**编组（7 分）**：编组、解组和嵌套编组是否符合第 2.4 项。

**吸附（7 分）**：吸附效果和参考线是否符合第 2.5 项。

**对齐与分布（6 分）**：对齐与分布的结果是否符合第 2.6 项。

**图层顺序与图层面板（8 分）**：层级操作和图层面板是否符合第 2.7 项。

**复制与粘贴（5 分）**：复制、剪切与粘贴的结果是否符合第 2.8 项。

**撤销与重做（11 分）**：撤销与重做是否符合第 2.9 项。

**SVG 导出与导入（8 分）**：导出与导入是否符合第 2.10 项。

**综合场景（8 分）**：多项功能组合使用时结果是否正确。

**交互体验与界面（10 分）**：操作反馈是否清楚，拖动是否跟手，界面是否清晰好用。

### 5.3 违规处理

- 页面无法打开或白屏：总分记 0 分。
- 页面加载时控制台报错：总分扣 3 分。
- 在 Microsoft Edge 中无法正常打开：总分扣 5 分。
