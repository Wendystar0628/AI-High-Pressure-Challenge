# AE风味动效设计编辑器

## 一、目标总览

制作一个在浏览器中运行、以合成与图层为骨架的动效设计编辑器。用户可以从空工程创建图形与文字，用关键帧、曲线和表达式组织动画，用程序节点生成几何，用空间场和图钉让几何变形，把路径和文字做成三维实体并布置材质、灯光与摄像机，让粒子从几何上发射并与表面碰撞，再用蒙版、效果、预合成、运动模糊和声音完成作品。

编辑器的每项功能都在普通工程中真实工作，可以创建、修改和组合：表达式实际求值，节点按连线计算，画面由实际生成的几何、材质与模拟渲染，不用写死的画面或固定结果代替。几何、变形、粒子与渲染使用同一份工程数据，改动源对象后，下游结果随之重新生成。

打开时自动载入一段用本编辑器制作的 15 秒示例动画，主题是「锻字」，要求见第三节。美术风格、界面布局、配色、字体、构图和镜头方案由你设计。

## 二、编辑器功能

### 2.1 工程、图层与界面

一个工程可以有多个合成，各自设置尺寸、帧率、时长和工作区。图层类型包括形状、文字、空对象、调整、预合成、摄像机、灯光、三维几何、粒子与音色，可以命名、显示、锁定、排序、复制、删除和裁剪入出点。

界面有项目、合成画布、时间轴、属性、曲线和节点等视图，它们是同一工程的不同视图，编辑、播放和擦洗时同步更新。画布上的运动路径、控制点、网格、场范围、光源和摄像机等辅助元素可以辨认，并指向真实对象；空工程、无选择和多选都有相应的呈现。界面布局和视觉语言自行设计，画布与实际作品始终突出。

### 2.2 变换、父级与直接编辑

图层有锚点、位置、缩放、旋转与不透明度，三维对象增加 Z 方向和 X/Y/Z 旋转。可以在画布中直接平移、旋转和缩放；单独移动锚点时，图层在画面上的位置不变。

父级可以多层嵌套，子层跟随位置、旋转和缩放，不继承不透明度；设定、更换或解除父级时保留当前画面。选择框、手柄、运动路径和控制点按最终画面绘制，在带动画的父级下拖动仍跟手。

### 2.3 关键帧、时间轴与曲线

属性开启动画后，从属性面板、画布、节点或其他入口修改它，都只在当前时刻创建或更新关键帧。关键帧可以框选、移动、复制粘贴、删除和按比例拉伸时间。

时间插值有线性、贝塞尔和定格，进入与离开分别设置，提供缓入缓出。位置另有空间插值，运动路径可以在画布上编辑，包含直线、曲线、尖角与独立的空间手柄；路径形状和时间缓动分别控制，线性时间下沿曲线路径匀速运动。

时间轴支持播放、暂停、循环工作区、擦洗、逐帧、跳到关键帧、缩放与吸附。曲线视图提供值曲线与速度曲线，位置的速度曲线是沿运动路径的实际速度；关键帧和手柄可以在曲线上拖动编辑。

### 2.4 表达式

可动画属性可以用表达式替代或叠加关键帧，至少支持：

- `time`、`value`、可复现的 `wiggle(频率, 幅度)`。
- `loopOut("cycle")`、`loopOut("pingpong")`。
- `linear(t, a, b, c, d)`、`ease(t, a, b, c, d)`。
- 本层、跨图层属性引用及向量分量，例如 `thisComp.layer("控制器").transform.rotation`。
- `valueAtTime(t)`，读取所引用属性在其所属合成中第 t 秒的最终值。

引用按依赖求值，循环或错误给出清楚的提示并退回关键帧值。曲线视图显示表达式属性的最终求值曲线。

### 2.5 矢量图形与形状操作

可以绘制和编辑矩形、椭圆和开闭合贝塞尔路径，操作节点和切线，组织多个轮廓与孔洞；形状有填充与描边。

修剪路径、重复器和并集、差集、交集可以动画、可以调整顺序，交换顺序得到相应的结果。修剪沿实际路径长度推进，重复器产生可继续处理的几何；布尔运算对用户新画的任意两个形状都有效。

关键形状之间可以做路径形变，含孔洞的轮廓在形变过程中保持对应。

### 2.6 文字

文字可修改内容，支持中文多行、字号、行距、对齐和字距。文字动画器按字、词或行选择范围，以起点、终点、偏移和软边控制位置、旋转、缩放与不透明度，字符绕自身中心变化。

所用字体的字形轮廓可以转为几何，参与形变、变形与三维挤出；可用字体和字符范围明确。修改文字后，字形和依赖它的结果重新生成。

### 2.7 程序节点

提供可视化节点编辑，能创建、连接、断开、分支、复制和封装节点组。节点以路径、文字或实体几何为输入，生成、分布、变换和处理几何；端口区分标量、向量、颜色、几何与场等类型，连接含义和当前结果可以查看。

一个几何输出可以同时连接显示、变形、发射和碰撞等多个使用者；换一个输入几何、修改参数或改变接线后，各使用者按新结果更新。

### 2.8 场与几何变形

可以创建可移动、可动画的距离衰减、噪声和旋涡等空间场，场可以混合，影响范围可以查看。同一个场同时作用于几何的顶点和粒子的运动。

轮廓几何可以生成三角网格，凹部与孔洞得到有效处理；位置、旋转和缩放图钉可以动画，多个图钉共同作用时形体不撕裂。三维实体支持弯曲、扭转和场驱动的顶点变形。

变形发生在实际几何上，结果可以继续挤出、发射粒子和参与碰撞，位置、法线、阴影与命中一起更新。

### 2.9 蒙版、遮罩、效果与混合

图层可以有多个矩形、椭圆或自由路径蒙版，支持反转、羽化和路径动画。轨道遮罩支持 Alpha、亮度及各自的反转。

效果至少包括高斯模糊、发光、投影和色相／饱和度／亮度，参数可以动画、可以排序，发光和投影能伸出图层原有边界。调整层处理下方的合成结果，范围受自身蒙版、不透明度和入出点限制。

支持正常、相加、滤色、正片叠底和叠加五种混合模式，透明与半透明背景下颜色和 Alpha 正确。

### 2.10 预合成、时间重映射与运动模糊

所选图层可以原位预合成，前后各时刻的画面一致，包括父级动画、柔边和半透明。同一个合成可以多次引用，各引用有自己的起始时间、变换和时间重映射，支持变速、倒放和定格。

图层有运动模糊开关，合成有总开关、快门角度与相位。模糊按快门区间内的实际运动生成，相对画面不动的内容保持清晰。

### 2.11 三维实体、材质与灯光

闭合路径、多个轮廓与文字可以生成真正的挤出实体，保留凹部和孔洞，有完整的前后面、侧壁、倒角与法线。挤出深度、倒角和源轮廓可以动画，修改后几何随之更新。

材质有基础色、金属度、粗糙度、发光和不透明度，参数可用关键帧或表达式驱动，粗糙与光滑、金属与非金属有清楚的区别。自行生成环境照明与反射，反射随表面、法线和视角变化。

提供平行光与点光源，可以编辑颜色、强度、位置或方向，可以设动画与父级。至少一个光源产生真实的几何投影，物体可以设置投射与接收阴影，孔洞、侧壁和变形都体现在阴影中。

### 2.12 摄像机与三维空间

摄像机有位置、目标点、视角、对焦距离和光圈，可以设关键帧、表达式与父级。景深由可见表面的实际深度决定，同一实体的近端和远端可以有不同的清晰度。

三维图层中的平面、实体、粒子与拖尾在同一空间中按深度遮挡，相交物体在交线两侧前后关系正确，透明部分和孔洞不整块挡住后方。点选命中可见几何上最近的可选表面；三维轴、图钉和运动路径与画面使用同一投影，在视图缩放、父级变换和几何变形后拖动仍准确。

### 2.13 粒子、力场与碰撞

粒子系统支持多个发射器，发射源可以是点、曲线或几何表面，直接使用当前变形后的几何，发射位置和方向与发射器的运动对应。粒子的速率、初速度、寿命、阻力和随机种子可以设置，大小、颜色和透明度随寿命变化。

重力、方向力、吸引或排斥与 2.8 的空间场实际改变粒子运动，可以组合。粒子与运动的平面、实体或正在变形的网格碰撞，按当前表面、法线和相对运动反弹与摩擦，碰撞位置与看到的表面一致。碰撞可以触发颜色或寿命变化和次级发射。

拖尾来自粒子的实际轨迹，可以调整长度、宽度、颜色和消退，与粒子一起参与三维遮挡。

### 2.14 取样、撤销与工程文件

同一工程在同一时刻的结果确定：直接跳到模拟后段，或先后跳转、倒放、重开文件后读取同一时刻，结果相同；运动模糊等多次取样不会重复推进模拟或重复触发事件。修改几何、场或模拟参数后，受影响的结果重新计算。

改变工程内容的操作可以撤销和重做，一次完整的拖动、输入或接线算一步。工程可以保存并重新打开，之后的编辑与取样结果一致。

### 2.15 声音

音色图层用内置音色生成配乐与音效，参数可以编辑，播放时声画同步。

### 2.16 快捷键

提供常用的 AE 快捷键，例如空格播放暂停、`F9` 缓入缓出、`Ctrl+Shift+C` 预合成、`Ctrl+Z` 撤销及常用的重做键。输入文字或表达式时，编辑器快捷键不抢占输入。

## 三、15 秒默认示例动画

### 3.1 主题与走向

打开编辑器时自动载入一个普通示例工程，主合成 15 秒，工作区覆盖全段，可以直接播放。

示例的主题是「锻字」：一个由你选定的汉字，从笔画写成字形，被锻造成有厚度的金属字块，在锤击下变形、迸出火星，最后冷却定型。全片的主体始终是这个字，大致经过四个阶段：

1. **写成**：笔画逐一出现，汇成完整的字形。
2. **成块**：字形获得厚度，成为炽热的金属字块。
3. **锻打**：锤击落在字块上，受击处变形，火星从变形处迸出。
4. **冷却**：炽热褪成金属本色，火星熄灭，字块定型。

选哪个字、各阶段的时长与具体内容、画面风格、配色、镜头和配乐由你设计。

### 3.2 观看要求

- 第 0 帧画面已经成立，最后若干帧停稳。
- 锻打是全片唯一的高潮，之前蓄势，之后回落；锤击等主要动作有预备、加速和收势。
- 在整个编辑器界面里显示的画布中，字仍清楚可辨，任一时刻只有一个视觉焦点。
- 景别、角度与焦点的变化用来看清字的状态变化。
- 配乐与音效由音色图层制作，重音落在锤击等主要动作上。

### 3.3 工程化

示例全部由编辑器中可定位、可修改的图层、节点、关键帧、表达式、材质与模拟设置生成，与空工程使用相同的编辑和渲染机制。修改源内容后，画面按新工程重新生成；把示例中的字换成另一个可用的字，字形、字块以及后续的变形和火星都按新字重新生成。编辑器自己生成的有效缓存可以使用。

## 四、交付与素材导出

### 4.1 运行环境

交付网页项目，入口为根目录下的 `index.html`，在 Chrome 中直接双击打开即可完整运行，不依赖网页服务器。库、字体和资源随项目提供，采用适合本地文件方式的加载方法。

只做 PC 端，界面使用简体中文，鼠标与键盘均可操作。画布预览与逐帧导出使用 WebGL 2 渲染，算法、库和文件组织自行选择。图形、模型、材质、图标与示例内容自行制作；不要求导入外部图片、视频或三维模型。

浏览器首次点击或按键后允许出声，第一次播放时建立正常音频。默认工程的声音由内置音色生成，字体支持范围清楚。

### 4.2 整个编辑器的逐帧接口

作品提供以下固定接口：

```js
window.videoExport.runs                          // ['demo']
await window.videoExport.begin(runId, { fps })   // 回到这一段的起始状态，返回 { frames }，总帧数
await window.videoExport.frame(i)                // i 从 0 起依次调用；完成时第 i 帧已完整显示在页面上
window.videoExport.end()                         // 回到正常的可操作状态
```

`demo` 展示整个编辑器界面，15 秒示例从头到尾播放一遍，画布、播放头、时间轴与属性同步变化。

`begin('demo', { fps })` 等待示例准备完成，回到第 0 秒，返回 `{ frames: 15 * fps }`。调用方无需再按播放。支持预览 3 帧/秒与正式导出 60 帧/秒。

`frame(i)` 使整个编辑器落在第 `i / fps` 秒，动画、模拟、声音对应的可视状态与界面共同完成取样，返回后即可截图。正常播放循环和音频时钟在导出模式下不额外推进时间；取样不会重复触发模拟事件。`end()` 恢复可交互状态。

分辨率由调用方设置的窗口决定，最高可能到 3840×2160。素材导出方负责截图与成片制作，作品不需要为这个接口另做录制按钮。

## 五、规定

1. 评测环境接入了浏览器 MCP，使用无窗口的本机 Google Chrome 和显卡，可以随时用它打开、操作作品并截图检查。
2. 全程不得访问 GitHub 上的任何仓库，无论通过网页、`git`、`gh` 命令行还是 API。
3. 工作目录是本题面所在的文件夹，即 `H:\AI_OneShot_Model\<厂商>\<型号>\<题名>\`，开始作答时你就在这个目录中。所有文件只能在这个文件夹内读取、创建和修改；绝对禁止访问其他任何文件路径，包括同一型号下其他题目的文件夹；只有运行编译器、解释器、库、浏览器等必需工具时必须访问的安装路径和临时目录除外。截图等临时文件应放在临时目录中。
4. 开发期间如需启动本地网页服务器，使用 18101 端口；交付的作品不能依赖网页服务器。
5. 作答过程中反复对照本题面逐项检查和完善，将发现的缺口落实为改进。
6. 全程独立作答，不得开启子代理（subagent），也不得使用任何多代理或并行协作功能。
7. 严禁使用以下命令：`runas`，以及任何以其他账户身份登录、需要输入账户密码的命令；按进程名批量结束进程的命令（`taskkill /IM`、`pkill`、`killall`、`Stop-Process -Name` 等）。需要结束进程时，只按 PID 结束你自己启动的进程。这些命令会锁定评测账户或误杀评测系统的进程，导致你的会话被中止。
