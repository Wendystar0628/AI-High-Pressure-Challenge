# 果冻冲击与造浪水槽

## 一、目标总览

在网页中制作两个可独立演示的三维物理模拟场景：重球冲击果冻台，以及同尺寸多密度球在透明造浪水槽中的浮沉与运动。作品以软体、刚体与流体之间的相互作用为内容，重点呈现有说服力的物理行为、丰富连贯的动态过程和清晰精致的画面。评分重点是形变、波浪和不同深度运动的视觉表现力。

## 二、场景一：重球冲击果冻台

### 2.1 主体、构图与材质

场景由果冻台、一个或多个重球、支撑平台或地面，以及灯光和背景组成。果冻可以采用块状或圆台等初始形状。采用居中的舞台式构图，果冻位于画面中央偏下，重球从上方落下，镜头能同时交代接触区域与整体形变。

果冻采用半透明材质，体积轮廓和表面起伏清楚；重球采用金属或石质等刚硬材质，与果冻形成明显对比。平台与背景简洁，灯光突出接触位置、形变轮廓和回弹过程。

### 2.2 模拟过程与重点效果

场景呈现从准备、冲击到余波消退的完整过程：

1. **准备**：果冻静置在平台上，重球位于其上方的初始高度，镜头保持稳定构图。
2. **下落**：触发后，重球自由下落撞向果冻，冲击前的运动过程清楚可见。
3. **接触与形变**：接触区域首先凹陷，形变从局部向周围传播，果冻出现压缩、拉伸和侧向鼓出，随后不同部位先后回弹与振荡。形变包含局部与整体的变化，不能仅用整体缩放表示。
4. **相互作用与余波**：果冻的反作用改变重球的运动，随参数与接触状态出现减速、弹起、陷入、滑落、滚落或停留等结果；重球的后续接触继续影响果冻，果冻的振荡逐渐衰减。
5. **稳定与重置**：系统趋于稳定，保留结束状态，可重置后重新触发。

重点呈现接触处的局部凹陷、形变向整体的传播、各部位回弹的先后与振荡层次，以及重球和果冻持续发生的双向作用。

### 2.3 三种冲击模式

以下三种模式均需完成，并可分别触发：

- **单球正中撞击**：重球从果冻正上方冲击，展示局部受压、形变传播和整体回弹。
- **偏心撞击**：重球偏向一侧撞击，展示不对称形变、整体倾斜及重球的后续运动。
- **多球连续冲击**：多个重球按间隔依次落下，后续撞击发生在前次形变与振荡尚未消退时，形成连续作用。

### 2.4 可调参数

参数按对象与作用组织：

- **重球**：质量、半径或尺寸、初始高度。多球模式可调球数与释放间隔。
- **果冻**：尺寸、软硬程度或弹性强度、阻尼、密度或质量、底部是否固定及固定方式。
- **碰撞与环境**：重力大小、平台摩擦、平台弹性，以及重球是否连续多次撞击。

## 三、场景二：同尺寸多密度球与透明造浪水槽

### 3.1 主体、构图与材质

场景由透明玻璃水槽、一定体积的流体、多个尺寸相同而密度不同的刚性小球，以及可控造浪装置组成。水槽为横向展开的长方体，镜头略带透视，能同时看到水面、水中和水底，避免过度倾斜造成遮挡。

玻璃边缘有清楚的高光，反射不遮蔽内部运动；流体透明或轻微染色，小球采用易于辨识的颜色区分密度组。背景简洁，水面轮廓、内部球体及底部接触位置均可辨认。

### 3.2 分阶段实验过程

1. **初始状态**：水槽中已有流体，小球位于待释放位置，或已有部分分布于水中，造浪装置静止。
2. **释放与入水**：多个不同密度的小球进入水槽，撞击水面并进入水中，激起明显的水面扰动。
3. **浮沉分化**：低密度球上浮，接近中性浮力的球在水中悬浮或漂移，高密度球下沉；球体之间出现碰撞、错位与滚动。
4. **启动造浪**：造浪装置开始运动，水槽内形成持续波浪或定向水流，水面、水中和底部的球体开始呈现不同响应。
5. **持续扰动**：轻球在水面漂浮并随波起伏，中性球随流体漂移或循环，重球在底部受推动、滚动或短暂离底；运动中的球体继续相互碰撞。
6. **停止扰动**：造浪装置停止，水体波动逐渐衰减，球体重新向各自的稳定位置分层分布，系统趋于稳定。

重点呈现密度引起的浮沉差异、明显的水面扰动、造浪过程中球体的连续响应，以及水面、水中、水底同时存在的动态层次。球体碰撞和受流体推动的运动须与当时的接触及水体状态相符。

### 3.3 密度分组

设置 3～5 组密度，至少包含低密度、中性浮力和高密度三类，组间以颜色区分。同一水槽中各组球体尺寸相同，密度差异通过浮沉过程和稳定位置体现。

- **低密度组**：上浮并在水面漂浮，较多露出水面。
- **中性浮力组**：在水中悬浮或缓慢漂移。
- **高密度组**：下沉至水底。

可在其间加入中低密度组与中高密度组，分别呈现浸入较多的近水面漂浮与缓慢下沉，并使高密度组的沉底过程与之区分。

### 3.4 可控造浪装置

采用侧向推板、往复式波板或活塞板等结构简洁、运动可见的装置，以周期运动产生持续波浪或水流。装置本体及其扰动水体的过程可见，能观察到扰动从装置处进入水槽并推动球体。

### 3.5 可调参数

- **流体**：水位高度或流体总量、重力大小、粘性或阻尼。
- **球体**：总数量、统一半径、各组密度、每组数量、初始位置或释放高度。
- **水槽**：长度、宽度（纵深）与高度。
- **造浪装置**：装置类型、启动时刻、运动幅度、运动频率与持续时长。

## 四、两个场景的共同要求

### 4.1 统一风格与画面

两个场景采用统一的简洁背景、灯光风格、界面视觉语言、材质细节程度和镜头语言，构成一套完整作品。主体轮廓与主要动态清楚，透明和半透明材质保持内部与表面的可读性，撞击、形变、波浪、浮沉和碰撞不被背景、反射或界面遮蔽。

### 4.2 控制与重复演示

两个场景均可独立进入、触发、暂停、继续、重置和重新运行，参数调节后能观察到相应的动态差异。场景一可切换正中、偏心与多球模式；场景二可再次释放球体，并单独开始或停止造浪。每个场景均保留初始状态、动态过程和结束后的稳定状态，并能慢动作播放。

### 4.3 音效

两个场景都有音效设计：撞击、回弹、球体碰撞、入水和造浪等主要事件有相应的声音，声音与当时的动态相符，界面上可以开关声音。浏览器要求用户操作页面后才能播放声音。

### 4.4 非目标

本题不要求工程或科研级仿真精度，也不以极限性能优化为目标。主要动态来自实际模拟或合理的物理驱动，不能只播放固定的预设动画。大量附加功能、复杂叶轮、强喷流和难以看清作用的内部机械装置不作为必做内容。

## 五、视频导出

### 5.1 接口

作品提供以下固定接口：

```js
window.videoExport.runs                          // ['jelly-center', 'jelly-multi', 'jelly-offset', 'tank-full']
await window.videoExport.begin(runId, { fps })   // 回到这一段的初始状态，返回 { frames }，总帧数
await window.videoExport.frame(i)                // i 从 0 起依次调用；完成时第 i 帧已完整显示在页面上
window.videoExport.end()                         // 回到正常的可操作状态
```

`runs` 为按上述顺序排列、只含这四个标识的数组：

- `jelly-center`：场景一的单球正中撞击。
- `jelly-multi`：场景一的多球连续冲击。
- `jelly-offset`：场景一的偏心撞击。
- `tank-full`：场景二从初始状态、释放入水、浮沉分化、持续造浪，到停止扰动后趋于稳定的完整流程。

### 5.2 导出语义与画面

每段使用作品预设的演示参数，从重置后的初始状态开始，到系统趋于稳定结束。各段可分别启动，不沿用上一段的运行状态。

`begin(runId, { fps })` 准备对应片段并返回总帧数 `frames`。随后从 `i = 0` 到 `frames - 1` 依次调用 `frame(i)`；第 `i` 帧对应仿真时刻 `i / fps`，不依赖真实时间，机器快慢不影响结果。调用完成时第 `i` 帧已完整显示在页面上，由调用方截图。

导出时页面只显示场景画面，没有界面元素。分辨率由调用方设置的窗口大小决定，作品要能适应，最高可能到 3840×2160。镜头采用作品设计的演示镜头：果冻场景看清撞击、接触区域和整体形变，水槽场景看清水面、水中和水底的运动。

调用 `end()` 后回到正常的可操作状态。该接口只管画面，不处理声音，不需要导出按钮，也不用交付视频文件；在 Chrome 中以本地文件方式打开作品时，接口也要可用。
