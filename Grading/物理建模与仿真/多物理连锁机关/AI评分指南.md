# 多物理连锁机关 · AI 评分指南

- 评分材料：题面 `E:\Project\AI_OneShot_Bench\物理建模与仿真\多物理连锁机关.md`，以及受测模型交付的网页项目（位置由用户提供）。本文件是题面第七节的展开，两者有出入时以题面为准。
- 总分 100 分，由下列 12 个分项组成。你打前 11 项，共 90 分；“综合体验”由出题人本人打。总分为各分项得分之和，再按文末处理违规。
- 下面只写各分项看什么。各分项在其分值内由你自行给分，可以打小数（保留一位小数），不必追求精确；视觉风格、连锁设计的巧妙程度等主观部分，由你自行裁决。
- 题面第六节“规定”的执行情况不在评分范围内。
- 输出：前 11 个分项的得分，每项附一两句理由；违规情况及处理；前 11 项合计（满分 90）。综合体验留空，由出题人补上后得出总分。

## 评分时需要核实
- 各机制的表现应与基本物理规律相符，可与解析结果大致对照。
- 每次交接都应真正由物理过程完成，而不是由脚本、预设动画或计时器触发。
- 画面应由实时推进的仿真得出，不能预先计算整段过程再回放。
- 界面显示的帧率、物理耗时和规模应是实测值。

## 六种物理机制（各 3 分）
每项看两点：第二节所列的现象是否在该机制的单项演示中全部呈现；表现是否符合物理规律。

| 分项 | 分值 | 要点 |
|---|---|---|
| 刚体碰撞与摩擦 | 3 | 堆叠后稳定静止；运动在多个刚体之间依次传递；摩擦使物体减速或停住；碰撞与接触合理 |
| 滚动 | 3 | 沿斜面或轨道滚动；滚动与滑动区分正确；滚动的运动合理 |
| 绳索与滑轮 | 3 | 绳索松弛时下垂、绷紧时传力；至少一个滑轮；绳端物体可以摆动；绳的形态与张力、滑轮两侧的运动关系合理 |
| 弹簧与振动 | 3 | 弹簧储能后释放、推动其他物体；有振动或摆动，振幅衰减；周期与衰减合理 |
| 流体 | 3 | 有自由液面，能流动、倾倒或溢出；物体漂浮或下沉；液体能推动物体；液面、体积以及液体与物体的相互作用合理 |
| 光学 | 3 | 光路可见；光线发生反射和折射；传播、反射与折射合理 |

## 机制交接与连锁设计（15 分）
- 至少 8 个环节，六种机制各至少出现一次，每个环节在画面中标出所用的物理机制。
- 至少 6 次交接发生在不同机制之间；每次交接都由物理过程完成（3.1 第 3 条），被触发前静止的物体靠支撑、约束或受力平衡而静止，没有看不见的墙、导轨、力场或额外的力。
- 光学是连锁的最后一环，光路按物体当时的位置实时计算反射和折射。
- 至少 2 处双向耦合，两处涉及的机制组合不同，且都是持续的相互作用。
- 由用户的一次操作启动，有明确的最终目标和收尾画面，完整过程 30–90 秒；能启动、暂停、慢放（至少到原速的 1/4）和重置，慢放时连锁的过程与正常速度一致。
- 交接是否由物理过程自然完成、巧妙多样；连锁能否稳定地完整运行。

## 数值稳定性（7 分）
- 长时间运行和连续重置后依然稳定：不发散、不穿透、不异常抖动。
- 能量不凭空增加。

## 参数响应（5 分）
- 参数面板覆盖各环节的主要物理参数，例如质量、摩擦系数、弹簧劲度系数、液体量和折射率；单项演示中的参数也可以调整。
- 调整后重置运行，连锁和单项演示的结果由仿真重新计算，并按物理规律变化。

## 视觉效果（25 分）
- 满足 3.4：整个连锁在一个连续的场景中展开，镜头自动跟随且可手动缩放和平移，当前环节标示明确，液体表现为连续的液体，关键时刻有视觉反馈，慢放时画面平滑。
- 画面中物体的位置、形状、液面和光路与仿真结果一致；比例尺随镜头缩放更新（3.2 第 1、2 条）。
- 整体视觉风格的完成度、统一性与美感；各物理元素的表现力与细腻程度。
- 连锁过程是否清楚、有观赏性，观看者能看清每一环怎样触发下一环。

## 仿真性能（20 分）
- 界面常驻显示帧率、每帧物理计算的耗时和当前规模，且都是实测值；物理在 Worker 或 GPU 上计算时，耗时包含这部分计算。
- 每一帧都推进物理仿真；正常速度下仿真时间与真实时间同步并显示在界面上，不为维持帧率而自动放慢仿真。
- 完整连锁运行全程保持 60 FPS。
- 单项演示在保持 60 FPS 时能支持的规模越大越好；增加的对象与其他对象实际相互作用，增大规模时精度不降低。
- 每帧物理计算的耗时；运行中有无报错或卡死。

## 综合体验（10 分）
- 由出题人本人完整观看和操作后主观评价，你不打这一项，也不给建议分。

## 违规处理（照题面 7.3）
- 页面无法打开或白屏：总分记 0 分。
- 使用了物理引擎或物理仿真库：总分记 0 分。
- 连锁中有交接由脚本、预设动画或计时器直接触发（光学最后一环除外）：机制交接与连锁设计、参数响应两项记 0 分。
- 预先计算整段过程再回放：机制交接与连锁设计、仿真性能两项记 0 分。
- 显示的帧率、物理耗时或规模与实际不符：仿真性能一项记 0 分。
