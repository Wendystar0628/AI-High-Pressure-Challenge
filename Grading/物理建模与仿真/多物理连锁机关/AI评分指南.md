# 多物理连锁机关 · AI 评分指南

- 评分材料：题面 `E:\Project\AI_OneShot_Bench\物理建模与仿真\多物理连锁机关.md`，以及受测模型交付的网页项目（位置由用户提供）。本文件是题面第七节的展开，两者有出入时以题面为准。
- 总分 100 分，由下列 15 个分项组成。你打前 14 项，共 90 分；“综合体验”由出题人本人打。总分为各分项得分之和，再按文末处理违规。
- 下面只写各分项看什么。各分项在其分值内由你自行给分，可以打小数（保留一位小数），不必追求精确；视觉风格、连锁设计的巧妙程度等主观部分，由你自行裁决。
- 题面第六节“规定”的执行情况不在评分范围内。
- 输出：前 14 个分项的得分，每项附一两句理由；违规情况及处理；前 14 项合计（满分 90）。综合体验留空，由出题人补上后得出总分。

## 评分时需要核实
- 各机制的表现应与基本物理规律相符，可与解析结果大致对照。
- 每次交接都应真正由物理过程完成，而不是由脚本、预设动画或计时器触发；双向耦合的双方、汇合处的两条支线都应由仿真持续算出、真正起作用，而不是按条件切换状态或叠加预设效果。
- 画面应由实时推进的仿真得出，不能预先计算整段过程再回放。
- 界面显示的帧率、物理耗时和规模应是实测值。

## 六种物理机制（各 3 分）
每项看两点：第二节所列的现象是否在该机制的单项演示中全部呈现；表现是否符合物理规律。

| 分项 | 分值 | 要点 |
|---|---|---|
| 刚体碰撞与摩擦 | 3 | 堆叠后稳定静止；运动在多个刚体之间依次传递；摩擦使物体减速或停住；静摩擦能停在斜面上、不足时下滑；非圆刚体能翻转倾倒；碰撞与接触合理 |
| 滚动 | 3 | 沿斜面或轨道滚动；滚动与滑动区分正确；质量分布不同则滚动快慢不同；摩擦不足时边滚边滑；滚动的运动合理 |
| 绳索与滑轮 | 3 | 松弛时下垂，绷紧时传力且长度基本不变；滑轮随绳转动；绳端物体可以摆动；滑轮两侧的运动关系合理 |
| 弹簧与振动 | 3 | 储能后释放、推动其他物体；振幅衰减；周期随质量、劲度系数或摆长变化，周期与衰减合理 |
| 流体 | 3 | 有自由液面，能流动、倾倒或溢出；静止后液面水平，体积基本不变；物体漂浮或下沉；液体能推动物体 |
| 光学 | 3 | 光路可见；反射与折射合理；超过临界角时全反射 |

## 机制交接与连锁设计（8 分）
- 至少 10 个环节，六种机制各至少出现一次并在画面上标出；至少 8 次跨机制交接，每次都由物理过程完成（3.1 第 3 条），被触发前静止的物体靠支撑、约束或受力平衡而静止，没有看不见的墙、导轨、力场或额外的力；光学是最后一环。分叉后两条支线确实有一段时间同时推进；汇合的一环确实要两条支线都起作用才启动。
- 除光学外每种机制都承担实际作用；完成作用的物体和液体留在场景中照常参与仿真；交接是否自然、巧妙多样；默认参数下反复重置，连锁能否每次完整走完。
- 一次操作启动，有明确的最终目标和收尾画面，完整过程 30–90 秒；启动、暂停、单步、慢放（至少到原速的 1/4）和重置可用，慢放、暂停后继续、单步和中途变速都不改变连锁的过程。

## 机制耦合（10 分）
- 至少 3 处双向耦合，机制组合各不相同，至少一处在液体与浸在其中的物体之间，有一段时间两处同时进行；双方都持续受到对方的影响。至少一个物体持续同时受三种以上机制作用，改动其中任一种机制的参数，它的运动都随之改变。
- 至少一份液体先后参与两个以上环节，流动过程由仿真算出，后一处的液体状态就是前面留下的结果，总体积基本不变。液体与物体：吃水与密度大致相符，浮沉随液体的实际状态变化；浸入时液面升降，液体不穿过物体和容器壁；运动受阻，波浪水花推动漂浮物，液流因物体而改变。
- 绳索两端相互制约，由松到紧时两端速度按质量关系改变；弹簧两端都可动时两端都被推动，振动受其他作用影响，弹出的动能不超过储存的弹性势能。交接中被触发一方的动量和能量来自触发一方，碰撞前后的速度与质量、弹性相符；总能量不凭空增加。
- 光路随运动的物体和液面实时、连续地变化；光学环节中至少一个界面是被连锁推动、仍在运动的物体或液面，前面各环的结果不同时最终光路随之不同；光线不穿过不透明物体。
- 至少 2 个耦合演示，机制组合不同，各有三种以上机制持续相互作用并含双向耦合；增大规模时，增加的对象参与其中的耦合。以上要求在各演示场景中出现相应情形时同样成立。

## 数值稳定性（5 分）
- 长时间运行、连续重置后依然稳定：不发散、不穿透、不异常抖动，能量不凭空增加。
- 软硬悬殊的作用同时施加在一个物体上、质量悬殊的物体相互作用、高速小物体撞击或入水、连续投放或移动物体、施加冲量、规模调到上限，以及参数面板范围内的各种组合（包括最轻与最重、最软与最硬）下依然稳定，绷紧的绳索不被明显拉长。

## 参数响应（4 分）
- 3.3 第 3 条列出的参数都可以调整，每一项作用于用到它的所有环节和物体，有单位；质量和劲度系数的上限在下限的十倍以上；各演示场景中用到的参数也可以调整。
- 调整后重置运行，结果由仿真重新计算并按物理规律变化；影响沿连锁向后传递，包括经过汇合处；作用于多处的参数（如重力加速度、液体或材料的折射率）各处一致生效；连锁无法继续时如实停下并指出停在哪一环，没有为走完连锁而修正结果。

## 视觉效果（12 分）
- 美术方向明确、统一并与题材呼应，环境、部件、液体、光线、特效和界面属于同一套视觉语言；达到完成作品的水准而不是调试画面；各演示场景同等完成度。
- 层次清楚：仿真物体与背景、固定结构与可动物体可区分，当前环节最突出；材料与部件可区分，外观与物理属性相符；外观能读出转动、滚动与滑动、绳的松紧、弹簧伸缩、液面与流向、光的强弱。
- 画面与仿真吻合：轮廓与仿真形状一致，接触处不留缝、不嵌入，连接点、液体交界、光线转折点都在仿真中的位置；比例尺随镜头缩放更新（3.3 第 1、2 条）。
- 液体连续、交界清楚；光路与转折处清楚；光学收尾有表现力。关键时刻有反馈，强弱与事件相称，特效不遮挡关键位置、不改变仿真结果；过渡自然，慢放平滑；远近两种尺度都经过设计；细节打磨到位。整体美感与各物理元素的细腻程度。

## 耦合与连锁的呈现（8 分）
- 镜头自动跟随平稳，交接和双向耦合的双方同在画面中，两条支线同时推进时都看得清；可手动缩放平移、恢复跟随、查看全貌。当前环节的标示与说明讲清物理过程和如何触发下一环；进度总览清楚，包括两条支线。
- 相互作用看得清：作用在哪里、谁作用于谁、多强；双向耦合双方的影响同时可见，同时受多种作用的物体各作用能分别读出；能量的转移与耗散看得出。辅助显示能叠加主要的力和各部分能量，数值来自仿真，与画面统一，开关不影响仿真。连锁过程是否有观赏性。

## 界面设计（5 分）
- 界面与画面属于同一套视觉语言，达到完成作品的水准，不是默认控件的堆砌或调试面板；完整连锁与各演示场景的界面风格和操作方式一致。
- 3.7 第 2 条所列内容齐全；分组清楚、主次分明，不遮挡正在进行的环节，面板可收起，收起后性能数值仍常驻。
- 演示场景中对物体的操作（3.4 第 4 条）：能投放新物体并设定种类、质量和初速度，能移动、转动已有物体或施加冲量，光学演示中的物体也能这样操作；数值可以精确设定；被操作的物体按仿真与其他物体相互作用。
- 参数面板：参数与场景中的物体能双向找到对应；名称、单位、当前值和范围齐全，能快速调整也能精确设定，越界输入不被接受并有提示；改过的参数能看出，可单项或全部恢复默认；生效时机明确。
- 运行状态与仿真时间一目了然；控件状态与操作反馈明确，不能进行的操作有提示；连锁停下时指出位置；常用操作有快捷键并注明，操作说明随时可打开。过渡自然，计算繁重时界面仍及时响应；文字和数值清晰可读、不重叠，带单位，变化的数值读得清。

## 仿真性能（20 分）
- 界面常驻显示帧率、每帧物理计算的耗时、当前规模和最近一段时间的最长帧时间，且都是实测值；物理在 Worker 或 GPU 上计算时，耗时包含这部分计算；每一帧都推进仿真，正常速度下仿真时间与真实时间同步，不为维持帧率而自动放慢。
- 完整连锁运行全程的帧率与流畅程度，计算最繁重的时刻和打开辅助显示时有无掉帧、卡顿；在流畅的前提下，连锁中参与仿真的对象越多、越精细越好。
- 各演示场景运行流畅时能支持的规模越大越好；规模上限能调到运行不再流畅为止；增加的对象与其他对象实际相互作用，增大规模时精度不降低。每帧物理计算的耗时；长时间运行、反复重置或切换场景后帧率和内存是否稳定；有无报错或卡死。

## 违规处理（照题面 7.3）
- 页面无法打开或白屏：总分记 0 分。
- 使用了物理引擎或物理仿真库：总分记 0 分。

- 预先计算整段过程再回放：机制交接与连锁设计、仿真性能两项记 0 分。
- 显示的帧率、物理耗时或规模与实际不符：仿真性能一项记 0 分。
