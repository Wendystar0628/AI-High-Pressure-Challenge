# 机械结构重建 · 评分指南

- 评分版本：一律评作答结束时工作目录中的内容，不看 git 提交。

- 材料：受测作答目录里的题面 `机械结构重建.md`、`机械结构重建\` 下的图纸和《建模描述.md》、`答案\第01题.json`–`第25题.json`；出题端参考零件在本目录 `参考答案\`，各题档次、分值和计分参数见 `references.json`，零件说明见 `参考答案.md`，程序说明见 `README.md`。
- 判定：用本目录的 `grade.py` 把作答描述生成实体，与参考零件比较表面吻合度，接受任何写法，只比较生成的形状。
- 形状要靠读图与手工推理。先读受测会话记录核对工具：允许运行题目自带preview.py，一次预览多题也允许；允许命令或脚本显示、列出、整理JSON尺寸目录的现有内容，包括字段提取、按编号/视图/类型排序或分组，等同于看图读数。不能仅因出现json.load、JSON解析、字段遍历或目录整理就判违规。
- 禁止用程序计算尺寸（累加尺寸链、求坐标、换算角度/法向等）、推导几何、重建/比对形状、生成/筛选候选模型；禁止CAD/几何内核等建模工具，禁止改动工具文件；用命令一次预览多题允许。违反这些限制的整份作答记0分，并在notes写出具体命令、证据位置和它做了什么。区分目录展示与产生新几何量；grade.py只算形状，不能代替工具核查。第五节的离线、工作目录、禁子代理、账户与PID限制同样有效。

## 计分

w 为该题分值。准确率 precision 按作答表面积计算：作答表面按面积确定性采样，统计落在同序号参考表面容差内的比例。完整率 recall 对参考每个几何面单独按面积确定性采样，先算各面落在同序号作答表面容差内的比例，再对全部参考面等权平均。容差为0.2毫米，F = 2PR/(P+R)。整题只在0.2mm档求一个最佳平移，不旋转；2mm档复用该平移。

参考面的合并使用 OpenCascade ShapeUpgrade_UnifySameDomain（合并边与面，不连接不同实体，禁止内部边），线性容差1e-7毫米、角度容差1e-7弧度。沿公共边相连、位于同一几何曲面的片段合成一个面：同平面须共面，同圆柱须同轴同径，圆锥、球面、环面等须同一支撑曲面；周期曲面的缝线不另计面。不相连片段、不同零件、不同曲面以及有真实折角的面不合并。每个合并面按面积采样，至少256点、至多5000点，密度0.5点/平方毫米；每面内部按面积算比例，面与面之间等权。

- 每档独立汇总P/R并计算F。先用0.2mm求平移，2mm固定沿用，不再对齐。`F综合 = 0.8 × F(0.2mm) + 0.2 × F(2mm)`，每题得 `w × min(1, F综合 / 0.99)`；宽档权重20%，不是平均。
- 装配按明细栏序号逐件比较、共用同一平移；precision 按整套装配的作答表面积加权，recall 对全部零件的参考面等权平均，每档由该档汇总后的P、R计算F，再按80/20合成；不平均零件F。缺件的参考面全部记0，多出的未知序号记录后不参与比较。
- 某个零件第 k 个特征生成失败时，该零件按第 k−1 步的实体比较，其他零件照常。
- 缺文件、JSON无法解析或整份描述生成不出任何实体，该题0分。

分项保留两位小数，总分用未舍入的分项求和后保留两位小数。笔记和解释文字不计分。

## 运行

`grade.py` 可以一次评一个或多个作答目录（包含 `答案/` 的题目工作目录），输出各题的两档F、综合F、两档precision/recall、对齐平移、失败零件与步骤、得分和总分：

```powershell
python grade.py <作答目录> --output 评分.json
```

缺失某题只影响该题。文件名略有出入时可以人工找到对应答案，改成规范名后用 `grade.py` 评，核心内容按《建模描述.md》。结果文件的 items 用“第01题”至“第25题”作分项名，max 填该题分值。
