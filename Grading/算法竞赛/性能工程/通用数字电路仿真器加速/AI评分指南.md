# 通用数字电路仿真器加速 · AI 评分指南

依据题面 `E:\Project\AI_OneShot_Bench\算法竞赛\性能工程\通用数字电路仿真器加速.md` 第九、十、十三节，满分 100 分。评分资料：本目录的 `grader/`（评测程序 `grader.cpp`）、`baselines/`（弱基线 `weak_solution.cpp`、强基线 `strong_solution.cpp`）、`performance/`（8 个性能输入及答案）、`correctness/`（7 个正确性输入及答案）；上一级目录的 `evaluate.py` 及其说明 `README.md`。

## 评分要点

- 用题面第八节的编译命令，把 `grader.cpp` 分别与提交、弱基线、强基线编译成三个可执行文件，再运行 `evaluate.py`，例如：

  ```
  python E:\Project\AI_OneShot_Bench\Grading\算法竞赛\性能工程\evaluate.py --task circuit --exe <提交.exe> --weak <弱基线.exe> --strong <强基线.exe> --report <报告.json> --pause 1
  ```

  本目录 `validation.json` 中的弱基线参考耗时是在 `--pause 1`（每次运行前停顿 1 秒）下测得的。
- 计分以 `evaluate.py` 按题面公式算出的结果为准：同一次评测中，弱基线和提交在 8 个性能输入上各运行一次，计时分别为 $W_i$、$C_i$，$s_i=W_i/C_i$；综合加速比 $G$ 为 8 个 $s_i$ 的几何平均。
- 得分按题面第十三节的锚点表在 $\ln G$ 上分段插值：$G$ 为 1、4、8、12、20、32、48 时分别得 0、3、15、30、52、75、100 分；$G\ge48$ 得 100 分，并注明需要复核。强基线只作参考，不影响得分。
- 按题面规则 8，内存占用过多导致系统内存紧张或运行异常的，酌情扣分。你记录提交的内存占用和有无异常，扣不扣、扣多少由出题人决定。

## 记 0 分的情形（照原文）

出现以下任一情形，本题记 0 分：

- 编译失败；
- 任一正确性输入或性能输入的任一次运行失败，包括输出错误、超过进程时间、崩溃；
- 任一性能输入上 $C_i>W_i$；
- 违反题面第十节的规则，即下列任一条：

1. 单个源文件 `solution.cpp`，不超过 256 KB，实现 `simulate()`，不含 `main()`。
2. 只用 C++ 标准库、OpenMP、Windows API、编译器内建函数和 CPU 指令内在函数，不用其他第三方库。
3. 只用 CPU 计算，不用 GPU。
4. 不读写文件，不使用或改动标准输入、标准输出和标准错误，不联网，不启动其他进程。
5. 程序通用：对任意满足题面第一、七节约束的输入都返回正确结果；不针对具体输入硬编码结果，不在源码中内嵌预先算好的数据。
6. `simulate()` 会被多次调用：可以复用线程池和已分配内存，但每次都重新初始化本次仿真状态，不复用之前调用的计算结果，本次计算在函数返回前全部完成。
7. 不修改评测程序，不干扰任何一次运行的计时（包括弱基线和强基线的运行）；不改进程或线程的处理器亲和性和优先级，不超出给定的逻辑处理器；不改系统设置或任何能延续到进程结束之后的状态，不访问或影响本进程以外的进程。
8. 每次运行的整个进程不超过 60 秒；内存见“评分要点”。

## 输出

得分；8 个性能输入的 $W_i$、$C_i$ 和综合加速比 $G$；对题面第十节各条规则的审查结论；提交的内存占用情况。题面“规定”一节（第十一节）的执行情况不在评分范围内。
