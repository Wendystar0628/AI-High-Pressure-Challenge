# 通用数字电路仿真器加速：隐藏测试数据

本目录是题目《通用数字电路仿真器加速》的隐藏测试数据和出题工具，**不能让被测模型接触**。

## 目录内容

| 路径 | 说明 |
|---|---|
| `performance/inputs/input_01.txt` – `input_08.txt` | 8 个隐藏性能输入，每个约 9 MB |
| `performance/expected/expected_01.txt` – `expected_08.txt` | 对应的标准答案（评测程序的标准输出） |
| `generator/gen_hidden.cpp` | 隐藏输入生成器 |
| `grader/grader.cpp` | 官方评测程序，与题面第五节中的代码逐字节一致 |
| `baselines/weak_solution.cpp` | 弱基线：认真的第一版写法，每次评测重新运行，作为加速比的分母 |
| `baselines/strong_solution.cpp` | 强基线：出题人写的通用优化解法，仅作参考 |
| `correctness/inputs/`、`correctness/expected/` | 7 个正确性输入及独立参考答案，不计分，任一失败记 0 分 |
| `validation.json` | 正式评测会话的逐次记录、弱基线参考中位数（健康检查用）、正确性记录和工具指纹 |

所有文件都使用 LF 换行。

## 八个电路

全部满足题面第七节的规模：$I=64$，$F=8192$，$G=500000$，$O=64$，$M=4096$，$T=512$。

| 编号 | 结构 | 生成参数 | 组合深度 | 占比最高的门类型 |
|---|---|---|---|---|
| 01 | 深链 | `deep 6151827736420917` | 191780 | 八种门均匀混合 |
| 02 | 多层宽网格 | `wide 2894406613587201` | 64 | 八种门均匀混合 |
| 03 | 阵列乘法器 | `multiplier 7302619945813557` | 11484 | AND 46.6%，XOR 33.0% |
| 04 | 分组密码轮函数 | `cipher 4417092288130663` | 3320 | XOR 45.3% |
| 05 | 控制逻辑 | `control 9930871154027349` | 24037 | MUX 58.1%，AND 24.2% |
| 06 | 寄存器堆 | `regfile 1278460039915783` | 9280 | MUX 67.6% |
| 07 | 16 级环形流水线 | `pipeline 5560319827746191` | 40557 | 八种门均匀混合 |
| 08 | 混合 SoC | `soc 3849172660553077` | 34061 | XOR 32.8%，AND 15.8% |

- **深链**：每个门的输入大多来自最近生成的门，依赖链极长。
- **多层宽网格**：40 层，每层约 1.1 万个门，输入主要来自上一层，另有约 20% 跨层长距离连线。
- **阵列乘法器**：大量 16×16 位阵列乘法器，部分乘积再经加法器累加。
- **分组密码轮函数**：64 位状态经异或轮密钥、4 位非线性替换、置换和线性混合，6–12 轮。
- **控制逻辑**：32 选 1 多路选择树、16 位比较器、相等判断、5–32 译码器。
- **寄存器堆**：128 个 32 位寄存器，64 个读口、16 个写口，外加胶合逻辑。
- **16 级环形流水线**：每级读上一级的寄存器、写本级的寄存器，最后一级接回第一级。
- **混合 SoC**：乘法器、密码轮、控制逻辑和随机逻辑块混合。

所有电路都满足：

- 每个门在结构上均可到达某个触发器或主输出，每个触发器都经异或折叠接到主输出。这不等于经过布尔化简后每个门都不可删除。
- 每个电路 4096 组激励的摘要 $H_m$ 互不相同；主输出为 1 的比例约为 0.499。

## 正确性输入

| 用例 | 覆盖内容 |
|---|---|
| `01_ff_forward` | 触发器按正向编号直接依赖，检查同时更新 |
| `02_ff_reverse` | 反向编号的触发器依赖，检查反向原地更新 |
| `03_direct_sources` | 常量、主输入、触发器的直接连接与直接输出、自反馈、无关门 |
| `04_shuffled_dag` | 八种门、重复输入、乱序 DAG、小规模组合与时序混合 |
| `05_shuffled_dag` | 257 组激励，覆盖向量批次与尾部处理 |
| `06_shuffled_dag` | 另一组固定随机 DAG 与不同周期数 |
| `07_fullsize_ff_snapshot` | 与性能输入同规模的双向触发器延迟链，检查大规模路径的同时更新 |

前六例由逐激励、逐周期的 Python 标量仿真器生成答案；第七例的门均为不被观察的 `NOT(0)`，输出只观察四个触发器和常量，由独立推导的周期波形计算摘要。全部可用上一级 `gen_correctness.py --task circuit` 重建。

- 强基线的综合加速比 $G=11.482$，按题面评分标准（$S_{\max}=316$）对应 42.4 分。
- **弱基线**：Kahn 拓扑序；每个门用 switch 计算；每个信号存 4 个 64 位字，一个线程一次处理 256 组激励。
- **强基线**：只保留能影响输出的门；在深度优先序和按层序中选需要存储位置更少的一种，并复用已不再使用的存储位置；软件预取；AVX2 一次处理 256 组激励；门计算无分支；用 64×64 位矩阵转置生成主输入、计算摘要。
- 本次会话中弱基线 3 次运行之间的差异在 4.2% 以内，强基线在 3.4% 以内。
- 每次运行的原始计时和逐例正确性结果见 `validation.json`。其中 `weak_baseline_medians_ms` 是 `evaluate.py` 健康检查的参考值：正式评测中弱基线的中位数若在任一输入上偏离超过 5%，或几何平均偏离超过 3%，报告会给出警告。
- 题面不再设固定的单输入时间上限：提交在任一输入上的中位数慢于同一次评测中的弱基线即记 0 分；每个进程仍有 60 秒的防挂起限制。

## 校验

- 标准答案由强基线算出。弱基线和强基线是两套独立实现，在 8 个输入上的结果逐字节一致。
- 两个基线在评测程序的预热调用中，样例电路的结果都正确。
- 新增 7 个正确性输入均使用独立参考答案验证两套基线；错误的原地触发器更新实现会在其中被检出，详见 `validation.json`。

## 评测时

在本目录的上一级运行统一工具，弱基线可执行文件必需：

```powershell
python evaluate.py --task circuit --exe C:\eval\circuit\grader.exe --weak C:\eval\circuit\weak.exe --strong C:\eval\circuit\strong.exe --report C:\eval\circuit-result.json
```

工具先运行提交的 7 个正确性输入（任一失败即记 0 分），再依次让弱基线、强基线和提交在每个性能输入上各运行一次，按题面评分标准输出 $W_i$、$C_i$、$s_i$、$G$ 和得分。具体说明见上一级 README。

以下命令展示单次运行和性能输入重建方式；手工评测时也必须执行正确性检查，并在同一次会话中先运行弱基线。

把 `grader/grader.cpp` 与选手解法放在同一目录编译（弱基线同理，把 `solution.cpp` 换成 `baselines/weak_solution.cpp`）：

```
g++ -O2 -std=c++20 -march=native -fopenmp -o grader.exe grader.cpp solution.cpp
```

对每个隐藏输入运行一次（一个新进程），读取 `simulate_ms`，并比较标准输出与 `performance/expected` 中的答案（忽略行尾的 `\r`）：

```
set OMP_NUM_THREADS=16
start "" /b /wait /high /affinity FFFF grader.exe input_01.txt > out_01.txt 2> time_01.txt
```

由生成参数重新生成输入，结果应与下面的指纹一致：

```
g++ -O2 -std=c++20 -march=native -o gen_hidden.exe gen_hidden.cpp
gen_hidden.exe deep 6151827736420917 > input_01.txt
```
