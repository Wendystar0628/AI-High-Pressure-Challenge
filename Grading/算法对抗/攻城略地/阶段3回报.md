## baselines格式

版本为 `siege-baselines-v1`，顶层 `opponents` 数组按弱到强排列。每项为：

```json
{
  "id": "tier1",
  "name": "第1档",
  "rating": 0.0,
  "score": 0,
  "source": "opponents/baseline.cpp",
  "defines": {"TIER": 1}
}
```

rating是实力值，score是分数锚点；两者严格递增。source相对配置文件目录解析，也可用绝对路径；defines可省略。阶段4用实测R1–R5填写五项，分数分别0、25、50、75、100，源码和宏按Astra最终交付填写。详细的四档示例和全部字段见 `评测脚本说明.md`。

临时四档配置用0/25/50/75锚点，脚本能正常编译、运行、拟合，分数映射只到75；不是把第4档升成100分。报告is_official_configuration=false，开发控制台只打印表和r。临时值和结果不作正式评分。
